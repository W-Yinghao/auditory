# Encoder training API and frozen decisions

`fit_supervised`, `fit_simclr`, and `fit_random` accept training EEG only. `FitScope.validation_groups` and `.test_groups` are forbidden input identities. SUP creates a deterministic 20% monitor subset inside the supplied training groups; the monitor scaler is fit exclusively on the remaining groups. It selects the epoch by candidate/class-balanced monitor CE, then refits a fresh scaler and reinitialized network using all training groups. The final learning-rate trajectory uses the original 80-epoch horizon truncated at the chosen epoch, matching the monitor schedule prefix. SIM uses 100 epochs and receives no labels. First-pass seed is 11 for all modes.

Each epoch draws ceil(N/batch) new batches with candidate-uniform draws and SUP class-uniform draws. The sampler rejects same-batch duplicate trials and original intervals less than 0.7s apart. Retries retain the same candidate/class where possible; exhausted support can produce a short batch. Rejection can affect realized balance, which is recorded through per-candidate sampling counts. Rejected attempts are not counted as admitted violations. SIM noise is 0.02 in the training-scaled channel coordinates, equivalent to 0.02 times the raw training channel scale before normalization.

Gradient clipping occurs before each optimizer step. CUDA is selected when available; actual jobs record device and memory. Inference is chunked. Checkpoints contain model/projector, scaler, scope, optimizer/scheduler, sampling epoch history, augmentation generator and Python/NumPy/Torch/CUDA RNG states. `FittedEncoder.load` verifies the version and scope and restores inference; automatic mid-epoch training resume is not implemented and is explicitly disallowed. Files are created exclusively. Diagnostics report training encoder/projector variance, effective rank, cosine, gradients and sampled candidate counts.

Short SUP/SIM tests optimize actual synthetic arrays and check monitor isolation, final scaling, clipping order, restoration and deterministic sampling. These are module checks; jobs additionally need export and real-input fit-scope integration gates.

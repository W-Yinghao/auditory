# v2 合成机制审计的解释范围

状态：`synthetic_001` 已于2小时硬预算内结束，Slurm为COMPLETED，科研执行回执为NUMERICAL_INCOMPLETE。全部300次A2 ridge和1620个分类头已尝试；630个神经头按统一2000步终末预算处理，其中分类头共150个数值未解决，导致90个独立分类世界不可评价。原始结果完整保存，未调用超时恢复工具、未重拟合。此文不改变生成器、拟合预算或判据。

本审计区分执行覆盖、数值稳定、机制识别和真实数据支持。方案只冻结了单世界效应门槛与对照，没有冻结跨世界最低恢复率或最高误检率；不在看到结果后新增通过阈值。完整执行不能自动变为科学阳性。

| 机制 | 预定解释 |
|---|---|
| A2 | null 下共享的固定非零预测项可以制造残差重复性；捕捉此现象是反例成功，不是恢复了刺激信号。可预测 nuisance 本身可重复，其阳性不等于统计假阳性。个体刺激世界检验未校正差异。四项恒等式用于内积，不直接用于 cosine。 |
| N1 | BACKGROUND_KEY、ADDITIVE_NOISE 检验条件解码/去干扰；PRIOR_ONLY、INDEPENDENT_BACKGROUND 检查背景被错误赋予额外信息。预算目录未覆盖真实 HB/HPP/donor 全矩阵。 |
| N2 | COVARIANCE_SIGNAL 检验方差增量及重复均值对照；MEAN_SUFFICIENT、TIME_DRIFT 检查均值/时间导致的错误解释。RFF 是次要诊断，不能替代主 VAR 结果。 |
| N3 | EEG_INCREMENT 检验超过历史和噪声扩维的增量；HISTORY_ONLY、NEAR_DETERMINISTIC_HISTORY 检查先验和有限读出容量造成的解释错误。 |
| G0 | 独立的零信息/注入夹具检验固定维度的读出行为；不是整个 encoder 流程的检验。 |

生成器的外推限制：N1 背景按试次生成，不是儿童级恒定背景；N1/N3 使用 P_nat 权重，但生成标签在每候选内实际上平衡；N2 方差世界对每袋去均值，是有意构造的强阳性对照；TIME_DRIFT 的 P_bal 评价消除了候选间类别比例差异。G0 每候选仅8次试次、64/400维，不能代表真实队列功效。分类结果只用 raw 分数，不含真实路线的训练内温度校准。

所有世界保留固定分母：A2每机制100次，N1/N2/N3每机制30次，G0零/注入各30次。A2三种W条件和N3两个模型族共享同次抽样，不能相加为独立世界。失败或未评价世界保持未知，报告比例识别界及Clopper–Pearson包络，不记为阴性。恢复不足只说明相应固定配置没有证明足够检出能力，不能充分否定真实EEG信号。

## 实际机制结果

以下均为冻结的单世界筛选规则下的次数，不是新增跨世界通过率规则。完整33行及Monte Carlo区间见 `results/auditory_next_v2/synthetic_001/synthetic_rates.csv`；A2四项分解及Delta/P/R统计见同目录 `A2_residual_audit_aggregate.csv`。A2的T是匹配减错配的余弦之差，并非单个余弦相似度，数值可以超过1。

| 对象 | 实际结果 | 对真实数据解释的限制 |
|---|---|---|
| A2 null | 未校正Delta为5/100；W=0残差5/100；固定非零W残差100/100；训练拟合W残差6/100 | 在没有真实Delta重复性时，固定共享预测项可以制造残差匹配。这支持审计反例，不能称刺激信息恢复。100/100的比例CI为[0.9638,1]；5/100为[0.0164,0.1128]。 |
| A2 predictable nuisance | Delta为100/100；拟合W残差99/100；固定W残差1/100；W=0残差100/100 | nuisance本身有真实重复性。校正后仍重复不等于刺激特异信息；各W条件共享同一世界，不是独立重复实验。 |
| A2 individual stimulus | 各条件未校正Delta及残差均100/100 | 该强注入世界可检出，但生成参数未拟合真实队列，不能据此宣称真实小效应功效充分。 |
| N1 additive noise | 30/30，平均主增益0.40717 bits/trial | 固定读出能在此构造中利用背景去干扰；比例CI为[0.8843,1]。 |
| N1 prior-only / independent background | 各0/30，平均增益分别-0.00142、-0.00032 | 未观察到预定正向筛选；各自比例CI上界仍为0.1157，不声称总体误检率为0。 |
| N1 background key | 30/30世界数值不可评价 | 恢复率未知，识别界及包络均为[0,1]，不是0/30恢复。尚未证明条件钥匙世界的检出能力。 |
| N2 covariance signal | 30/30，平均主增益0.90208 bits/bag | 固定logistic能恢复该强方差信号且超过重复均值对照。真实k=8负主结果仍只限制当前均值加方差估计器。 |
| N2 mean-sufficient / time-drift | 各0/30，平均增益约-0.000031、-0.000199 | 这些已评价构造中未发现额外主增益；不推广为任意时序混杂均已排除。 |
| N3 EEG increment / history-only | 每机制30/30世界不可评价；两族均扣留 | 同一世界的规定模型矩阵需完整；即使其中某线性头稳定，也不从失败世界选取线性结果。关键正/零信息识别能力未完成，不能充分否定真实EEG增量。 |
| N3 near-deterministic history | 两族各0/30，共享30个世界 | 当前构造中没有额外正增益；不能将两族相加为60个独立世界。 |
| G0 injected / null | 注入15/30，比例CI[0.3130,0.6870]；null为0/30 | 注入夹具只获得部分检出，且包含两种固定维度。不能据真实弱解码推断没有神经信号，也不能宣称整个编码器流程的功效已验证。 |

本轮最明确的机制证据是A2的残差解释反例，以及N2固定线性读出对强方差构造的恢复。N1只完成部分机制区分；N3关键机制受数值门限阻断。所有真实主结果和失败集合保持原样，不据这些合成结果重新选真实模型、窗口、seed或样本。

合成关键控制中的数值未完成必须与真实数据阴性分开：N1/N3当前真实比较未达到推进门槛，但其关键合成检出能力不完整；N2当前k=8均值加方差线性实现未触发本轮预定的集合网络推进条件，次要神经族未解决另列。A2真实未校正主T未达到门槛，不能用预测项或残差替换。以上不构成JBHI级临床效度或独立确认验证。

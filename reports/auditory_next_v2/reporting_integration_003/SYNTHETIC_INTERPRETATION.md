# v2 合成机制审计的解释范围

状态：执行中，实际恢复次数与区间待 `synthetic_001` 终态后填写。此文不改变生成器、拟合预算或判据。

本审计区分执行覆盖、数值稳定、机制识别和真实数据支持。方案只冻结了单世界效应门槛与对照，没有冻结跨世界最低恢复率或最高误检率；不在看到结果后新增通过阈值。完整执行不能自动变为科学阳性。

| 机制 | 预定解释 |
|---|---|
| A2 | null 下共享的固定非零预测项可以制造残差重复性；捕捉此现象是反例成功，不是恢复了刺激信号。可预测 nuisance 本身可重复，其阳性不等于统计假阳性。个体刺激世界检验未校正差异。四项恒等式用于内积，不直接用于 cosine。 |
| N1 | BACKGROUND_KEY、ADDITIVE_NOISE 检验条件解码/去干扰；PRIOR_ONLY、INDEPENDENT_BACKGROUND 检查背景被错误赋予额外信息。预算目录未覆盖真实 HB/HPP/donor 全矩阵。 |
| N2 | COVARIANCE_SIGNAL 检验方差增量及重复均值对照；MEAN_SUFFICIENT、TIME_DRIFT 检查均值/时间导致的错误解释。RFF 是次要诊断，不能替代主 VAR 结果。 |
| N3 | EEG_INCREMENT 检验超过历史和噪声扩维的增量；HISTORY_ONLY、NEAR_DETERMINISTIC_HISTORY 检查先验和有限读出容量造成的解释错误。 |
| G0 | 独立的零信息/注入夹具检验固定维度的读出行为；不是整个 encoder 流程的检验。 |

生成器的外推限制：N1 背景按试次生成，不是儿童级恒定背景；N1/N3 使用 P_nat 权重，但生成标签在每候选内实际上平衡；N2 方差世界对每袋去均值，是有意构造的强阳性对照；TIME_DRIFT 的 P_bal 评价消除了候选间类别比例差异。G0 每候选仅8次试次、64/400维，不能代表真实队列功效。分类结果只用 raw 分数，不含真实路线的训练内温度校准。

所有世界保留固定分母：A2每机制100次，N1/N2/N3每机制30次，G0零/注入各30次。A2三种W条件和N3两个模型族共享同次抽样，不能相加为独立世界。失败或未评价世界保持未知，报告比例识别界及Clopper–Pearson包络，不记为阴性。恢复不足只说明相应固定配置没有证明足够检出能力，不能充分否定真实EEG信号。

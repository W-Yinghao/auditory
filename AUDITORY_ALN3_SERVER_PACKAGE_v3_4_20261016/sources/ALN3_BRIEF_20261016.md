## B\_ALIGNED：查询对齐的基础模型读出（ADDENDUM\_06，seed 3401，NCE）

**需要你决定**：这组结果在报告里怎样定位：是接口定位链中的一环，还是一个并列的变体。还要决定改善归因到哪一层、FM 与局部模型怎样比较、配方和适配的标签怎样写，以及是现在写还是等种子面板跑完再写。

### 问的是什么

- **背景**
  - B\_DENSE 在 5.6 s context 上用固定 patch 网格读出，在中期汇总里处于或接近机会水平。
    - B2 `dense_query` 在每个格中都是 R = log2(n\_candidates)，区间宽度为 0（BC\_INTERIM\_QC\_NOTES §1）。
    - B1 `channel_phase_linear` 只是"slightly above chance"：FAU REVE gain ≈ 0.07，DTU ≈ 0.18；local 为 1.04 / 2.01 / 0.26。
    - B-LOCAL 的 120/120 个成员都是 I<0。这个数合计了 NCE 和 CS\_SINGLE，其中 NCE 为 60/60。
  - 探针 P1–P4 排除了四种解释：C 的评价路径、训练与评价的查询不一致、恒定时间错位、读出对查询不敏感。P5 表明适配器输入保留了信息（≥ 0.9 · r(F0)）。
  - P6 在 DTU 训练参与者上：冻结的查询对齐 token 保留了同窗原始 EEG 线性可读性的 0.75–0.97，未对齐 token 约为 0。FAU 功效不足，Federici 没有做 P6。
- **问题**：配方不变、只换读出接口时，比较以下几项的真查询风险：
  - B\_ALIGNED 对固定网格孪生（AL-INTERFACE）；
  - B\_ALIGNED 对局部模型（AL-LOCAL）；
  - 随初始化的变化（AL-INIT）；
  - 随适配方式的变化（AL-ADAPT）。
- **设计**（ADDENDUM\_06 在任何 B\_ALIGNED 单元或探针运行之前冻结）
  - 输入：每个查询 t 读取 \[t−0.4 s, t+0.6 s)，段首之前置零。FAU/DTU 是 128 Hz 下 128 个点，Federici 是 100 Hz 下 100 个点；适配器重采样到 200 Hz，得到一个 1 s 的 patch。
  - 读出 `aligned_patch_linear`：通道 token → LayerNorm → flatten → Linear → d = 32 → L2。
  - 配方：与 B\_DENSE 完全相同。
  - 规模：2 个 backbone（CBraMod、REVE）× 5 种适配 × 25 个折格（FAU 10、DTU 10、Federici 5）= 250 个单元。只用 NCE 和 seed 3401。
  - 完成情况：250/250 完成，排除的配对为 0。工程探针的检查项都满足：表示差 ≤ 4e-7，显存 2.9 GB（IMPLEMENTATION\_RECEIPT §11）。
- **n**（按身份计，种子和折不增加 n）
  - FAU 67：TH-heldout 14，HA 29，CI 24。
  - DTU 44：NH 22，HI 22。
  - Federici 86：CI 33，HC 37，HC-v 16；phantom 已排除。
- **终点与统计**
  - R = `unified/regular/logloss_bits`，即真测试段在全部候选中的交叉熵，单位 bits / 5 s query。
  - ΔR = R(参照) − R(候选)，正值表示候选风险更低。
  - 区间：身份层面 bootstrap-t 95%（B = 4,000）。同时区间取家族内 max-t，临界值 2.10–2.49；分类以同时区间为准。
- **家族**（每个数据集 × backbone 一组）
  - AL-INTERFACE：B\_DENSE `channel_phase_linear` 孪生 → B\_ALIGNED，5 个成员。
  - AL-LOCAL：A\_LOCAL `lag_local_tokens` full（L0）→ B\_ALIGNED，5 个成员。
  - AL-INIT：`random_full` → `pretrained_*`，4 个成员。
  - AL-ADAPT：`pretrained_frozen` → peft/partial/full，3 个成员。

### 注意事项与意外

- **接口是成套改变的**：对齐方式、窗口/context（5.6 s 变为 1 s）和读出头是一起换的。参照 B1 本身只略高于机会，所以 ΔR 大的部分原因是参照接近机会水平。
- **AL-LOCAL 两边的 EEG 访问不对等**：L0 读 \[t, t+0.6 s)，B\_ALIGNED 还多读了之前 0.4 s 的 EEG（ADDENDUM\_07 §1）。访问相同的对照是 AI-ACCESS（L1 → B\_ALIGNED），见下一节（ALIGNED\_INTERFACE\_RESULTS §2）。该文件于 10-16 08:13 生成，尚未公开（0600），也在等你定框架。
- **配方事实**（CORRECTION\_01、EFFECTIVE\_UPDATE\_REPORT）
  - backbone 学习率：`random_full` 为 3e-4，`pretrained_full` 为 1e-5，相差 30 倍。

## ALN3.2 第 1 波：对齐接口对照与真正全量更新（ADDENDUM\_07）

你需要决定四类读数各自以什么范围、限定和时机写进报告：一是 TF-INIT（唯一可使用“匹配全量更新下的预训练先验收益”这一短语的族；CBraMod 12/12 格为正，REVE 0/12）；二是真全量和旧前缀配方下“FM 对 local”的读数；三是过去 0.4 s EEG 的读数；四是编码器对同窗 ridge 的读数。

### 问的是什么

- **问题**（ADDENDUM\_07 §5）：都在 B\_ALIGNED 的对齐 1 s 接口上。
  - (i) EEG 访问相同时，FM 与 local 的风险差：AI-ACCESS（L1→B\_ALIGNED）、AI-POSTONLY（L0→F2）。
  - (ii) 前 0.4 s EEG 的作用：AI-CONTEXT（F2→B\_ALIGNED，在 FM 内）、AI-PASTEEG（L0→L1，在 local 内）。
  - (iii) 编码器对同窗正则化线性读出：AI-RAW（R0→L0、R1→L1、R1→B\_ALIGNED frozen）。
  - (iv) 主干全部允许参数都更新时：
    - TF-INIT：random→pretrained，同一配方、同一 lr 格。
    - TF-RECIPE：one-step→warm-up；旧前缀→真全量也属此族，结果文件 §9 列出，附录和 JSON 记作 TF-VS-LEGACY。
    - TF-LOCAL：L0/L1→真全量 FM。
- **数据**：
  - 身份数：FAU n=67、DTU n=44、Federici n=86。seed、fold、内容 fold 都不增加 n（ADDENDUM\_05 §2）。
  - 每族全部 25 个 fold 格（FAU 10、DTU 10、Federici 5；ADDENDUM\_06 §3）；seed 3401，NCE。
  - 主干：CBraMod（12 块、100 轮）和 REVE（22 块、50 轮）。
- **各臂**（ADDENDUM\_07 §1–§2）：
  - L0：现有 local `lag_local_tokens`，读 \[t, t+0.6 s)，正好是 B\_ALIGNED 窗的后段。
  - L1：同一编码器读 B\_ALIGNED 窗 \[t−0.4, t+0.6) s，段首之前置零；128 Hz 下编码器有 42 个 token。

    - 设计格：{full\_onestep\_v1, warmup\_then\_all\_v1} × 主干 lr {1e-5, 3e-4} × {random, pretrained}。

- **终点与统计**（ADDENDUM\_05 §3、§6）：
  - R 是 unified 读出下，真实测试段在全部候选中的交叉熵，单位 bits / 5 s 查询。
  - unified 读出指：训练侧 ridge 映射到标准化声音目标，加训练侧温度，所有模型用同一规则。

- **旧配方事实**（CORRECTION\_01）：
  - 旧配方中 random\_full 主干 lr 为 3e-4，pretrained\_full 为 1e-5，相差 30 倍。LLRD 0.75，逐步开放前缀。

## SCI\_R2 科学分析第 2 轮（docs/13）：嵌套前向模型与共同时间面板

需要你决定的是：嵌套特征增量、共同毫秒网格上的包络可读性曲线（含负 lag 对照与 2–8 Hz 敏感性）和组差，各以什么层级、什么措辞写进报告/论文，以及本轮怎样与尚未登记的后续分析（F0/voicing 等）衔接。

### 问的是什么

- **Q1（S2，嵌套前向模型）**：在留出参与者上，每个声音特征族在前面各族之上，为 EEG 预测增加多少。
  - 嵌套顺序：M1 env → M2 +onset → M3 +spec（log-mel PCA-5）→ M4 +flux → M5 +Ac（Whisper 第 1–2 层 PCA-5）→ M6 +Lz（Whisper 第 27 层 PCA-5）。特征都带通到 1–8 Hz。
  - 模型：前向 ridge，用滞后 −200…+600 ms 的特征预测全部通道。α 用 5 个参与者组的分组 CV 选（seed 20261014）。
  - 终点：每个测试身份所有通道留出 Pearson r 的平均；Δr\_k = r(M\_k) − r(M\_{k−1})。
  - Federici 只有 M1，因为它的缓存里只有 2–8 Hz 包络。
- **Q2（S1c，共同时间面板）**：统一的 lag 网格 −200…560 ms，步长 20 ms；每个 lag 用等宽 40 ms 的原始 EEG 窗，经 ridge 读出包络，终点是每个身份的 Pearson r。负 lag 是对照。
- **Q3（频带敏感性）**：把 FAU/DTU 的 EEG 限制到 2–8 Hz（零相位 FIR，按片段做 filtfilt）后重做 Q2。主结果仍是 1–20 Hz。
- **人群与 n**（按身份计数，fold 不增加 n）：
  - DTU 成人 n=44（HI 22、NH 22）；
  - FAU 成人 n=67（CI 24、HA 29、TH 14）；
  - Federici 儿童，人类身份 n=86（CI 33、HC 37、HC-v 16），幻影 1 个实体已排除；
  - 私有队列不在本轮。
  - 共 25 个 CPU 任务：作业 1040271–1040275，汇总作业 1040462，2026-10-14 20:52 完成（ALN32\_IMPLEMENTATION\_RECEIPT §7）。
- **统计与单位**：
  - 身份级 bootstrap-t，B=4,000，以已拟合的模型为条件；
  - 曲线用跨 lag 的 max-t 同时带；每个队列的 5 个增量为一族（family max-t）；
  - 组对：FAU HA−TH、CI−TH、CI−HA，DTU HI−NH，Federici CI−HC、HC-v−HC。Q1 组差只给逐点区间，Q2 组差给曲线的 max-t 带。
  - 单位是 Pearson r，不是 SCI\_R1 用的 bits/query。

### 注意事项与意外

1. **Federici 的频带标注有误。**
   - SCI\_R2\_RESULTS 中 Federici 小节的 Q2 标题写的是"1–20 Hz EEG"。这是聚合代码给所有数据集共用的标题（`sci_r2_aggregate.py` 第 120 行）。
   - 实际数据是作者提供的 2–8 Hz、100 Hz 缓存，滤波器未知（SCI\_R1\_PREREG §3）；目标是 2–8 Hz 包络（SCI\_R2\_PREREG §4）。
   - 所以，Federici 的 Q2 在 EEG 频带上对应的是 FAU/DTU 的 Q3。但目标频带（1–8 Hz 对 2–8 Hz）、采样率、滤波器、语言和人群仍然不同。
2. **负 lag 与滤波，以及两轮规则的冲突。**
   - 目标做 1–8 Hz 零相位滤波，扩散约 ±78 ms；EEG 约 ±25 ms（SCI\_R1\_PREREG §3）。
   - FAU 的 stage-B ICA 对各组用同一规则，去掉了包络互相关峰落在 ±23 ms 内的成分（同上）。
   - 冻结的 SCI\_R1\_PREREG §11 解读表规定，"负 lag 对照 > 0"读作存在刺激自相关、零相位滤波或慢状态带来的"泄漏"。SCI\_R1\_RESULTS §1 第 2 条据此报告了 DTU 原始负 lag 平均 gain +0.087 \[+0.068, +0.106\] bits。而 SCI\_R2\_PREREG §4 和 docs/06 规定"不称泄漏"或"不一律叫训练泄漏"。两份冻结文件的措辞直接冲突。
   - 改用 2–8 Hz 后，FAU 大多数负 lag 的带含 0，DTU 在 −200 ms 也含 0（见上）。
3. **长 lag 尾部。**
   - 1–20 Hz 下，DTU 在 560 ms 仍是 +0.039；2–8 Hz 下是 +0.000 \[−0.004, +0.005\]。
   - Q3−Q2 在 400 ms 处，DTU 为 −0.023，FAU 为 −0.019。
   - 2–8 Hz 滤波是按片段单独做 filtfilt（奇延拓）的，只对片段内部的窗口计分（§5）；片段边缘的影响没有单独评估。
4. **Q1 的可比性。**
   - r 是所有通道的平均；三个队列的导联数不同：FAU 31、DTU 64、Federici 32（SCI\_R1\_PREREG 通道表）。因此跨队列比较绝对值时，会受到通道数、频带和刺激的影响。

   - Ac/Lz 是全窗自注意的 Whisper 状态，含非因果上下文（SCI\_R1\_PREREG §3）。
5. **组差。**
   - Q1 组差只有逐点区间：预登记没有规定族；而 SCI\_R1 的 S4 组差是成族的。
   - FAU CI 每人去掉了 2–4 个磁体附近的电极（docs/auditory\_c3/C3\_LANDING\_PLAN\_v1），在 stage-B 中用球面样条插值补回（`auditory_c3/stageb.py`）。

### 机械判定（冻结措辞规则给出的说法）

**SCI\_R1（预登记 §11）**

- R(E)−R(E,L)>0：“在该模型族与训练合同内，加入晚窗降低了真实 EEG 风险”。这不等于晚窗有独有信息。
- SB 大：“在这一读出类内不能由其余 token 恢复”。
- 晚−早 ≠ 0：须配三件套报告，不读作“信息更多”。
- 负 lag>0：存在泄漏。正 lag 结果须相对这一基线解读，不能做减法来宣称纯度。
- 冻结>原始：只表示在 400 片段探针下更易线性读出。
- 交互含 0：不写成“两窗相同”。
- 组差：只作“同模型、同任务下的描述”，不作设备因果解释。
- 禁用说法：
  - 时间与来源：神经潜伏期；源定位；“早声学/晚语言”；“信息时间进程”；窗独有信息。
  - 指标：把 gain 称为信息量；跨数据集合并绝对比特。
  - 样本与统计：把 3401 单 seed 写成三 seed；把幻影会话当 9 个实体；“一组显著、另一组不显著”。
  - 读出：把探针当上限。
  - 弱结果：“无 EEG 信息/无发育作用/天花板”。
  - CI–TH 差距：差距缩小写成“伪迹已去除”，或清理后仍低写成“神经性”。

**ALN2**

### 互补的措辞门槛

- **“来自预训练表示的互补”**：残差（ADDENDUM\_10）、简单融合（ADDENDUM\_09）和 C 族中期汇总（ADDENDUM\_05）都要求同时满足两条：
  - 价值对比的区间 > 0；
  - 两个归因对比的区间也都 > 0，即 pretrained 对 random、对同等小容量分支都更好。
- **只满足价值、不满足归因**：写成“加入分支降低风险，但来源（预训练还是额外容量或结构）未分离”。
- **残差的特殊情形**：价值约为 0 且选中 epoch 0 的比例高时，读作“没有采纳修正”。这既不算互补，也不算 local 失败。

### 明确禁止的说法（ADDENDUM\_05 §7）

- 笼统地说“FM 更好”或“FM 更差”。
- 根据 seed 3401 做任何 seed 稳定性的结论；seed 面板还在跑。
- “dense 比 ALN2 的粗接口好”。
- 只凭 `gain_bits` 或错配损失得出互补。
- 由这些对比得出任何关于 HA/CI、年龄或发育的结论。
- 把 C 族的收益归因于“正确的预训练 EEG 观测”：所需的错配上下文对照和仅位置对照没有实现。

### 本文档是怎么来的

- 所有结果都由冻结的分析代码生成。运行前核对过代码 sha256，合成数据测试通过，隐私扫描 PASS。
- 每组由一个只读代理阅读结果文档和对应增补，起草本节；再由另一个代理逐个核对数值、区间、n、机械判定和措辞。
- 数值一律抄自结果文档，并注明所在节。表中的区间是逐点 bootstrap-t 95% 区间；有同时区间（max-t）的地方另行注明。
- 本文档只描述结果和需要你做的选择，不替你定框架，也不推荐选项。

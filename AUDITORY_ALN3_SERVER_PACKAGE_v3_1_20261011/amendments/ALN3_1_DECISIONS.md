# ALN3.1修订决定与依据

## 0. 版本关系

这是对ALN3 v3.0的兼容修订，不是新的一轮实验重置。上一轮A局部、B细时间读出、C互补、D注意/适配、E私有迁移的主要任务保持。明确冲突时本增补优先；没有冲突的实现、数据切分和有效结果继续使用。

**依据分层**：
- **已有报告**：仓库d5b2315中的ALN2结果和实现；本次再次确认GitHub最新仍是该提交，不是server实时作业状态。
- **新server事实（用户转发）**：HC-v独立原始代码和人口学；Artifact九次会话为一个phantom；item-2/3进度与已提出的去重安排。尚未独立读取该server原始元数据；执行时将来源文件hash记入manifest即可，不再开启漫长身份搜索。
- **候选意见**：2026-10-10《项目进展检查》、2026-10-11《下一阶段方向设计》。保留它们的问题线索，但不是所有“主张”都成为执行结论。
- **本次决定/推理**：多seed优先级、配对面板、并行科学分析、可选资源扩展；都不是已完成实验。

## 1. 修改而不推翻的理由

旧包的空间/时间保留、局部通路、基础模型读出、训练侧教师选择仍有现成结果依据。不应因为新评议偏好TRF或新数据，暂停已批准训练。需要修的是：
1. HC-v同儿童假设及其年龄映射与推断单位；
2. 旧粗接口全矩阵补seed与新密集读出之间的重复算力；
3. 科学分析交付偏晚——增加逐lag、时间泛化与明确特征对比的并行工作；
4. 主要比较的控制臂也需要相同seed，而不是仅把新方法重复三次；
5. 资料与性能口径可能支持错误的“上限/机制”推论，需要写入正确解释，但不新增绩效门槛。

## 2. 明确撤回/不采纳

| 候选说法 | 修订后的处理 |
|---|---|
| 私有oddball所有对齐都关闭；只能作失败案例 | 不采纳。二类刺激身份不足以独立分解多种确定性声学属性，但不排除分类、时间组织、历史条件或迁移研究。 |
| 任何gain均不超过log2 K | 错误。项目错配NLL差与Shannon MI不同；类别数不解释AUC接近0.5。 |
| CI差距缩小才说明清理有效；清理没改善则低值是神经性的 | 不采纳。只检验已知污染的敏感性、参考任务保留与真实记录外推，不用人群差缩小作为训练/择模目标。 |
| I(Z;队列\|完整刺激ID)低即稳健 | 各队列刺激不相交时该量可恒为0；不作为主指标。 |
| 三个时钟同时回归即可分离 | 年龄、恢复/验配年龄、经验可能线性依赖；先定义可识别比较。 |
| TRF峰与解码峰必须贴合 | 不采用峰距通过线。幅度与可读性、噪声结构是不同对象，允许不一致。 |
| HBN直接是正常听觉常模；z化后可合并各临床目标 | 不采纳。参考人群与行为构念须分别定义。 |
| 至少六条线一直跑到第三个月 | 不采用日历或线路数量硬规则；依据依赖、信息价值和新干预安排。 |

这不是反向维护旧方案：如密集读出、残差互补没有任务收益，应完整报告并改变方法；只是不能把一次配方比较提升成原始EEG信息不存在。

## 3. 对item-3冻结登记的显式修订

批准将3b/3c并入B，不以“已冻结”强制重复400次训练。server保留原登记及已观察范围，新建 `ITEM3_TO_B_MAPPING`：old unit/comparison → B配置 → 保留问题 → 变化的时间目标/训练配方 → source checkpoint → 状态。

B的新训练默认包括head warm-up后解冻（适用的微调臂）、每epoch固定开发内容验证、训练身份内多个开发块与layer-wise LR decay。数值从开发侧选，保持同一比较内可比；原一次性联合训练作为有限配方控制。冻结/随机初始化臂按其定义处理，不强行套相同的“解冻”动作。

3a是诊断资产，不是B能否成功的科学门槛；A和无依赖私有训练更不能等待3a的成绩。

## 4. 不改变已有模型身份，正确处理真实改变

只变汇总标签/条件权重：复用预测，新evaluation version。若旧错误年龄只在事后关联里使用，重算关联，不重训。

真实输入、fit/cal/test范围、音频坐标、训练损失、head、初始化、teacher或训练配方改变：新的执行版本，继承旧logical comparison ID并加execution hash。源数据清理可复用，但不能把新旧target结果混在一列。

同一儿童和同一音频多seed多fold不是新样本；新seed不使已经看过的数据重新成为盲验证。

## 5. 新包不是现场执行记录

用户最近转发的数字是一个过去快照：item-2小编码器1474/2220，FM58/1860；3a500个评价单元，3b/3c400个训练单元。它们**不是本包生成时的实时状态**。若已完成就复用；若状态变化按相同优先级处理，不要求重现这些数字。

本包无远程作业提交或删除动作。server无需为已授权范围再逐项求批；只升级真实阻塞、数据使用权限或超出现有资源授权的事项。

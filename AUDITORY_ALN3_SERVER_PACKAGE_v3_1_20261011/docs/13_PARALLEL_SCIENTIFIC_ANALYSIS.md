# 13 · 科学分析与方法训练并行

目的：让ALN3不仅输出方法排行榜，还逐步回答“何时可读、什么声音关系可读、是否跨时段/人群使用、儿童中如何变化”。这些分析用已有或逐fold完成的checkpoint即可展开，不等待B/C全部完成。

## S1. 逐lag可读性与时间泛化

### 可读性曲线

从保留局部信息的模型导出`tokens[query,lag,feature]`，同时保存实际EEG访问区间、声音目标上下文、预处理滤波信息。不能将混有全局context的token称局部来源。

每个lag的主读出在训练参与者/训练内容上拟合，查询使用同一held-out人/内容。目标标准化、PCA、ridge、温度都留训练侧；沿lag使用相同容量/选择规则，避免某时段单独额外调参。

两条曲线分开命名：
- 冻结群体编码器上的局部probe：这个已学表示在某lag的可读性；
- 原始EEG严格局部输入独立训练：该方法在相应窗口可读取什么。

原模型删token/遮挡的变化是模型依赖，删窗重新拟合是可替代性；都保留但不互换名词。邻近lag共享数据、滤波、声学自相关，不当独立采样点。

### 时间泛化矩阵

训练侧在lag τ拟合一个读出并固定，将其应用到所有测试lag τ′，得到风险矩阵`R[τ,τ′]`。连续任务须同一声音目标坐标；私有任务用同一current-class标签，不注入Hist/年龄/阶段到声称EEG-only的读出。

“对角可读但离对角差”可提示读出结构随时间改变，但还可能来自信噪比、标度和正则化；不要单凭这个矩阵证明独立发生源。方法参考King & Dehaene 2014（来源W01）。

对于全训练链已用全部lag训练过的编码器，TG是冻结表示上的时间读出，不是原始信号跨时间训练的完全独立证据。保留raw-linear局部参照，在主要面板做更严格局部输入训练敏感性。

### 输出与推断

每人整条曲线/整张矩阵进入聚类bootstrap；主要预定窗口差与交互优先，完整扫描为探索并提供同时区间或预定多重比较处理。不将CI必须延迟20 ms、TRF必须在30 ms内吻合设为通过线。不同年龄组使用不同故事时，年龄与内容的支持同时报告。

## S2. 正向编码参照与明确声音特征

mTRF/正则化前向模型作为补充，不成为深度对齐先通过它才可继续的门槛。比较held-out EEG预测风险；权重峰、预测相关与解码峰是不同对象，允许不一致。原始幅度大而噪声更大时，较小幅度时段也可更好解码。

成人有真实波形的任务按可得内容建立嵌套特征组：包络/起始、谱/谱变化，必要时F0及voicing，再加入冻结深层表示。每个增量保持同一目标、内容和开发能力；不能直接比较Ac/Lz不同维度检索力称“哪层神经信息更多”。

如果做`q0(L|Ac)`与`q1(L|Ac,EEG)`，它回答指定背景模型之外的预测增益；背景欠拟合和共同上下文仍是竞争解释。不称精确CMI或纯语言量。Federici仅有2–8 Hz缓存与包络时，只做实际支持的分析，不虚构Whisper目标或重建原始宽带δ活动。

固定EEG、改变声音表示分别作“固定模型目标扰动”和“重新拟合后的表示预测比较”；它们不是参与者真正听过另一声音的因果实验。

## S3. 空间读数

优先输出输入通道/区域敏感性及明确线性读出的activation pattern。Haufe变换用于其适用的线性映射及相应输入协方差；深度hidden token的空间权重不能直接称头皮发生源（W02）。

不要求源图一定集中颞上回才成立。没有个体电极/MRI或合理forward模型时，不制造源定位主张；有来源的模板敏感性可作补充。

## S4. 人群、发育与功能

由训练侧规则选定或结构性预登记的主模型作组分析，而不是把5996个单元每个都做一遍临床显著性排名。全部方法任务结果保留；科学主面板及探索范围分开。

- 成人共同模型下比较HA/CI/TH或HI/NH；适配前后用同query与信息预算，组差不等于设备因果作用。
- Federici HC-v独立组、正确年龄；Artifact一个实体九次会话单列。没有同儿童声码器配对。
- 私有按固定年龄/阶段规则做当前声音及历史条件风险、逐lag和时间泛化，不仅报告AUC；缺临床字段不影响任务训练人群。
- 年龄=首次恢复/验配年龄+经验在适用人群中导致共线；不同时解释为三个独立因果系数。儿童内变化也混有成熟与时间。
- SRT、HSM、理解正确率、SIR、SSQ/努力不能靠z标准化合成同一真值。固定表示接各自低维头，在实际构念范围内报告；不重启大规模私有问卷搜索。

## 首轮分析的模型面板

默认用旧有效局部基线、ALN3 lag-local NCE/CS、一个同架构随机对照与对应预训练dense读出，以及local+FM的预定主配方。checkpoint按训练侧政策和可用依赖选择；没有完成的模型先标待补，不阻止已有面板分析。

交付 `SCI_TIME_CURVES`、`SCI_TEMPORAL_GENERALIZATION`、`SCI_FEATURE_INCREMENT`、`SCI_SPATIAL_READOUT`、`SCI_GROUP_DEVELOPMENT`。先交真实生成的图/表和可复用输出，再写解释。不把未生成的图标记“完成”。

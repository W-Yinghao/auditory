本版不把八个探索簇全部加入主矩阵；不规定六条线必须存活三个月。先用本轮已批准接口完成full experiments，另行登记少数可并行且有明确支持的新资源/干预。此处是**候选及本次建议**，不是已下载、已授权访问或已完成的新实验。

## 2. 同刺激跨人学习（候选增补，不进入全部ALN3组合）

在实际共享的声音锚点上，用不同训练参与者形成多正样本，再与声音对齐共同训练。匹配声音及注意指令/目标状态；同一混合音频但注意流不同，不把完整EEG强行拉成同一表示。

比较声音监督单独、同刺激EEG一致性单独、两者联合；群体共有分量与个体/条件残差可作为候选结构。没有必要对所有HA/CI组别做不变约束。匹配监督覆盖与总更新量，结果在留出身份/内容上评价；没有结果配额。

## 3. 采集稳健性与跨队列迁移

同一记录上构造有物理意义的合法通道子集、参考与采样变化，固定参与者与刺激检验测量扰动。它不是生物学组别抹平，也不等于真实跨医院问题全部解决。

真正跨队列先统一声音坐标/标准化政策、电极接口和candidate规则。现有各队列PCA或随机投影不能直接互换。严格zero-shot、仅无标签目标统计适配、有目标配对校准三种分开登记。队列改变同时改变语言/年龄/任务，称跨队列而非纯语言效应。

不使用`I(Z;D|完整刺激ID)`作为主稳健指标：刺激ID可确定队列时该量恒为零，即使Z=D。用实际目标迁移成绩与同刺激测量扰动比较。

## 4. CI污染的半合成敏感性支线

构造`X_reference + α A_phantom`时，已知的是参考记录和注入项，不是纯神经CI真值。phantom一个实体九次会话，只能跨会话/参数测试，不能声称泛化到九个独立植入系统。

保持参考EEG/刺激不变，改变已知污染的幅度、延迟、空间传播；同时测参考任务保留和污染敏感性。零表示既不敏感也无任务用途，不能视为成功。不用CI−TH差距缩小作为训练目标/成功判据，不用清理无收益推断神经缺损。

保留无处理、既有实际可实现的ICA/SOBI/相关清理参照；所有模拟假设和实际带宽单列。原始较宽频数据不存在时不“补造”高频污染真值。该支线不成为所有真实CI训练的前置条件。

## 5. 不继续膨胀的范围

不引入VCS-QMI；不强制更大FM；不重新猜私有未知刺激；不把病例量表z化为统一指数；不把普通话纯音当普通话语音；不把Shannon类别熵界强加到CS或错配NLL差上。

这些是纠正估计对象，不是以低性能关闭可探索科学问题。新采集提案可另写，但当前工作不依赖医生回信。

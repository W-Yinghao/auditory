## 立即修正Federici

HC-v使用其自己的原始参与者代码和人口学信息。**不按同文件编号合并HC与HC-v，不做同儿童HC−HC-v配对。** 现有证据支持把它们作为不同组分析；若将来出现具体可信的身份重叠证据，单独更正，不能用年龄/性别相同代替身份确认。

Artifact为同一个phantom的九次会话，独立于人类结果；不输出九个独立实体的置信区间。原预测可保留为其原训练/分折条件下的结果，旧HC-v年龄分析重算。**不因元数据修正一律重训**：只有当错误年龄进入训练、教师选择、采样，或确实发现train/test泄漏，才重跑相应依赖链。新训练使用纠正清单。

## 不变的研究纪律

当前样本不足以用大量旧配方的弱结果证明“没有信息”“发育无效”“模型天花板”。保留所有有效弱值、负值与反向结果；不按想要的阳性选组、选seed或选模型。允许基于具体实现与重复性降低某些作业优先级，**算力取舍不是不存在证明**。

私有儿童继续做任务匹配的当前声音读出、历史条件证据、时间组织和先验迁移，不伪称有连续语音波形，也不预定为“二类别上限”的负例。不使用未发表VCS-QMI或神经critic。

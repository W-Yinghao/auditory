# 06 · 对比与基线

没有"我们的模型 vs 他们的模型"；基线按度量层级选，每层回答一个审稿质疑。

## 第一层：追踪度量基线（"你分解的那个数是什么"）

| 基线 | 出处 | 用途 |
| --- | --- | --- |
| 前向 TRF 预测相关 | mTRF（Crosse 2016）；Jehn 2026 流程 | 总 MI 应与之单调相关 |
| 后向重建 + 注意解码准确率 | O'Sullivan 2015；Jehn 2025/2026 | H1 阳性对照 |
| Match–mismatch 准确率（开源 DNN 一个） | VLAAI（Accou）或 Thornton 2024 | 展示"准确率只是总量"；不自己训 |
| 跨儿童单试次 AUC（私有） | 仓库 GX | 与 I(T;Cur) 并排 |

## 第二层：刺激表示基线（"语言层多了什么"）

包络、包络起始、梅尔谱（Whisper 输入）、音素/词起始、音素惊讶度、GPT-2 词惊讶度、wav2vec2/HuBERT 同位置层。层选择只在 TH 一半参与者上做。

## 第三层：估计器与分解度量（"方法稳不稳"）

| 对比项 | 内容 |
| --- | --- |
| MI 估计器 | 主 GCMI；对照 KSG、分箱；合成偏差曲线进图 6 |
| PID 度量 | 主 I_ccs；对照 MMI；BROJA 仅在低维可算处 |
| 分解路径 | 直接 vs 预测中介 |
| 代理方案 | 循环移位 vs 标签打乱 vs 相位随机化 |

## 第四层：已发表结果逐项复现

Jehn 2026（三组准确率、早峰不受注意影响、CI 理解分与解码相关）；Federici 2025（短/长尺度）；Fuglsang 2020（包络层，若做）；仓库自身（HA 0.556、NH–HA 0.04、读出与佩戴时长在月龄之上无关）。

## 第五层：功能与发育基线

临床基线 C；总 MI I(T;Ac,L)；常规追踪指标作预测子；EEG 年龄模型（对照为日历月龄）。

## 不放进去

EEG 基础模型（LaBraM、CBraMod）；个人参照校准；测试时适配；SparrKULee 排行榜。

## 最小集合

mTRF 相关 + 注意解码准确率；包络 + GPT-2 惊讶度；MMI 对照 + 合成偏差曲线；Jehn 与 Federici 逐项复现。

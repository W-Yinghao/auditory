# 08 · 合成核对

`reference/gcmi_core.py` 是参考实现（只用于核对）；`reference/synthetic_checks.py` 运行 S1–S8 并写出 `reference/checks_c3.json`；`tests/test_core.py` 为 pytest 断言。本包附带的 `checks_c3.json` 是打包时的一次运行结果，供对照，不替代服务器自己的运行。

运行：

```
python -m pytest -q tests
python reference/synthetic_checks.py
```

| 核对 | 构造 | 应得到 | 打包时结果 |
| --- | --- | --- | --- |
| S1 解析高斯 | ρ=0.6，I = −½log₂(1−ρ²) = 0.3219 | GCMI 在 0.01 内 | 0.3216 |
| S2 共同原因 | x←z→y | I(x;y)>0，I(x;y\|z)≈0 | 0.433 / −0.00003 |
| S3 冗余 | T≈A，B=A+噪声 | MMI：R 由较弱源决定，S≈0 | R 1.79，S ≈ 0 |
| S4a 可见协同 | T=A+B+ε | S 明显 > 0 | S 1.79 |
| S4b 不可见协同 | T=A·B | GCMI 全部 ≈ 0 —— **估计器盲区，必须写入限制** | 全部 < 1e-4 |
| S5 偏差曲线 | 独立变量，d∈{1,3,5,8}，n∈{200…3000} | 偏差校正后 ≈ 0；原始偏差随 d/n 增大 | d=8,n=200 原始 0.036 比特；校正后 < 0.01 |
| S6 早滞后混叠 | AR(1) 刺激，响应只在滞后 40 | 早滞后 20 有 MI；条件于真滞后后 ≈ 0；TMIF 峰在 40 | 0.322 / −1e-5 / 40 |
| S7 oddball 历史 | logit 只依赖当前类别 vs 另含 run 长度 | 分层置换校正后前者 ≈ 0，后者明显 > 0 | 0.0019 vs 0.224 |
| S8 共同伪迹 | T=2A+B+k(A+B) | 神经权重不变，MI 差随 k 变 | 0.886 → 0.555 → 0.261 |

两条直接写进方法的限制：

1. GCMI 是下界且看不见 XOR 型协同（S4b）；主张中的"协同"只指 GCMI 可见的那部分。
2. 当 d=8、n=200 时原始偏差约 0.036 比特，与组间差异同量级；所有组比较必须在偏差校正之后，且每组分别校正。

`I(T;Hist|Cur)` 的零假设用分层置换（在当前类别内打乱 T），保持 I(T;Cur) 与历史序列统计；`I(T;Cur)` 的零假设用标签打乱。两种代理不混用（已写入 03 §3.6 的补充）。

I_ccs 未在参考实现中提供；P1 必须接入 Ince 的参考代码并通过其论文中的高斯示例核对，否则 PID 层整体标 `TECHNICALLY_UNEVALUABLE`，主张退回 CMI 层。

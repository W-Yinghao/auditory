# 05 · 私有端分析

私有数据承担 R2：在没有语音、没有配合的婴幼儿里，用同一估计器回答"刺激信息里多少是当前刺激、多少是历史"，以及两者随发育与佩戴阶段怎么变。全部复用缓存，不训新编码器。

## 5.1 变量

| 变量 | 定义 | 来源 |
| --- | --- | --- |
| T | 冻结 EEGNet 逐试次 logit；δ/θ 限带版本；30–45 Hz 版本；模型无关敏感性：120–320 ms 窗 ROI 幅值前 3 主成分 | GX/PF 缓存 |
| Cur | 当前试次类别（标准/偏差） | 事件表 |
| Hist | 上一试次类别；距上一偏差的事件数（截断 8）；前置 run 长度 | 事件表 |
| EEGage | 仓库年龄模型的偏差校正估计 | D2/H8 |
| D | HA 使用月数；阶段 [0,2] / (2,13) / ≥13；NH 单列，不填 0 | 临床表 |

## 5.2 分解（H4）

每名儿童：I(T;Cur)、I(T;Hist)、I(T;Cur,Hist)、I(T;Hist|Cur)；PID 为解释层。代理：儿童内打乱类别并重算历史变量。

预期：I(T;Cur) > 0（多数儿童）；I(T;Hist|Cur) ≈ 0。与 GX 的"历史不增益"一致，但现在有单位、可跨范式比较。

## 5.3 发育与阶段（H5）

- I_Cur 对 EEGage 与 D 联合回归（03 §3.9）；主要阶段对比 [0,2] 对 ≥13；13 对月龄匹配沿用 PF。
- 儿童层面 I(I_Cur; D | EEGage) 表达"发育之上的佩戴信息"。
- I(T;Hist|Cur) 是否随 EEGage 出现：按年龄带报区间，不做阈值裁定。
- 配对访视：I_Cur、I_Hist|Cur 的配对差，双侧精确符号检验，按实际独立人数；每儿童一对。

## 5.4 CI 频带归属（H6）

对 (δ/θ 证据, 30–45 Hz 证据) 计算 I(T_cls; low)、I(T_cls; high|low) 与 PID（这里 T 为类别，源为两个频带证据）。若刺激信息主要在 δ/θ 项，且高频证据集中 0–80 ms，则高频进入伪迹敏感性表，CI 的神经估计只取 δ/θ。信息归属，不是来源裁决。

## 5.5 承担主张的判定

至少一项成立才写"私有提供独立主张"：[0,2] 月组 I(T;Cur) 区间不含 0 且与 NH 重叠；I(T;Hist|Cur) 的发育依赖有明确区间；频带归属改变了对 CI 读出的解释。都不成立写"私有部分提供跨范式单位下的边界"。

## 5.6 披露与禁止

- 披露：儿童已被约 20 轮分析查看；窗与阶段定义来自历史探索；戴机状态按 2026-09-24 说明；量表不进入功能分析。
- 禁止：新的 SIR/MUSS 头；按查询成绩删人或翻转方向；重新寻找最佳分组或窗；未知任务语义恢复；声调分类；HA–CI 因果比较；在看到公开结果后改历史变量定义。

# 03 · 度量规格（G1 冻结）

记号：T 响应变量；A、B 刺激变量；C 条件变量；τ 滞后。单位：比特。

## 3.1 量

| 量 | 定义 | 用途 | 度量依赖 |
| --- | --- | --- | --- |
| MI | I(T;A) | 总量 | 否 |
| CMI | I(T;B\|A) = I(T;A,B) − I(T;A) | "A 之上 B 带来的信息"：声学之上的语言、当前之上的历史、发育之上的佩戴 | 否 |
| TMIF | I(T_t; A_{t−τ})，τ ∈ [−200, 600] ms | 时间分布；报曲线、AUC、预定窗积分，不挑峰 | 否 |
| PID | I(T;A,B) = U_A + U_B + R + S | 把 CMI 拆成唯一与协同 | 是 |
| 信息率 | I/Δt（连续）或 I(T;Cur)·r_trial（oddball） | 跨范式量级对照，不进主张 | 否 |

主判据用前三行；PID 只做解释层。

## 3.2 估计器

- 高斯 copula 互信息（GCMI, Ince 2017）：每变量秩变换 → 标准正态分位数 → 高斯闭式 MI；带小样本偏差校正项。性质：单调变换不变；真实 MI 的下界；**XOR 型协同不可见**（见 08 的 S4 核对）。
- 连续–离散（oddball 类别）：类条件高斯模型（`gcmi_model_cd`）。
- 条件版本：I(X;Y|Z) = H(XZ) + H(YZ) − H(XYZ) − H(Z)。
- 实现：参考 `reference/gcmi_core.py`（核对用）；生产用 Ince 的 gcmi 工具箱，二者在合成数据上差异 < 1e-6 比特才允许切换。

## 3.3 降维（源变量 ≤ 5 维）

| 变量 | 原始 | 进入估计器 |
| --- | --- | --- |
| Whisper / wav2vec2 层表示 | 512–1280 维 / 20 ms | 每层 PCA 前 k=5（训练侧拟合，不看 EEG）；重采样到 EEG 采样率；k=3、8 敏感性 |
| 语言基线 | GPT-2 德语词惊讶度 | 1 维，按词起始展开 |
| 声学基线 | 包络、包络起始 | 各 1 维 |
| EEG | 32 / 128 导 | 单通道逐个估计后在预定 ROI 平均；或 ROI 内 PCA 前 3 维作多变量 T |
| 冻结 EEGNet 证据（私有） | 1 维 logit / 试次 | 直接使用；另有 δ/θ 限带版本与 30–45 Hz 版本 |
| 类别与历史（私有） | 离散 | 直接作离散源 |

## 3.4 两条路径

- 主路径（直接）：T = ROI 投影；A、B = 降维刺激；在预定滞后窗内逐时刻估计后取窗内平均。
- 次路径（预测中介）：岭回归从 A、B 各得交叉验证预测 ŷ_A、ŷ_B（一维），对 (T; ŷ_A, ŷ_B) 估计。
- 两条都报；主张以主路径为准。

## 3.5 PID 度量

- 主：Ince 的 I_ccs（pointwise common change in surprisal）。生产实现在 P1 接入 Ince 的参考代码并通过其发表示例核对后才可用；核对未过则 PID 层整体标 `TECHNICALLY_UNEVALUABLE`，主张退回 CMI 层。
- 次：Barrett 的高斯 MMI（`reference/gcmi_core.py` 已含）。结构限制：两个唯一项至多一个非零，所以 U_L 在 I(T;L) < I(T;Ac) 时恒为 0——这正是不能用 MMI 作主度量的原因。
- 主张要求两种度量方向一致；不一致写"度量依赖"。

## 3.6 代理与偏差校正

| 数据 | 代理 | 规则 |
| --- | --- | --- |
| 连续语音 | 刺激相对 EEG 循环移位，最小移位 ≥ 5 s，不跨试次边界 | ≥ 200 次；每个量减代理均值；报代理分布 |
| oddball | 儿童内打乱类别标签（保持比例），历史变量按打乱后序列重算 | 同上；历史源代理必须保持序列统计 |
| 组间 | 各组分别校正后比较 | 不允许跨组校正 |

补充（来自 08 的 S7）：oddball 中 I(T;Cur) 的零假设用标签打乱；I(T;Hist|Cur) 的零假设用**分层置换**（在当前类别内打乱 T），保持 I(T;Cur) 与历史序列统计。两种代理不混用。

写法固定："偏差校正后 X 比特（代理均值 Y，n_sur=200）"。

## 3.7 滞后窗与 ROI（冻结值）

| 数据 | 主时域 | 窗 1 | 窗 2 | 窗 3 | 诊断窗 |
| --- | --- | --- | --- | --- | --- |
| 三联集 / DTU 语音 | [0, 600] ms | [0, 80) | [90, 300) | [300, 600] | [−200, 0) |
| Federici 语音 | [0, 600] ms | [0, 150) | [150, 600] | — | [−200, 0) |
| 私有 oddball | [0, 600] ms | [120, 200) | [240, 320) | 其余正滞后 | [−200, 0) |

ROI：额中央（Fz/FCz/Cz 及邻近）、左颞、右颞；全体组同一规则；缺失电极记录并插值，真实观测通道版本作敏感性。

滤波：主分析 1–8 Hz（语音）、1–20 Hz（oddball 证据已在模型内）；1–20 Hz 语音作敏感性；在物理连续区间内滤波，保护带 ≥ 滞后跨度 + 滤波冲激响应。

## 3.8 语言层的选择与冻结

- 在三联集 TH 组随机一半参与者上，对 Whisper 各层计算 I(T;L_ℓ|Ac)，取最大者为 L；同时记录 wav2vec2 同位置层。
- 之后对所有组、所有参与者冻结；**不在 CI 组或 HA 组上重选**。
- 选层过程及其结果作为补充材料公开。

## 3.9 发育与设备作为条件变量（儿童层面）

I_i = β0 + β_age·EEGage_i + β_D·D_i + γᵀV_i + ε_i；EEGage 为仓库年龄模型的偏差校正估计；D 为 HA 月数（阶段 [0,2] / (2,13) / ≥13）或 CI 年限。横断面只能部分分离，纵向不能（V4 附录 A7）。

## 3.10 功能模型

按 V4 §10.1 登记目标与似然。比较链固定：C → C + I(T;Ac,L) → C + I(T;Ac,L) + I(T;L|Ac) → C + {U_Ac, U_L, R, S}。参与者留出；功能头为低维岭或有序回归；报全表。

## 3.11 冻结规则

G1 时同时冻结：估计器与偏差校正配置、k、语言层、滞后窗、ROI、代理方案、私有历史变量定义、阶段分组、配对访视规则。之后任何改动必须留痕（旧版本、原因、影响范围）；技术错误允许修正，不允许为了结果修正。

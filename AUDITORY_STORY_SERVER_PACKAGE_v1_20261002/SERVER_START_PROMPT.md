# 可直接交给服务器代理的启动指令

请将本包作为新的story-first候选研究规格实施，不要继续沿NEXTMAP的技术现象清单自动扩展。

**研究主问题：** 利用已知刺激条件下的跨块响应预测，学习紧凑儿童级表示，是否能在少量临床标签时改善助听儿童的档案言语功能读出？

先读01_STORY、02_SERVER_EXECUTION、03_METHOD_SPEC和config/story_v1.yaml。资料依据为当前W-Yinghao/auditory，参考SHA为558e6509d64e0decb4d796ee51964f7ff6a30ee2。工作树更新时不reset，记录相关差异。

按以下范围工作：

1. 复用现有主访问、身份图、合格试次和PF2三个种子404/505/606的外折。不要扫描全数据，不再联系医生或补造标签。
2. 固定SIR 1–5为主、MUSS为次；12/24/all是临床标签数量，不是儿童试次数。不按新性能换量表、选孩子、选时段或调标签阈值。
3. 核对每外折同一冻结M_o的源范围；优先复用合法全试次缓存。没有合法缓存时只做必要推理，不训练新的原始EEG主干。
4. 本包reference只是核心原型。先实现你们现有Cohort/事件/临床适配，补上临床头、Slurm断点和单元测试；不要宣称新CLI已经存在。
5. 完成30个小型SRP/pooled摘要模型，以及预定SIR矩阵、MUSS与技术敏感性。所有对照在同样临床标签集合上拟合。
6. 保持外层儿童及物理采集隔离；隐藏标签不得进入表示、早停、预处理或子集选择。内层允许利用固定外层训练池的无临床标签EEG，这一半监督范围必须写清。
7. 实际运行全部经Slurm；沿当前runfill和允许设备约束。P100禁止。以服务器最新明确指令为准，不自行扩大资源。
8. 逐人数据、概率、权重、精确日期、身份和源路径全留private。不要push或发给第三方。
9. 记录训练模式、最终损失、KL、梯度、优化状态、概率阈值、标签mask与训练范围hash。不要仅留下最后一个MAE。
10. 最后按templates/RESULTS_REPORT.md报告功能结果、方法结果、必要对照和失败边界。查询响应或年龄成功不等于功能story成立。

如果某一个单元存在真实来源冲突，暂停该单元并说明具体冲突；无关元数据未知不阻断全部工作。实现正确但结果阴性，完成预定矩阵后如实报告，不继续增加模型。MFF验证与竞争story默认关闭，不能因为主结果不理想而自动启动。

**目标是回答选定的功能学习问题，不是把剩下的任何阳性改写成新主线。**

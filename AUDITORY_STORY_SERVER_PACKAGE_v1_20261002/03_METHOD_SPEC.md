# SRP 数学与实现定义 v1.0

本文件是候选方法的实现合同。它是本版设计，不是仓库已经完成的算法。配套 `reference/` 仅实现核心张量运算与评分；数据适配、Slurm主控制器和临床头仍由服务器按本包实现。

## 1. 单位、可见信息与输出

- 儿童 i 是独立临床样本；首轮只用其已登记主访问。
- 一个外折内使用同一冻结刺激编码器 f_o；禁止混合不同模型的192维坐标。
- EEG输入沿用已有 20×200（250 Hz，−0.2到0.6秒）的合格试次；主干全程eval、no_grad。
- 编码器输出以训练池儿童／条件等权拟合标准化与PCA，固定32维；若合法秩小于32，使用实际秩并记录，不填随机方向。
- PCA每名训练儿童每条件最多128个试次、固定种子采样；不用临床标签，不使用外层测试儿童。
- 模型只接收 e、操作刺激类s、前事件历史h、支持／查询划分及匿名child索引。child索引用于分组与等权，绝不作为embedding输入。
- 支持摘要输出 q_phi(u|A) 的均值和对角方差；u为8维。临床头主输入仅为均值，方差只作诊断，不称为已校准临床置信区间。

## 2. 物理块与训练样本

按D1物理连续区间内的相对秒划60秒块。记录间不拼接。epoch中心距块边界至少5秒；不跨原始断点。奇数块和偶数块构成两组，方向A→B、B→A轮换。

这是物理分离，不声称统计独立；5秒不能排除慢漂移或同次会话背景。原D1零相位滤波已做过，不能将此合同说成严格因果输入。

每个训练episode均匀选4名训练儿童，每名每条件支持32、查询32个试次，不放回；同儿童支持与查询不重叠。人数不足只减批内人数，不复制儿童伪增n。

若某主访问在分块后某方向的某条件不足32，则该方向不用作辅助训练episode；不能按其功能成绩排除临床评价。临床表示仍可由该次记录已有两类试次生成。缺少两类本身属于输入不支持，须在揭示新结果前记录。

h固定为三个前事件量：log1p(前置标准数)、log1p(前事件间隔秒)、记录内相对位置。字段若缺失，不从当前或未来标签补推：使用训练中位数＋缺失情况报告；首轮缺失掩码不额外输入网络。三个量的尺度仅在辅助训练池拟合。

## 3. 冻结人群条件响应模型

对每个条件s，令H=[1,h]，拟合多输出线性均值 m0(s,h)=H A_s。

每名儿童每条件总权重相同，w_r归一化满足每条件sum w=1：

    min_A sum_r w_r ||e_r-H_r A||² + α_pop ||A_nonintercept||²

α_pop=0.1。截距不惩罚。用FP64线性求解；方差为对应训练残差的加权逐维方差，log方差裁到[−4,3]。相同m0/v0供pooled与conditional两个摘要臂使用。

该模型只处理已定义前事件信息，不是声学因果模型，也不能解释为已去掉全部历史信息。

## 4. 两个摘要臂

### 4.1 共同结构

每试次φ(e)：32→32(tanh)→16(tanh)。

- conditional：每个条件分别求φ均值，按固定条件次序拼接成32维。
- pooled：先在两个条件各自求均值，再取二者等权平均，重复两份形成同样32维输入。

两个臂使用相同网络维数、decoder、优化器、训练步数和支持／查询。pooled不使用支持标签的分组差异，但decoder仍知道查询条件s。这个对照检验的是“支持集合按条件组织”的价值，不是比较有无全部实验信息。

拼接向量经一个线性层得到8维μ与8维log v。log v裁到[−6,2]。训练用一次重参数采样 u=μ+sqrt(v)ε，测试用μ。先验为N(0,I)。不额外加入身份分类、阶段、年龄或临床损失。

### 4.2 条件decoder

    mean(e | s,h,u) = m0(s,h) + B_s u
    logvar(e | s,h,u) = clip(v0(s) + D_s u, −4,3)

B_s为32×8，D_s同维；总规模为小型模型。m0、v0固定，B用小随机值初始化，D置零。u=0时预测应精确恢复人群模型。

不是两个生理发生器，不对B_s或u要求正交／独立，不解释潜维的符号与排序。

## 5. 损失与训练规则

对每名儿童、每个条件平均query的高斯负对数似然，再除以表示维数；条件和儿童各等权。加β/d_u倍KL，β=0.01固定。

    NLL(e) = 0.5 * sum_d[log(2π)+logvar_d+(e_d−mean_d)²/exp(logvar_d)]
    KL(q||N(0,I)) = 0.5 * sum_j[exp(logv_j)+mu_j²−1−logv_j]

总目标 = mean_child(mean_condition(mean_query(NLL/d_e))) + 0.01*mean_child(KL/d_u)。

Adam学习率1e−3，最多3000步，梯度范数裁5，FP32模型；每100步保存训练损失、查询NLL、KL、μ范数、梯度和模式状态。**固定使用第3000步，不用临床验证成绩选择checkpoint。** 数值故障停止对应单元并记录；不得跳过失败种子后只报告成功者。

模型本身无BatchNorm/Dropout；冻结f_o一直eval。任何复用的历史训练辅助函数仍需模式测试，不以“本新头没BN”替上游免责。

## 6. 推理与支持预算

临床主预测利用本主访问全部合格试次；分条件聚合，每类权重1/2，与类比例无关。按batch流式累积φ，不能将最后一个batch均值等权代替逐试次均值。

临床头每名儿童一行。不得将3000个episode、32个支持样本或多次抽样当作独立功能标签。

E3跨块预测只使用A构造u，评价B，并反向重复；与使用全部记录得到的临床u分开存储。

## 7. 临床头的统一规格

### 7.1 标签与协变量

主SIR保持1、2、3、4、5五类。次MUSS保持源表原单位（既有百分制记录为0–100）。不使用SIR>3选参数；不把SIR或MUSS互相作为协变量。

C使用年龄与log1p(佩戴月数)。主临床设计为各变量的二次B样条：degree=2，n_knots=3，include_bias=false，结点由**当前有标签训练样本**分位数拟合。若唯一值不足，用事先定义的线性回退，所有相应臂同规则。标准化、缺失填补也只在当前有标签训练集合拟合。

各EEG视图在同一有标签训练集合标准化。普通刺激条件均值用[μ_std,μ_dev]，不额外按年龄选择PCA。若需要降维，主协议统一用本外折已固定的32维试次坐标；该64维临床输入由正则化头处理。另设C_MEAN8：将每儿童64维条件均值在外层辅助训练池做无标签PCA8，随后使用相同临床头。PCA不得使用外层测试儿童或SIR/MUSS；这个变换与SRP一样可以利用固定辅助池的无标签EEG。谱使用固定D2+增强谱，不重新选波段。

### 7.2 五级比例优势模型

    P(Y ≤ k | x) = sigmoid(t_k − xᵀw), k=1..4

t1自由，后续t按softplus正增量构造，最小间隔1e−4。采用FP64稳定log概率，若实现使用概率相减则需log-difference稳定测试。

最小化平均NLL + (λ/2)||w||² + (0.001/2)sum_k(t_k−a_k)²；a_k=logit(k/5)。截距由阈值承担，不重复自由截距。λ候选[0.01,0.1,1.0]。临床和EEG系数都标准化后使用同一定义。

先验阈值惩罚仅防极稀少／缺失等级时的数值发散，不制造伪临床样本。某训练子集没出现1级或2级时仍保留五类输出，不能删除测试儿童或改成三分类。

内层3折按**平均RPS**选λ；平局取较大λ。每个λ最大400次优化迭代，收敛阈值1e−6；日志记录状态。允许经测试的旧OrdinalLogistic适配，但必须保持本目标尺度和概率定义。每次最后在本标签集合重拟合一次。

### 7.3 MUSS

正则化线性头，目标先在本有标签训练集合中心化和尺度化；损失为平均平方误差 + λ||w||²，λ候选与SIR相同，内层选MAE。闭式实现对应X'X+nλI，不是X'X+λI。返回原单位；输出裁到量表合法范围的规则对全部臂一致，另报未裁剪敏感性，不采用Tobit或创造超量表潜在分数。

## 8. RPS与聚合口径

对y∈{1..5}，F_k=sum_{j≤k}p_j：

    RPS(p,y) = (1/4) sum_{k=1}^4 (F_k − 1{y≤k})².

期望风险在每一阈值上可写为(F_k−F*_k)²+F*_k(1−F*_k)，故真实CDF使总体RPS最小。这个性质不等于有限OOF评价有自动覆盖保证。

主要风险聚合：先每儿童平均同预算下标签抽样与外层seed的损失，再跨儿童平均。**先平均损失，不先平均预测做隐含ensemble。**

    R_low = 0.5(R_12 + R_24)
    Δclinical = R_low(C) − R_low(C+SRP)
    Δmethod = R_low(C+mean) − R_low(C+SRP)

全标签风险单列。bootstrap在儿童层重抽，保留该儿童全部seed/mask预测，2000次；这是固定预测的区间。若提供两个主比较的p值，采用同一预定方法并Holm校正；不能用seed作为独立n。

五类概率对NLL共同floor=1e−6并归一化；另读存档概率以1e−8与1e−4重评分，不重训。概率AUC用P(SIR>3)，禁止把不同折的潜变量混在一起排序。

## 9. 必要消融不是新研究树

默认两个摘要臂：conditional与pooled。人群q0提供无个体摘要参照。普通条件均值与组合谱是功能基线。

不默认加入多个β、latent维数、模型宽度、新的增强、MRI预训练或Mamba。若首轮不能区分条件化作用，不自动扫参数到显著。

## 10. 参考实现的范围

`reference/srp.py`：支持集合编码、人群基线、条件decoder、儿童／条件等权的NLL+KL。  
`reference/metrics.py`：RPS、NLL、MAE口径、等儿童聚合。  
`reference/contracts.py`：身份集合检查、隐藏标签暴露检查、模式恢复。

这些文件接受已经准备好的张量或数组，不读取私有路径，不实现全部临床训练，不提交Slurm。本包用合成数据测试公式、形状、梯度、同条件置换不变性和u=0基线复现；没有验证真实临床效应。

# 实现说明模板

## 已有入口与新入口映射

列出Cohort/主访问/临床字段/试次索引/编码器/谱缓存的实际函数、路径和hash。不要复制真实姓名与临床值到公开版。

## 协议与代码差异

逐项写明为什么需要差异，是否在看到相应结果之前提出，是否影响估计对象。没有差异也写“无”。

## 必要测试

身份隔离、当前折同编码器、隐藏标签不影响表示、支持查询不重叠、类别和儿童等权、模式恢复、RPS和概率合法性、零u恢复人群q0、预算计数与断点恢复。

## 临床头

样条拟合范围、阈值参数化、目标归一化、正则定义、缺失等级处理、优化器和概率评分。

## 曝光范围

外层测试儿童是否从所有拟合排除；内层临床验证儿童的无标签EEG是否在辅助池中；历史上已探索的队列限制。

## 完成与未完成

模块可运行不等于真实实验完成。逐项标出implemented / tested_on_synthetic / tested_on_server / run_completed。

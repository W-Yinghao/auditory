# 11｜默认全量计划与运行清单说明

本清单由随包配置实际展开，所有状态都是`planned`，尚未连通真实服务器训练。
计划规模是可调整排程，不是研究结论、算力保证、固定上限或独立样本数。不能为了凑行数重复已有兼容结果。

当前有 **15个实验族、8,640条比较计划记录**。初步按计划字段得到8,520个复用签名；真正能否复用由服务器解析后的数据、模型、输入和读出provenance决定。

|---|---|---:|

## 计算类型不是同一单位

| work_type | 记录数 | 含义 |
|---|---:|---|
| full_fit | 6,960 | 一项完整候选训练/比较配置；完全相同旧结果可经核对复用 |
| staged_full_fit | 480 | 包含/引用继续预训练donor与任务适配，计算量可能多于一次fit |
| transfer_full_fit | 300 | 公共先验或teacher后的迁移训练 |
| adaptation_bundle | 900 | 一个外折模型下多名测试参与者的support适配/评价组合，不是一项独立主干训练 |

不同工作类型不能相加后宣布完成同等数量独立实验，更不能当作新增儿童。基础模型可能远慢于小CNN；本包不估计未经测量的GPU小时。

## 直接可运行的本地脚本

```bash
python scripts/make_plan.py
python scripts/dry_run_plan.py --family B_FM --index 0
python scripts/run_short_checks.py
python scripts/validate_package.py
```

上述脚本仅生成/检查计划与小型张量测试，不训练真实EEG、不下载权重、不提交作业。服务器按已有规则经Slurm运行数值脚本；文档编排和查看无需伪装成计算作业。

默认计划覆盖全部外折和三个seed。资源需分批时，按A/B/C/D并行和技术依赖排程，而非先删去表现不佳的实验族。可新增完整配方，保留提出时间和前序暴露。

所有foundation checkpoint与迁移donor在本包中仍待服务器解析；这是接入状态，不是科学阴性。

## 运行

```bash
python checks.py --out results.json
```

## 覆盖范围

检查条件预测增益的KL恒等式、固定背景项不改变梯度、只有历史的AUC、XOR条件交互、背景失配导致正增益、固定协方差高斯风险，以及平衡训练与自然分布概率的区别。

这些检查不证明条件匹配负样本来自真实条件分布，不验证真实EEG处理、C3生产估计器、神经网络收敛、模型泛化或任何临床主张。7类检查通过是数学与数值检查通过，不是完整研究实施通过。

## 1. 先披露：与预期不同或需要特别注意的结果

1. **Federici 的时间结构与 FAU/DTU 方向相反。**
   - FAU/DTU：
     - 加入晚窗显著降低早窗模型的风险，`R(E)−R(E,L)` 为 +0.22…+0.63。
     - 删去晚窗 token 后重拟合，风险上升，SB_R(L) 为 +0.20…+0.52。
     - 逐 token 可读性晚窗高于早窗。
   - Federici：
     - `R(E)−R(E,L)` 约为 0：NCE +0.011 [−0.016, +0.037]，CS +0.030 [−0.007, +0.067]。
     - `R(L)−R(E,L)` > 0：+0.053 / +0.089。
     - SB_R(E) +0.043 / +0.040，SB_R(L) ≈ 0。
     - 冻结晚−早为 −0.111 / −0.108。
   - 两者的协议窗口定义不同：Federici 早窗为 0–150 ms（6 个 token），FAU/DTU 早窗为 0–80 ms（2 个 token），晚窗起点分别为 150 ms 与 90 ms。滤波与目标也不同（Federici 为作者 2–8 Hz 缓存与包络）。因此这不是同一窗口上的直接对比。
2. **DTU 负 lag 对照不为 0。**
   - 原始负 lag 窗口（锚点前约 −203…−39 ms）的平均 gain：DTU +0.087 [+0.068, +0.106]，FAU +0.008 [+0.005, +0.012]，Federici +0.008 [−0.002, +0.018]。
   - 按解读表，这表示存在刺激自相关、零相位滤波或慢状态带来的泄漏，DTU 正 lag 的结果须相对这一基线解读（不做减法来宣称纯度）。
3. **未训练局部编码器已有相当的可读性**（NCE 面板，冻结 vs 未训练 seed 3401，早窗/晚窗 gain）：

   | 数据集 | 冻结 早/晚 | 未训练 早/晚 |
   |---|---|---|
   | FAU | 0.205 / 0.278 | 0.102 / 0.166 |
   | DTU | 0.480 / 0.670 | 0.155 / 0.273 |
   | Federici | 0.132 / 0.021 | 0.059 / 0.008 |

   - 3 个随机抽样的均值与 seed 3401 不同：FAU 略低（0.091 / 0.133），DTU 略高（0.187 / 0.314），Federici 相同。单个随机网络之间存在变异。
   - 旧基线 ALN2 与 ALN3 的冻结曲线几乎重合，例如 DTU 为 0.472/0.668 对 0.480/0.670。
4. **FAU 早窗的模型依赖与可替代性取决于跨界 token。**
   - 只删完全落在早窗内的 token（k=0,1）：MD_R 与 SB_R 都约为 0。
   - 也删跨界 token（k=2,3，样本支持延伸到约 110 ms）：MD_R +0.047 / +0.041，SB_R +0.036 [−0.005, +0.077] / +0.041。
5. **私有任务**：结果只在服务器上的私有文档中（未发布；预登记 §12 要求私有组聚合经用户批准后才进入发布）。
6. **FAU 去 ICA 敏感性。**
   - 未经 ICA 的数据上，原始早窗 gain 总体更高：0.164 [0.106, 0.222]，ICA 版为 0.125 [0.104, 0.147]。
   - CI−TH 早窗差：未经 ICA 为 −0.140 [−0.299, +0.019]，ICA 版为 −0.097 [−0.147, −0.046] {−0.173, −0.021}。
   - 按预登记，差距变化不作为清理有效的证据，也不据此称神经性。

**表注**：
- 花括号为族内同时区间；不带区间的值，其同时区间都含 0。
- 冻结−原始的 rank_gain：FAU 两个 objective 的同时区间都不含 0。DTU 除 CS 晚窗 {−0.003, +0.025} 外都不含 0。Federici 都含 0。
- 早晚交互 `(冻结−原始)_L−(冻结−原始)_E` 的同时区间在全部 6 族中都含 0（DTU 的 95% CI 不含 0）。
- 原始族的晚−早（gain）：FAU +0.081 {+0.049, +0.113}，DTU +0.213 {+0.140, +0.286}，Federici −0.160 {−0.208, −0.111}。
- 三件套的 seed 政策：NCE 为 3 个 seed 平均，CS 为 seed 3401；其余 P0 量为 seed 3401。

**按解读表的含义边界**：
- `R(E)−R(E,L)` > 0：在该模型族与训练合同内，加入晚窗降低了真实 EEG 风险。这不等于"晚窗独有信息"。
- SB 大：在这一读出类内，删去后损失的部分不能由其余 token 恢复。
- 冻结 > 原始（rank_gain 同向）：在 400 片段探针下，冻结表示更易线性读出。竞争解释：编码器训练所用的数据量与监督、原始 ridge 的估计方差、非线性。
- 早晚交互区间含 0：未见交互；不写成"两窗相同"。
- 曲线峰不称神经潜伏期，也不支持"早声学/晚语言"。

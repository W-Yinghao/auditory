# ALN3 增补 01：Federici 实体与身份更正（2026-10-10，用户批准）

**来源核实**（原始数据集元信息，而非文件夹名）：
- 原始数据中 HC-v 的 EEG 文件名为 `mat_data_cut_1001` … `1016`，与 HC 编号相同；但元信息表 `Descrittive&BehavHCCDDDHCv.xlsx` 把 HC-v 单列为第 3 组（`1vocod` … `16vocod`），带有各自的年龄与性别。16 名 HC-v 中，没有一名与同编号 HC 儿童年龄、性别一致；与任一 HC 儿童同时匹配年龄和性别的只有 1 名（看起来是巧合）。没有任何正面证据表明二者是同一批儿童。
- `Artifact` 9 条记录由数据集 README 第 6 节确认为幻影头（"Phantom Head (only Artifact activity)"），是同一幻影头的 9 次会话（`PhantomHeadJunior.xlsx`：3 个日期 × 双侧/左/右）。

**更正规则**（ALN3 起执行；ALN2 旧表保留不覆写）：
1. HC-v 与 HC 为不同身份，除非出现身份重叠的正面证据；**不做同儿童 HC − HC-v 比较**，HC-v 与 HC 只作独立组比较。ALN3 包 02 中的同儿童配对项因此不执行，记录为"前提不成立"。
2. 9 条 Artifact 会话 = 1 个幻影实体；只作声音同步污染的敏感性参照，不进入任何参与者/儿童平均、年龄模型、训练或 donor。
3. 年龄映射：旧 loader 给 HC-v 文件 `100N` 赋予 HC 儿童 `100N` 的年龄（错误）。更正为元信息中 `Nvocod` 行的年龄、性别与行为正确率（文件序号 N ↔ `Nvocod`，按编号顺序对应；元信息未直接给出文件名，此对应记为"按序号推定"）。
4. 泄漏核查：旧 loader 把同编号的 HC 与 HC-v 记录归为同一身份并放入同一外折。不同儿童被合并只会让划分更严格，不会造成训练/测试重叠；幻影头记录一直是 test_only，从未进入训练。因此**无训练/测试泄漏，不需重训** ALN2 模型。
5. 受影响的 ALN2 汇总重新生成：Federici 独立儿童数 = HC 37 + CI 33 + HC-v 16 = **86 名独立儿童**（另 1 个幻影实体、9 次会话）；HC-v 的年龄相关分析使用更正后的年龄。上一轮（核 CS）中涉及 HC-v 年龄的结果受影响，不覆写其文件，在 ALN3 报告中注明。

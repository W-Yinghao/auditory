# ALN3 Addendum 02 — family bindings, registered extensions and queue policy (2026-10-10)

Written while the affected families were being released, before any of their units produced a result. Each binding was
engineering-probed (2–3 epochs, scratch directory, mechanics only; no result was inspected for a decision). Code hashes at
release are listed; a unit records the hash it ran with.

## 1. Registered extension rows (item-3 addendum 01: 3b/3c folded into B)

`private/auditory_alignment_v3/plan_ext.jsonl` (sha256 prefix `bbc96cd30c40b27c`, 300 rows, ids `ALN3X_*`), generated by
`private/auditory_alignment_v3/make_plan_ext.py` from the frozen plan without touching it. Representative configurations, not
chosen on results: readout dense_query, objective NCE, FAU/DTU/Federici, every fold, seed 3401, adaptations pretrained_peft
and pretrained_full, both architectures.

| B_LR_PANEL | 200 | ALN3 recipe with backbone learning rate × 0.3 and × 3 (head unchanged) |

Runner `run_dense_ext.py` (group dense_ext, hash `c97ffc95db6dd0a3`). Queue indices ≥ 100000 address extension rows.

## 2. Workpackage C and local factors

* C_COMPLEMENT / C_CAPACITY_CONTROL (group complement `10c8d0f59f23c310`): base = the same-fold A_LOCAL lag_local_tokens full
  unit (same dataset, subject fold, content fold, seed, objective), frozen; zero-initialised residual in the shared target
  space. Probe: initial prediction equals the base to 6e-8. A row enters the queue only once its base is complete.
* A_LOCAL_FACTORS (group local_factors `3eb149d5684bd45f`): lag_local_capacity_control (width multiplier closest to the
  density_tokens parameter count) and local_unshared_control (per-lag rank closest to lag_local_tokens); parameter counts
  recorded per unit.

## 3. Workpackage D (lag_local_tokens arms)

The dense_fm_policy / complement_policy arms need the training-side model policy of B / C and are not bound yet.

* D_ADAPT (group adapt `f029aabd1ea656c1`): base = same-fold A_LOCAL lag_local_tokens full unit, frozen; adapters none /
  input_spatial (C×C, identity init) / output_low_rank (rank 4, zero init); support = first 10 % or 30 % of a test
  participant's segments in recording order, query = last 70 %; steps from {20, 50, 100} chosen on training participants'
  early-stopping content (ALN2 C_ADAPT rule on the dense grid).
* D_COVERAGE (group coverage `31129b3539ef647f`): each unit trains full_available (all training participants of the
  population) and matched_exposure (same pool; optimizer updates per epoch and cosine length capped at the TH_ONLY count of
  the same fold). Primary eval = full_available; both recorded. Trainer `coverage_train.py` is generated from local_train with
  three declared substitutions.
* D_ATTENTION (group attention `988bda85c8d8e404`): training_task attended_alignment / selection_only /
  alignment_plus_selection (selection weight from {0.1, 1.0} by early-stopping 2AFC accuracy, the ALN2 rule); evaluation adds
  attention windows of 5 / 10 / 20 s (1 / 2 / 4 consecutive segments of one trial) with mean_score and learned_temporal
  integrators. **The integrator is an evaluation-time choice: the mean_score row trains the model and evaluates both
  integrators; the learned_temporal row is a derived record of that model (`shared_model_with`).** This makes the integrator
  comparison paired and avoids training the same configuration twice.

## 4. Private dependent families

* E_COMPLEMENT (group e_complement `910cbe21fafe0d9c`): logit space; base = same-fold E_LOCAL lag_local_tokens full unit,
  calibrated native score (positive affine on training children's early-stopping blocks); context branch CBraMod / REVE
  (pretrained_frozen | pretrained_peft | random_full) on the padded private epoch → ChannelSpatialProjection → zero-initialised
  residual on [u_base; context]; BCE on training children's fit trials, ALN3 recipe (warm-up, unfreezing, LLRD), per-epoch
  early-stopping-block BCE, one positive affine recalibration. Probe: initial logit equals the base exactly.
* E_DISTILL (group distill `0b8fecf567651371`): the package specifies distillation_targets = task_output_distribution, so
  the student matches the teacher's calibrated class probability: loss = task objective + λ·BCE(σ(student logit), p_teacher)
  (= KL + teacher entropy). Trainer `distill_train.py` is generated from ALN2 `distill.py` with nine declared substitutions.
  Teacher candidates (same outer fold, seed, objective): local_teacher = E_LOCAL whole-epoch units (window full or joint,
  every local architecture); generic_pretrained_teacher = E_GENERIC pretrained_{frozen,peft,partial,full} × {CBraMod, REVE};
  auditory_adapted_teacher = ALN2 D_FM_PUBLIC auditory_pretrained_peft; legacy_full_teacher_control = ALN2 D_FM_PUBLIC
  auditory_pretrained_full. Choice = minimum recorded best_selection_score, made only when **all** candidates are complete
  (never by completion order). λ ∈ {0.1, 1.0} chosen by the student's own selection score; λ = 0 is trained and evaluated in
  every unit as the baseline.

## 5. B_LAYER_PROBE (group layer_probe `839a50064c064715`; released after its probe)

Frozen CBraMod / REVE; layers bound to the real architecture: patch_embedding = input of block 1, middle = output of block
n/2 (6/12, 11/22), last = backbone output. Probe = the package ChannelPhaseLinearReadout form fitted in closed form: z-scored
channel×feature tokens → PCA 256 (300 training segments; the reference starting point) → phase basis (TimeFeatures(4),
Gaussian patch weights 0.75 s) + intercept; 16 grid queries per training fit segment; ridge alpha on early-stopping segments
by mean per-dimension correlation, refit on fit + early stopping. Native readout for evaluation = the CS_SINGLE regression
readout. All three layers reported; none selected.

## 6. Queue policy (resource order only; no performance gate)

Breadth seed before panel seeds; within a seed scope, round-robin across bound families so every family progresses
(C starts alongside B). Within each family, dependency feeders come first: A_LOCAL / E_LOCAL lag_local_tokens full bases (C,
D_ADAPT, E_COMPLEMENT) and E_GENERIC seed-3401 pretrained units (E_DISTILL generic teacher). Every foundation-model unit
uses a whole GPU (user, 2026-10-07); E_DISTILL (small student; brief teacher forward pass) shares a card at weight 12.
Engineering probes run at nice 0, pool workers at nice 50.

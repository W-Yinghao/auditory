## 3. lag 网格、时间支持与固定名称

**token 的样本访问支持**以编码器 `br.offs` 为准：
- FAU/DTU full（128 Hz）：token k 读锚点后 `[3k, 3k+5)` 个样本，k=0..24。
- Federici full（100 Hz）：`[2k, 2k+4)` 个样本，k=0..28。
- 私有 full（250 Hz，以刺激为零点）：`[5k, 5k+10)` 个样本，k=0..28。

**原始曲线**用与 token 完全相同的样本切片，取自同一 fp16 舍入的 EEG。

**负 lag 对照**只用于原始曲线，同宽同步长：
- FAU/DTU 8 个，起点 −26…−5 个样本。
- Federici 9 个，−20…−4 个样本。
- 私有 9 个刺激前窗口，起点 −200…−40 ms。
- 工程检查 E2 核对这些切片不越过试次、块或 epoch 的起点：FAU 起始保护 314 个样本，DTU ≥64，Federici 块内起点 20，私有 epoch 样本 0。

**每张图和表都须标注**：
- 目标是从锚点起的 8 帧窗口（128 Hz 为 62.5 ms，100 Hz 为 80 ms），因此偏移 o、宽 w 的 token 对应"刺激→EEG"滞后 `[o−7, o+w−1]` 个样本。
- 零相位滤波：FAU/DTU 的 EEG 为 1–20 Hz，90% 能量半宽约 ±25 ms；目标为 1–8 Hz，约 ±78 ms。Federici 一律标注"作者 2–8 Hz 缓存上的窗口受限读出"（滤波器未知）。私有 EEG 为 0.5–45 Hz。
- 相邻 lag 窗重叠：FAU/DTU 40%（w=5、步长 3），Federici 与私有 50%；它们不是独立采样点。
- **所有 FAU 曲线**：stage-B 的 ICA 对每个组用同一规则，去除了 1–8 Hz 包络互相关峰在 ±3 个样本（±23 ms）内的成分。FAU 早窗 token（k=0,1，滞后约 −55…+31 ms）与负 lag 对照都受此规则影响。
- **P4 的 Ac/Lz 曲线**：目标是全窗自注意的 Whisper 状态，带有非因果上下文。
- Federici 最早的负 lag 窗（−20 个样本）恰好读到每块的第 0 个样本，作者的滤波器未知，标注为"触及块起点"。
- 不称"信息时间进程"，曲线峰不称神经潜伏期。

**图表固定名称**：
- **冻结群体编码器局部探针曲线**（P0/P1/P3/P5）：输入严格局部，权重由全部 lag 共享训练。

- **模型依赖 MD**：统一读出与温度固定。
- **可替代性 SB**：编码器固定，只重拟合读出与温度。

## 4. 逐 lag 读出与指标（同一数据集内，所有 lag、所有特征集用同一规则）

### 4.1 连续任务（FAU、DTU、Federici）

沿用 ALN3 评价的统一读出与检索协议（`auditory_alignment/evaluate.py`），只把表示 `u` 换成逐 lag 特征。

**特征集（每个 lag）**：
- 冻结：`h_k = token_k − pos_k`，32 维。
- 原始：`C×w` 维切片（FAU 155、DTU 320、Federici 128）。
- 原始 PCA-32（P6）。
- 未训练 token（P2）。

**训练行**：与该单元原评价相同的 400 个训练参与者 fit+es 片段，按原调用顺序从 `default_rng(seed+1000)` 抽取。目标为原始 8 帧目标窗，用训练行的均值和 SD 标准化。

**ridge（带截距）**：
- `alpha = λ × tr(XcᵀXc)/p`，`λ ∈ logspace(−4, 4, 17)`。
- 在 es 行上以逐维 Pearson r 的均值选 λ。若最优 λ 在网格边缘，按 ×10 向外扩展，最多到 1e±8。
- 选定的 λ（与尺度无关）用于 fit+es 上的重拟合，alpha 由 fit+es 的 Gram 重新计算。
- 在相关准则下，λ→∞ 与 λ→0 时选择量都会进入平台，所以落在边缘是预期内的、无害的，只记录不处理。
- 每个 lag 记录 λ 与是否在边缘。

**打分、温度、测试集**：同原评价。
- 统一分数为重建相关。
- 温度在训练参与者的 es 查询（≤300）与 es 候选池上逐 lag 标定。
- 测试为 held-out 参与者 × 测试内容，查询为 ss 片段；错配 EEG 为记录顺序上的前一段（循环：第一个查询取最后一段）；困难池 K=8。

**每名参与者的指标**：
- **主指标** `gain_bits = logloss(错配 EEG) − logloss(真实 EEG)`，单位为比特/5 s 查询。gain 是"对应敏感性"，不是预测增量。
- 次指标：真实 logloss（即风险 R）、top-1、top-5、MRR、rank_pct、`rank_gain`（与温度无关）、`hard_gain_bits`。

**原始、P6 与负 lag 曲线**不依赖 objective：每个（数据集、内容折、外折、seed 3401）只计算一次，在主要量中也只列一次。

**温度偏差与维数有关**：读出在训练参与者上重拟合，温度也在同一批参与者的 es 查询上标定，这种样本内乐观随特征维数增大（原始 128–320 维，冻结 32 维），会使温度偏小、使冻结−原始的 gain 差对原始不利。因此冻结−原始、冻结−P6 的比较以与温度无关的 `rank_gain` 为共同主量；只有 `rank_gain` 方向一致时才解读 gain 或 R 的差。

**与原评价的两处偏离**：
1. 相对 alpha 网格加边缘扩展。
2. 用逐 lag 特征代替 `u`。

管线由第 10 节 E1b 验证。

### 4.2 私有任务

- **试次与标签**：`data.load_private()` 的全部试次（与 E_LOCAL 训练、评价同一集合），标签为 current_class。
- **分折**：已存的 5 折儿童分配。
- **拟合与评价范围**：读出只在训练儿童的 es 块上拟合，在测试儿童的全部试次上评价。

**特征**：
- 冻结：`h_k`，32 维。
- 原始：`x[:, :, 50+5k : 60+5k]`，20 通道 × 10 样本，取 fp16 舍入后的副本（与 `PrivateBatcher.Xall` 的取值相同）。k=−10..−2 为刺激前对照。

**读出**：特征在训练侧标准化，L2 逻辑回归 C=1。原始参照另报在全部训练试次上拟合的敏感性。

**每名测试儿童的指标**：
- AUC（免校准）。
- 用训练 es 上拟合的正斜率仿射校准后，计算自然 NLL（比特/试次，风险 R）、Brier，以及相对训练基率的 gain。校准斜率下限为 1e−8：方向反了的格（TG 离对角或遮挡后）会出现 AUC<0.5 而 NLL≈先验熵。

**历史条件版**：
- **主量** `R(q_hist) − R(q_hist+EEG_k)`，在自然分布、全部试次上计算：模型 `q_hist+EEG_k = sigmoid(logit q0[bin] + [1, h_k]·w_k)` 在训练 es 上拟合，q0 表来自训练儿童。
- `h_k` 与原始特征先按训练 es 标准化，再进入 `_fit_offset_logistic`（L2，C=1，截距不惩罚）。原始特征同样做历史条件版。
- 共同支撑（0.01<q0<0.99）为次要量，同时报告支撑比例。
- **孪生对应敏感性**：孪生读出在训练 es 的交换 EEG（同记录、同 bin、不同物理块；无其他块时退回同 bin）上单独拟合、在测试交换 EEG 上评价，取真实 EEG 增量与孪生增量之差。报告每名儿童的 `swap_strict_fraction`。不称增量、精确 CMI 或纯当前声音信息。

组别、年龄、时长、阶段一律不进入任何读出或选择。

## 5. 模型依赖与可替代性（S1c；P0 与 P1）

**窗口 token 集与跨界 token**（窗口见第 6 节）：
- 窗口 token 集 = 样本支持完全落在协议窗内的 token。
- 跨界 token：FAU/DTU 早窗 k=2,3、晚窗 k=3,12；Federici k=6,7；私有早窗 k=5,9、晚窗 k=11,15。
- 写法为"删去完全落在早窗内的 token"，不写"删去早窗"。
- 另报删去所有与窗相交 token 的 MD_W、SB_W 作为敏感性。

### 5.1 连续任务

- **MD**：
  - 把 token k（或窗口 token 集）换成它在训练行上的均值（含 pos），经该单元自身的 LayerNorm + Linear + L2 归一化（即 `TokenEncoder.forward`）得到 `u′`。
  - 沿用在未遮挡 u 上按第 4 节规则拟合的读出和标定的温度，原样应用。
  - 指标：主量为风险增加 `MD_R = R(遮挡) − R(完整)`（真实 EEG 的 unified logloss，同一查询、候选池、目标），次量为 `MD_G = gain(完整) − gain(遮挡)`。
- **SB**：训练、es、测试三组都删去，读出与温度按同一规则重拟合。主量 `SB_R = R(删去后重拟合) − R(完整)`（docs/04 第 25 行"删窗后重拟合的真实 query 风险差"），次量 `SB_G`。
- 每个 lag、每个窗口集都计算两者。

### 5.2 私有任务

- **MD**：原生分数（NCE 原型余弦差 / CS 类核对数几率）。CS 的核参考集（训练儿童 es 块上以 seed+77 抽取的 ≤6000 个**未遮挡** u）、基率与 σu（单元记录 `objective_calibration.sigma_u`）全部固定，只替换测试儿童的 u；NCE 原型固定。在训练 es 的未遮挡分数上拟合正斜率仿射校准后固定。报 ΔAUC 与 ΔNLL。通道遮挡用同一规则。
- **SB**：在标准化 `u` 上做逻辑探针（训练 es），训练与测试都删去后重拟合；ΔNLL 用探针 logit 在训练 es 上拟合的正斜率仿射校准。

**窗口到 token 的映射**（只取样本支持完全落在窗内的 token）：

窗口汇总 = 每人在窗口内各 lag 上的指标均值。早窗只有 2 个 token、晚窗 8 个，两者的 token 数不同。

**时间泛化（TG）**：
- 范围：只在同一分支内做，包括 full 模型（P0、P1、P2）、原始参照，以及 P5 early、late 模型的窗内 TG。
- P5 的窗内 TG 与 full 模型限制到同一窗口 token 集的 TG 块并列，作为 docs/13 第 25 行的 TG 敏感性。
- 读出固定：在 τ 拟合的读出（包括其标准化和 PCA）固定，应用于 τ′ 的特征，查询、候选与标签不变。
- 连续任务：
  - 主格值为两个并列矩阵：真实 EEG logloss 风险矩阵 `R[τ,τ′]`，以及对应敏感性矩阵 `G[τ,τ′]`（gain）。温度在 τ′ 的训练侧 es 上重新标定（单个标量），对角线即 S1a。
  - 次格值：与温度无关的 `rank_gain`。
  - 温度固定为 τ 的版本放在附表报告。
  - G 的差标注为"对应敏感性之差（温度按同一训练侧规则逐 τ′ 标定）"，不称预测增量或独有信息。
- 私有：AUC 矩阵，以及在 τ′ 的训练 es 上重新校准后的 NLL 风险矩阵。EEG-only 的 TG 中不注入历史。
- 预定块汇总（每人，在 R 与 G 上都报）：
  - `D_E`、`D_L`：早、晚窗的对角均值。
  - `G_EL`：τ∈早、τ′∈晚 的均值；`G_LE`：τ∈晚、τ′∈早 的均值。
  - 泛化落差 `D_E−G_EL`、`D_L−G_LE`。
- 比值只作描述。分母的 CI 含 0 时写"比值不可解释"，并给出分子与分母。
- 解读须附说明：full 编码器用全部 lag 训练，TG 是冻结表示上的时间读出，不是原始信号跨时间训练的独立证据。

**Q4 窗口三件套**：
- 数据来源：直接读 P5 与 P0 的单元记录（不重算），按同样的身份聚合。单元记录用的是原评价的读出（无边缘扩展），不与第 4 节曲线相减。
- 连续任务：
  - 主量为真实 EEG logloss（`unified/regular/logloss_bits`；native 为次要）差 `R(E)−R(E,L)`、`R(L)−R(E,L)`，同一测试池、同一目标。R(E,L) 取 P5 joint 单元；P0 full 只并列报告（`R(E,L)−R(full)`）。
  - 各窗的 R 与 gain 作描述。
  - NCE 用 3 个 seed，CS 用 seed 3401。
  - P4 目标（Ac、Lz）各自另给一套。
- 私有：用存档的正斜率仿射 NLL（风险）与 AUC。

## 7. 空间读数（S3）

**(a) 原始逐 lag 线性读出的 Haufe 模式**：
- 连续任务：`A_τ = Σ_X B (Bᵀ Σ_X B)^+`，`Σ_X` 取训练行。通道摘要 = 对样本和输出维取均方根，归一到单位 L2 范数，再对窗口内的 τ 平均。
- 私有任务：`A_τ = Σ_X w / (wᵀ Σ_X w)`，在输入空间（z 标准化 EEG 单位；w 为标准化空间的权重除以训练侧 SD）计算，给出带符号的 [20×10] 图与通道均值。

**(b) 第一层空间滤波**：`lag_local` 的第一层 Conv1d(C→16, k=1) 是纯线性的，下一层也是线性的，所以这组滤波器只在可逆混合意义下可识别。摘要用每个通道的方差中可被 16 个滤波输出解释的比例 `diag(Σ W1ᵀ (W1 Σ W1ᵀ)^+ W1 Σ) / diag(Σ)`，它对任何可逆混合不变；`Σ` 取训练行 EEG，每个样本只计一次。激活模式 `A1 = Σ W1ᵀ (W1 Σ W1ᵀ)^+` 只存档。

**(a)(b) 的估计对象**：都是模型层面的量，因为读出与滤波都在合并的训练参与者上拟合。按数据集 × objective 报跨单元的均值与范围，不做身份 bootstrap，不分组。

**(c) 通道遮挡敏感性**（P0）：
- 测试时把通道 c 在整个输入窗内置 0。EEG 按参与者、按通道在该参与者全部载入试次（含测试试次）上 z 标准化，所以 0 即该参与者自身的通道均值，不是训练侧均值。平均参考使通道线性相关（FAU 秩 30）。
- 读出、温度、校准都固定。
- 每名测试参与者得到一个值 Δ_c，用于分组描述，并给跨通道的 max-t 带。

**通用规则**：
- 保留通道身份，标注重建、插值或移除的通道。
- 不称头皮发生源，不作源定位（W02）。
- 通道图不集中在颞区，不构成失败或通过。
- 私有数据所得的一切空间模式（含组平均）只放 `private/`。

## 8. 汇总与推断

**聚合顺序**：
1. 单元内逐参与者计算。
2. 跨该参与者的单元平均（FAU/DTU 两个内容折；P3 跨 seed）。
3. 汇到身份：Federici 由记录汇到主体，儿童等权。
4. 汇到组。

**bootstrap**：
- 在各组内按身份有放回重抽，B=4000，seed 20261011，整条曲线或整张矩阵一起重抽。
- 区间用逐重抽学生化的 bootstrap-t（固定 SE 的 max-t 在 n=9–22 时覆盖不足）：
  - `se_hat = sd(Y)/√n`；每次重抽 `se* = sd(Y*)/√n`（下限 1e−3·se_hat）；`T* = |m* − m_hat| / se*`。
  - 标量与逐点区间：`m_hat ± q95(T*)·se_hat`。
  - 曲线带：`m_hat ± q95(max_l T*_l)·se_hat`，逐 lag（含负 lag 段）。TG 矩阵对全部 (τ,τ′) 格、通道遮挡 Δ_c 对全部通道取最大值。
  - 独立组差：`se = √(se_a² + se_b²)`，两组分别重抽。OLS：每次重抽的经典系数 SE。
  - 百分位区间作为次要列保留。
- 区间以已拟合的模型为条件；训练随机性另由 P3 报告。

**主要（预定）量**（每个数据集 × objective 分开，NCE/CS 不合并）：
- **(a) 时间结构三件套**（docs/04 第 25 行）：
  - P5 各窗独立训练的真实 query 风险 R(E)、R(L)。
  - 联合增量 `R(E)−R(E,L)`、`R(L)−R(E,L)`。
  - P0 删窗后重拟合的可替代性 SB_E、SB_L（风险 R 上），同表并列 MD_E、MD_L 并标为模型依赖。
- **(b) 逐 lag 探针的窗口差与交互**：
  - 冻结、原始曲线各自的晚−早。
  - 冻结−原始，每窗一个值；以 `rank_gain` 差为共同主量，同时报 gain 与 R 的差。
  - `(冻结−原始)_L − (冻结−原始)_E`。
  - 原始曲线不依赖 objective，在族中只列一次。
- **(c)** 第 9 节预定组对的组 × 窗口差之差（S4 族）。

**规则**：
- 早窗、晚窗各自的均值是主要描述量：给 CI，不进入多重比较族。
- 任何时间结论须同时引用 (a) 的三项；仅凭 (b) 的事后受限读出，不得单独构成时间结论。
- 完整 lag 扫描、TG 格值、通道图、MD/SB 逐 lag 曲线、负 lag 逐点值都是探索量。

**多重比较**：
- 主要量按"数据集 × objective"各成一族。同时给未校正 95% CI 与族内 max-t 同时区间（逐重抽学生化；同一组在族内各成员间共用相同的重抽下标，以保留成员间的相关）。
- TG 块汇总另成 TG 族；S4 组间、发育、功能各成一族。
- 族成员在冻结时固定，不按结果增删。

**幻影（Artifact）**：
- 9 次会话由每个 Federici 外折单元评分，按会话平均后报逐会话值、均值与范围。
- 不给 bootstrap 区间或同时带，不作零分布，不从人类组中减去。
- 只说明 Federici 采集链的伪迹可读性，不外推到 FAU CI。

**计数与内容支持**：每张组表报身份数、记录数、测试内容组数、查询数，以及各组之间测试内容的重叠。

**缺失值**：非有限值或缺失一律不静默丢弃，逐项列出原因，报告实际计数。

| 某些 lag 的冻结曲线同时带不含 0 | 已学表示在这些 lag 线性可读；不是神经潜伏期，不是窗独有信息 |
| 早窗（FAU/DTU k=0,1；Federici k=0..5）可读 | 协议早窗 token 线性可读。k=0 对应刺激→EEG 滞后约 −55…+31 ms，目标零相位滤波扩散约 ±78 ms，含非因果滞后与滤波泄漏；不称早期听觉成分，须与负 lag 对照并列 |
| 晚−早 ≠ 0 | 两窗 token 的平均可读性不同（事后受限读出）；不是"信息更多"或成分身份；受滤波、重叠与 token 数（2 对 8）影响；须配三件套 |
| `R(E)−R(E,L)` > 0 | 在该模型族与训练合同内，加入晚窗降低了真实 EEG 风险 |
| `R(L)−R(E,L)` > 0 | 同上，方向为加入早窗 |
| 联合增量含 0 或 < 0 | 未见联合降低风险；不写"另一窗无额外信息"；可能是优化、正则化或容量竞争 |
| 冻结 > 原始（同 lag、配对） | 在 400 片段探针下，冻结表示更易线性读出。竞争解释：编码器用全部训练片段有监督训练（数据量差）、原始 ridge 的估计方差（看 PCA-32 与 λ 边缘）、非线性。这是 G 的配对差，不称独有信息 |
| 原始 > 冻结 | 编码器在该 lag 的冻结 token 上线性可读性较低，或原始的维数优势在起作用（看 PCA-32）；不等于完整模型丢失了该信息（对照 MD/SB） |
| 冻结 ≈ 未训练 | 在探针下未见训练带来的差异；不证明可读性来自结构，也不说明训练对完整模型无用 |
| 负 lag 对照 > 0 | 存在刺激自相关、零相位滤波或慢状态带来的泄漏；正 lag 结果须相对这一基线解读，不做减法来宣称纯度 |
| 负 lag ≈ 0 | 不证明正 lag 无泄漏 |
| 私有刺激前窗口 AUC > 0.5 | 序列历史或期待可以预测类别；不做减法来宣称纯诱发 |
| MD 大而 SB 小 | 完整模型用到了这些 token，但重拟合后其他 token 可以替代；"冗余"只相对于这一读出类与固定的编码器 |
| SB 大 | 在这一读出类内，删去后损失的部分不能由其余 token 恢复；不等于绝对意义上的窗独有信息 |
| 各窗独立训练也可读 | 单个窗口就足以学到可读的表示 |
| TG 宽（离对角接近对角） | 读出结构在 lag 间共享；对冻结 token 可能来自共享权重与慢成分；须对照原始参照；附第 6 节关于全部 lag 训练的说明 |
| TG 窄 | 读出结构随 lag 改变，或信噪比、标度、各 τ 选定的 λ 不同；不证明存在独立发生源 |
| `G_EL ≠ G_LE` | 不推断信息流方向 |
| 组间曲线形状或峰位不同 | 不称潜伏期延迟，不设 CI 延迟通过线 |
| 组差 | 描述同模型、同任务下的差异；不作设备因果解释 |
| 组差区间含 0 | 不写"各组相同"或"设备无影响" |
| HC-v − HC | 两个独立组，声码器与身份混杂；不是声码器效应 |
| 年龄斜率区间不含 0 | 关联，不是成熟度或因果 |
| 年龄斜率区间含 0 | 本样本与本读出下未见斜率；不能写"发育无作用" |
| 阶段分箱差 | 年龄与时长混杂；NH 不是"0 个月" |
| 功能关联 | 不是临床预测改善；区间含 0 时不写"无临床信息" |
| 孪生对应敏感性 > 0 | 以所设背景模型为条件；不是 CMI |
| 私有 EEG-only AUC > 0.5 而历史条件增量 ≈ 0 | 可读成分可能来自序列历史，而不是当前声音 |
| NLL 改善而 AUC 不变 | 只是校准改善，不是信号更强 |
| 私有 TG 离对角或遮挡后 AUC<0.5 而 NLL≈先验熵 | 读出方向反转；正斜率校准把它压到先验，不是"无影响" |
| ALN3 − ALN2 | 训练合同的整体差 |
| Δ_c 小 | 可能是邻近通道冗余 |

**禁止的说法**：
- 时间与发生源：神经潜伏期；源定位；独立发生源；"早声学/晚语言"；"信息时间进程"；窗独有信息或"早窗独有证据"；dense 曲线称局部。
- 指标：把 gain_bits 称为信息量或互信息，或跨数据集合并绝对比特；精确 CMI；校准改善称信号更强。
- 样本与统计：把 seed/折/会话当作新样本；把幻影会话当 9 个实体；以作业数或 seed 数称"已试尽"；把 3401 单 seed 写成三 seed；"一组显著、另一组不显著"。
- 名词互换：把探针当上限；把模型依赖称为可替代性（或反过来）。
- 发育、设备与临床：成熟度或发育迟滞；设备、验配或经验的因果作用；NH = 0 个月；MMN、变化检测或 P300 机制；听觉理解；康复指标；临床诊断、临床预测改善或"纯神经来源"。
- 目标与组别解释：Ac = 声学、Lz = 语言或纯语义；HC-v − HC = 声码器效应；CI–TH 差距缩小 = 伪迹已去除，或清理后仍低 = 神经性。
- 通过线：CI 延迟、TRF 峰与解码峰的距离作为通过线。
- 弱结果：写成"无 EEG 信息""无发育作用"或"天花板"。

任何"无收益"或"未见"的句子，须写明配置、任务与人群。

## 12. 计算与输出

**计算**：
- 只用 CPU：Slurm 的 `CPU` 或 `cpu-high` 分区，不占 fleet 的 GPU 名额。
- 环境：`PYTHONDONTWRITEBYTECODE=1`，线程数固定。
- 每个作业加载一个队列（数据集 × 内容折）后处理该队列的单元。FAU 的未经 ICA 版本按内容折单独作业。

**代码**：
- 新模块 `auditory_alignment_v3/sci_r1/`，不注册到 FAMILY_CODE，不改动任何计入代码哈希的文件。
- 测试放在 `tests/auditory_alignment_v3/test_sci_r1_*.py`。

**输出**：
- **`private/auditory_alignment_v3/sci_r1/`（0700）**：
  - 逐人数据：逐查询分数、逐人曲线与矩阵、散点与逐人曲线图、逐人的插值通道清单。
  - 模型派生物：读出权重、温度与 λ、全部空间模式。
  - 其余：检查输出、私有的逐折与逐单元量。
- **`results/auditory_alignment_v3/sci_r1/`**：
  - 仅组层面的聚合。
  - 私有任务的组聚合放 `results/auditory_alignment_v3/sci_r1/private_agg/`（0700），未经用户批准不进入发布候选。
  - 私有数据所得的空间模式（含组平均）不进 `results/` 或 `docs/`。
- **披露规则**：
  - 不报逐折儿童数；n<5 的格只报 n。
  - 年龄三分位边界取整到 6 个月（Federici 取整到 0.5 岁）；不报个体年龄。

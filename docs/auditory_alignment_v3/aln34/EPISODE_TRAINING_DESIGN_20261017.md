Each source (inner and outer) gets two100-update continuations from identical weights:

1. Ordinary group ERM: draw one source-training person each update, compute the NCE query objective using the unadapted encoder. Training people vary across updates.
2. Source-person episode: same person/support/query draw, fit a newly zero-output rank4 spatial adapter on the first30% of this person's source-fit segments for3 Adam steps, then take the encoder gradient of NCE on the fixed last70% queries through that fitted adapter. Adapter weights are treated as constants for the outer gradient (first-order; no higher-order derivative). Reset the adapter each episode.

The ordinary control performs the same3 support-adapter steps as sham computation and discards that adapter before query prediction. Both have the same source exposure, selected query anchors,100 encoder updates and support computations. Only the episode query gradient passes through the fitted adapter. This is not conventional mixed-person-in-one-batch ERM, and equality of update counts does not guarantee exactly equal FLOPs/wall time; record both. All model parameters receive gradients from the first continuation update. Both models stay in eval mode during gradient computation so dropout/running-stat changes cannot distinguish regimes.

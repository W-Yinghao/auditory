# S34_PRIVATE calibration diagnosis — exploratory analysis note

Written on 2026-10-17 before computing this comparison. Already seen: E_MULTI_SEED_RESULTS v3, including the REVE CS_SINGLE NLL outliers and stable AUC, and its proposed self-matching mechanism. Also seen: the completed D analyses, the latest TF–local paired summary and record-level complement findings. This is a result-informed diagnosis; it does not replace the registered private E endpoints or their historical values.

Stage 1 reads all 120 completed CS_SINGLE panel records: 90 E_GENERIC (CBraMod/REVE × random_full/pretrained_peft/pretrained_full × 3 seeds × 5 folds), 15 E_LOCAL and 15 E_PUBLIC_TRANSFER lag_local_tokens/task_partial. For every child, compare the stored class_kernel and positive_affine NLL and Brier, the native score AUC, and gain relative to the same training base rate. Positive NLL difference = positive_affine minus class_kernel, so positive means calibration made the loss worse. Report all eight configurations and all seeds; do not select only outlier seeds. Average within child across the three seeds, then bootstrap children (B=4000, existing bootstrap-t; max-t across eight configurations separately for each endpoint). The 64 children remain n=64. Intervals condition on these fitted models. Fold-level slopes and score scales are descriptive; folds and seeds do not create independent people. Check row/code provenance, identical identity sets/trial counts, unchanged score AUC and matching implied base entropy before aggregation.

Stage 2 will evaluate the same 120 frozen checkpoints under a new evaluation version, without training an encoder or selecting models. On training calibration trials, remove only that trial's own reference-kernel contribution when it was selected into the reference bank. Retain all other reference entries and the original pseudocount, random selection, bandwidth and training base rate. Fit the same positive-slope affine calibrator on the corrected training scores. Test-child scores use the unchanged full training reference bank. Record the old and corrected calibration curves, their parameters and per-child metrics; store per-trial scores privately. AUC of the same test score must be unchanged. This isolates a calibration self-match intervention but does not remove all dependencies between the reference sample and calibration sample or prove out-of-sample calibration. Nested cross-child calibration is a separate possible intervention.

Before reporting Stage 2, reproduce the original scorer from the frozen checkpoint and retain explicit original-device versus current-device provenance and numerical differences. Failed reproduction is a technical diagnostic, never silently a negative scientific result. Evaluate all registered units; no deletion, seed filtering or test-set fallback. GPU work uses Slurm runfill and the project-wide ten-GPU cap. This diagnostic is below the public-prior probe and ongoing true-full panel in scheduling priority.

Outputs: a new PRIVATE_CALIBRATION_DIAGNOSIS.md and aggregate JSON; private per-child tables and unit provenance. The existing E report is retained and linked.

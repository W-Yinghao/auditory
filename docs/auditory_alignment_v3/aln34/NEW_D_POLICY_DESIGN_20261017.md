# ALN3.4 independent-person adaptation policy, v1

2026-10-17, recorded before new policy outcomes. Known results: legacy local D input-spatial hurts DTU at 10% support but improves it at 30%; CBraMod matched true-full beats same-access L1 on the completed DTU three-seed panel. Existing D records and their true-risk correction remain unchanged.

Start on DTU, where all outer source pairs exist: L1, CBraMod pretrained/random (3e-4) and representative REVE pretrained (1e-5), all ten outer person/content cells and seeds 3401/3407/3413. This gives 120 bundled evaluation units. Legacy L0 D remains a separately labelled comparator; it is not relabelled as a new nested-policy arm. No full architecture/loss/adaptation cross-product is added.

Each unit needs its original completed outer source and the independently trained inner source registered in data_inner_v1. The inner source excludes both outer-test identities and inner-development fold (outer+1)%5 from encoder fitting, checkpoint selection, target-statistics fitting and readout fitting. Inner policy development uses only those inner identities' original source-ES content, never outer-test content. The matched outer source supplies the refit for final outer evaluation. This is one prespecified inner split per outer fold, not exhaustive inner cross-validation.

Adapters are identity/zero initialized: none, diagonal spatial scaling, rank-4 spatial residual, full spatial matrix, rank-4 output residual and a shared three-tap temporal residual inside the declared accessible EEG window. The frozen base stays in evaluation mode even while the adapter learns. Select steps separately for each adapter and support fraction from 0/20/50/100, using mean **true native NLL** across all inner-development identities with valid support/query. Ties choose fewer steps. The independent zero-step candidate is always retained; no outer-test fallback is allowed. Report every fixed candidate on development and only the selected policy plus the unadapted baseline on outer test.

Support is the first 10% or 30% of the original source-ES/deployment-test segments in physical order. Query is the same last 70% for both. Training uses only known support audio targets, never query audio as decoder input. Drop support training anchors whose actual EEG window would reach the first query segment. This direct sample-access guard does not reverse the historical noncausal preprocessing filter; that limitation is recorded and needs a separate filtering/history sensitivity. Record both requested support segments and actual eligible anchors.

Support optimization uses eight fixed grid-spaced anchors per segment starting at offset zero, sampled without replacement up to 256 anchors per step. This differs from the old D random-phase recipe and is stated as part of this new policy version, not retroactively attributed to one factor. The same eligible anchors, seed and training schedule are shared across adapters within a source/support cell.

Training-side native/unified readouts and their temperatures remain fixed to the base source, fitted on source-training fit/es only. Positive benefit is base true query loss minus adapted true query loss. Preserve mismatch gain as a separate diagnostic. Candidate audio pools, query identities/order, head and temperature are identical before/after adaptation. The selected steps, parameter count, adapter changes, actual support/query access and source hashes accompany every unit. Report native and unified endpoints separately, identity-level seed means, actual paired coverage and simultaneous intervals across adapters/support fractions; seeds are not new people.

Episode training is a separate subsequent intervention. This policy evaluation does not claim its source models were trained to be adaptation-ready. Broadening beyond DTU and adding auditory-prior sources uses explicit new dependencies after their source records exist; weak performance is not an entry gate.

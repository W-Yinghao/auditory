## 0. 更正

我在对话中说"TCS 把三个声学视图混在一个核里，核质量大的视图会主导"，这是错的。现行 TCS（`aln41/temporal_objectives_torch.py`）的做法是：
- 每个视图（env / ss / sc）各有一个 32 维投影头，各算一个 CS 项；
- 损失取三项的等权平均（`objective_loss`：`torch.stack(values).mean()`）；
- THSIC 需要质量校正，是因为 HSIC 不具备尺度不变性，和视图混合无关。

W4 的结果也不是单纯的"稀释"，而是一种权衡：
- 只用 env 时，DTU 包络 r 更高（0.089 对 0.079）；
- 但 FAU 历史残差 r 更低（0.042 对 0.049）。

所以 W7 **不设**视图重新加权的 arm：权重只能参照下游结果来选，那就等于用测试信息做选择。

## 1. 要回答的问题

在同一个 CBraMod 骨干、同一套 source 数据流和冻结读出协议下，回答五个问题：

1. **审计 A**：不融合的 CS 依赖目标（TCS）学到的依赖，在噪声 EEG 或错误音频下会不会消失？CALRA 在 W5（CBraMod 上的重新实现）中会被共享 dropout 捷径满足；完整 MindMix 系统的 smoke 提示另一种泄漏（候选音频经融合进入 EEG 表示，审计进行中）。两者都需要某种跨模态通道；我们要证实不融合的 TCS 没有这类通道。
2. **判决规则 R**：直接比较 EEG 表示与两条候选声流的 CS 依赖，作为注意判决规则，和现在的岭回归读出相比怎么样？
3. **条件依赖 RES**：把目标从边际依赖改成"去掉音频历史之后的依赖"，能否提高与之对应的下游终点（历史残差 r、儿童条件增益）？
4. **信息保持 PRES**：加一个依赖形式的"不遗忘"约束，即新表示与初始 EEG-only 表示之间的 CS-QMI，能否收回 TCS 相对 B0 丢掉的信息（年龄 MAE 26.9 对 25.1；DTU 注意解码 0.612 对 0.626）？另有核条件 CS-QMI（CCS）作为真正的 CS 变体。
5. **个人适配 D**：Table 5 的个人适配增益几乎为零，原因是容量不够还是准则不对？用依赖准则和交叉熵准则、在相同容量下比较。

## 2. 组成部分

### 2.1 审计 A：不融合依赖的抗捷径性（描述性）

- **对象**：B0、TCS、TNCE，seed 3401。CALRA 的数字直接引用 W5 审计 v2，不重算。
- **数据**：DTU 的 cs 测试锚点，即 `aln41/frozen.py` 的几何。
- **条件**：
  - 真实 EEG + 对应音频；
  - 噪声 EEG + 对应音频：每个锚点、每个通道按该锚点裁剪区间内的均值和方差生成高斯噪声，与 W5 一致；
  - 真实 EEG + 错误音频：跨家族双射，与 TCS_WRONG 相同；
  - 32 行完全相同的输入。
- **度量**：
  - `paper.cs_atlas` 的估计器（`aln41.cs_qmi_reference.cs_qmi`），按人计算 EEG 表示与 env / ss / sc 视图特征的 CS-QMI；
  - 置换零分布：对每人打乱音频行 1,000 次，报告真实值在零分布中的分位数。
- **预测**：TCS 在真实条件下的 CS-QMI 高于置换零分布；在噪声 EEG 和错误音频两种条件下，落入零分布。CALRA 的对照数字是：训练模式下 ClipLoss 约 0.001，与条件无关。
- **算力**：噪声 EEG 需要过一次骨干，1 个小 GPU 单元，约 0.3 GPU-h；其余在 CPU 上算。

### 2.2 判决规则 R：用 CS 依赖直接做注意判决（CPU）

- **对象**：B0、TCS、TNCE（3 个 seed），用现有的冻结 cs 特征，即 Table 2 后验敏感性分析中用过的 `cs_pca_sf<sf>`：16 个锚点 × 3 个时间片 × 64 维，PCA 在训练者身上拟合。
- **音频特征**：两条声流在每个锚点的当前包络（冻结单元中的 `cs_env_att` / `cs_env_ign`，1 维，就是下游直接终点用的目标）。F3 查明 cs 锚点**没有**存历史滞后，所以 R 只用当前包络，不从原始数据补算。
- **单个片段**：在时间片 s 上计算 I_CS(X^s; A₁) − I_CS(X^s; A₂)。时间片之间按 q0 = softmax(source a) 加权（B0 用均匀权重），得到片段的 margin。两个候选完全对称，不受目标槽伪影影响。
  - 带宽：EEG 和音频各用中位数启发式，在该折训练者的特征上算一次后固定。
  - 5 / 10 / 20 s 的判决：对 1 / 2 / 4 个连续片段的 margin 取平均，与 `aln42.external_eval.integrate` 一致。
  - NLL：在训练者的 cs 片段上拟合一个尺度 τ（logistic），与主表的积分方式相同。
- **对照**：同一份特征上现行岭回归读出（`aln41 readout.attention`）的结果。
- **预测**：不预设方向，作双侧检验（见 §5 解读表）。

### 2.3 RES：去掉音频历史之后的依赖（GPU，Table 6 协议）

- **定义**：TCS 的 env 视图音频向量 a（8 维）换成残差 a − ĥ(H)。
  - H 为该锚点在 −20 / −100 / −200 / −500 ms 处的包络，即下游历史残差终点所用的同一组滞后；
  - ĥ 是从 H 到 a 的岭回归映射，只在 source fit 行上拟合一次，α 用 source dev 选，之后冻结。
- ss、sc 两个视图不变。
- **名称**：如实称为"历史残差化 TCS（偏依赖）"，不称为完整的条件 CS 散度。
- **CCS（第四个 arm，研究者指定必须做；主要假设 H3）**：真正的核条件 CS-QMI。
  - 定义：I_CS(U; A | H) := D_CS(f₁ ‖ f₂)，f₁ = p(u,a,h)·p(h)，f₂ = p(u,h)·p(a,h)。对正的 p(h)，D_CS = 0 当且仅当 U ⊥ A | H。
  - 估计：高斯核密度估计；U、A 的带宽与 TCS 该视图的固定带宽相同，H 的带宽用 source fit 行上的中位数启发式定一次后固定。高斯乘积的积分化为两两核乘积的多重求和，N = 32 时最多 O(N⁴) 项。
  - 只作用于 env 视图（H 同 RES）；时间片混合与 TCS 相同（q² 混合）；ss、sc 视图仍用 TCS 项。
  - **估计器验证门**（在任何 Stage2 运行之前，只用合成数据）：(i) 条件独立的高斯三元组：估计值落在置换带内；(ii) U 只通过 H 依赖 A：同上；(iii) 给定 H 后 U 仍依赖 A：估计为正，且随耦合强度单调增加；(iv) 自动微分梯度有限，与有限差分一致；(v) N = 32 时单步时间不超过 TCS 的 2 倍。(i)–(iii) 任一不通过时，CCS **不撤销**（研究者指定必须做）：修正估计器（例如带宽或数值稳定化），写成附录并在任何 Stage2 输出之前冻结，然后重新验证。
- **算力**：与 TCS 相同。每个 seed 的 Stage2 约 0.6–1.2 GPU-h（SV_env 实测 10,000 次更新用 2,131 s），冻结传递约 0.8 GPU-h。

### 2.4 PRES：用依赖约束遗忘（GPU，Table 6 协议）

- **损失**：TCS 损失 − β · mean_slot I_CS(P z_θ ; P z₀)。
  - z_θ 是当前骨干的 token，z₀ 是同一裁剪在初始骨干（Stage1，即 B0）上的 token；z₀ 不反传梯度。
  - P 是在 source dev 上用 B0 token 拟合的 PCA64 基，冻结。
  - 带宽在初始状态用中位数启发式定一次，之后固定。
- **含义**：不限制参数改动的秩，只要求表示在统计上保留对初始表示的依赖。这是"用统计依赖代替强制低秩"在参数适配层面的版本。
- **β 的选择**：只用 source 数据校准。候选 {0.1, 0.3, 1.0}，各跑 1,000 次更新（seed 3401），用通用 dev 岭探针选择（`aln41/source.py` 的 select 规则，完全打平时取最小的 β）。学习率沿用 TCS 的 R1 学习率。
- **算力**：每次更新多一次骨干前向（无梯度），约 1.5 倍于 TCS。

### 2.5 析因设计

在现有 TCS（3 个 seed）之外，新增四个 arm：TCS_RES、TCS_PRES、TCS_RES_PRES、TCS_CCS。每个 arm：
- 跑 seed 3401 / 3407 / 3413；
- 复用该 seed 的 ALN4.1 episode 流、panel 和 sigma 回执（与 `paper/arms.py` 相同的字节复制和哈希检查）；
- 10,000 次更新，传递最终快照；
- 下游沿用 `aln41/frozen.py` 和 `readout.py`，以及 Tables 2–4 的读出（注意、事件 AUC、年龄），全部不改代码，只在进程内重新指向。

实现上沿用 `paper/arms.py` 的模式：新模块加 shim，在注册表末尾登记新 lane，不改动任何运行中的代码。

### 2.6 暂缓：只做可行性研究，另写附录冻结（只剩 T）

- **T（时间分辨）**：每个裁剪目前对应一个 CBraMod patch（400 ms 窗口，步长 200 ms，3 个时间片）。更细的时间片要改下游的 3 时间片读出，工程量大。先评估成本，不进入本轮的确认性对比族。
- **D 移到 §2.7**：研究者指出儿童数据有逐 trial 的结构。

### 2.7 D：依赖驱动的个人适配（儿童数据，Table 5 协议）

- **前提**：儿童数据是 oddball 范式，每个 trial 的刺激是 standard 或 deviant（MFF `stad` / `devt`，BDF 事件 '1' / '2'），也就是 Table 3 / 5 预测的事件类别。实验者在每个 trial 都知道播放了哪个刺激，所以用支持 trial 的刺激类别做适配，与现行 Table 5 的 δ 和 cal 用的是同样的信息，没有额外泄漏。
- **问题**：Table 5 中时间适配的增益只有约 1e-5 bits。原因可能是容量太小（δ 只调 3 个时间片的混合权重），也可能是准则不对。D 把两者分开检验。
- **设置**：沿用 Table 5 的支持约定（`aln35.support_contract.private_split`；U30 = 最早约 30% 的物理 block，查询 = 其余 block）。基础模型为 B0、TCS 的已选全量微调检查点（3 个 seed × 5 个外层折），θ 和时间片输出头冻结。
- **适配参数**：在 EEG 输入端插入每个儿童一份的空间滤波 W_c = I + ΔW（通道 × 通道，从单位阵开始，L2 拉向单位阵，系数 0.1），5 步梯度，学习率 0.1，与现行 δ 的步数和正则一致。
- **两种准则（容量相同）**：
  - D_CE：支持 trial 上混合预测的交叉熵；
  - D_CS：支持 trial 上输出头输入特征 Z 与刺激类别 Y 之间的 CS-QMI（取负作损失）。Z 的带宽用该儿童 U0 状态下的中位数启发式，定一次后固定；Y 用离散类别的 δ 核。
- **终点**：查询 NLL bits/trial（主要）；Brier、AUC（补充）。两种准则之后都接同一个现行 cal 步骤（同一份支持数据），NLL 才可比；另报告不接 cal 的 AUC。
- **对照**：现行 δ、cal（已有结果，同一批儿童、同一支持划分）。
- **算力**：每个儿童 × 检查点几秒到几十秒 GPU；64 名儿童 × 2 个基础模型 × 3 个 seed × 2 种准则，估计 2–4 GPU-h。

## 3. 冻结前必须完成的可行性检查（只查代码和元数据，不计算任何结果）

- **F1（已查，采用方案 (a)）**：source 锚点的物理访问区间是 [off − 12, off + 39) 个 tick（64 Hz），即 [−188, +609) ms。`check_stream` 断言 support / query 的访问区间互不重叠。−20 和 −100 ms 两个滞后在区间内；−200 和 −500 ms 在区间外。最早的锚点（off = 26）的 −500 ms 会落到 5 s 片段开始之前约 94 ms。两个方案：(a) 只把刺激音频的历史放到 EEG 访问区间之外。刺激在任何时刻都是已知的，EEG 的访问不变；需要另加断言，确认这段音频历史不来自另一条录音。采用此方案。(b) 只用 −20 和 −100 ms 两个滞后，条件化比下游终点弱，需在论文中说明。
- **F2（按定义解决）**：P 在 W7 的 prepare 步骤中，用 B0 骨干在 source dev 探针池（`source.ridge_probe` 的 dev 池）上的 token 拟合 PCA64，只用 source 数据；在 β 校准之前算好、记录哈希并冻结。
- **F3（已查）**：冻结单元有 `cs_env_att`、`cs_env_ign`（每段 16 个锚点）和 `cs_pca_sf0..4`（16 × 3 × 64），但没有 cs 锚点的历史滞后（`env_history` 只对应单说话人锚点）。R 因此只用当前包络（见 §2.2）。
- **F5（D 的数据接口，smoke 之前查）**：确认 `private_ft` 的管线能为每个测试儿童取出逐 trial 的 EEG 裁剪、刺激类别和支持 / 查询划分，并能在冻结的检查点前插入空间滤波器后重新前向。如果查明有不可行之处，以附录形式修改 D 的参数化（例如滤波器放在 token 层而不是输入层），并在任何 D 输出之前冻结。
- **F4（smoke 时测量）**：如果 PRES 的显存超过 40 GB 或单步时间超过 TCS 的 3 倍，改为预先计算：source 流是预先生成的，B0 骨干固定，可以把每个流锚点的 P z₀ 一次算好并缓存，数学上与在线计算完全相同。

## 4. 终点、统计和对比族

**终点**（与 manuscript v2 的终点同名）：
- 公开数据：content_direct_r、content_r（历史残差）、time_fixed_loss（DTU、FAU）；attention20_acc、attention20_nll_bits（DTU、FAU）。
- 儿童数据：content_hist_bits、current_auc、age_abs_err（64 名儿童）。

**统计方法**：
- 以人为单位；每人先在 seed（以及内容折）上取平均；
- 配对的人员 bootstrap，B = 4000；
- bootstrap-t 族内 max-|T*| 同时 95% 区间（`aln41.analysis.family`）；
- 只纳入每个成员都有值的人，并报告覆盖率；
- B0 不分 seed。

**对比族**（冻结时写进 W7_FAMILIES_v1.json）：

**主要假设**（H1、H2、H3 三条；其余都是次要终点）：
- **H1**：TCS_RES 在 FAU 和 DTU 的 content_r 上高于 TCS。

- **H4（次要，D）**：在同一份 U30 支持数据上，以 CS 依赖为准则的个人适配，其查询 NLL 低于以交叉熵为准则、容量相同的适配。

## 5. 预先写定的解读

| 结果 | 含义 |
|---|---|
| A：TCS 在噪声 EEG / 错误音频下落入零分布，在真实条件下高于零分布 | 不融合的依赖目标学到的是 EEG 与音频之间的真实依赖，与 CALRA 的捷径形成对照，可以写进论文 |
| A：TCS 在噪声条件下仍高于零分布 | TCS 也存在不依赖 EEG 的依赖来源。必须先查明原因，比如带宽或批内结构，然后才能声称它抗捷径 |
| R ≥ 岭回归（区间不含负值） | 表示中有可用的依赖，但线性读出没有充分利用；CS 既可以作目标，也可以作判决规则 |
| R < 岭回归 | 有监督的读出结构是必要的。CS 判决只作为对称、不受目标槽影响的参照，不作为主方法 |
| H1 成立 | 目标与终点对齐会有帮助：要的是条件依赖，就应该优化条件依赖 |
| H1 不成立，content_direct_r 下降 | 残差化只丢掉了信号，没有起到聚焦作用。报告为否定结果 |
| H2 成立 | 依赖形式的保持约束可以替代结构性约束。这是对"强制低秩"最直接的回答 |
| H2 不成立 | 遗忘不是表示层面依赖丢失造成的，或者 β 太小。报告为否定结果，不在测试数据上调 β |
| 只有 RES_PRES 有效，两个单独的 arm 都无效 | 报告为交互作用，只作描述，不追加假设 |
| H3 成立且 CCS ≥ RES | 核条件 CS 比线性残差化更好地抓住了条件依赖，可以作为方法上的"CS 变体" |
| H3 不成立而 H1 成立 | 条件化有用，但 N = 32 时核条件估计的方差抵消了它的好处；报告为否定结果 |
| D_CE+cal 明显优于 cal，D_CS 与 D_CE 相当 | 个人适配的瓶颈是容量而不是准则 |
| D_CS+cal 优于 D_CE+cal | 在支持 trial 很少时，依赖准则比似然准则更能提取个人信息（H4） |
| 两者都不优于 cal | 输入端的个人空间差异不是 Table 5 增益小的原因；报告为否定结果 |

## 6. 主张清单

**不能说**：
- "W7 打败了 mTRF / VLAAI"，除非 attention20 的区间真的支持；目前的差距是 0.61 对 0.82。
- "RES 就是条件 CS 散度"：它是线性残差化的偏依赖。
- "PRES 证明低秩约束是有害的"：W7 没有低秩对照 arm。
- 把 H1 / H2 说成事先就有的假设：它们是看过 Tables 2–6 之后提出的。

**必须写明**：
- 所有超参数只用 source 数据选择；
- β 和带宽都在冻结前或用 source 数据确定；
- 审计 A 中的置换零分布，以及噪声 EEG 的生成方式。

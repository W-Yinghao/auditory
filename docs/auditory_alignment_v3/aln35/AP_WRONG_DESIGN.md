# ALN3.5 matched APwrong: bounded exploratory comparison

Registered before any new APwrong outer result. Scope: prior33/core/NCE/seed3401,
target-excluded DTU, FAU and private_bdf donor lineages; two arms per lineage;
10 DTU + 10 FAU + 5 private target cells per arm, 50 target executions. Existing
compatible S target outputs are reused. Old AP/XP/J*/XM and their results remain.

CPU source audit 1047280 finds the first impossible strict canonical-group audio
permutation at one-based updates FAU 1872, DTU 3226 and private_bdf 1880. The
failure is a Hall-condition violation within equal-multiplicity canonical-anchor
groups. Each original donor uses the same 78,874-update h30 branch; the realised
full horizon was FAU30, DTU40 and private30. All source records, full curves,
selection states, donor pools, manifests, existing checkpoints and first failing
batches are bound in `source_audit.json`. A single impossible batch disproves an
exact pure-audio intervention on the original sampling stream.

Therefore each lineage receives the package-authorized minimal common revised
sampler and fixed h30 AP/APwrong pair. The old AP is retained as a distinct
historical result, never mislabeled as the equal-budget new comparator. Both new
arms use stable learning rate through ep-eq27 and the original three-ep-equivalent
linear decay to30, no independent improvement trigger, the same 30 source-dev
validation candidates and true-paired calibrated CE selection (strict minimum;
earlier tie retained). The original donor has no epoch0 candidate, preserved here.
Target training remains the unchanged 200-epoch prior33 recipe and endpoint.

The original sampler chooses a stratum, listener segments, partner view, phases
and montage. If no exact wrong-audio matching exists, both arms redraw the whole
batch within the same chosen stratum until feasible, using the original sampling
generator. The complete deterministic h30 metadata stream is checked before
registration. The matching RNG is independent (`SeedSequence([3401,0x41505752])`)
and never advances the EEG sampling stream. The rules use source metadata only.

Canonical anchors collapse known-clock presentation aliases to (family,sample);
unknown-clock anchors retain presentation identity. Every equal-multiplicity
canonical group moves as a whole. Every assignment crosses the entire stimulus
family, conservatively excluding identical audio, overlapping neighbours and
legal multi-positive equivalents. Within each multiplicity bucket, family order
and within-family order are randomised; rotating by the largest family block is
an exact no-same-family perfect matching when every block occupies at most half
the bucket. Otherwise the batch is refused; constraints are never relaxed.

Only the audio row array changes. Both EEG views, the fixed audio head, nominal
keys, original exclusion masks, 2B×B bidirectional multi-positive NCE, optimisation
and per-step EEG/audio multisets remain common. A compressed per-batch ledger
records nominal/actual keys, time interval starts, audio permutation, mask hashes
and exact exposure histograms; no EEG/audio values enter this ledger. Target and
source checkpoints, ledgers and probes live under
`<private checkpoint storage>/auditory_alignment_v3/aln35_apwrong_v1/`.

Targets use the original mode-T unified primary risk on public cohorts and
original native class endpoint on private children. The unchanged target function
accepts an AP-shaped loading adapter; each new record separately names and checks
the actual AP or APwrong donor checkpoint and target-excluded lineage. No new
bridge fitting or zero-shot panel is introduced by this control.

Report AP−S, APwrong−S and AP−APwrong by within-person paired differences. Risk
direction is reference−candidate; AUC direction candidate−reference. Metrics have
separate comparison families and actual paired identity counts. No interval is
made by subtracting aggregate confidence limits. All comparisons are exploratory;
benefit only over a harmful wrong control does not establish improvement over S
or the effective full CB main candidate. Preserve favorable, weak and reversed
effects without selection or performance thresholds.

GPU work uses Slurm runfill and the project aggregate cap10. CPU checks and the
frozen plan precede real-data probes; production is enabled per target only after
its engineering receipt passes. Probe scores are never a scientific entry gate.
No running or frozen prior33 source is modified.

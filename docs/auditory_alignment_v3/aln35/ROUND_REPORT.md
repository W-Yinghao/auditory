## 这轮已经弄清楚的内容

当前证据支持继续研究共享声音结构、个人支持和时间读出，但需要把表征作用与概率读出作用分开。真全量 CB 在 DTU/FAU 的 history 残差包络读出上优于相同 EEG 访问的 local；私有 AP 先验相对 XM 的 probe AUC 增量为0.00919，同时95%区间[0.00061,0.01777]，64名儿童、seed3401。AP 与 XM 同时改变训练目标，因此这还不能归因于正确声音配对本身。新 APwrong 成对实验已为这个具体问题实现并开始执行。

等校准 history-only 对照没有吸收 AP 的全部 log-score 增量：AP 的 EEG−B1 为+0.002314 bits/trial，严格异 block twin 对照为+0.003470。64名儿童的56,426条 query 都有合法异 block twin，旧面板实际同 block/self 回退均为0。此处是固定表征、单seed的描述性均值，没有新增群体显著性结论；J*/XM 的结果和 S 的负值同样保留。

CB四个保存状态的诊断已在A100任务1047349完成。原供体开发NCE为5.11945→4.07993→4.07889→4.07612 nats，按源端最小风险仍选择10000步，复用已有10/10目标格子。相同256个源端anchor上，backbone有效秩238.88→140.91→152.44→155.26，readout秩31.17→6.34→6.68→6.53。早期表示明显压缩、2500步后开发损失改善很小；这些诊断既不等于信息丢失，也不能判断各状态的目标迁移优劣，更不是整个目标训练流程的inner-person选择。完整记录见 `CB_AUDIO_STATE_RESULTS.md`。

Bridge的4个冻结donor重放及40个原zero-shot任务分解已完成，CPU1047402分析、1047403独立验证通过。固定T=1时，DTU的AP−XM风险改善在B_donor为+0.01668、B_bridgecal为−0.00443 bits/query；FAU的XP−XM分别为+0.02361、−0.00947。源端温度校准进一步改变幅度，同一B内的候选排序和top1严格不变。因此，这里的正负方向对映射选择敏感，并非温度首先造成变号；B还同时包含拟合人群与采样差异，不能据此单独归因于编码器。DTU44人、FAU67人均有两content fold的全部四格，以上为单seed描述均值，不新增显著性结论。原端点及历史重放差异完整保留，见 `BRIDGE_FACTOR_RESULTS.md`。

固定读出在相对位置移至600ms时性能下降，重拟合读出后部分恢复。这说明读取关系随位置变化；输入始终包含完整一秒 EEG，不能据此命名单点神经潜伏期。注意力积分器的顺序敏感性已从固定分数进行重分析，现阶段要求三seed共同覆盖后只有部分 DTU 人可进入完整比较，FAU完整条件仍不足。均值读出对顺序严格不变是算术核查，不是总体等效或无时间信息的证据。

## 勘误与执行来源

SCI35-C01准确限定68条native私有E_LOCAL/E_PUBLIC_TRANSFER的pre或相关TG记录：实际pre输入为全零，不能称为刺激前EEG证据。旧数值和family保留，post/full、真实FM pre以及先验输出不因此失效。实际batch检查与独立来源核验见 `CORRECTION_PRIVATE_PRE_ACCESS.md`。

APwrong原sampler存在无法构成合法错误匹配的batch。三条新lineage因此对AP和APwrong共同采用经过全程metadata审计的修订sampler，每模型78,874更新，保留原AP训练轨迹，禁止把两种sampler混成纯损失对照。两条private episode源依赖实际是合法v1兼容复用，新增明确继承ID，保留旧执行身份，不重训内层源。

现场基准为发布提交 `5ef4a60bf77eeaeab5582c2cb076077c0b15bd11`。本轮没有新的GitHub推送。CPU1047366复核发现旧状态文字所写“1002 holds”不符合实际文件：未改动的 `held_executions.json`包含1,602条ID，均无主runner完成记录。这里修正报告计数；没有释放、增加或修改任何hold。

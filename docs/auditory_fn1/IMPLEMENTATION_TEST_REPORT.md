# FN1 W0 实现验证报告

全部数值任务经 Slurm 执行（作业 999691 `prepare_request`、999694 `test`、999696 固定测试）。未读取任何真实 EEG 样本，未计算任何 EEG–目标关联，未拟合任何真实模型。

## 1. 结论

**`IMPLEMENTATION_UNRESOLVED`**（按方案 §15.3 的状态词汇）。计算图与记录级监督已验证可工作；**M4 相对 M3 的顺序优势在本轮固定复杂度下未被证明可检出**。

## 2. 限定合成检查（方案 §11）

预算严格为三机制 × 四种子 × M3/M4 各一次 = **24 次小网络拟合**，实际 24 次；另有 24 次线性求解（每个世界一个纯临床基线）。全部预测有限，无数值故障，M3/M4 参数量均为 **1209**。

判据在生成任何结果之前写入代码，且相对**纯临床岭回归基线**衡量测试 MSE 下降——不是相对训练均值。后者太弱：每个世界都带临床信号，两种顺序都能不用 EEG 通路就击败常数预测器，该判据什么也证明不了。这一点是本轮实测发现并当场收紧的（相对训练均值，机制 3 的 M3 也能拿到 4/4，而它按构造对均值池化不可见）。

|---|---|---|---|---|---|
| clinical_sufficient_eeg_independent | M3 | 否 | — | — | −0.127 |

### 各机制说明

- **无信号世界**：两种顺序相对纯临床基线均为约 −0.12，即加一条不携带信息的 EEG 分支是有代价的。这是预期行为，不设置"必须全负"的伪保证；偶然的小增益会被保留而不是压掉。
- **片段均值决定目标**：两种顺序都达到 +0.978。这证明了完整计算图、记录级监督（32 个片段先产生一个记录预测再算损失）以及两种汇总顺序都实现正确——**不是只有 M4 被实现对了**。
- **分布形态决定目标**：M3 只有 +0.030，这是**设计如此**（该世界的逐记录片段均值被精确置零，均值池化看不到信号）。但 M4 只有 +0.031，未达门槛。

### 排错记录（方案 §11 允许一次）

第一次构造把不对称性放在 140 维中的 8 维上；第一层对 140 维求和后，中心极限效应把这点不对称冲掉，**M4 也学不到**，该世界因此不是一个有效的正对照。用掉唯一一次合成尺度排错，改为跨全部维度相干的逐窗幅度双态机制（高幅窗概率随目标变化，逐记录实现均值精确置零）。**模型、优化器与判据均未改动。** 改正后 M4 仍为 0/4（+0.031）。按 §11，一次之后仍失败即记录能力未建立并停止 W1，不再调整。

### 这不是实现缺陷

M4 在机制 2 上达到 +0.978；片段置换下 M4 输出严格不变（最大差 0.0）；解析梯度与有限差分在两种顺序上的最大相对误差分别为 7.7e-09 与 2.4e-09。计算图是正确的。未建立的是"140→8→8、tanh、400 步 Adam、L2∈{0.01,0.1} 这一固定复杂度的网络，能否提取分布形态信号"这一**能力**命题。

**对方案的直接含义**：M4 优于 M3 的核心假设，在本轮冻结的架构与预算下尚未被证明可检出。即使临床锁到位，这一点也应先于 W1 解决——否则 W1 的主方法比较可能在没有检出能力的前提下进行。

## 3. 固定实现测试（方案 §11 + §13）

`tests/auditory_fn1/test_contracts.py`，**27 项全部通过**（Slurm 999696）。覆盖：

- **§13 强制项**：顺序号与实际行号错位的专项测试。正确表得 `{0: 95}`，历史错位表得 `{3: 95}` 并抛出。额外补了一条回归测试——守卫找不到自己的输入列时必须**报错**，而不是把"列缺失"静默降级成"全部键无法解析"（本轮真实发生过：该 bug 一度把**已被独立验证为正确**的 `pta_007` 误报成错位）。
- 行重排、空表行、重复表头不改变实际源行关联；错配身份被拦截。
- 临床锁无法靠默认值或由代理翻转布尔值满足。
- M3/M4 参数量相同且等于窗口契约；片段重排不改变输出；每次访问只有一个损失；复制片段不产生新身份；标签缺失掩码不进入片段特征。
- 解析梯度对有限差分。
- 身份不跨折；分折与输入顺序及任何结果无关；支持不足时报告而非缩小设计。
- 窗口不跨存储缺口；**0.7 秒旧 epoch 拼接得到 0 个候选窗**（拼接被拒绝）；区间来源必须显式声明；窗口按时序、均匀、不重复。
- 140 维契约；频带分箱不重复计数；10 Hz 正弦准确落入 8–13 Hz 带；通道顺序继承自既有定义而非重新定义。
- bootstrap 在身份组计数旁报告**配对差非零的身份数**；非有限输入拒绝而非丢弃。
- 报告模块不 import 任何估计器（修报告无法重新进入训练）。

## 4. 信号入口：继承了什么、新写了什么、缺口是什么

方案允许复用已测试定义，但禁止把新代码当作已有验证来呈现。

**继承（显式 import，未重新推导）**：`auditory5.preprocessing` 的 `HA_CHANNELS`（20 通道规范顺序）、`fixed_sos`（Butterworth SOS，HP 4 阶 @0.5 Hz + LP 8 阶 @30 Hz，`sosfilt` 带状态因果滤波）、`effective_impulse_support`、`CausalPreprocessor`（选 20 通道 → 平均参考 → 因果滤波 → 固定栅格整数抽取）；以及 `auditory5.adapters.ha` 的 vendor 数字轨饱和规则（取自 BDF 头的一个量化步长，不是猜测的微伏阈值）。实测 1000 Hz 下滤波支持 **10.823 s**、保护区 **max(20 s, support) = 20 s**，与既有回执逐位一致。250 Hz 由"LP8 抗混叠 + 整数抽取因子 4"得到——仓库中**没有**重采样器，这就是已核验的规则。

**本模块新写（仓库中此前不存在任何实现）**：固定栅格、与事件无关的 4 秒窗口选择；Welch 带功率（2 秒 Hann、50% 重叠）与 80 维带功率；采样率作为参数的 Hjorth（既有实现把 250.0 硬编码进 mobility 换算，只在 250 Hz 正确）。

**必须如实声明的缺口**：`AGENTS.md` 中"长记录流式 FIR 已核验"指的是 **CI/MFF 的零相位路径**，既非 HA、也非因果路径。**HA BDF 在本仓库中没有任何采集缺口检测**，历次 HA 运行都隐含假设单一连续区间 `[0, n_samples)`。因此 `select_windows` **要求调用方显式声明区间来源**，整记录区间会被标为 `assumed_single_interval_unverified`，回执不会暗示一个不存在的验证。另：现有 guard 是**仅启动端**的，尾端 20 秒保护区是新代码。

## 5. 信号可行性（元数据层面，非 QC 结果）

84/84 HA 记录为 1000 Hz、同一 22 通道蒙太奇（含全部 20 个规范通道，多出的只有 A1/A2），头部证据下 **0/84 存在多于一个存储区间**（信号 BDF 注释数为 0，事件流中 `boundary` 标记数为 0，文件体与声明的数据记录逐字节吻合）。56 个当前合格记录两端各去 20 秒后，最差仍有 **134** 个不重叠 4 秒窗，中位 **189**，**0/56 几何上不足 32 个窗**，最差余量 **4.19×**。

**这只是时长算术。** 这些窗有多少能通过 §6.3 的固定窗口 QC 无法从现有回执推断——必须读信号。唯一相邻的经验锚点是旧的事件锁定 0.7 秒 epoch 保留率（HA 中位 0.793 @150 µV），而它**不可迁移**：4 秒窗比 0.7 秒 epoch 长约 5.7 倍，逐窗幅度判据只会更难通过。W0 不预测该数字。

现有两种"连续"导出均**不可复用**：EEGLAB `.SET` 只覆盖约 7 条 HA 采集（合格队列内 3 条），带逐文件 ICA 去分量与球面插值、参考混用，且 16 条连续文件中 **12 条含 EEGLAB `boundary` 事件**——它们是拼接过的，不是连续的；`ha_export_001` 虽然 DSP 定义正确，但只持久化 0.7 秒 epoch，不是流。

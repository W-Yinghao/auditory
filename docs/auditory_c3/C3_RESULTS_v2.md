### 1.2 CI 伪迹（方法学结果）

- Federici 幻影头（只有伪迹）在 0–20 ms 与 100–110 ms 的 MI 约为 120，是儿童被试的约 20 倍。
- Federici 的 CI 儿童在刺激之前（0 ms 与 −50 ms）就有"信息"。

- **只衡量幅度的 MI 度量在 CI 用户中被伪迹主导**；基于零滞后的剔除规则只能去掉其中一部分。

### 1.3b 第 27 层特征构成的敏感性（`P3_l27z.json`；登记于 `POST_G1_CHANGELOG.md`，结果之前）

### 1.10 扩展分析（详见 `C3_EXTENSIONS_RESULTS.md`）

- 收敛的非线性声学背景之上，深层增量保留约 70%。
- 去除眼电伪迹后，声学追踪提升 15–40%，但深层增量与 C3-DL 的 EEG 特异增益不变。
- 最小预处理会让 EEG 特异增益消失；不加条件的 CLIP 式检索主要靠声学。
- 词层级的深度模型没有一致的 EEG 特异证据。
- 惊讶度信息在丹麦语 DTU 中复现，HI 与 NH 相当；CI 低于 TH（提示性）。

## 2. 有限的模型推论

1. 在 TH 与 HA 中，EEG 在一份有限声学摘要之上，仍与 Whisper 深层表示有依赖；在一个交叉拟合的非线性声学背景之上，约 70% 的依赖仍然保留（§1.3c）。这种依赖在以下检查中都站得住：换语音模型（XLS-R）、换更丰富的声学参照（log-mel）、换维数（k = 3/8），并且被注意调制。
2. **文本派生的 GPT-2 惊讶度在声学和词起始之上有滞后特异的信息**，这是"深层增量中包含语言成分"的会聚证据。但深层增量本身包含双向上下文与非线性声学成分，不能整体称为语言信息。
3. HA 与 TH 在声学总量、深层增量及其注意调制上**没有可分辨的差异，但也不能写成等效**。
4. **HA 的 EEG 在深层预测之上的声学独有信息多于 TH，DTU 中 HI 对 NH 也是如此**：对照量的 q ≤ 0.07，I_ccs 的 U_Ac 区间不含 0，MMI 方向一致。这是目前最稳的组差。与助听器放大增强声学驱动反应的假设相容，但没有被直接检验。
5. 私有端：冻结的读出携带超出可预测序列的当前声音信息（I(T;Cur \| Hist) 大于 0，阶段 0 的 G_cond 大于 0），**但量很小**，比协议历史提供的信息小一到两个数量级。读出中没有可检出的历史信息。佩戴时长在月龄之上不携带信息。这些结论只针对这一个冻结读出。

## 3. 开放假设（需要独立数据）

- H-A′：助听器用户的皮层追踪在深层预测之上携带更多声学独有信息（放大假说）。
- H-B：CI 用户的深层增量减弱。方向与原预测一致，但被伪迹污染。需要对伪迹不敏感的度量，例如带幻影头模板回归的 TRF，或条件解码（C3-DL），再加上 CI 关机或幻影的对照。
- H-C：DTU 的 HI 组包络注意调制更强（w2 窗，额中央 q = 0.04），究竟是 CamEQ 放大带来的响度差异，还是听损本身的效应。
- H-A″：跨队列一致的"听损组声学独有信息更多"，究竟来自放大还是听损本身。需要放大开关的组内对照。
- H-D：CI 儿童 30–45 Hz 证据中的独有类别信息来自刺激同步瞬态，需要按潜伏期重新定位。
- H-E：验配初期儿童的当前声音依赖在儿童内可测，但还不能转化为跨儿童读出的增益。

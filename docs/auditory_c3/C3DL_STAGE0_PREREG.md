# C3-DL 阶段 0 预注册：私有端条件解码增益（2026-10-05，写于任何计算之前）

**问题**：在 HA/BDF 纯音 oddball 中，冻结的 EEGNet 读出对"当前是偏差音还是标准音"的判别，有多少**不能由可预测的序列历史解释**？

**不训练任何 EEG 模型**：z = GX 的冻结证据，即种子平均的折外 logit 差（`GX1_bdf_puretone_shared`，按儿童划分折）。只拟合低维 logistic 头。结论只涉及这个读出，不涉及 EEG 整体（复核补充第 5 项）。

## 数据

- 与 `private_mi2` 相同：符合条件的 55 名 HA 与 9 名 NH，每人取 PF 主记录中通过 QC 的试次。
- Hist = 截至上一个声音的历史（严格过去）：分箱为"自上一个偏差音以来的标准音数"{0}、{1}、{2}、{3}、{4,5}、{6+}，再加上一个声音的类别。历史未知的试次在**所有模型中**一并排除。

## 模型

所有模型都在其余 63 名儿童上拟合，在被留出的儿童上评估（留一儿童）。logistic 用 L2 正则，C = 1.0；证据在训练集内标准化。

| 模型 | 形式 |
| --- | --- |
| M_prior | 自然先验（训练儿童中偏差音的比例） |
| M_hist（q0） | 每个历史分箱的偏差音频率，加 0.5 平滑。对给定分箱这是饱和的最佳背景 |
| M_ev | logit = α + γ·e（只有校准后的证据，没有历史）。核对 7：以自然频率拟合截距，恢复自然先验 |
| M_hist_ev（q1） | logit = logit q0(bin)（偏置项，固定；核对 2）+ α' + γ·e + δ·e·prev_class |
| M_twin（空孪生，核对 5） | 与 M_hist_ev 结构相同，但 e 在"儿童 × 历史分箱"层内置换（训练与评估都置换），用于衡量额外参数和背景失配带来的增益 |

## 量（每名留出儿童，比特每试次）

- G_hist = E log₂ M_hist / M_prior：协议本身的可预测性
- G_naive = E log₂ M_ev / M_prior：不考虑历史的"当前刺激解码"增益
- **G_cond = E log₂ M_hist_ev / M_hist**：历史之上的增益（主量）
- G_null = E log₂ M_twin / M_hist；**G_cond_corr = G_cond − G_null**
- 敏感性：把 e 换成不依赖模型的 T，即 120–320 ms 窗内 20 个通道的平均幅值（一维），其余不变。
  - **运行前修订（2026-10-05，没有任何计算）**：原写法是"儿童内拟合的前 3 个主成分"。但各儿童的主成分基底不同，不能放进跨儿童共享的 logistic 头。改为跨儿童可比的通道平均幅值。

各组（HA 全体、HA 0–2 个月、HA ≥13 个月、NH）报告均值与 95% bootstrap 区间（10 000 次，在儿童间重采样）。

## 判读网格（写于看到任何结果之前）

1. G_cond_corr 的区间不含 0（> 0）：在该组中，冻结读出携带超出可预测序列的当前声音信息。
2. G_naive > 0（区间不含 0），但 G_cond_corr 的区间含 0，且点估计小于 G_naive 的 25%：该组中读出表面上的"当前刺激解码"主要由序列历史解释，H4a 的解释在该组不成立。
3. G_naive 与 G_cond_corr 的区间都含 0：没有可检出的读出信息。
4. 如果 |G_null| 超过 |G_cond| 的 25%：存在背景失配或过拟合，该组结果标为 `TECHNICALLY_LIMITED`。
5. 与 GCMI v2 账本中 I(T;Cur|Hist) 的方向是否一致：只描述，不作判据。

## 不做

不选模型、不调 C、不换分箱、不按结果剔除儿童。不做任何临床或功能推断。

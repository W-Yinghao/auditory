# C3-DL 开发试跑结果（2026-10-05）

规格：`C3DL_PILOT_SPEC.md`（§1–11，含门槛失败、诊断与每一轮的修订）。数据：
- `private/auditory_c3/c3dl_pilot/`：checks*、debug_w1、budget_diag、pl_*、pl2_*、pl3_*、hc_*；
- 汇总：`results/auditory_c3/C3DL_pilot.json`（第一轮）。

**性质**：
- 全部在开发样本上：P-L 用选层用过的 14 名 TH；H-Cur 用第 1 外层折的训练儿童。
- 这些是**接口检查和信息收集，不是主张**。
- 正式评价面板没有被触及：留出 TH、HA、CI，以及 H-Cur 第 1 折的测试儿童。

单位：P-L 为比特每采样点（128 Hz），H-Cur 为比特每试次。区间为 14 名被试上的 bootstrap。

## 1. 实现与门槛

| 检查 | 结果 |
| --- | --- |
| 修正项置零时 q1 = q0（P-L、H-Cur、交互头） | 最大差 0.0 |
| 候选置换等变 | 最大差 0.0 |
| 训练模式恢复 | 所有验证轮次都恢复为 train |
| 输入通道 | 31 导，无辅助通道 |
| 数值 | 所有运行没有非有限值 |
| W1（无条件信息），第 1 次 | **未通过**：在"已见声音"上，D2 得到 +1.65 |
| W1、W2，修订后 | 通过：W1 约为 0；W2 中 D2 为 +3.66，空孪生为 −0.02 |
| W3（只有交互） | **两种头都未通过**；把训练上限提到 200 个 epoch 也不变（D2 都在第 0 轮早停） |

由此得到的设计结论：
1. **"已见声音"不能用来主张 EEG 证据**。所有被试听同一批录音，网络会记住片段特有的内容；EEG 反映声学，就像一枚"刺激指纹"，帮助查到记住的内容。在真实条件信息为 0 的模拟里，这能造出 +1.65 的"增益"，空孪生只能扣掉其中一部分。
2. **在这一数据规模下，这个结构（无论加性头还是交互头）学不到可泛化的非线性交互**，而且不是训练预算的问题。所以"深度模型能看见 GCMI 看不见的交互"这一点，在 C3 的数据上没有实现层面的支持。

## 2. P-L 第一轮（10 人训练、4 人评分；目标 Lz，背景 Ac；3 个种子；两种头）

- 深度臂在未见内容上的增益约为 +0.15 到 +0.21，**但空孪生与之持平**：G − G_twin 在 −0.016 到 +0.006 之间。测试时换成错配 EEG，增益也几乎不变。
- 这部分增益来自背景容量：修正头里的 MLP 学到了比线性 m0 更好的"由声学预测 L"，与 EEG 无关。
- 换成冻结 L27 目标时，背景容量带来的增益约为 +0.5；换成 log-mel 背景时，约为 +0.26。两者同样与孪生持平。
- 线性 B1：增益为 +0.001 到 +0.002；换成错配 EEG 后，4 名验证被试全部下降。
- 整条匹配片段的检索，所有臂都完全答对（对数损失为 0），也就是说背景本身就暴露了答案，这套检索不提供信息。
- 耗时：一个完整配置（两种头 × 8 个训练臂，外加 B0、B1）在 A40 上约 135 秒。

## 3. P-L 第二轮（14 名开发 TH，7 折被试交叉验证，2 个种子；强背景两段式）

BG 是与 D2 同结构、但 EEG 表示置零的背景模型，训练后冻结。D2s 在冻结的 BG 上再训练 EEG 修正。

| 对比（未见内容，14 人） | 配置 A：第 1 段拟合，第 3–4 段测试 | 配置 B：第 1–2 段拟合，第 4 段测试 |
| --- | --- | --- |
| BG − m0（只用刺激侧的非线性背景） | +0.335 | +0.370 |
| D2 − D2_twin（单段式） | +0.0001 [−0.0035, +0.0035] | +0.0048 [−0.0014, +0.0115] |
| **D2s − D2s_twin（两段式）** | **+0.0024 [+0.0006, +0.0044]**（两个种子 +0.0031、+0.0017） | +0.0024 [−0.0002, +0.0049]（+0.0027、+0.0021） |
| D2s：e − e_mismatch | +0.0095 [+0.0068, +0.0122] | +0.0141 [+0.0099, +0.0179] |
| B1：e − e_mismatch | +0.0040 [+0.0022, +0.0057] | +0.0088 [+0.0060, +0.0126] |
| D4s − D4s_twin（η = 0.5，τ = 1） | +0.0002 | +0.0005 |
| D4s − D2s | −0.0038 | −0.0052 |

1. **在强背景之上，EEG 修正有一个小而稳定的 EEG 特异增益**：约 0.0024 比特每采样点，两种配置、两个种子都一致。它与线性 B1 的 EEG 依赖同一量级。
2. 单段式 D2 测不到这个增益：两个独立训练的网络之间的差异（约 ±0.004）比信号大。**正式方案应采用两段式**，主量为 D2s − D2s_twin。
3. 拟合数据翻倍后幅度没有变；测试段更少，所以区间更宽。
4. 条件对比（D4s）在固定的 η、τ 下所有折都在第 0 轮早停，没有学起来；η、τ 的选择见 §5。
5. **刺激侧事实**：Lz 对声学有很强的非线性依赖，非线性背景比线性 m0 多出约 0.34–0.37 比特每采样点。C3 的"深层表示增量"是相对线性声学参照（ŷ_Ac）定义的，其中可能含有非线性声学成分。`C3_RESULTS_v2.md` 已有这条注意事项，这里在刺激侧量化了它的规模。
6. 耗时：每个配置 7 折约 270–420 秒。

## 4. H-Cur（第 1 外层折的训练儿童：33 人拟合、7 人早停、11 人评分，HA 9、NH 2；3 个种子）

| 训练臂 | G（比特每试次；3 个种子） | AUC | 读法 |
| --- | --- | --- | --- |
| B0：b(h) | 0 | 0.847 | 只靠历史，AUC 就有 0.85 |
| B1：b(h) + 冻结 GX 证据 | **+0.0041**（HA +0.0025，NH +0.0113） | 0.856 | 与阶段 0 同一量级 |
| D0：只用 EEG | −0.252 | 0.52 | 不看历史，远差于背景 |
| D2：b(h) + 修正 | +0.0001 到 +0.0004 | 0.849 | 约为 0 |
| D4：加历史内的有监督对比 | 0 到 +0.0003 | 0.849 | 约为 0 |
| G − G_twin | D2：0 到 +0.0005；D4：0 到 +0.0011；D1：−0.0002 到 +0.0022 | | 约为 0 |

- 历史背景 q0 按分箱为 [0.00, 0.00, 0.20, 0.25, 0.40, 1.00]：刚出现偏差音后几乎必然是标准音，长串标准音后几乎必然是偏差音。
- **新训练的深度模型没有超过冻结的 GX 读出**，后者大约多 10 倍。按方案的判读，这属于"新训练没有带来条件证据"。这里只用了 33 名儿童训练，而 GX 读出的训练数据多得多。
- 耗时：每个种子 10 个训练臂约 5 分钟（A100）。

## 5. 第三轮：更强的背景与条件对比的 η、τ（配置 A，14 名开发 TH，7 折，2 个种子；BG 训练上限 100 个 epoch）

| 对比（未见内容） | 第二轮（BG 训练 40 个 epoch） | **第三轮（BG 训练 100 个 epoch）** |
| --- | --- | --- |
| BG − m0 | +0.335 | +0.381（最优轮次 98，仍未收敛） |
| D2s − BG | +0.0042 | +0.0014 [+0.0003, +0.0025] |
| D2s_twin − BG | +0.0019 | +0.0004 |
| **D2s − D2s_twin** | **+0.0024 [+0.0006, +0.0044]** | **+0.0009 [−0.0002, +0.0021]**（两个种子 +0.0008、+0.0011） |

| D4s（η, τ） | D4s − D4s_twin | D4s − D2s | 最优轮次（最小/中位/最大） |
| --- | --- | --- | --- |
| 0.02, 1 | +0.0010 [−0.0003, +0.0024] | +0.0001 | 0 / 4 / 6 |
| 0.02, 10 | +0.0011 [−0.0000, +0.0023] | +0.0002 | 0 / 3 / 6 |
| 0.1, 1 | +0.0003 | −0.0006 | 0 / 0 / 3 |
| 0.1, 10 | +0.0008 | −0.0001 | 0 / 3 / 6 |
| 0.5, 1 | +0.0004 | −0.0021 [−0.0031, −0.0011] | 0 / 0 / 0 |
| 0.5, 10 | +0.0006 | −0.0003 | 0 / 0 / 4 |

1. **背景越强，"EEG 特异增益"越小**：从 +0.0024 降到 +0.0009，区间含 0。
   - 真实 EEG 带有当前这段声音的信息，能补上背景没学到的那部分声学；空孪生拿到的是另一段声音的 EEG，补不了。所以 D2s − D2s_twin 中混有"EEG 弥补背景欠拟合"，即方案中 G = I(Y;Z|C) + D0 − D1 的 D0 项。空孪生控制得住"容量"，控制不住这一项。
   - **在这一数据规模下，无法把"EEG 提供了声学之外的深层信息"与"EEG 替背景补课"分开。**背景仍未收敛，真实的上限可能更小。
2. **条件对比在 6 组 η、τ 下都没有超过 D2s**，大 η 时更差，最优轮次多为 0。最好的一组（η = 0.02）与 D2s 相当，等于"几乎不用对比项"。
3. **条件检索被背景主导**：所有臂（包括不看 EEG 的 BG）的 top-1 都是 0.511。条件负样本 m0_i + (L_j − m0_j) 是相对线性 m0 构造的，强背景能从声学中预测出 m0 残差的一部分，从而认出一半正样本。真正"条件"的负样本应相对强背景构造：BG_i + (L_j − BG_j)。
4. 耗时：每个种子 7 折 × 15 次训练约 700 秒（A100）。

## 6. 对后续的含义

**关于 C3 本身（最重要的一条）**
- 刺激侧，Lz 对声学有很强的非线性依赖：只用声学的非线性背景比线性 m0 多出约 0.38 比特每采样点。
- C3 的 H3a（深层表示增量）是相对线性的 ŷ_Ac 定义的。EEG 如果编码了声学的非线性函数，而这些函数又与 L 相关，即使没有任何"深层"加工，I(T;L \| ŷ_Ac) 也会大于 0。
- 现有对照中，log-mel 与 XLS-R 都没有排除这一点。真正指向非声学内容的，只有文本派生的 GPT-2 惊讶度。
- **建议的直接检验**（便宜，GCMI 侧，需另行登记）：把刺激侧非线性背景对 L 的预测（L̂_BG，按故事或段落交叉拟合）作为额外的刺激特征，计算 I(T;L \| ŷ_Ac, ŷ_BG)。深层增量若在此之后仍大于 0，才能说它超出了非线性声学。

**关于 C3-DL 正式矩阵**
1. 按当前设计（P-L 的 D1 对 D4、D3 对 D4），开发数据显示：条件对比没有作用，EEG 特异增益在背景足够强时接近 0。正式矩阵大概率得到"没有建立训练原则的优势"，而且无法区分"EEG 无增量"和"背景仍不充分"。
2. 若仍要运行，设计必须改为：
   - 两段式，并把背景训练到收敛（报告增益随背景强度变化的曲线）；
   - 条件负样本相对强背景构造；
   - 主评价放在未见内容上；
   - 不主张交互。
3. H-Cur：从头训练的深度模型不如冻结的 GX 读出（约 0.0003 对 0.0041 比特每试次）。正式矩阵对 H-Cur 的价值低。
4. 资源不是限制：整个正式矩阵预计 < 3 GPU 小时。

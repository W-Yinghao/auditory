# B2 登记：以模拟电极图作为 CI 伪迹背景（2026-10-05；写于任何 EEG 侧计算之前）

依据：`C3_NEXT_DIRECTIONS_DRAFT.md` §B 第 2 条；`C3_EXTENSIONS_REG_v1.md`（B1、B3）。代码：
- `auditory_c3/ci_edg.py`：刺激侧，不读 EEG；
- `auditory_c3/ci_edg_mi.py`：EEG 侧分析与汇总。

## 暴露

- 已经看过的 FAU/TUD CI 结果：CI 的 I(T;Ac) 被伪迹抬高（诊断窗是 TH 的约 3 倍）；超出 ŷ_Ac、ŷ_BG 的深层增量，CI 为 1.7–2.0，TH 为 1.8–2.6；惊讶度（超出 ŷ_Ac、ŷ_Ons、ŷ_BG），CI − TH 为 −0.08 / −0.05 / −0.11（q = 0.06–0.11）。
- 本登记写定之前，只看过刺激侧电极图的完整性检查（与 Ac 的相关、PCA 方差）。之后会对 CI 102 和 TH 301 各跑一个单人探针，结果在此文件末尾披露。

## 1. 刺激侧：模拟电极图

- **原理**：CI 伪迹的低频部分，跟随处理器从音频中提取的各通道脉冲幅度包络。所以这类包络是"伪迹可能长什么样"的刺激侧近似。
- **三类编码策略**，按 Table 4：
  - **ace**：Cochlear ACE，22 通道，188–7938 Hz，每帧取 8 个最大通道（n-of-m）；
  - **ab**：AB 的 HiRes Optima-S 与 HiRes-S（Fidelity 120），16 通道，250–7900 Hz（8000 Hz 是 16 kHz 采样的奈奎斯特频率），所有通道；
  - **medel**：MED-EL 的 FS4、FSP 与 HDCIS，12 通道，100–7900 Hz，所有通道。精细结构的时序高于 EEG 频带，不模拟。
- **流程**：轻度预加重 → 对数等距的 4 阶 Butterworth 带通（因果） → 全波整流 → 200 Hz 低通（因果） → 1 kHz 帧 → n-of-m（仅 ACE） → 响度增长映射（40 dB 输入动态范围，ρ = 416，参照该类策略在全部刺激上的 99.9 百分位） → resample_poly 到 128 Hz → 在唯一刺激上拟合 PCA-5。分析时再做 1–8 Hz 带通，与其他特征相同。
- 这只是近似：没有个人的 T/C 电流水平、映射参数和电极阻抗。因此"建模了伪迹"只能说到"建模了伪迹中由声学经处理器包络决定的部分"。

## 2. 每名被试的背景

- **CI**：按 Table 4 两侧的编码策略确定类别。两侧类别不同时（只有 111 号：FSP 与 ACE），把两类的 PCA-5 拼成 10 维。其余 CI 被试两侧同类，为 5 维。
- **TH 与 HA**：都用通用的 ACE 模拟，作为对称的对照。对他们而言，这只是一个更丰富的声学背景。
- **ŷ_EDG**：用注意流与干扰流的 EDG 特征，在滞后 −200 到 600 ms 上对 T 做留一试次岭回归，与 ŷ_Ac、ŷ_BG、ŷ_Ons 的做法相同。

## 3. 量（81 名被试；三个 ROI；窗口 all、w2、diag；TH 参照为留出的 14 人）

- **主量**：
  - I(T;L27 \| ŷ_Ac, ŷ_BG, ŷ_EDG)：深层增量在线性声学、非线性声学和设备包络之上；
  - I(T;Sur \| ŷ_Ac, ŷ_Ons, ŷ_BG, ŷ_EDG)：惊讶度在这三类背景之上。
- **辅助量**：
  - I(T;EDG \| ŷ_Ac)：EEG 是否追踪 Ac 之外的设备包络。预期 CI 远大于 TH 和 HA，这正是伪迹的标志；
  - I(T;Ac \| ŷ_EDG)：声学信息在设备包络之上还剩多少；
  - I(T;EDG)、I(T;Ac)，以及 I(T;L27 \| ŷ_Ac, ŷ_EDG)；
  - 在同一模式中重算 I(T;L27 \| ŷ_Ac)、I(T;L27 \| ŷ_Ac, ŷ_BG) 与 I(T;Sur \| ŷ_Ac, ŷ_Ons, ŷ_BG) 作参照。
- **组差**：CI − TH、HA − TH，配合 BH 校正；另报逐被试加入 ŷ_EDG 前后的配对变化。

## 4. 读法（事先写定）

1. **伪迹标志**：若 CI 的 I(T;EDG \| ŷ_Ac) 远大于 TH（CI − TH 的区间不含 0，并且在诊断窗也是如此），则模拟电极图捕捉到了 Ac 无法表示的设备特异成分。若 CI 与 TH 相当，模拟没有抓住伪迹的设备特异部分，后面两条只作描述。
2. **深层增量**：
   - 若在 ŷ_EDG 加入之后，CI 的 I(T;L27 \| ŷ_Ac, ŷ_BG, ŷ_EDG) 仍与 TH 相当（CI − TH 的区间含 0），写作"在建模了设备包络之后，CI 与 TH 的深层增量没有可分辨的差异"；
   - 若 CI 明显低于 TH，写作"在设备包络之上，CI 的深层增量低于 TH"；
   - 两种情况都注明模拟的局限（§1）。
3. **惊讶度**：若 CI − TH 在加入 ŷ_EDG 之后，仍在至少两个 ROI 中为负且区间不含 0，则 B1 的结论对设备包络也稳健；否则写"不稳健"。
4. TH 与 HA 中，加入 ŷ_EDG 后的变化预期很小，因为对他们而言它只是另一个声学背景。若 TH 或 HA 的深层增量也明显下降，说明 EDG 背景携带了 Ac、BG 之外的一般声学信息，读法 2 中对 CI 的解释要相应减弱。

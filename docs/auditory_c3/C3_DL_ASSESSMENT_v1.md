## 1. 我理解的方法

目标不再是用 Gaussian-copula 估计 CMI，而是**条件预测增益**：

- 背景模型 q0(y | c)：只用条件变量 c，例如历史、声学摘要。
- 条件模型 q1(y | c, z)：再加上 EEG 表示 z。
- 在留出数据上计算 G = E[log₂ q1/q0]（比特）。

核对 1 给出的恒等式是

**G = I(Y; Z | C) + D0 − D1**

其中 D0 = KL(p(y|c) ‖ q0)，D1 = KL(p(y|c,z) ‖ q1) ≥ 0。所以：**当背景模型是正确的（D0 = 0）时，G 是条件互信息的下界**。

对比学习版本：critic 区分匹配与不匹配的 EEG–刺激对，**负样本来自同一条件**，即 y' ~ p(y|c)，这时 InfoNCE 给出 I(Z; Y | C) 的下界。其余核对的含义：

| 核对 | 含义 | 对 C3 的直接意义 |
| --- | --- | --- |
| 2 固定背景项的梯度为 0 | q1 = q0（作为偏置项固定）+ f(z, c)，可以直接优化增益 | 残差式训练，背景模型不被 EEG 头"吃掉" |
| 3 只用历史的 AUC = 0.625 | 只靠序列历史也能"解码"当前偏差音（0.073 比特） | **私有端的当前刺激读出必须以历史为背景**，与复核补充第 5 项的 I(T;Cur\|Hist) 是同一个问题 |
| 4 XOR | 边际信息为 0、条件信息为 1 比特，深度模型能看见 | 补 GCMI 的盲区（S4b、非线性共同原因） |
| 5 背景失配 | 真实 CMI = 0 时，如果 q0 比 q1 中的背景部分弱，G 仍有 0.35 比特 | **最大的风险**：条件模型在背景变量上的容量必须与背景模型一致 |
| 6 共享协方差的高斯 | 负对数似然增益 = 加权均方误差增益 | 编码模型（刺激 → EEG）的预测改善可以换算成比特 |
| 7 平衡训练的先验 | 平衡先验的概率直接当自然概率用，会少算 0.28 比特 | **GX 的 EEGNet 正是用类别加权交叉熵训练的**（`auditory_gx/train.py`），用于似然增益前必须做先验校准 |

## 2. 为什么值得做（结合 C3 现状）

1. 它把复核指出的"模型条件依赖"变成一个**明确、可在留出数据上检验的量**：G 只有在背景模型充分时才是下界，而背景模型的充分性可以单独检查。
2. **C3 中最好的用武之地是私有端**：
   - 复核补充的核心问题是"解码器识别到的是当前声音，还是可预测的序列"，核对 3 说明这在协议上是真实存在的混杂。
   - 而且**不需要训练新的 EEG 模型**：z = 已冻结的 EEGNet 证据，q0 = 历史的 logistic 模型，q1 = q0 作为偏置项 + 证据项，在儿童之间交叉拟合。这完全符合 C3"不训新编码器"的规定。
3. 公开端，它可以检验 GCMI 看不见的非线性结构。CMI 的线性条件化做不到这一点。
4. **对 CI 伪迹有一个可证伪的用法**：伪迹是声学（经 CI 处理器）的函数。如果背景 c 包含足够丰富的声学表示，"声学之上"的增益就应当对纯伪迹不敏感。**Federici 的幻影头记录可以作为阴性对照**：在只有伪迹的数据上，条件增益应约为 0，而总增益明显大于 0。如果这一点成立，C3 中因伪迹而搁置的 CI 对比，就可能以条件形式重新获得解释权。这是目前唯一看得到的、让 CI 部分起死回生的路径。

## 3. 必须满足的条件（按严重程度）

1. **背景容量匹配（核对 5）**：
   - 增益的对照不能是一个独立训练的 q0，而应是**同结构的"空孪生"模型**：同样的网络，但 z 换成条件匹配的空样本（z 在同一 c 层内置换，或刺激侧的 L 换成 p(L|Ac) 的近似样本）。
   - 报告 G − G_null。
   - 用核对 5 的构造作为阳性测试：真实 CMI = 0、背景失配时，修正后的增益必须约为 0。
2. **条件负样本的来源**：
   - 自然语音里不能对同一段声学重新采样 L。只能近似，例如以 Ac 预测 L，再打乱残差。
   - 这个近似**只涉及刺激侧**，可以完全不看 EEG，用大量刺激数据先验证（残差与 Ac 是否独立、是否同方差）。这是本方法相对 GCMI 的一个优势。
3. **先验校准（核对 7）**：GX 证据先在训练儿童上做 logistic 重标定，恢复自然先验，再计算比特。
4. **样本单位**：
   - 按试次（私有端）或片段（公开端，例如 1–5 s）报告比特，留出单位是被试或试次块。
   - 不报信息率（复核补充第 9 项）。
   - 自相关的逐采样比特不累加。
5. **选择与冻结**：结构、超参数和片段长度只在 TH 开发子集上选（就是选层那 14 人），冻结后才在留出的 TH、HA、CI 上评估。功能终点不参与任何选择。
6. **阳性与阴性对照**：
   - 植入 XOR 的合成 EEG：深度增益应能检出，GCMI 应检不出。
   - 植入"只有声学"的合成 EEG：条件增益应约为 0。
   - Federici 幻影头：条件增益应约为 0。
7. **与 C3 冻结协议的关系**：C3 v1 规定"不训练新的 EEG 模型"。所以 C3-DL 中需要训练网络的部分，**必须作为单独预注册的新分支**（C3-DL v1），不替换 C3 的冻结结果。GPU 训练按惯例需要你确认后才开始。

## 5. 我的判断

方法在数学上是对的，7 项核对都切中要害。它最有价值的地方不是"更强的模型"，而是**把"背景是否充分"变成一个可以检验的前提**，并且天然要求以历史或声学为条件。

主要风险集中在背景失配，以及条件负样本的近似。前者可以用空孪生模型控制，后者可以在刺激侧单独验证。

建议先做阶段 0：不训新网络、计算量极小，直接回答复核补充提出的私有端核心问题。阶段 2 等拿到主方案文档后再定。

## 6. 与主方案的对齐（读完全文后）

1. **任务定义**：主方案的核心是公开端 **P-L** 与私有端 **H-Cur**，训练臂为 B0、B1、D0–D4。我在第 4 节说的"阶段 2 深度对比模型"，对应的是方案中的 D3 和 D4，**单独一个 D4 不够**：主比较是 D1 对 D4（是否超过简单的条件拼接）和 D3 对 D4（条件匹配是否超过普通对比）。
2. **阶段 0 的定位**：在方案 8.3 节中，"固定旧 logit 与新深度表示"是一个必须保留的对照。阶段 0 用冻结的 GX 读出算出 G_Cur\|Hist，就是这一对照，同时提供 H-Cur 的 B0（只用历史）与 B1 式（线性条件加读出）参照。它不替代方案中需要时域 EEG 的新编码器。
3. **公开端的初始形式**：方案 5.2 节规定首轮是固定共享协方差的残差预测，e 为马氏距离差除以 2 ln 2。它不是对比损失本身；对比项是 D3 和 D4 的附加项，而且"匹配检索增益"必须与"自然分布预测增益"分开报告（6.1 节）。我在第 4 节的阶段 1（线性编码增益）应改为：以 L 为目标、m0(Ac) 为背景，即 P-L 的 B0 与 B1，而不是以 EEG 为目标。
4. **启动条件**：方案明确说明本文件不授权提交作业，要先做 D0（定义、时域输入、候选与历史支持、测试分布），再登记正式矩阵和资源上限。我据此**先只运行 D0 的支持表**（`auditory_c3/c3dl_d0.py`，只用刺激侧特征与事件元数据），不训练任何网络。
5. **确定性历史**：方案要求区分"协议禁止"和"样本中没出现"。阶段 0 对所有历史分箱做 0.5 平滑；D0 会核对"偏差后紧接偏差"在数据中是否出现（GX R3 显示会出现），从而确认第 0 箱不是结构性确定。

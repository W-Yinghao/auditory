起因有两个：一是用户转来的方法分析（即方案的前身讨论），据此逐条对照方案原文，修正了草案中与方案不一致的地方；二是 L27 诊断和 Jehn 的回复。

2. **所有训练臂用同一套评价**（方案 §10.1）：都在共同的自然分布测试集上评，也都在共同的匹配候选集（P-L）或历史可比集（H-Cur）上评。B0 的检索分数，就是"不看 EEG 的候选匹配器"。
3. **新增条件错配的 EEG 对照**（方案 §8.3、§11.4）：错配时保留背景关系，不用完全随机打乱代替。

6. **功能层提前到 FAU/TUD**：CI 用 Table 4，HA 待数据到达。修订 1 只在 DTU 上做。
7. **P-L 的目标改为 Lz**（见 §2）。
8. **资源上限改为两步**（方案 §10.4）：先用开发样本做一次小试，测出实际耗时，再登记正式矩阵和上限。所以本次只申请开发小试的 GPU。

## 2. P-L 规格

- **目标**：**主目标是 Lz**，即 Whisper 第 27 层坐标标准化后的 PCA-5（`pca_k8_128hz_whisper_z27.h5`，128 Hz）。冻结的 L27 PCA-5 作为次目标，保持与 C3 的连续性。
  - **理由只来自刺激侧**（`L27_diagnostic.json`）：冻结的 PCA-5 中，PC1 占 99.85% 的方差，几乎全部来自 4 个超大坐标；PC2 基本是声学，并带有编码窗接缝的跳变。它实际上不是一个 5 维的深层表示。Lz 的前 5 个主成分解释 49%，分布在大量坐标上。
  - 这个选择写在 `aggregate p3_l27z` 汇总之前，**不依据 l27z 的 EEG 结果**。
- **背景** m0(Ac)：用 Ac（Whisper 浅层 PCA-5）在 [t−1 s, t+1 s] 的上下文，经岭回归预测 L_t。
  - **必要检查**：用 log-mel PCA-5 替换 Ac 作背景，重复主比较。
  - "未见内容"的设置中，m0 只在训练内容的刺激上拟合（方案 §7.3）。
  - 共享协方差 Σ 取训练折残差的协方差（方案 §5.2）。
- **EEG 输入**：阶段 B 的 ICA 后 31 导，1–20 Hz。预测 L_t 的输入窗为 [t, t+600 ms]（刺激在前）。输出保留时间维，不把 5 s 片段汇成一个向量（方案 §10.3）。
- **模型**：L̂1 = m0(Ac) + g_θ(f_θ(X), Ac)；q0 = N(m0, Σ)，q1 = N(m0 + g_θ, Σ)。**g 置零时逐样本恢复 q0**。
- **评分**（所有训练臂都用同一套）：
  - 自然分布：每个 5 s 片段内逐采样点的 e = (‖L − m0‖²_Σ⁻¹ − ‖L − m0 − g‖²_Σ⁻¹) / (2 ln 2) 取均值，再在被试内平均，被试等权。另报标准化 MSE 与校准。
  - 匹配检索：每个锚点配 8 个近邻候选（同一朗读者、不同段落，按 Ac 摘要距离），以候选索引的对数损失计分；每个候选的分数是该臂对候选 L 的对数似然。B0 的检索损失就是"不看 EEG 的候选匹配器"。
  - **条件错配 EEG**：把 EEG 换成同一被试另一时间段的 EEG，该时段的 Ac 摘要与原片段相近（同一匹配规则）。对每个深度臂重算两项分数；增益应当消失。
- **训练臂**（同一个轻量编码器：空间投影 16 → 3 个时序卷积块 [32, 32, 64] → 32 维时间表示）：
  - B0：m0；
  - B1：m0 + EEG 滞后的线性岭（输入含 Ac 交互项）；
  - D0：只用 EEG 的深度模型，没有 Ac；
  - D1：EEG 与 Ac 拼接后的深度模型（容量与 D2 相同）；
  - D2：m0 + g_θ(f_θ(X), Ac)，只有自然损失；
  - D3：D2 + 随机负样本的 InfoNCE；
  - D4：D2 + 匹配负样本的 InfoNCE。
  - D3 与 D4 的损失、候选数（K = 8）和训练步数完全相同。η 与 τ 只在开发子集上选，选定后冻结。
- **划分**：
  - 开发：选层用过的 14 名 TH，只用于结构与超参数选择（内部交叉验证）；
  - 评价面板：留出 TH（14 人，若收到缺失的被试则为 15 人）、HA 29 人、CI 24 人（只作描述）；
  - 外层：按组分层的 5 折被试交叉验证。每折的训练集 = 开发 TH + 其余 4 折的被试，测试集 = 该折被试；
  - 内容：同一故事的第 1–2 段与第 3–4 段互为训练和测试，分别报告"新被试、已见声音"和"新被试、未见内容"（方案 §7.3）；
  - 种子：3 个。
- **主比较**：被试配对的风险差 R(D1)−R(D4)、R(D3)−R(D4)。另报 R(B0)−R(D4)、R(D2)−R(D4) 和 R(B1)−R(D4)。区间用被试 bootstrap，不作精确 p 值（方案 §11.4）。

## 3. H-Cur 规格

- **输入**：GX_stage_001 中通过 QC 的分段（20 导，250 Hz，−200 到 600 ms）。
- **背景** b(h)：训练儿童在固定历史分箱中的偏差音频率，加 0.5 平滑（与阶段 0 相同）。
  - D0 支持表显示，第 0、1 箱在 64 名儿童中有 63 名的偏差音少于 5 个。但"偏差后紧接偏差"在数据中出现过 16 次，所以这两箱不是结构性确定的。
  - 按方案 §5.1、§6.4，这两箱照常平滑，标为"支持不足"，单独登记，不用来主张条件增量。
- **模型**：logit q1 = b(h) + r_θ(f_θ(x), h)。**r 置零时逐样本恢复 q0**。
- **训练臂**：
  - B0：b(h)；
  - B1：b(h) + 冻结的 GX 证据（即阶段 0）；
  - D0：深度模型，不输入历史；
  - D1：深度模型与历史拼接；
  - D2：b(h) + r_θ(f_θ(x), h)，只有自然损失；
  - D3：D2 + 有监督对比，不按历史匹配；
  - D4：D2 + 历史可比集合内的有监督对比（同一记录、同一历史分箱、不重叠的物理块）。
- **外层**：按组分层的 5 折留儿童交叉验证，3 个种子。每次验证后恢复 `train()` 模式，并记录模型模式、损失、梯度、参数范数和数值异常。
- **评分**（所有训练臂都用同一套）：
  - 自然分布（约 80/20）下的 G_Cur\|Hist、AUC、Brier 和校准；
  - 共同支持历史上的标准化版本（方案 §6.4）；
  - 条件错配 EEG：同一记录、同一历史分箱、另一物理块中的试次 EEG。
- **补充的时间局部性对照**（方案 §8.3，范围事先限定）：比较 Hist + X_pre（−200 到 0 ms）与 Hist + X_pre + X_post（0 到 600 ms），只用 D2 的结构。

## 4. 训练之前必须通过的实现检查

1. 修正项置零时，q1 逐样本等于 q0（P-L 与 H-Cur 都查）。
2. 三个模拟世界，都在留出数据上判读：
   - 只有背景：所有臂的条件增益约为 0，包括背景失配的情形（方案 §4.3）；
   - 有已知大小的条件增量：D2、D4 能恢复，误差在事先给定的范围内；
   - 只有非线性交互（XOR）：D1、D2 能读出约 1 比特。
3. 候选置换：输出随之置换。
4. 训练模式恢复。
5. 辅助通道不进入输入。
6. 历史金标准测试（已有）。

## 5. 功能层（方案 §7.4、§11.1、§11.3）

- **终点与连接**：沿用 `H7_FUNCTION_PREREG.md`，即 CI 的 HSM（Table 4）；HA 的数据到后按同一规格。
- **比较链**：B → B + S_overall → B + S_overall + G_cond。
  - S_overall：D0 的自然分布总解码分数。
  - G_cond：D4 的条件增益。
  - 两者都是外层折外的逐人标量。不拼接 32 维潜在坐标（方案 §11.3）。
- **CI 的伪迹对照**：加入伪迹指数 A，与 H7 的登记相同。
- 上游网络只用刺激目标训练，没有用功能标签。所以一个人的行为不会进入任何人的证据生成；同一个人的 EEG 会参与其他折的训练，这一点照实说明。
- 功能结果不参与 C3-DL 任何配置的选择。

## 8. 判读（照搬方案第 17 节，结果之前固定）

- D4 优于 D1 与 D3，且增益依赖正确的 EEG 对应（条件错配后消失）：支持条件匹配这一训练原则。
- D1 与 D4 相当：简单拼接可能已经足够，条件匹配的必要性没有建立。
- 只有检索提高，自然分布任务没有提高：学到的是特定难例比较。
- 所有深度臂都不超过 B0、B1：该流程没有建立 EEG 增量，不推出"EEG 没有信息"。
- H-Cur 中任何深度臂都不超过 B1（冻结读出）：新训练没有带来条件证据。
- 换成 log-mel 背景之后主比较的方向改变：结论只对浅层声学参照成立，照实写明。

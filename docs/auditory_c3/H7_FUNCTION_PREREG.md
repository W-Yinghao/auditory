## 2. 终点

- **主终点**：HSM 噪声下语句测验（65 dB 言语 / 60 dB 噪声）的正确率 p（%）。
- **变换**：y = logit((p + 0.5) / 101)，在 logit 尺度上用 Gaussian 模型。不把百分比当作删失值。
- **次终点**（同一比较链，结果报全表，在 H7 族内做 BH 校正）：Freiburg 单音节词正确率（同样的变换）；ACALES（若 Table 4 有，按原尺度）。

## 3. 预测量（均为冻结测量，逐人值取自已有输出，不重新选择）

- **C（临床背景）**：年龄（岁）和 CI 使用年限（双侧植入时取较长的一侧），按 Table 4 中实际有的字段。两者都有时两项都用；只有一项时用这一项；都没有时只用截距。这一规则在看到表之前写定。
- **S（总体追踪）**：I(T;Ac)，0–600 ms 窗，三个 ROI 的均值（`main_v2`，`TMIF_Ac_att/all`）。
- **G（深层增量）**：I(T;L27 \| ŷ_Ac)，0–600 ms 窗，三个 ROI 的均值（`main_v2`，`CMI_L_att_given_yAc/all`）。
  - 敏感性：Lz 版本（`l27z`，`CMI_Lz_given_yAc/all`）。
  - 这对应服务器包中 C → C + I(T;Ac,L) → C + I(T;Ac,L) + I(T;L\|Ac) 的比较链。修正案 001 之后，S 加上 G 即为链式分解下的 I(T;Ac,L)，所以采用 C3-DL 方案 §7.4 的写法 B → B + S → B + S + G。这是对原登记的说明，不是改动。
- **A（伪迹指数，新增）**：I(T;Ac) 在诊断窗 [−200, 0) ms 的值，三个 ROI 的均值。依据是 Decision 001：CI 被判为 ARTIFACT_LIMITED，而在幻影头和 CI 中，刺激之前就有"信息"。

## 4. 模型与风险

- 都用 OLS，按参与者留一。预测量的标准化只在训练折内计算。
  - M1：C
  - M2：C + S
  - M3：C + S + G
  - M2a：C + A + S
  - M3a：C + A + S + G
  - M1a：C + A
- 风险 R 是留一预测在 logit 尺度上的平方误差均值。
- **主比较**：ΔR = R(M2) − R(M3)。区间用参与者配对 bootstrap（2000 次，种子 7701）。
- 另报 R(M1) − R(M2)、R(M1) − R(M1a)、R(M2a) − R(M3a)，以及各模型留一预测与观测值的相关。

## 5. 判读（事先写定）

| 结果 | 读法 |
| --- | --- |
| ΔR 的区间不含 0（> 0），**且** R(M2a) − R(M3a) 的区间也不含 0 | 在临床背景、总体追踪和伪迹指数之上，深层增量对 HSM 有留一预测价值（H7 的预测成立） |
| ΔR > 0，但加入 A 之后区间含 0，或者 A 本身就有预测价值（R(M1) − R(M1a) 的区间不含 0） | 功能收益与伪迹分不开：**ARTIFACT_LIMITED，不作主张** |
| ΔR 的区间含 0 | 没有建立增量预测价值。不推出"无关"（n 约为 24，功效低） |
| ΔR < 0（区间不含 0） | 加入 G 使预测变差，照实报告 |

- 对 H7b（HA），A 照算并报告，但 HA 不受伪迹判定的限制：主判读只看 ΔR，A 作为对照列出。
- C3-DL 的功能层（`G_cond` 的折外标量）另行登记，不与本分析合并，也不用本分析的结果来选择 C3-DL 的配置。

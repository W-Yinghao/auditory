# SIR 预测余量报告（C0）

**日期**：2026-10-01
**协议**：`NEXTMAP_PROTOCOL_FROZEN.md` §3；`NEXTMAP_PROTOCOL_ADDENDUM_001.md`（复现门槛的数值容差，写于看到 C0 评分之前；其中"诊断结果"一节写于评分之后，且不改变门槛）
**运行**：
- `c0_001`（Slurm 1017318）：重拟合，465 次有序优化；
- `c0_diag_001`（1017322）：诊断，62 次；
- `c0_rescore_001`（1017324）：只读重评分，0 次。

全部为 runfill，没有被抢占。累计有序优化 527 次，上限 600。

## 1. 数据对象

- PF 第一轮的 55 名有标签合格 HA 儿童（与 A0 是同一批人），外层种子 101/202/303 × 5 折。
- 目标：完整 SIR 1–5 等级（档案终点，不代表同期临床效度）。附属目标：SIR>3。
- 条件 C：原 PF H14 临床模型，即年龄的 B 样条 + log1p(佩戴时长) 的 B 样条，比例优势有序 logistic，λ 由内层 5 折选择。
- 等级分布：SIR 1 有 2 人，2 有 1 人，3 有 21 人，4 有 14 人，5 有 17 人。**等级 1–2 合计只有 3 人。**

## 2. 概率从哪里来

- PF 存档只保存了逐儿童误差，没有保存概率。因此用原函数在原折上精确重拟合，再从同一拟合对象导出五类概率。
- **复现情况**：
  - 每个种子的 AUC 与存档逐位相同（0.97446 / 0.98253 / 0.98790）；
  - MAE 与存档相差 2.0e-6；
  - 逐儿童误差最大相差 7.3e-5。
- 冻结门槛是 1e-9，按它判为"概率来源未决"。诊断发现，同一单元换一个计算节点就会差 7.0e-5，而线程数不影响结果。可见差异来自 L-BFGS-B 终点对浮点内核的依赖。附录 001 把门槛改为优化器容差的量级（AUC 逐位一致、MAE ≤1e-4、逐儿童 ≤1e-3）。
- 因此这里的概率是"原 H14 规格在优化器容差内的精确重拟合"，不是存档参数的逐位复原。

## 3. 数值

概率先截断到 ≥1e-6，再逐行归一化；所有模型用同一规则。主汇总是先在每个种子上平均，再在 3 个种子之间平均。

| 量 | 临床模型 C | 训练集类频率参照 | 均匀五类 |
|---|---|---|---|
| **交叉熵 CE（bit/人）** | **1.35**（各种子 1.04 / 1.22 / 1.79） | 1.95 | 2.32 |
| Brier（五类） | 0.29 | 0.71 | 0.80 |
| MAE（E[Y]，原协议口径） | 0.209 | — | — |
| SIR>3：CE / Brier | 0.42–0.57 bit / 0.05–0.06 | — | — |

儿童 bootstrap 区间（2000 次，条件于已有 OOF 预测，不是 CMI 上界的覆盖保证）：
- 参照 CE − 临床 CE：+0.59 [−0.20, +1.22] bit；
- 参照 Brier − 临床 Brier：+0.42 [+0.28, +0.54]；
- 临床 CE 本身：1.35 [0.59, 2.33]。

**按真实等级拆开的 CE**（三个种子的平均）：

| SIR | 人数 | 平均 CE（bit） |
|---|---|---|
| 1 | 2 | 6.67 |
| 2 | 1 | 19.31 |
| 3 | 21 | 0.75 |
| 4 | 14 | 1.25 |
| 5 | 17 | 0.49 |

- 那 1 名 SIR=2 的儿童，模型给真实等级的概率在 1e-6 量级。仅这 3 名稀少等级儿童就贡献了平均 CE 中约 0.59 bit；其余 52 人的平均约为 0.80 bit。
- 截断规则影响了 39–45% 的概率分量（多为非真实等级上的极小概率）；保护前的最小概率为 0（数值下溢）。
- **校准（描述）**：平均预测类分布与实际分布接近，SIR>3 的平均预测概率为 0.560，实际比例为 0.564。
- **分数类型与 AUC**（`final_001` 从已存输出计算，不拟合）：
  - 把各折模型的**潜变量**直接合并后算 SIR>3 的 AUC：0.974 / 0.983 / 0.988，即 PF 存档的 0.982；
  - 改用各折自己的阈值换算成 **P(SIR>3)** 再合并：0.970 / 0.961 / 0.970，平均 0.967；截断与否结果相同。
  - 饱和造成的并列每个种子最多 1 个，不是差别的原因。比例优势模型在单个折内，P(SIR>3) 是潜变量的单调函数；差别来自各折模型的阈值与尺度不同，跨折合并时潜变量不在同一刻度上。
  - 因此跨折合并时，概率口径的 AUC（0.967）比存档的 0.982 更恰当。两者都说明二元排序接近完美，结论不变。

## 4. 怎么读

信息论关系：I(Y;X|C) ≤ H(Y|C) ≤ CE(q_C)。经验 OOF CE 不是总体 CE，固定预测的 bootstrap 也不构成上界证书。

对照执行版 §5.4 的五种情形：

| 情形 | 本轮 |
|---|---|
| CE 很低、概率合理 | **不符合**：平均 CE 1.35 bit，去掉稀少等级后约 0.8 bit |
| **AUC 高但 CE／概率差** | **符合**：SIR>3 的排序几乎完美（概率口径 AUC 0.967，存档潜变量口径 0.982），但五级概率仍留下明显不确定性；少数儿童被极度自信地判错 |
| CE 不低而 EEG 没有增量 | **符合**：已有的 C+EEG（CZ）对 MAE 和 AUC 都没有增量（ΔMAE −0.001，AUC 0.982→0.983）；当前的 EEG 表示、样本或读出没有利用这部分余量，原因仍开放 |
| **稀少等级主导误差** | **符合**：等级 1–2 只有 3 人，却贡献了约 44% 的平均 CE |
| 只有重校准改变风险 | 本轮没有做重校准（按协议） |

**结论**：
- "SIR 已被病历变量决定"**没有得到支持**：二元排序几乎完美，但五级概率的经验 CE 远不为零。
- 多轮"EEG 加不上"**不能**用"没有预测余量"来解释。同样，CE 高也不说明 EEG 一定有信息：CE = H(Y|C) + KL，其中一部分是临床模型自身的过度自信（KL 项），不是不可约的不确定性。
- 能确定的是：这个终点的有效分辨率主要在 SIR 3–5 之间，等级 1–2 的支持只有 3 人。

## 5. 尚不能推出什么

- 不能说"真实条件互信息小于某个值"，也不能把这里的 CE 当作个体临床证书。
- 结论只针对这 55 名 HA 儿童的档案 SIR 与这个临床模型 C，不推广到其他言语功能或其他量表（MUSS、CAP 都没有纳入）。
- 不能把"EEG 没有增量"解释为"神经信号不存在"，也不能解释为"EEG 学到的只是病历"。

## 6. 哪个下一步因此值得、哪个不值得

- **不值得**：在这 55 人、这个终点上继续换 EEG 模型（已经约 12 轮）。
- **值得（作为现有稿件的分析章节，不另立论文）**：
  - 在报告 AUC 的同时报告完整类别概率的 CE 与校准，避免"临床基线已到天花板"这类过度表述；
  - 指出等级 1–2 支持不足。
- 若要真正检验"剩余不确定性里有没有 EEG 信息"，需要更多低等级儿童，或者新的 HA 队列。这是数据问题，不是模型问题。

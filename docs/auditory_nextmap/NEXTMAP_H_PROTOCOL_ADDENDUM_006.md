# NEXTMAP H 系列附录 006：H11（组合特征下的记录时长曲线）（事后；2026-10-02）

**时点**：写于看到 H10 之后、H11 计算之前。

## 起因

D2 稿件的第二个核心结论是"128 导下，记录长度约 2 分钟就饱和"（RBF 读出，修正后 12.22 ± 0.05，对比全长 12.50 ± 0.27）。组合特征（D2 谱 + 增强谱）改变了绝对误差，需要检查这一结论是否仍然成立。

## H11 定义

- **数据**：D2 时长分析的队列与筛选。只取每条记录最早 N 分钟内的可用窗口（D2 的 `minutes` 规则），N ∈ {1, 2, 4}，对应 59、60、61 条记录。外层折用 `D2_dur_m{N}_s{11,22,33}_predictions.json` 存档的折。
- **特征**：
  - `d2_128`：必须重现存档的 RBF b128 预测；
  - `d2plus_128`：同样的最早 N 分钟窗口上算出的增强谱，与 D2 谱拼接。
- **读出**：D2 的 RBF 嵌套选参（复现与组合特征都用）；组合特征另做 D2 的线性读出。缺失值用每折训练集中位数填补。
- **参照**：全长结果取 H8 的种子 11/22/33。
- **报告**：
  - 每种时长的 MAE（3 个种子）；
  - 组合特征下 1、2、4 分钟与全长的配对差；
  - 描述性的饱和点：MAE 首次进入全长种子间范围时的时长。
- **读法**：
  - 若组合特征在约 2 分钟时已接近全长：D2 的时长结论在更好的特征下成立；
  - 若需要更长时间：稿件需要更新时长建议。

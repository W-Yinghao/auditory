## 1. A0：已有单编码器嵌入上的年龄信息分解

- **队列**：PF2 `prepare_002` 中 `group = labelled`、主访视有每类 80 的抽样、年龄有限的儿童（P0 核对为 55 人）。一名儿童就是一个统计单位。NH 不进新比较。
- **划分**：PF2 的外层种子 404/505/606/707/808 × 5 折，沿用原有划分，不新建。
- **单元**：(预算, 视图, 种子, 折)。每个 (种子, 折) 只用该折 `stim_002` 的 M_o 导出（`agg_source = single_encoder_M_o`），不跨单元混用坐标。测试儿童的任何访视都不在 M_o 的训练或早停里。
- **预算**：
  - 主层 `single_draw80`：每个源种子取 `agg_base[:, 0]`，即 draw0，每类 80 个不放回；
  - 敏感性层 `draw_ensemble10`：10 次抽样嵌入的平均，报告实际用到的唯一试次数；只跑 common 和 joint 两个视图。
- **成对缩放与旋转**：
  - 在当次拟合的训练儿童上，把每名儿童的两类均值堆叠，儿童与类别等权，得到每维共同的中心 m_j 与尺度 s_j（ddof=0）；s_j < 1e-8 时置 1，并报告这样的维数。
  - z_s = (μ_s − m)/s；c = (z0+z1)/√2，d = (z1−z0)/√2。
  - 视图：std = z0、dev = z1、common = c、contrast = d、joint = [c,d]、pair = [z0,z1]。旋转后不再分别标准化。
  - 内层选参时，在内层训练子集上重估缩放。
- **读出**：
  - min_{b,w} Σ(A − b − xᵀw)² + α‖w‖²，截距不罚，FP64。p ≤ n 时解原问题，p > n 时解对偶问题，一律用 solve，不求逆。
  - α ∈ {1, 100, 10⁴}。内层 3 折，按儿童划分；种子 = `stable_int("nextmap_inner", s, k)`。按平均验证 MAE 选 α，差在 1e-12 以内的并列取较大的 α。外层测试儿童不参与选参。
  - 称为"冻结表示上的内层探针选参"，不是重新训练编码器的完整嵌套验证。
- **其他视图**：
  - `spectral_ridge`：`features_001` 的 cont [20,9] 展平，训练内 z 分数，选参同上；
  - `spectral_rbf`：同一输入、训练内 z 分数，γ = 1/训练集非零平方距离的中位数（无正距离时 γ = 1 并记录）；核按训练均值中心化，求解 (K_c + αI)a = y_c，α ∈ {0.01, 1, 100}；
  - `technical`：record_scale、accept_fraction、qc_over_mean、log1p(n_acc)、log1p(d1_seconds)，缺失值用训练中位数填补并加缺失标志，再做 z 分数。**解读：record_scale 是逐记录幅度，与年龄有生理关联，所以这是"幅度水平 + 质控"参照，不是纯技术参照；**
  - `median_train` / `mean_train`：外层训练年龄的中位数和均值；
  - `pair_equivalence`：用 joint 选定的 α 拟合 pair。预测、目标值和能量与 joint 的相对差必须都 ≤ 1e-8，否则该单元记为 NUMERICAL_FAILURE。
- **用户批准的增补**（标注为敏感性，不替换主比较）：
  - (a) `contrast_bs` / `joint_bs`：在训练儿童上对 c、d 分别做 z 分数；
  - (b) `technical_noscale`：technical 去掉 record_scale。
- **主终点**：
  - 每名儿童先在 5 个源种子上平均绝对误差，e_i^(m) = (1/5) Σ_s |A_i − Â_{i,s}^(m)|；
  - **G_{D|C} = mean_i(e_i^common − e_i^joint)**，正值表示加入差异表示后误差下降，负值完整保留。
- **区间**：配对儿童 bootstrap 2000 次，种子 27092701，所有比较共用同一套重采样索引。这是"条件于已有拟合的描述性区间"，不做置换显著性检验，不设门槛。
- **预定次要比较（a − b，正值表示 b 更好）**：std − dev；median_train − contrast；spectral_ridge − joint；spectral_rbf − joint。
- **敏感性比较**：
  - draw_ensemble10 的 G；
  - (a)：common − joint_bs、median_train − contrast_bs；
  - (b)：technical_noscale − technical。
- **一并报告**：每个种子的 MAE、MSE、儿童误差分位数、集成预测（先平均 5 份预测）的 MAE（只作敏感性）、各 α 被选次数、测试儿童超出训练年龄范围的次数、按训练侧年龄三分位的描述性误差。不按成绩挑选年龄窗口。
- **完整性**：任何视图缺折、缺儿童或出现非有限值，就整体记为 INCOMPLETE 或 NUMERICAL_FAILURE，不对成功部分取平均。

## 2. A1：信息来源对照（不训练新编码器）

- **trained_common_matched**：A1 支持集等于 A0 队列时，直接复用 A0 的 common 预测，不重拟合；是严格子集时，在子集上重拟合（读出规则同 A0）。
- **random_common**：
  - 每个 (种子, 折) 一个同架构的 EEGNet（F1 16, D 2, F2 32, k1 25, k2 15；20 通道 × 200 点），初始化种子 = `stable_int(27092702, s, k)`；
  - eval 模式，不训练，不做 BN 适配，不按年龄成绩挑种子；
  - 嵌入 draw0 的两类试次，取类均值后按成对缩放得到 common。
- **raw_common**：
  - GX 暂存 x（已除以 record_scale、clip ±60 的 float16，**没有基线校正**）的 draw0 试次，按 5 个样本（20 ms）一个的非重叠窗取均值，得到每通道 40 个 bin、共 800 维；
  - 取类均值后用成对缩放得到 common。
- **nonaligned_common**：
  1. 每条主访视记录，以 draw0 两类试次所在 60 秒块（`block_id = floor(onset/60)`）的计数作为每块配额。
  2. 候选锚点 a 必须满足：[a − 50, a + 150) 落在同一 D1 存储区间内且两侧各留 2 s guard；与该区间内**所有已记录的 target 和 unknown_sound 事件**相距 > 20 个样本（80 ms）。比执行版只排除已知声音更保守，目的只是避免精确对齐，不给这些事件补标签。
  3. 每块候选用固定种子 `stable_int(27092703, record, block)` 打乱，依次在 µV 上做暂存的同一质控（峰峰 >150 µV 的通道超过 10%，或平直 <0.5 µV 的通道超过 10%，即拒收），取前"配额"个通过的锚点。
  4. 窗口按暂存方式变换：float32 / record_scale（暂存文件中的值，转为 Python float）、clip ±60、float16；不做基线校正。
  5. 用该折的 M_o 嵌入后取均值，得到 n_i，以 μ0 = μ1 = n_i 进入 common（等价于乘 √2）。不跨块、不跨记录补样；不够的记录退出该比较，所有比较在完整支持子集上重算。
- **一致性门槛**：
  - 主访视记录的目标 epoch 由 D1 和事件表重切后，必须与暂存的 x 完全相等（float16 逐位）；
  - M_o 重新推理 draw0 得到的类均值，与 `agg_base[:,0]` 的最大绝对差 ≤ 0.05（bf16 内核差异），并报告实际差值。
  - 任一门槛不通过，只阻断非对齐比较。
- **比较**：trained_common_matched − {random_common, raw_common, nonaligned_common}，正值表示对照更好。bootstrap 同 A0；支持集不同时，用同一种子在该支持集上重新生成索引。
- **推理**：使用支持 bf16 的 GPU 分区（A100、A40、L40S、A30），在 CUDA 上用 bf16 autocast，与 `stim_002` 的嵌入口径一致。GPU 长时间不可用时，全部 A1 嵌入改用 CPU FP32（包括重算训练编码器的 draw0），并在报告中写明。

## 3. C0：SIR 五类概率与预测余量

- **对象**：PF 第一轮 `prepare_001` 的 E 组（有标签且合格，P0 核对与 A0 队列相同，55 人），外层种子 101/202/303 × 5 折。
- **路径**：`h14_err` 只存了逐儿童误差，因此用原函数 `clinical_design`（年龄与 log1p(时长) 的 B 样条）和 `stats.ordinal_cv`（λ 6 档、内层 5 折、种子 s·10+k）做精确重拟合。五类概率从 `ordinal_cv` 返回闭包中的同一拟合对象（OrdinalLogistic + Standardizer）用 `proba` 导出。共 465 次有序优化。
- **复现门槛**：
  - 逐儿童、种子平均的 |E[Y] − SIR| 与 `h14_err.C` 的最大差 ≤ 1e-9；
  - 每个种子的 AUC 与存档值相差 ≤ 1e-12；
  - MAE 与存档值相差 ≤ 1e-9。
  - 不通过则记为 PROBABILITY_SOURCE_UNRESOLVED，不另建临床模型。
- **评分**：
  - p ← max(p, 1e-6) 后逐行归一化，所有模型同一规则，并报告保护前的最小概率和受影响比例；
  - CE_i = −log2 q_i(Y_i)，Brier_i = Σ_k (q_ik − 1{Y=k})²；
  - **主汇总**：每个种子在 55 人上取平均，再在 3 个种子间平均；
  - 敏感性：3 个种子的平均概率；
  - 同时保留原协议的 MAE（E[Y]），以及 SIR>3 的概率 q4+q5 对应的 AUC、Brier 和 CE。
- **参照**：每个外层训练集的平滑类频率（每类 +0.5），以及均匀五类分布（log2 5 bits，Brier 0.8）。儿童 bootstrap 2000 次（种子 27092704），只作描述，不是 CMI 上界的覆盖保证。
- **校准**：只作描述，包括类分布、SIR>3 的平均预测概率与实际比例、按真实等级分的 CE。不做温度选择或重校准。
- C+EEG（CZ）的 CE 不算，因为会超出 600 次的上限。

## 4. B0：证据规则

- **证据等级**：DIRECT、LINKED、SCOPED、CANDIDATE、UNKNOWN、CONFLICT，定义见研究版 §4.3。各字段独立升级。两个强来源冲突时保留 CONFLICT。
- **不能作为真值证据的**：SOA、偏差比例、目录相似、解码成绩、文献或幻灯片里的预期人数。它们最多是 CANDIDATE。
- **身份**：不用 EEG 相似度定身份；空的 subject_fields 或 Patient ID 不能自动产生新儿童。可能是同一人时，保守地并组。
- **年龄**：只来自可信的 DOB 加原始记录时间，或已核实的对应年龄列；部分精度保存为区间，不取中点。
- **曝光**：每个候选都写入曝光清单；`not_found_in_checked_runs` 不等于从未使用。
- **BDF 时钟**：只用元数据（头文件时间、伴随文件的时间记录）确定候选偏移，不用信号选偏移。
- 恢复人数不设成功阈值。恢复后只输出任务卡，不自动训练。

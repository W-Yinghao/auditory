## 0. 结论先行

1. 两份文档可以在服务器上执行，本轮仍是 **0 个新编码器训练**。A0、C0、B0 只需 CPU；A1 需要 1 个 GPU 推理作业。
2. 核对后有三处会改变执行路径：
   - **C0 没有现成概率。** PF 的 H14 只在私有输出里存了逐儿童误差，没有存五类概率、潜变量或模型参数。按执行版 §10.2 第二条，改为对原临床模型做一次完整重拟合，并用旧的逐儿童误差逐项复核，以证明重拟合的就是原模型。
   - **GX 输入没有基线校正。** 输入只经过逐记录幅度标量 record_scale 归一化。非对齐片段必须沿用"无基线 + 同一 record_scale + 同一 µV 质控"。执行版要求的"相同基线校正"在这里就是不做基线校正。
   - **技术基线里的 record_scale 本身随年龄变化。** 儿童 EEG 幅度随年龄下降，而事件嵌入和持续谱都已经除掉了这个量。A-TECH 应读作"幅度水平 + 质控"参照，不是纯采集参照。
3. 建议两个小的敏感性增补（§3），需要你批准；加上后仍在执行版的资源上限内。

## 2. 必须的适配（实现时照此执行）

1. **路径与环境。** 脚本放在 `slurm/auditory_nextmap_{cpu,gpu,tests}.sbatch`（项目惯例，执行版写的是 `scripts/slurm/`）。直接使用 `/home/infres/yinwang/anaconda3/envs/eeg2025/bin/python`，并设 `PYTHONHASHSEED=0`。日志放 `private/auditory_nextmap/logs/`。代码包 `auditory_nextmap/`，配置 `configs/auditory_nextmap_v1.yaml`（执行版 §14，外加适配字段），测试放 `tests/auditory_nextmap/`。旧包一律不改，只导入。
2. **C0 走完整重拟合**（新运行 `c0_001`）。共 3 种子 × 5 折 × (6 λ × 5 内层 + 1) = **465 次有序优化**，不超过 600 的上限。只有同时满足下面两条，才把这次重拟合当作"H14 的临床模型"：
   - 逐儿童、种子平均的 \|E[Y]−SIR\| 与 `h14_err.C` 的最大差 ≤1e-9；
   - AUC 0.982、MAE 0.209 能复现。

   满足后，从同一批拟合对象用 `proba` 导出五类概率。不满足则记为 `PROBABILITY_SOURCE_UNRESOLVED`，C0 到此为止，不另造临床模型。C+EEG（CZ）的 CE 不计算：它需要再做 465 次拟合，会超出上限。CZ 只沿用已有的 MAE 和 AUC。
3. **A1 非对齐片段沿用 GX 定义。** 不做基线校正；直接用暂存文件里的 record_scale，不在新片段上重估；质控在 µV 上做，规则与暂存相同；clip ±60 后存 float16。设两道一致性门槛：
   - 用同一流程重切一组固定记录的目标 epoch，必须与暂存的 x 在 float16 上完全一致；
   - 用 M_o 重新推理 draw0，复现 `agg_base[:,0]`，报告最大差与中位差。

   任一门槛不通过，只阻断非对齐比较。
4. **A1 匹配参照不重复拟合。** 连续记录约 13 分钟，预计非对齐片段能覆盖全部 55 人。若覆盖，`trained_common_matched` 直接复用 A0 的 common 预测；只有支持集是严格子集时才重拟合。
5. **GPU 只用支持 bf16 的分区。** 若 GPU 排队超过约 1 天，改为在 CPU 上用 FP32 计算 A1 的**全部**嵌入，包括重算训练编码器的 draw0，使 A1 内部的数值口径一致，并在报告中写明精度变更。
6. **A-TECH 的解读。** 按 §0 第 2 条第三点，A-TECH 读作"幅度水平 + 质控"参照。
7. **C0 的主汇总方式。** 每个种子的 OOF（55 人）先算 CE，再在 3 个种子间平均；集成概率的 CE 作为敏感性。这与 A0 "先平均误差、不平均预测"的规则一致。

## 6. 结果预期（写在执行之前，供解读时对照）

- **A 线。** 儿童皮层听觉诱发反应（如 P1 的潜伏期与形态）随年龄显著成熟，这是已知现象。因此 common 与 raw_common 很可能承载大部分年龄信息。如果固定的 raw 分箱平均（本质上就是平均波形）接近训练编码器的 common，就说明事件表示里的年龄信号主要是必然性诱发反应的成熟，而不是刺激解码器学到的特殊信息。这决定候选论文一有没有方法新意。本轮没有做系统文献检索，相关结论需投稿前另行核查。
- **C 线。** 只用年龄 + 佩戴时长，SIR>3 的 AUC 已到 0.982，CE 很可能很低。若如此，这个档案终点留给任何额外观测的预测余量有限；若 CE 不低，结论仍然开放。
- **B 线。** 只有 U1 有可能打开新的比较。U3 的净新增身份预计不多，且其连续记录大多已进入过自监督预训练（曝光），不能当作独立验证。

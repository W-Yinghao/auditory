## 1. 数据对象

- 与 NEXTMAP A0 完全相同：55 名 HA 儿童的主访视，PF2 的 25 个单元，评估预算是 draw0 每类 80 个试次。
- 年龄网络的结构、优化器、数据增强、早停规则都与刺激编码器 M_o 相同，只是目标换成年龄。训练儿童是外层训练折中有年龄的儿童（约 45 人参与拟合，约 9 人做早停验证）。
- **这批儿童已被多轮使用；G1 的方向来自已看到的 A0/A1 结果**，是事后提出、事前写定规则的再检验。

## 3. 怎么读（对照冻结协议预先写定的读法）

| 预先写定的情形 | 结果 |
|---|---|
| 单试次年龄网络接近或好于刺激训练 | **不符合** |
| **单试次年龄网络明显差于刺激训练** | **符合**：差 9.0 月。直接用约 45 名儿童的年龄标签训练，网络几轮之内就开始记住训练儿童，验证误差回升；刺激监督提供了在儿童之间泛化的表示，而年龄恰好可以从这种表示里线性读出 |
| 单试次年龄网络明显好于原始线性 | **不符合**：差 −0.4，区分不出。给原始单试次同等的网络容量、直接用年龄监督，并没有超过原始平均波形的线性读出 |
| 子平均 ≈ 单试次 | **不符合**：子平均好 3.9 月。直接学年龄时，降噪的输入更容易学 |
| M_o 作用于平均波形明显差于刺激训练 common | **符合**：差 6.4 月。逐试次的非线性特征在平均之前就携带年龄信息；"平均的嵌入"不等于"嵌入的平均" |
| 原始 RBF ≈ 原始线性 | **大致符合**：RBF 好 2.3 月，区间跨零 |

**合起来看**：
- NEXTMAP 中训练编码器 23.2 对原始分箱 31.9 的差距，**不能用读出容量解释**。原始分箱换成 RBF 读出、或换成同等容量的直接年龄网络，都只到 28–32。
- 差距也**不在平均波形里**：M_o 看平均波形只有 29.6。
- 差距在于**刺激训练学到的、逐试次计算后再平均的表示**。这使 A-LEARN 的含义更具体：起作用的是刺激判别这个大样本（试次级）监督任务所提供的归纳偏置，而不是"任何监督学习都行"。直接年龄监督在这个样本量下明显过拟合。

## 4. 尚不能推出什么

- **这不是"刺激训练学到了听觉发育特征"的证据**。只能说：在这个读出流程里，刺激训练的表示比直接年龄监督更好地保留了可在儿童间泛化的年龄结构。这种结构可能是一般的波形与幅度形态，并非听觉特异。
- **直接年龄网络的失败依赖样本量和训练设置**（约 45 名儿童、与 M_o 相同的超参数与早停）。更强的正则、冻结前几层，或刺激与年龄的多任务学习，都可能改变结果，本轮没有测试。
- 仍然只有 HA/BDF 的 55 人，与 PF/DV/NEXTMAP 是同一批儿童，不是独立复现。
- 验证儿童少（约 9 人），早停点的选择有噪声，种子间范围也较宽。

## 5. 哪个下一步因此值得、哪个不值得

- **不值得**：用现有样本量继续直接训练"年龄网络"或加大网络。
- **可以考虑**（新的 GPU 规格，需要你批准）：
  1. **多任务或预训练后微调**：先用刺激判别（试次级大样本）训练，再用年龄微调或联合训练，检验"刺激监督作为正则"能否在此基础上进一步降低年龄误差。
  2. **跨系统检验**：在 MFF 上，用更好的刺激编码器，或用试次数更多的车道，检验同一机制。
- 对候选论文一，G1 补上了"读出容量"这一环：优势来自刺激训练的逐试次表示，而不是读出器或平均波形。剩下最大的缺口仍是独立复现，需要新儿童或另一系统。

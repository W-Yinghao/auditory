本文件把材料包的 01_STORY、02_SERVER_EXECUTION、03_METHOD_SPEC 和 `config/story_v1.yaml` 落实为服务器实现。材料包留给服务器决定的细节，在下文写定。写定时间：在任何 SIR/MUSS 相关拟合或比较之前；在 P0 结构探针（作业 1018053）之后。P0 探针只读结构信息：字段、形状、可用性与块计数，没有读取结局分布。冻结后改动只能写进带日期的附录。机器可读配置为 `configs/auditory_story_v1.yaml`。

## 1. 问题与终点（不改）

- 主终点：SIR 1–5 五级有序等级。次终点：MUSS 原分（0–100）。
- 不自动更换终点；年龄、IT-MAIS、CAP 不进入本轮。
- 两项主比较：低标签平均 RPS 下的 C＋SRP 对 C，以及 C＋SRP 对 C＋普通刺激条件均值。

## 2. 队列与单位

- 主队列：通过 NEXTMAP `AgeSource` 读取 PF2 `prepare_002` 中带标签的 HA 主访问。条件为有固定预算 draws 且年龄有限，共 55 名儿童，每人一个主访问。
- 独立单位是儿童；其他访问不进入任何拟合，NH 不进入主矩阵。
- 临床值来自 PF2 记录表，并由 P0 用 `private/auditory_repair/ha_prepare_001/cohort.csv` 逐项复核：每个主记录恰好一行，SIR、MUSS、年龄、佩戴月数完全一致。
- SIR 必须在 1..5 之内，MUSS 必须在 0..100 之内。

## 3. 外折、辅助池与可见范围

- 外折：PF2 种子 404、505、606，各 5 折，从 Cohort 读取，不重排。T_o / E_o 在儿童、身份组和主记录三个层面都不相交。
- 编码器 f_o：`stim_002/unit_s{s}_k{k}/models/M_o.pt`。
  - 它的刺激训练范围是该 lane 在 T_o 中的全部儿童，包括 NH、无标签儿童和 2 名不在主队列的有标签儿童，记入曝光表；
  - E_o 从未进入 f_o 的训练。
- 辅助池 U_o：主队列 T_o 的 EEG。
  - 内层临床验证儿童的无标签 EEG 进入 P1 的变换、人群模型与摘要训练；
  - 他们的 SIR、MUSS、年龄从不进入 P1。

## 4. 输入定义

- **试次嵌入**：复用 `private/auditory_nextmap/h_infer_001/items/ha_s{s}_k{k}.npz`，即每个单元 M_o 对 55 个主记录全部接受试次的 192 维嵌入（bf16 推理，float16 精确存储）。P0 必须再次核对三项：
  - `all_idx` 与当前队列完全一致；
  - 缓存 draw0 类均值与 stim_002 `agg_base` 的差 ≤ 1e-5；
  - M_o 文件早于缓存。

  因此新增冻结主干推理为 0 个单元。
- **32 维坐标**（每单元）：
  - 拟合样本：T_o 每人每类最多 128 个试次，种子 2026100201，不放回；
  - 按 child×class 等权做标准化与 PCA，取实际秩与 32 的较小者，不补随机方向；
  - **本实现对 PCA 分数做白化**：除以对应特征值的平方根，使每维在训练池等权方差为 1。目的是让冻结的 log 方差界 [−4, 3] 和 tanh 输入尺度不起截断作用。C_MEAN 与 C_MEAN8 之后会重新标准化，不受影响。
  - 主成分符号：最大绝对载荷为正。
- **前事件历史 h**：
  - 取 ST1 事件表（与 GX stage 按 `trial_id` 连接）的 `previous_run_length` 和 `previous_gap_s`，分别做 log1p；
  - `previous_run_length` 是"到前一个声音为止的同码连续长度"，与配置字段名一致。材料包正文的"前置标准数"与它只在偏差音后的第一个标准音上不同（1 对 0）。
  - 链断点处的未知值保持缺失；
  - 第三项是记录内时间位置 (onset − 首个目标音)/(末个目标音 − 首个目标音)；
  - 缺失值用训练池中位数填补；之后用训练池 child×class 等权均值和标准差标准化。缺失掩码不输入网络。
- **物理块**：
  - 以 epoch 中心（onset＋0.2 s）在其 D1 连续区间内的相对秒，划分 60 秒块。55 个主记录都只有一个 D1 区间。
  - 中心距块边界 < 5 秒、或距区间末端 < 5 秒的试次，不进入支持/查询；
  - 偶数块为 A 组，奇数块为 B 组。
- **episode 资格**：两组各类都有 ≥32 个守护试次（P0 探针：55 人中 54 人）。不足的儿童不进辅助训练 episode，不进 E3（单列为不支持），但仍有临床摘要。

## 5. 人群模型与两个摘要臂

- q0：
  - 每条件做加权岭回归 [1,h]A_s。每名儿童在该条件的总权重相同，权重和为 1；
  - α=0.1，截距不惩罚，FP64；
  - 方差取加权残差逐维方差，log 方差裁到 [−4, 3]；
  - 拟合用 T_o 全部接受试次。
- 网络与损失：φ 为 32→32(tanh)→16(tanh)；μ 与 log v 各 8 维，log v 裁到 [−6, 2]；解码器为 m0＋B_s u，log 方差 v0＋D_s u 裁到 [−4, 3]；B 用小随机值初始化，D 置零。损失为儿童/条件/维度等权的查询 NLL 加 0.01×KL/8。
- 训练：
  - Adam，lr 1e-3，梯度范数裁到 5，FP32；
  - 固定 3000 步、取第 3000 步，不做任何基于验证的选择；
  - 每步 4 名儿童（不放回），每类支持 32、查询 32（不放回）；方向逐步交替（偶数步 A→B，奇数步 B→A）。
- 两个臂（conditional、pooled）使用相同初始权重和相同 episode 流，差别只在支持集合是否按条件组织。
- 每 100 步保存检查点（模型、优化器、torch RNG、采样器状态、诊断）。
- 临床摘要：每名儿童用主访问全部接受试次，按条件流式累计 φ 的精确均值（每类权重 1/2），测试时 u=μ。
- 数值故障：停止该单元并记录，不只报告成功单元。

## 6. 临床头

- 设计：
  - 年龄与 log1p(佩戴月数) 各做二次 B 样条：3 个分位结点，不含 bias，边界外常数外推；
  - 结点、填补中位数、标准化都只在当前有标签拟合行上拟合；
  - 唯一值少于 4、或分位结点重复时，改用该变量的线性项。这是事先定义的线性回退，所有臂同规则。
- 各臂的视图：
  - C_MEAN：32 维坐标的 [μ_std, μ_dev]，共 64 维；
  - C_MEAN8：64 维条件均值先用 T_o 的均值和标准差标准化，再在 T_o 上做 PCA8；
  - C_SPEC：PF `features_001` 的 cont [20×9] 与 H4 `specplus` [20×8] 拼接，共 340 维，即 H8c 的 `spec_d2_plus`；
  - C_POOL / C_SRP / SRP_ONLY：对应臂的 8 维 μ；SRP_ONLY 不含临床列；
  - C_TECH：记录尺度、接受比例、QC 超限均值、log1p 接受试次数、log1p D1 秒数；C_TECH_SRP 为 C_TECH＋SRP μ。
- SIR 头：
  - 比例优势模型，目标为平均 NLL＋(λ/2)‖w‖²＋(0.001/2)Σ(t_k − logit(k/5))²；
  - t1 自由，后续阈值为 softplus 正增量，最小间隔 1e-4；
  - FP64，稳定 log 差分，解析梯度（已与有限差分核对）；
  - L-BFGS-B，最多 400 次迭代，gtol 1e-6；初值 w=0、t=logit(k/5)。
  - 训练集缺少某等级时，仍输出五类概率。
- 标签集合：
  - 种子 2026100212；每个 rep 对 T_o 排序后做一次不读目标的置换，12 取 24 的前缀；
  - 12、24 各 3 个 rep，全量 1 个；所有臂共用；
  - 集合 hash 写入 P0 摘要。
- 内层：
  - 把 L 按种子 2026100203（与单元、预算、rep 绑定）做不读目标的置换，再轮流分成 3 折；所有臂共用；
  - SIR 选 λ 的依据是全部内层留出儿童的平均 RPS，MUSS 是裁剪后 MAE；平局取较大 λ；最后在全部 L 上重拟合。
  - 每次头部拟合等于 10 次优化器调用。
- PRIOR：L 的类频率，每类加 0.5 伪计数，不拟合。
- MUSS 头：
  - 目标在拟合集上中心化并按尺度标准化；
  - 损失为平均平方误差＋λ‖w‖²，闭式解 (X'X＋nλI)w = X'y；
  - 输出裁到 [0, 100]，未裁剪值另报。

## 7. 评价

- 指标：
  - 每次预测记录 RPS、NLL（bit，共同 floor 1e-6 后归一化）、Brier、期望分数 MAE、P(SIR>3)；
  - floor 1e-8 与 1e-4 只做重评分，不重训。
- 聚合：每名儿童先在同一预算的 rep 与外层种子上平均损失，再跨儿童平均；不先平均预测。R_low = (R_12＋R_24)/2。
- 主比较（正值表示 C_SRP 更好）：Δclinical = R_low(C) − R_low(C_SRP)；Δmethod = R_low(C_MEAN) − R_low(C_SRP)。
- 不确定性：
  - 儿童层 bootstrap 2000 次，种子 2026100299，所有比较共用重抽样索引；
  - 给出百分位 95% 区间，以及双侧 bootstrap p = 2·min(P(d*≤0), P(d*≥0))；
  - 两项主比较做 Holm 校正；
  - 这些都条件于已保存的 OOF 预测，不覆盖整个开发路径的不确定性。
- 次要比较（描述性）：C_POOL、C_SPEC、C_MEAN8 对 C_SRP，PRIOR 对 C，C 对各 EEG 臂，各预算单列。
- AUC：P(SIR>3) 在每个种子×rep 的 55 名 OOF 儿童上计算，再平均；不合并不同折的潜变量。
- 逐等级损失只用于解释，不用于分层挑选。
- **E2**：MUSS 全标签 C、C_MEAN、C_SPEC、C_SRP；报告 MAE、RMSE、未裁剪 MAE、满分人数；比较 C、C_MEAN、C_SPEC 对 C_SRP。
- **E3**：
  - 设置：留出儿童、两个方向；支持与查询各每类 32 个，选择种子 2026100204，与臂无关；
  - 指标：q0（u=0）、pooled、conditional 的查询 NLL（每维、类等权）；
  - 汇总：配对增益在每名儿童的种子与方向上平均，再做 bootstrap；
  - 另报均值 MSE、z² 校准，以及 conditional 臂交换支持条件后 NLL 的增加量；
  - 这些量都以训练 PCA 坐标为测量对象，不称为原始 EEG 互信息。
- **E4**：全标签 C_TECH 对 C_TECH_SRP。
- **E5**：用全标签已拟合的 C_MEAN 与 C_SRP 头（同一次拟合、不新拟合），对 A 组与 B 组守护试次分别生成的摘要做预测，报告分歧和误差变化。这不是复测效度。

## 9. 判读规则（冻结）

按以下顺序取第一条满足的状态：

1. **TECHNICAL_FAILURE/SUPPORT_LIMITED**：任一必需单元缺失或数值失败，主比较不能合法完成。
2. **FUNCTIONAL_GAIN_SUPPORTED_WITHIN_SCOPE**：需同时满足三条：
   - Δclinical 与 Δmethod 点估计都为正；
   - 两者 Holm 校正后 p < 0.05；
   - R_low(C_SRP) ≤ R_low(C_SPEC)。
3. **METHOD_GAIN_WITHOUT_CLINICAL_INCREMENT**：Δmethod 满足上述支持条件，Δclinical 不满足。
4. **AUXILIARY_ONLY**：两项功能比较都不满足，但 E3 中 conditional 对 q0 的查询 NLL 增益 95% 区间下限 > 0。
5. **LOW_PRECISION**：任一主比较的 95% 区间同时越过 −δ 与 +δ。δ = 0.1 ×（R_low(PRIOR) − R_low(C)），即临床基线相对先验改善量的 10%。
6. **NO_ESTABLISHED_GAIN**：其余情况。

另外报告各条件的布尔标记（例如 AUXILIARY_ONLY 同时宽区间）。有两种组合不对应材料包的任何专门状态：

- 只有 Δclinical 获得支持；
- 两项都获得支持，但 C_SRP 不优于 C_SPEC。

这两种情况按顺序落入第 5 或第 6 条，同时 `clinical_contrast_supported` 等标记为真，报告必须明写。对应材料包的判读是："可能是普通刺激预训练或谱已有价值，新学习原则未被证明必要"。状态只用于防止执行和解释混淆，不作为论文贡献。

## 11. 已登记的历史代码问题（不重训）

`auditory_nextmap/gpu_age.py::train_age` 每个 epoch 验证时调用的 `predict()` 会把模型设为 eval，之后没有恢复 train。因此从第二个 epoch 起，训练实际在 eval 模式下进行：dropout 关闭，BatchNorm 使用冻结的运行统计。

- 受影响：G1 的 `age_trial`/`age_subavg` 直接年龄臂，以及 H3 的 `ft_from_stim` 臂。
- 不受影响：
  - H3 `train_multitask`（显式恢复 train）；
  - 本轮复用的 M_o。它由 `auditory_pf/gpu.train_stim` → `auditory_gx.train.fit` 训练，其 `predict` 结束时恢复 train。

依材料包 §4，不为修历史报告重训。G1/H3 中"直接年龄监督过拟合"的结论应附此限定。

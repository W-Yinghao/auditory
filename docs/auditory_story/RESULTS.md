## 5. 方法是否必要

- **条件摘要 vs pooled**：
  - SIR 上没有可见差别：低标签 +0.0013 [−0.0000, +0.0026]，全标签 +0.0002；
  - 辅助任务上 pooled 反而略好。
- **跨块查询预测（E3，54 名留出儿童，324 行）**：

  | 比较 | 查询 NLL 改善（nats/维）[95% 区间] |
  |---|---|
  | conditional 对人群模型 q0 | +0.018 [+0.011, +0.026] |
  | pooled 对 q0 | +0.020 [+0.013, +0.029] |
  | conditional − pooled | −0.0019 [−0.0038, −0.0002] |

  - 均值 MSE 从 0.988 降到 0.981；z² 校准为 q0 0.98、pooled 1.01、conditional 1.02。
  - 把支持集合的两类条件标签交换后，μ 平均移动其范数的 47%，但查询 NLL 不变：−0.0002 [−0.0028, +0.0023]。
- **摘要稳定性**（附录 001，事后描述）：
  - 同一记录两半生成的 μ 跨儿童相关为 conditional 0.95（单元范围 0.91–0.97）、pooled 0.96；64 维条件均值为 0.70；
  - E5 中，全标签 C_SRP 头对两半输入的预测几乎一致：期望分数差 0.014，最可能等级不一致 0.6%。C_MEAN 头对应为 0.245 和 21%。
- **EEG 系数没有被压掉**：全标签 C_SRP 头在 15/15 个单元都选了最小的 λ=0.01。

**结论**：SRP 学到的是一个在记录内非常稳定、能预测另一时间块响应的个体结构。但这个结构与条件组织无关（交换条件标签不影响），也与 SIR/MUSS 无关（不在年龄和佩戴时长之外增加信息）。这正是 01_STORY §6.3 预先列出的反例：e = g(s) + n_i + ε，其中 n_i 稳定但与功能无关。P0 合成场景也复现了这一点：只有背景个体信息时，查询预测改善 0.077，但留出目标 R² 为负。

## 7. 判定

- **冻结规则给出的状态**：**METHOD_GAIN_WITHOUT_CLINICAL_INCREMENT**。附加标记：`auxiliary_query_gain_supported = true`，`clinical_contrast_supported = false`，区间不宽（δ = 0.0091）。必须连同下面的限定一起读：
  - 这里的"方法增益"相对的是 64 维普通均值，那个视图本身比 C 差得多；
  - C_SRP 在低标签下显著差于 C，全标签下与 C 持平。
- **三项贡献**：
  - **C1（方法预测性）**：部分成立。摘要能预测同一儿童另一物理时间块的响应；但条件组织没有作用。
  - **C2（标签效率）**：不成立。12/24 标签下 C_SRP 差于同标签数的 C。
  - **C3（临床增量）**：不成立。SIR 与 MUSS 在全标签下都与 C 持平；技术背景不改变结论。
- **可以使用的表述**：
  - 在这批回顾性助听儿童数据中，冻结刺激编码器上的跨块条件响应摘要在记录内高度稳定，并能预测另一时间块的响应；
  - 但它在年龄和佩戴时长之外不提供档案 SIR/MUSS 信息；
  - 低标签下加入任何 EEG 视图都会降低有序概率质量，高维视图尤甚。
- **不能使用的表述**：
  - 标签高效的功能评估；
  - EEG 改善了 SIR 预测；
  - 刺激条件结构驱动了临床收益；
  - 摘要是生物标志物或康复指标。
- **辅助阳性**：只得到了辅助阳性（跨块响应预测）。
- **核心贡献**：C2 与 C3 都没有完成。

## 9. 下一步决定

1. **在这 55 名儿童上结束本实例。** 按材料包的停止规则，不再追加 β、潜维数、宽度、种子或新主干。也不自动转向 MFF 验证、竞争 story 或年龄主线，三者都保持关闭。
2. **如果要继续这个功能学习问题，缺的是数据，不是方法。**
   - 本队列的 SIR 几乎由年龄和佩戴时长决定（全标签 AUC 0.985，RPS 0.038），剩余误差集中在只有 3 人的 SIR 1–2；
   - EEG 摘要虽然稳定，但对这部分剩余变异没有信息；
   - 能检验这个 story 的，是在相同年龄与佩戴时长下 SIR 仍有足够变异、低等级儿童更多的新队列。

另外登记一个历史代码问题（详见协议 §11）：`gpu_age.train_age` 在每个 epoch 验证后没有恢复 train 模式。受影响的是 G1 的直接年龄臂和 H3 的 `ft_from_stim`，"直接年龄监督过拟合"的结论应附此限定。本轮复用的 M_o 不受影响。

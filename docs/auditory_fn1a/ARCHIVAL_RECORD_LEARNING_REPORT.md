## 2. 三项预定比较（gain > 0 favours candidate；固定 OOF 身份级 2000 次配对 bootstrap，百分位区间，所有比较共享同一抽样索引）

**三点必须直说：**

1. **两个目标上，记录级 EEG 模型都显著差于临床基线**，区间不跨零。这不是"未检出增量"，是明确的退化，幅度约 3 MAE 分。
2. **学习顺序没有价值。** M3 与 M4 在两个目标上都约等于零（+0.055 / −0.005），区间紧贴零。方案押注的候选方法贡献不成立。
3. **M2 在两个目标的全部外折中都选择了"关闭 EEG"的候选**——与 M1 的配对差精确为 0，非零差 **0/52**。即在内层选择下，连固定片段均值这一最简单的 EEG 参照也没有被采用。

## 3. 两个必做对照

| 对照 | A_archive | V_archive_given_A |
|---|---|---|
| M1+振幅 → M4+振幅 | −3.459 [−5.773, −1.062] | −2.814 [−4.735, −0.954] |
| M0 → M4+振幅（相对**原始**临床基线） | −3.388 [−5.762, −0.863] | −3.707 [−5.489, −1.953] |
| M1 → M4 错配 | −7.285 [−10.794, −3.697] | −2.696 [−4.647, −0.543] |
| **M4 错配 → M4 真实** | **+3.697 [+0.356, +7.367]** | **−0.237 [−1.969, +1.406]** |

加入振幅摘要后 M1 略微变差（6.655→6.834；5.638→5.896），M4 基本不变；结论不因技术调整方式改变。按方案 §7.3，**不只报"M4 优于 M4 错配"**：上表同时给出相对原始 M0 的误差，两者都仍然是负的。

**错配对照在两个目标上行为不同，这是本轮最值得注意的一格：**

- `A_archive`：真实对应显著优于错配训练（+3.697，区间不跨零）。即 EEG 特征确实携带了被模型使用的记录特异信息。
- `V_archive_given_A`：真实与错配无法区分（−0.237，区间跨零），且错配模型与目标的相关（+0.883）反而**高于**真实模型（+0.840）——打乱 EEG 对应关系略微改善了拟合，说明那里的 EEG 特征在把临床分支往偏里拉。

按方案 §10.1，错配模型表现差**不能**替代"超过 M0/M1"的证据；反之，真实与错配相近**也不能**宣称真实条件互信息恰为零。

## 4. 对"为什么 M3/M4 差于 M0/M1"的诚实分析

从保存的预测做的只读诊断（未重新拟合）：

| | 预测 sd / 目标 sd | corr(预测, 目标) | 预测下界 |
|---|---|---|---|
| A：M1 | 0.875 | +0.741 | 31.5 |
| A：M4 | 0.672 | +0.559 | 59.3（目标最低 45） |
| V：M1 | 0.916 | +0.907 | 31.7 |
| V：M4 | 0.784 | +0.840 | 33.3 |

M3/M4 **没有**塌成常数，确实学到了实质内容，但相对 M0/M1 系统性收缩，且在 A 上完全打不到低端。

**最可能的解释，必须写明：这个比较混淆了优化预算与信息含量。** M0/M1/M2 是闭式岭回归解；M3/M4 的临床分支从零开始、由 400 步固定 Adam 与 M1 选定的惩罚共同学出。方案冻结了 400 步并明言"有限预算完成不等于达到全局最优"。因此：

- **M3 vs M4 的比较是干净的**——同架构、同初始化规则、同输入、同预算，唯一差别是非线性映射相对汇总的位置。这项比较的结论（无优势）成立。
- **M3/M4 vs M0/M1 的比较不是纯粹的信息比较**，它同时包含了"400 步 Adam 联合拟合"与"闭式解"的差别。本轮不能据此宣称"记录级 EEG 学习没有信息"，只能说**在本轮冻结的固定复杂度与优化预算下，它没有超过临床基线，反而更差**。

## 5. 按方案 §10.3 的结论

- M4 既未优于 M3，也未优于 M0/M1 → **不能声称档案目标存在额外的 EEG 效用**。
- M2 退回关闭 EEG → **不支持"记录简单表征可用"**，也不支持汇总顺序的方法贡献。
- 结果整体弱 → 只限制**当前目标、来源、输入与有限算法**，**不宣布 EEG 无信息**；A 上的错配缺口本身就说明 EEG 特征并非纯噪声。

# R0：方法审查用诊断探针（计算前冻结）

**性质声明：这是诊断，不是确证性检验。** R0 不产生任何新的科学主张，不设 go/no-go 阈值，不改变任何已冻结结论。它的唯一用途是回答"我们过去八轮的阴性结果，是因为 EEG 与目标无关，还是因为测量对象/表征/损失设定本身不可能出结果"。任何 R0 数字都不得被引用为 EEG 与临床量表有或没有关系的证据。

## 为什么需要它

已完成各轮全部是模型对模型的比较。从未报告过**朴素基线**（预测训练均值），也从未做过**正对照**（证明本管线能从这批 EEG 解码出某个先验上必定可解码的量）。在这两样都缺席时，阴性结果不可解释。

## 固定不变（全部复用已冻结产物，不重读原始 EEG，不重拟合 M 矩阵）

- 52 身份、5 外折 × 3 内折、`FN1A_support_001` 的折归属与种子
- `FN1A_export_001` 的 52 个特征包（每条 32×140），窗口起点一并复用
- 已保存的 K1/FN1-A 逐人预测（只用于误差分解，不重新拟合）
- 解释器与线程设置同既有规则；全部 CPU；无 GPU

## 六项探针

| 编号 | 问题 | 做法 | 读数 |
|---|---|---|---|
| R0-1 | 我们建的东西打得过"猜平均数"吗 | 同一固定外折上计算训练均值与训练中位数预测子的 OOF MAE/RMSE | 各模型相对均值基线的技能分 `1 − MSE/MSE_mean` |
| R0-2 | 误差住在哪里 | 用已保存预测，把 MAE 按"在上限 100"与"不在上限"两组分解；报告目标的聚合结构（分位、取值粒度、相异取值数） | 两组各自的 MAE 与占比 |
| R0-3 | EEG 表征是不是空的 | 同一折结构上，用闭式岭回归从 EEG 特征预测 **年龄（月）** 与 **较好耳裸耳 PTA** | 相对均值基线的 OOF 技能分 |
| R0-4 | OOF 机器本身可信吗 | R0-3 的负对照：身份打乱后的年龄，同一管线 | 技能分应 ≈ 0 |
| R0-5 | 特征测到记录级属性了吗 | 每条记录的 32 窗按奇偶分半，140 个特征各自在 52 条记录间求分半相关 | 140 个相关系数的分布 |
| R0-6 | DYN 候选是否可行 | 从 `window_start_original` 统计真实窗口间隔 | 间隔分布（聚合） |

**R0-3 的读法（计算前写定）**

- 技能分明显为正（年龄）→ 表征非空。阴性结果来自 EEG 与问卷数字之间，不来自特征提取。同时必须检查冗余：年龄本身就是 M0 的临床协变量之一，若 EEG 能很好地预测年龄，则 EEG 在条件于 C 之后所剩无几是**可预期的**，这会重新解释既往全部零增量。
- 技能分 ≈ 0（年龄与 PTA 都不行）→ 表征基本是空的。此时既往八轮的阴性对"EEG 有无信息"不构成证据，问题在特征与预处理，而不在临床关系。
- 只有 PTA 为正、年龄为零（或反之）→ 分别记录，不合并叙述。

**不做的事**：不搜索 QC 阈值，不换特征族去追阳性，不删天花板样本，不换二分类阈值，不把 R0 升级为方法贡献。岭惩罚网格固定为 `numpy.logspace(-2, 4, 13)`，内折 MSE 选择，写定于此不再调整。

## 隐私

只输出聚合量。逐人预测、身份、目标值、年龄与 PTA 原值一律留在 `private/auditory_r0/`。

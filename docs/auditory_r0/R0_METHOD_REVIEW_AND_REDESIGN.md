# R0：方法审查与项目重新设计

对象：全部既有轮次（Phase 0–3、auditory5、auditory_next v2、auditory_v21、auditory_v3、
auditory_fseries、auditory_repair、auditory_retrain、FN1、FN1-A、K0、K1）。
新增证据：R0 诊断探针（Slurm 1000289、1000290），预注册见 `R0_DIAGNOSTIC_PREREGISTRATION.md`。

本文不推翻任何一轮已冻结的数字。它改变的是**这些数字该怎么读**。

## 1. 一句话诊断

> 八轮阴性结果不是"EEG 与听觉功能无关"的证据。它们是一个结构性后果：
> **这个项目可靠测到的量与听觉无关，而与听觉有关的量测不可靠。**

两把刃都有数字，且来自两次互相独立的测量。

### 1.1 可靠的那一侧测的是发育，不是听觉

R0-3/R0-5，52 身份，固定外折，闭式岭回归：

| 探针 | 技能分（相对训练均值） | MAE |
|---|---|---|
| EEG → **年龄（月）** | **+0.574** | 20.99 月（目标 SD 40.53） |
| EEG → 较好耳**裸耳 PTA** | −0.008 | 11.37 dB |
| EEG → 较好耳**助听 PTA** | −0.051 | 5.92 dB |
| EEG → 年龄（身份打乱，负对照） | −0.001 | — |
| **技术协变量**单独 → 年龄 | +0.006 | 32.61 月 |
| EEG + 技术协变量 → 年龄 | +0.572 | 21.09 月 |

负对照干净（−0.001），技术协变量单独几乎为零（+0.006）且加入 EEG 后无增益——
**年龄信号确实在 EEG 里，不是记录质量的代理。** 同一组特征的记录内分半信度中位 **0.979**，
140 个特征全部 >0.92。

也就是说：FN1-A/K1 使用的 140 维连续窗特征**极其可靠，并且携带大量成熟度信息，
但几乎不携带听力水平信息**。

### 1.2 与听觉有关的那一侧测不可靠

这个数字本项目早已测出（`results/auditory_repair/reliability_matched_001/`，matched-43，odd/even），
但从未被当作门槛使用：

| 特征库 | 32 试次 | 64 | 128 | 256 |
|---|---|---|---|---|
| HJORTH（谱/统计） | 0.894 | 0.935 | 0.971 | **0.984** |
| SPATIAL | 0.824 | 0.901 | 0.946 | **0.972** |
| POST（试次平均诱发） | 0.136 | 0.249 | 0.339 | **0.515** |
| **CONTRAST（码2−码1 差值波）** | 0.074 | −0.004 | −0.022 | **0.062** |
| PRE（刺激前） | −0.025 | 0.036 | 0.034 | 0.134 |

POST 随试次单调上升（0.136→0.515），说明诱发响应本身**是**可测的，只是噪声大。
**CONTRAST 在 8 倍试次下始终在零附近**——这不是噪声问题：若存在稳定的个体差异，
8 倍试次必然把它抬起来。这个语料里，偏差−标准差值波在儿童之间**没有可靠的个体差异**。

信度是效度的天花板：可达相关的上界是 √(信度)。CONTRAST 信度 ≈ 0 ⇒
**任何模型、任何目标、任何样本量都不可能从它得到关系。** 而它在 auditory_repair 多轮中
被直接送进临床模型。

### 1.3 两侧互相印证

- Phase 3 用**诱发库**预测年龄：MAE 28.843 → 28.739，差值 −0.105 [−4.048, +3.723]，**零**。
- R0 用**谱/Hjorth 库**预测年龄：MAE 20.99，技能分 **+0.574**。

同一个目标、同一类儿童，不可靠的库给零，可靠的库给强阳性。这不是巧合，是 1.1 与 1.2 的直接推论。

## 2. 目标一侧同样是设计缺陷，不是运气

R0-1 首次给出**朴素基线**（八轮从未报告过）：

| 目标 | 猜训练均值 MAE | M1_CQ | M4s（校正后） | M1 技能分 |
|---|---|---|---|---|
| A_archive | 13.96 | 6.66 | 6.49 | **0.537** |
| V_archive_given_A | 17.48 | 5.64 | 5.53 | 0.831（M0 为 **0.870**） |

两点立刻可读：

1. **临床模型其实很好**，八轮从未给过它这个信用。EEG 要在技能分 0.54 之上再加东西。
2. **`V_given_A` 接近同义反复**：M0（只用临床协变量＋同一行已观测的 A）技能分 0.870，
   且**加入技术协变量反而变差**（0.870→0.831）。最强预测子是同一档案行的另一份问卷。

目标本身的结构（R0-2）：

| | A_archive | V_archive |
|---|---|---|
| 落在上限 100 | **26/52 (50%)** | 17/52 (33%) |
| 相异取值数 | 15 | 20 |
| 取值粒度 | 2.5（即 40 分条目和） | 2.5 |
| 中位 / SD | 98.75 / 16.23 | 86.25 / 20.13 |
| 下限处 | 0 | 0 |

**72–75% 的总绝对误差住在 26 名不在天花板的儿童身上**（各模型一致）。
所以有效推断样本量是 **26**，不是 52。

而这个目标同时是：量表版本未知（IT-MAIS 还是 MAIS，56/56）、问卷日期未知（56/56）、
采集时设备状态未知（56/56）、阈值单位未知（56/56）。

全部模型用连续平方/绝对损失处理它，上限只靠事后 `clip_to_bounds` 截断，
**没有任何一轮用过删失（Tobit）或有序（累积链接）似然**。

## 4. 为什么八轮修不好它

每一轮都在优化**模型**：编码器、表征、聚合顺序、容量门、目标函数尺度。
K0/K1 甚至把一个真实的 n 倍惩罚缺陷找出来并改对了——校正后 M4\* 恢复 +3.75（A）/+3.04（V）。

但校正之后 **M1→M4\* 仍是 +0.1618 [−0.3148, +0.6420]**。因为瓶颈从来不在模型侧。
输入是一个可靠但只编码年龄的成熟度描述子，而年龄本来就是 M0 的四个临床协变量之一。
条件在 C 上之后，EEG 剩下的东西自然接近零——**K1 训练诊断记录的 EEG 输出绝对值中位数
只有 0.0592（A）/ 0.0369（V），目标尺度 0–1**，这与本文的诊断完全一致。

## 5. 重新设计

### 5.0 主张的转向

停止问"EEG 能否在临床模型之上再加一点"，改问：

> **能否从这批儿童的听觉 EEG 构造出一个在个体层面可靠的听觉响应测量？**

理由：信度是效度的前置条件，不是修饰。而且这个问题本身对 IEEE JBHI 是可发表的
（测量学/生物标志物方法），并且**用现有数据就能回答**——包括那 763 个从未被碰过的
MFF epoched/evoked 容器。

### 5.1 S1 测量学阶段（门槛：信度）

主战场换到 **MFF 支线**（203 条规范记录，显式 stad/devt/hdev/ldev，129 通道），
BDF 作为重复验证，理由是 MFF 的条件语义是显式的而 BDF 的码语义至今未核实。

必做三件事：

1. **参考蒙太奇作为显式因子。** 129 通道可以重建乳突/鼻尖参考。把参考选择
   （全平均 / 乳突 / REST）当成被检验的设计变量，而不是继承下来的默认值。
   这是对 CONTRAST 零信度**成本最低、先验最强**的一个解释，必须先排掉。
2. **画信度–试次曲线**，对：(a) 标准音的 P1/N1 CAEP 幅值与潜伏期；
   (b) 偏差−标准对比；(c) hdev vs ldev。预注册门槛 **分半信度 ≥ 0.7**。
3. **门槛不过就如实报告。** "在这批儿童 HA/CI 语料中，皮层辨别响应在可达试次数下
   不是个体可靠的测量"——这是一个正当且有用的方法学阴性结论，
   **比八个零回归强得多**，而且它解释了后者。

### 5.2 S2 效度阶段（S1 过关才开）

- 只有过了信度门槛的测量才能进来；预注册效度天花板 √(信度_EEG × 信度_结局)。
- **换损失函数**：对 40 分条目和用删失（Tobit）或有序（累积链接）似然，在条目和尺度上报告，
  不再用百分比上的 MAE + 事后截断。
- **换结局，优先考虑纯客观目标**：用皮层响应估计**听阈**（客观听力学 / CAEP 阈值估计）。
  它没有天花板、没有版本歧义、没有日期歧义，是有文献锚点的真临床问题；
  而 R0 已经证明现有的连续窗特征对它技能分 ≈ 0（−0.008 / −0.051），
  因此任何阳性结果都可归因于诱发响应而非成熟度混淆。这是目前最干净的一条路。
- 若仍要用问卷：优先 CAP(0–9)/SIR(1–5) 这类有序且天花板较轻的量表。
- **停用 `V_given_A`**（M0 技能分 0.870，接近同义反复）。
- 每张表都必须并列**朴素基线**与**临床独有基线**。

## 6. R0 自身的界限

- R0 是**诊断**，不是确证性检验，不设门槛，不改任何已冻结结论。
- n=52，单一特征族，只用闭式岭回归，惩罚网格预注册后未调整。
- EEG→年龄的技能分在一个年龄跨度很大的队列上取得（SD 40.5 月），其中一部分是容易的。
  它证明的是"表征非空且编码成熟度"，不是"神经年龄"。
- 1.2 的信度表来自 HA matched-43 队列的既有产物，不是 MFF 支线的测量；
  S1 需要在 MFF 上重新测，不能直接外推。
- 本文未重读任何原始 EEG，未重拟合任何 M 矩阵，未分配 GPU。

# Phase 3：以旧科学问题为依据的探索实验

2026-09-16。此轮由用户要求覆盖 CI，并检验原项目目的。原始问题见 [原目标证据矩阵](ORIGINAL_IDEA_EVIDENCE_MAP.md)。Phase 2 的 HA/MUSS 结果已被查看，本轮不是独立确证或事前注册。实验规则记录在 [phase3_science_v1.json](../configs/phase3_science_v1.json)，在本轮新关系/解码结果产生之前锁定；遇到来源或实现问题另存新版本，不按结果调门槛。

## HA：平均幅值遗漏的信息能否支持年龄、经验或功能目标

保留 Phase 2 最早记录和唯一候选链接规则，从实际模型 53 个候选中进一步要求明确四频计算的双耳裸耳 PTA 可用。better-ear 为双耳完整四频 PTA 的较小者；单位在原 Sheet1 未明写，保留原数值，不宣称确证 dBHL 或刺激可听度。

主临床基线为年龄、log(1+使用月数)、better-ear PTA。临床终点仍为 MUSS；固定幅值为已评估的 code 1、Fz/Cz、50–250 ms 均值。新时空特征固定为同一主方案已接受 code 1 试次均值、20 通道×0–400 ms 内八个互不重叠的 50 ms 均值，不搜索峰或通道。增加 −200–0 ms 内四个 50 ms 均值作为预刺激参照。预刺激序列已做原 epoch 基线，可能仍含慢变状态、滤波及序列效应，不能假定其严格为零或完全无信息。

比较临床、临床＋固定幅值、临床＋刺激后模式、临床＋预刺激模式。标准化与 alpha 选择全部在训练数据内，5 次重复的 5 折候选人外层、4 折内层，岭回归 alpha 固定网格 0.1/1/10/100/1000，内层以 MAE 选参。MUSS 预测截断至 0–100%。同目标各模型使用同一人群与外层/内层划分。主比较为刺激后模型减临床 MAE；其余为解释性比较，无事后胜出模型的独立验证宣称。

两个次要探索目标为年龄和 log(1+使用月数)：基线仅输入另一个时间变量及 PTA，再加相同 EEG 特征。**目标变量本身不得进入协变量**。这检验有限样本中是否存在条件于另一时间变量的预测信息，不能称为纯成熟度、因果康复效应或“第三时钟”。报告目标单位和相同候选支持；折/重复不视为新增人数。区间仅按候选人重抽固定外层预测损失，明确不包含全流程重训不确定性。保留所有模型结果，不因 MUSS 阴性改换量表。

## CI：去重、重新分段、可靠性与刺激可区分性

逐一登记所有原始连续 MFF、其处理版本与 EGI raw 出处；有足够目标事件、结构可读者才进候选连续信号处理。同采集时间和形状并不足以合并，须核对全 binary 哈希。其余不同时间/版本保留，不将联通分量当作儿童。姓名/拼音、患者ID、检查日期和临床行共同构成候选链接，首字母或日期单一线索不自动确证；名称碰撞、日期冲突保留为未知。临床工作簿是扩展版本，不把重复 sheet 行相加。

从原始连续区段 0.5–30 Hz FIR 后分段；每个真实存储连续区段分别处理，边界保护 10 s。epoch −200–500 ms，基线左闭右开 −200–0 ms，按事件零点降至 250 Hz。依据传感器坐标选择最接近 Fz/Cz 的通道，距离须≤40 mm，原采集参考作为虚拟顶点通道时注明。平均参考使用每条记录固定的良好非参考 EEG 通道。坏通道与拒绝规则见配置，基于全记录信号统计，不用量表或刺激响应强弱筛选；至少保留 75% 非参考 EEG 通道。拒绝任一 ROI 通道峰峰值>150 μV 或>10%良好通道超阈值的试次；全部良好通道均≤150 μV 为严格敏感性。此算法为透明技术基线，不称为已验证的 CI 伪迹移除方法。

保存每一个候选目标 epoch 的数值 QC、代码、原始样本和区段/拒绝理由；每码≥40 次才报告记录层测量，两半每码≥20 次。分类以实际 literal code 与历史分段规则为依据，不凭 80:20 或论文补填频率。对 `stad` 与每一实际偏差码分别进行时间块隔离的收缩 LDA，五折按采集时间划分，训练试次距测试时间边界至少10 s。输入为两 ROI 的五个40 ms均值；固定比较预刺激、50–250 ms 和250–450 ms，评估 AUC。多偏差码不合并为单一声学条件。

时间块解码只回答同条采集记录内的事件码可区分性。设备伪迹、不同声学、适应、时序以及处理均可贡献可分性；刺激后 AUC 提高不能单独证明皮层机制或新儿童泛化。完整元数据支持后，才按候选人汇总和做儿童内跨刺激比较；同名未确证、样本数不足及跨硬件不可比的结果须如实标注。

## 交付决策

为旧目标建立“直接实验支持／有可行性但证据受限／本次未显示支持／设计上无法回答”的结果矩阵。把实际效果、不确定性、样本支持、伪迹和身份边界共同用于判断。深度学习或 foundation model 是可选后续方法，不是原目标已被实现的证据；本轮先完成可解释的基线实验。所有计算、统计、测试、图表与必要依赖准备经 Slurm；共享环境和原始数据不修改。

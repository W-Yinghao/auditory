# B prespecified diagnostic implementation, v1

This addendum implements the three outstanding B.5 diagnostics after the L0 and supervised primary results have been observed. It cannot replace the frozen primary window, endpoint, cohort or threshold. Every representation keeps its own outer-fold coordinates, encoder, training-only transformations, common-support gate and inner readout CV. No new encoder is trained.

Early [0.05,0.25) and late [0.25,0.45) windows contain exactly 50 samples on each event's existing 250Hz grid. L0 uses their ten 20ms bins per channel. Learned representations apply the existing outer-training encoder/scaler to those 50 samples, as already done for the 50-sample prestimulus view. This changes the encoder input duration for a diagnostic, not its training. All five B readouts are refitted on exactly the same selected training/test trials as the primary common-support cohort; neither window is selected as a replacement.

Quality sensitivity adds two fixed nuisance terms to every context-only and EEG-augmented head: log1p(maximum channel epoch peak-to-peak amplitude in microvolts) and log1p(maximum channel prestimulus peak-to-peak amplitude). Their scaling is fit inside each training fold. They remain outside EEG PCA, with the same logistic C grid and temperature calibration as the original readout. This is offline sensitivity to measured quality, not an artifact-free EEG claim.

The circular-shift diagnostic uses the already fitted primary heads. Within each held-out record, acquisition segment and fixed position third, retain segments with at least 100 eligible trials, at least 20 of each H, gap IQR/median <=0.1 and maximum gap <=1.5 times median. Within each eligible segment ordered by original onset, 20 fixed-seed shifts move post features by at least 20 observations in either circular direction. Candidate count/class/block support is rechecked on this common diagnostic subset. Context, pre features, labels and time provenance remain in place. Report the observed and mean shifted candidate CE difference on exactly that subset, with fixed-OOF candidate bootstrap. Do not report an exchangeability p value or call this a conditional-MI test. Absence of sufficiently stable segments is SUPPORT_INSUFFICIENT for this diagnostic, not evidence of no history information.

The original gap/position distributions and their common-support retained fractions are saved per identity privately, with aggregate class-equal means/standard deviations and eligibility counts publicly. This does not change the primary support gate.

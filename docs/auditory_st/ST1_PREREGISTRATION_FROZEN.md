## 1. 问题

> 在纯音、音节（bapa）以及 HA 分支的纯音 oddball 中，声音条件差异何时可以从儿童多通道 EEG 中读出？这种可读性是短暂的还是跨多个响应阶段持续的？儿童之间的画像差异有多大，同一儿童在独立时间块上是否稳定？

本轮只回答上面的问题。不预测年龄、量表或设备时长；不做跨任务配对；不训练神经网络。

## 3. 信号与事件

- **信号：** D1 合同 `auditory_d1_continuous_v1`：零相位 0.5–45 Hz、平均参考、整数步长至 250 Hz、按真实存储区间分别滤波。不重滤波、不插值、不选通道（MFF 128 个物理通道，BDF 20 个头皮通道）。
- **事件坐标：** MFF 事件取自 MNE 注释的原始采样位置（与 D1 区间使用同一采样轴，无声学延迟校正）；HA 事件取自事件伴随文件注释秒数 × 1000 Hz。映射公式：`exported = interval.start + (onset − interval.original_start_sample) // stride`。落在未导出（< 60 s）区间或间隙中的事件记为不可用并计数。
- **刺激历史：** 用 `auditory5.events.build_event_history` 在完整、未经 QC 的事件链上计算（前一声音码、间隔、前序等码连续长度、链起点）。两个声音字面码落在同一采样点时按保守规则中断历史。
- **时间零点的含义：** 全文的 t=0 是事件标记时刻，不是声学起点；标记到声音的物理延迟未知且不在本轮估计。

## 4. 时段、窗口与预处理（冻结规则）

| 项 | 冻结值 / 规则 |
|---|---|
| 预刺激 | −0.200 s |
| 刺激后终点 `post` | 每个 lane 由规则 `floor20ms(min(0.80, SOA_p05 − 0.06))` 确定，其中 SOA_p05 为该 lane 内各记录 SOA 第 5 百分位的最小值；具体数值由范围表填入附录 A，**填入后才允许提取特征** |
| 区间边缘保护 | epoch 距所在导出区间两端 ≥ 2.0 s |
| 基线校正 | 不做（预刺激窗口留在曲线里作为自身对照） |
| 记录尺度 | 每条记录一个标量：所有接受 epoch 的 |x| 中位数 |
| epoch QC | 拒绝：>10% 通道峰峰值 > 150 µV，或 >10% 通道峰峰值 < 0.5 µV，或含非有限值；拒绝原因逐条保存 |
| 窗口 | 长 80 ms、步 20 ms，从 −0.200 s 起铺满整个 epoch；特征为每通道窗内均值 |
| 时间块 | 60 s 块（`onset // 60`）；早/晚两半以首末目标事件中点切分；两个划分均对训练/测试边界施加 10 s 保护 |

## 5. 读出与参照（冻结）

1. **主读出：** 每个窗口一个收缩 LDA（sklearn，`solver=lsqr, shrinkage=auto`，先验 = 训练集类频率），输入该窗口的全通道均值向量。
2. **划分：** 留一儿童（identity group）交叉验证；训练儿童数 < 10 的 lane 不做读出。任何测试儿童的任何记录都不在训练集中（代码断言）。
3. **参照：**
   - 类别先验：训练集偏差比例的常数预测。
   - 刺激历史：在训练儿童试次上拟合的 logistic 回归，特征 = {前一码 0/1/未知, log(1+间隔), 前序连续长度 1/2/3/4/≥5/未知, 链起点}。
4. **条件增益（计划 5.3 的 G）：** `q1(s|x,h)` 为交叉拟合的堆叠 logistic 回归（输入 = 训练儿童内 5 折分组交叉得到的 LDA 判别值 + 历史特征），`q0(s|h)` 为历史模型；`G_hist = mean log2 q1 − log2 q0`（bits），先在儿童内对试次取均值，再跨儿童汇总。同时报告 `G_prior = LL_prior − LL_eeg`。**G 是样本外对数损失差，不称为互信息。**
5. **判别指标：** AUC（阈值无关）、平衡准确率（阈值取训练先验的对数几率，等价于等先验 LDA）、对数损失（bits）。
6. **跨时间读取：** 在窗口 t 训练的 LDA 应用于窗口 t′，得到每个儿童的 AUC 矩阵，跨儿童取均值；仅作描述。
7. **重复性：** 用同一儿童留出模型分别在该儿童的两个独立时间块上计分（早/晚；奇/偶 60 s 块），跨儿童计算两块得分的 Spearman 相关、平均绝对差与儿童间标准差。次要：儿童内在块 A 训练、块 B 测试（每类每块 ≥ 20 试次才做）。
8. **汇总与不确定度：** 每个儿童等权；跨儿童均值的 95% 区间来自以儿童为单位的 bootstrap（n=2000，seed 20260920）；同时给出中位数与四分位距。固定时间带（不挑峰）：pre [−0.20, 0)、early [0.05, 0.25)、mid [0.25, 0.45)、late [0.45, post]。

## 6. 主要终点与预先承诺的解释

对每个主分析 lane：

| 终点 | 量 | 解释规则（写在看结果之前） |
|---|---|---|
| E1 可读性曲线 | 儿童均值 AUC(t)、bAcc(t) 及 95% CI | 某时间带内 AUC 区间下界 > 0.5 且 E2 同带下界 > 0 → 该带"可读"。只在 early 带可读 → 短暂；early 与 mid（或 late）同时可读 → 跨阶段持续。 |
| E2 条件增益曲线 | 儿童均值 G_hist(t) 及 CI | 下界 ≤ 0 的时间带不称为 EEG 提供了历史之外的信息。 |
| E3 预刺激对照 | pre 带 AUC、G_prior、G_hist | pre 带 AUC 显著 > 0.5 但 G_hist ≈ 0 → 预刺激可读性由已编码的刺激历史解释；pre 带 G_hist > 0 → 背景/未编码序列信息，只能写成"记录内背景与序列相关"，不写成预期或提前神经预测（D1 为零相位滤波）。 |
| E4 跨时间矩阵 | 均值 AUC(t, t′) | 对角带宽窄 → 局部模式；宽方块 → 较持久的可读模式。描述性，不做检验。 |
| E5 重复性 | early/mid 带内块间 Spearman | ≥ 0.5 且儿童数 ≥ 20 → 儿童画像跨块可重复；否则报告"个体差异小于测量波动或样本不足"，不据此裁剪儿童。 |

lane 之间（纯音 vs 音节 vs HA 纯音）只并排描述：类别数、先验、SOA、通道数、医院来源不同，不给任务排"难度"或"语言能力"。

**若三个主 lane 均无任何时间带满足 E1+E2：** 结论为"在本轮固定读出下，任务内多通道时间模式没有提供高于历史参照的可读结构"，并保留全部曲线；不追加分类器搜索，不改窗口重跑。转向计划 7.1 的做法五时间组织。

## 7. 禁止与要求的措辞

- 禁止：把 t=0 后某一窗口命名为 MMN/P1/N2 等成分；把 bAcc 差异写成听觉能力差异；把 unknown lane 的可读性写成纯音或音节；把 CI/CIHA 标签写成设备操纵比较；把 `G` 写成互信息；用单一划分或单一 seed 下的曲线下结论。
- 要求：给出每个 lane 实际进入的儿童数与记录数（分开）；给出保留记录及原因；给出 pre 带对照与历史参照在同一图中；每个数字附对应表格文件名。

1. `tests/auditory_st` 全部通过（经 Slurm）。
2. 范围表（`ST1_scope_001`）完成：期望事件记录数 = 实际 OK + FAILED，FAILED 逐条列出原因。附录 A 填入 `post` 与支持数后，配置哈希重新记录。

## 附录 B（2026-09-21，写于特征舰队运行中、任何读出聚合曲线生成之前）

**已看到的内容：** 范围表；探针 `ST1_probe_001/002`（记录 M0015 的确定性、网格、支持数以及下述单记录类别差异统计）；测试结果。没有看到任何跨儿童曲线、任何读出预测。

**B1 校准后验（新增，不替换）。** 第 5 节第 5 点的对数损失原按 LDA 原始后验计算。审查指出 128 通道收缩 LDA 的原始后验可能过度自信，使 `G_prior` 偏负，且与前几轮（auditory5 / auditory_next 的温度校准 CE）不可比。因此新增：在训练儿童内 5 折分组交叉得到的 LDA 判别值上拟合一维 logistic（斜率＋偏置）作为校准器，应用于测试儿童判别值，得到 `p_cal`；`ll_eeg` 与 `G_prior` 改用 `p_cal`，原始后验的 `ll_eeg_raw` / `G_prior_raw` 仍全部报告。AUC、bAcc、`G_hist`（堆叠模型本身即交叉拟合）不受影响。E1/E2 的判定规则不变。

**B2 探针"操纵检查"的定性（澄清，不改冻结读出）。** 第 8 节第 3 条把"标准/偏差窗口均值差在刺激后大于预刺激"列为探针检查。实际代码门只含确定性、有限值、网格与支持四项；单记录检查只作披露。M0015 的结果：128 通道平均 |z| 预刺激 0.086、刺激后 0.070；按标准误标准化后每窗最大 |z| 预刺激均值 2.60、刺激后 2.36，总体最大 3.02（出现在 0.66 s），|z|>2 的通道比例预刺激 5.9%、刺激后 3.1%。这些数值与纯噪声的期望（116 对 691 试次时平均 |z| ≈ 0.08，128 通道最大值 ≈ 2.5–3.0，>2 比例 ≈ 5%）一致，即**单条记录上看不到偏差—标准差异**。这一检查在设计上没有检出中等效应的功效，因而不能充当门；它作为一个如实披露的观察保留，"操纵是否有效"由预注册的跨儿童合并曲线回答。若合并曲线同样为零，第 6 节末段的结论措辞照用。

**B3 运行快照。** `ST1_scope_001` 的 `start.json` 快照是 `sources` 命令时的代码；`scope` 表由修正了一处聚合语句（`cli.py` 第 113 行，`int()` 作用于 Series 的错误）之后的代码生成，其他逻辑未变。此后每个命令的 receipt 记录执行时各源文件的 sha256（`source_hashes_at_attach`）。

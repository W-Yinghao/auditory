# F1/F2 档案数值初筛 v1：继续检验的范围修订

用户在 F-series 资格审查结束后明确要求继续检验。本轮将继续执行落实为一个较弱、可计算的探索问题：**按候选身份隔离后，记录级 EEG 摘要能否补充预测 HA 档案中的原始量表列数值？** 不要求这些标签已确证同期，但必须保留其未知时间、混合版本与档案关联性质。此前严格临床问题的支持不足结论保持不变。本版本没有把未知条件改写为已知。

本轮不将 IT-MAIS/MAIS 混合列宣称为单一 IT-MAIS；两列目标用原表百分比数值，不与 CI 的 0–40 档案混合。主要比较是 A（听觉混合列）给定临床 C，以及 V（MUSS 列）给定 C 和真实 A；另报告 V 给定 C。后一个条件场景明确需要已有听觉档案值，不声称仅凭 EEG 输出完整功能画像。CAP/SIR 不进入本轮模型选择，不因结果不利替换目标。

## 人群与来源

从原始 93 条 BDF 来源的既有全量候选索引开始，只取 HA，每个候选按 vendor 采集时间锁定原先最早记录，不用后续记录替换差质量记录。排除 DOB 冲突、来源隔离或多临床候选连接；保留唯一姓名＋标签日期的档案链接，明确它不是同期证明。要求两个目标、年龄和设备月数数值可读；裸耳/助听 PTA 缺失在训练内插补并加缺失指示，不因 PTA 缺失机械沿用旧 50 人。至少 64 个总有效 epoch，不要求每码 40 次，不限制旧 49/53 人子集。若少于 30 身份组，停止模型阶段并报告支持量。

## 预先固定的 EEG 表征

复用 Phase 1 的 20 通道、250 Hz、−0.2 至 +0.5 s 全 epoch，应用原始主 QC mask，保留两种本地事件码。按采样位置排序，在有效 epoch 中确定性均匀取至多 256 个。标签和量表不参与片段选择，不把 epoch 当作独立临床样本。

每个 epoch/通道先减去自身时间均值，计算方差、Hjorth mobility 和 complexity，分别取自然对数，再在记录内按通道取中位数，总计 60 维。mobility 使用采样率换算，complexity 无量纲。差分方差与比值使用预先固定的 1e−12 数值下界。它是短实验片段的振幅/变化统计，不是频谱估计、静息态、ERP 峰值或条件差分。保留原滤波/参考和处理局限，不宣称已排除设备或眼动来源。

C 为年龄、log1p 设备月数、双耳四频均完整时的较好耳裸耳与助听 PTA 源单位。质量/可用性 Q 为 log1p 有效 epoch 数、拒绝比例、log 记录内 median 最大头皮 peak-to-peak、log 记录时长。peak-to-peak 也可能包含生理信息，因此 Q 是针对替代解释的摘要，不称为纯伪迹。全部记录来自同一 HA/BDF 来源体系，来源限制通过单独建模该体系执行，不与不同单位的 MFF 档案合并。

## 有限模型和验证

一个记录对应一个候选身份。固定 5 外折、3 内折和一个随机种子；分折先于关联结果冻结。所有插补、缺失指示、标准化、二次展开与正则选择只使用对应训练部分。

| 模型 | 内容 |
|---|---|
| MEAN | 训练目标均值 |
| C_LINEAR | 线性临床岭模型 |
| C_BEST | 内层选择线性或二次临床模型 |
| Z_ONLY | 固定 EEG 岭模型 |
| C_Z | C_BEST 候选＋临床/EEG 分别惩罚的组合模型 |
| C_Q | 同样的临床候选并加入固定 Q |
| C_Q_Z | C_Q 候选＋EEG 分块惩罚 |
| C_SHUFFLED_Z | 每次拟合仅在训练身份内部打乱 EEG 行，测试 EEG 保持本人的内容对照 |

临床正则为 0.1/1/10/100，EEG 正则为 1/10/100/1000。组合模型包含对应“不使用 EEG”的完整临床候选，防止强迫引入 EEG。所有模型预测截断在原表 0–100 范围。内层以合并留出身份 MAE 选择，平局按固定枚举顺序选简单模型，不查看外层目标。负对照是一个固定种子的诊断，不能当作置换检验 p 值。

主增量为 C_BEST−C_Z 的 MAE，必要对照为 C_Q−C_Q_Z，内容对照为 C_SHUFFLED_Z−C_Z。MAE 使用原档案列单位，不换名为 bit。报告逐目标、逐折与完整 OOF 结果，缺失折/数值失败不以部分成功替代。2,000 次固定 OOF 身份 bootstrap 在原外折内重采样，不包含全流程重训变异；两项主任务是探索性筛查，不声称多重比较校正后的确认性发现。

仅当主增量与质量调整增量的 95% 下界均为正，且内容对照点增量为正，才标记值得进一步检验。否则收束此实现。无论结果如何，都不能解决原始量表日期、量表逐行版本或临床效度；不自动进入架构搜索。旧 MUSS 阴性完整保留，新配置是已探索队列上的后续探索。

## 预算与执行

所有数据处理、导入检查、测试、拟合、bootstrap、图表与哈希必须经 Slurm；不重复上一轮本地调试例外。上限 8,000 次岭拟合尝试（包括合成测试/失败），申请 12 CPU core·h、0 GPU。最多 4 个 CPU 作业并行。使用独立 `auditory_fseries_archival` 运行目录，源码/配置及结果版本化，逐人数据、预测、系数和分折留 private。F3/F4 与 CI 临床模型不在此轮拟合范围。本轮不自动 push。

# Phase 2：个体幅值稳定性、参考敏感性与档案标签可行性

2026-09-16，`phase2_v1`。在查看本轮个体幅值信度及 EEG–量表关系前写定配置。继承已执行 Phase 1 数据和滤波，原版本不修改。这是项目内部分析锁定，非预注册；既往重启包已有临床关系探索。全部计算和测试使用 Slurm。

## 候选人及记录选择

从全部 93 条 BDF 来源中，以 vendor 实际采集时间选择每个姓名候选身份簇的最早记录；同时间以 recording_id 决胜。无法解析完整候选簇的时间则不假定已知最早记录。出生日期冲突的簇不进入候选人层汇总。最早记录未通过来源、试次或链接门槛时保留缺失，不改选更晚、更干净或有量表的记录。HA 为主要技术分析人群，NH 单独描述；名称分组和无 DOB 冲突仍不等于已经确证独立儿童，跨队列同一身份尚未完全解决。

## 固定技术终点

主要幅值为 Fz/Cz、50–250 ms 的 code 1 均值，code 2 与 code 2−code 1 为次要。优先级来自上一轮未使用量表的测量结果。数字码不解释为声音频率，不命名皮层成分。

每条记录和处理版本均需每码至少 40 个试次、各覆盖至少 8 个 30 s 时间块；两半各每码至少 20 个试次。交替 30 s 块和时间前后半（按所有存储候选目标事件首尾中点固定边界）分别计算半份幅值；主比较保留各半全部合格试次，另在每个记录、每个代码内取两半较小试次数，固定种子各抽一次，检查不平衡影响。参考变换使用相同试次及同一个抽样序列。平衡试次数不平衡时间块数，不是独立重测。

在候选人之间计算两半幅值的 Pearson 相关、两向绝对一致单次测量 ICC(A,1)、B−A 偏差和描述性一致性界限（均值±1.96 SD）。不把波形时间点视为人，不把不同记录视为不同儿童；不作 Spearman–Brown 外推。ICC 使用 `(MS_R−MS_E)/(MS_R+(k−1)MS_E+k/n*(MS_C−MS_E))`，k=2；允许负值，常数退化情形返回缺失。至少 8 个候选人方计算，候选人配对 bootstrap 2,000 次，百分位区间，同时报告有效抽样数。NH 仅小样本描述。不同方案比较同时报告各自支持和共同完整支持集，避免变化仅来自人群变动。

固定处理敏感性为：Phase 1 主方案；0.5 Hz 高通相同试次；平均参考排除 Fp1/Fp2（18 通道）相同试次；原主试次中额极均值减枕极均值的峰峰值≤100 μV；原 100 μV 全头皮门槛。18 通道参考是线性重新参考，不重新基线。额枕差使用 Fp1/Fp2 和 Oz/O1/O2，基于保存的 250 Hz 数据，在全 epoch 计算。它是额枕瞬变代理，**不是 EOG、眨眼诊断或设备伪迹检测**；100 μV 为事先固定的技术敏感性阈值，无最优性依据。不得因提高信度就称为神经有效性改善。耳参考已出现严重异常，不在此轮作为替代主参考。逐 epoch 输出额枕代理值及各版本保留标记；被拒绝数据不删除。

同一主方案试次另外做 30/60/90 s 联合块 bootstrap，各 500 次，检查长程依赖对幅值标准误的影响。区块界定均按原始采样时间，不按拒绝后的序号；这仍不保证独立。

ICC 的类型与定义参照 [Koo & Li 2016 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4913118/)。bootstrap 中指标非退化的抽样少于 95% 时不报告区间。两半来自同一次采集，报告为本次采集内的幅值一致性，不能称为跨日重测信度。置信区间也不包含未知身份、设备状态或参考选择造成的系统误差。

## 临床档案探索的限定范围

正式同期临床推断仍受 `ANALYSIS_PROTOCOL_DRAFT.md` 的时间、状态和身份门槛约束。本轮允许一个独立标明的**档案候选链接可行性实验**：只用无 DOB 冲突、最早记录、唯一姓名加标签日期链接、技术可测且 MUSS/年龄/设备使用月数完整的 HA 候选。标签日期不宣称为量表评估日。保持全使用时长范围，不沿用历史 0–60 月截断。不按 MUSS 高低或 EEG–MUSS 关系选择记录。

先审计年龄与 DOB/实际 EEG 日期的一致性、量表范围和天花板。MUSS 仅作为原表百分比列，版本和评估时间未知如实标注。至少 30 个完整候选才执行模型；如达不到则报告可行性不足。只拟合预定主要幅值，无差值、频段或模型搜索。

固定岭回归 alpha=1、训练集标准化及未惩罚截距，比较训练均值、年龄+使用月数、EEG 单变量、年龄+使用月数+EEG。相同候选、相同 20 次重复的 5 折候选人划分；每个候选仅一条记录，重复/epochs 不进入折间。没有超参数调优，因此无需嵌套搜索。预测统一截断至量表范围 0–100%。主指标为临床加 EEG 减临床模型的 MAE（负为改善），附 MAE/RMSE/R²。先对每人跨重复的损失求均值，再按候选人 bootstrap 5,000 次得到差值区间；该区间条件于固定 OOF 模型，**未重新训练全流程，不能当作完整泛化不确定性或显著性检验**。折和重复次数不当作独立样本数。

原始行、实际年龄/日期和量表值、每人预测均保存 private；公开目录仅不透明索引、技术 EEG 数值和聚合临床结果。年龄和使用时长基线未纳入可靠的听力/可听度指标，不能称为充分临床基线。即使出现增益，也只能说明现有候选档案标签上的探索结果，不能宣称临床效用、同期效度或未来预测；阴性结果同样记录。身份/日期未知不由模型或 EEG 波形反向填补。本阶段不启动深度学习或 GPU。

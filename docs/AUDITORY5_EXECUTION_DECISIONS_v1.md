# Auditory5 v1: implementation decisions before real model outcomes

The author-supplied plan `AUDITORY_FIVE_IDEAS_SERVER_PLAN_v1.md` (SHA256 `6df2b97d06491a631ae17c531cb5abaa219e7309b7d9f2385f8bac7b538d5656`) governs this work. These decisions resolve implementation details using metadata and synthetic filter tests, before fitting new real-data models.

- Active workspace and curated Git checkout are separate. S0 compared original source hashes with the release manifest's source hashes: no changes to prior scientific code/configurations. New work stays in `auditory5/` and versioned restricted run directories.
- HA includes its existing earliest candidate index whenever source/identity gates pass. Old EEG trial eligibility is not reused as a new inclusion criterion. Clinical completeness is evaluated separately. Source scores are never inputs to the encoder, identity graph, signal QC or stimulus task selection.
- Identity split groups conservatively connect audited HA name groups, MFF source tokens, all accepted full-name candidate links (including date-mismatch links), and the two audited cross-archive overlaps. A unique same-day MFF candidate remains required for inductive source eligibility. Ambiguous and unknown sources stay out of such training.
- MFF per-task indices use the earliest real acquisition per candidate/task before signal QC. Tasks retain separate literal code maps and native layout evidence. Metadata support gives only 16 bapa indices in the shared 128-sensor layout, so E1 cannot meet its 20-per-task threshold even before QC. The nine previously identified same-day pairs define E0's feasibility input; no extra group interpretation is added.
- Synthetic effective impulse support at the three audited sampling rates is approximately 10.82 s. Startup guard remains 20 s. Boundary embargo is the maximum of 10 s and the measured support over the eligible rates (10.823 s); A's block width is the smallest 30 s multiple meeting `4*embargo+0.7`, hence 60 s for every A record. The direct epoch must lie inside its block with this guard on both sides. General trial/block eligibility and B cross-child support use the original 30 s time blocks; these are not within-record trained-head validation splits.
- HA numeric 1/2 are the only frozen local classes. Other annotations have unresolved semantics and conservatively break the history chain; they are not assigned a frequency or claimed to be known acoustic stimuli. History is computed before any EEG rejection. No history crosses a true gap, explicit restart or unresolved event. Large interstimulus gaps alone are not declared storage gaps.
- P1 and P2 start from raw microvolt signals, with the plan's separate causal reference/filter definitions and a fixed recording sample grid. No baseline correction, epoch variance normalization, phase compensation or event-specific resampling is added. Half-open epochs contain 175 samples at 250 Hz; the saved per-trial grid offset preserves trigger alignment.
- New QC version uses the retained 250 Hz causal waveform's per-channel peak-to-peak threshold of 150 µV, and original-rate raw flatness (<0.5 µV) and saturation checks on the direct epoch. Rejected complete epochs remain stored. Physically incomplete epochs remain in the event ledger without a signal row. Record-level raw finite/flat checks are explicitly offline quality checks. This is a new QC version, not assumed identical to Phase 1.
- Clinical D uses unique archived HA MUSS percentage scores, age, log1p duration and the audited complete better-ear four-frequency threshold in source units. Unknown scale timing and threshold units remain unknown. New EEG QC, not old outcome/model success, determines trial support.
- Module tests, integrated data checks and scientific outcomes have distinct statuses. A module test PASS alone does not authorize model interpretation. Failed development runs and logs are retained; no failed output is silently reused as a successful scientific run.

Additional model/readout implementation details will be frozen before those stages run. Existing Phase 0–3 negative results remain intact. No new participant-derived artifacts or model weights are authorized for automatic GitHub publication.

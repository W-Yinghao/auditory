# 核 CS-QMI 全量轮：下一步解释（草稿，等待框架决定）

数据来源：`FULL_RESULTS.md`、`OPTIMIZATION_RESULTS.md`、`TEMPORAL_RESULTS.md`、`GROUP_DEVELOPMENT_RESULTS.md`，以及 `results/auditory_alignment_kernel_cs/*.json`。

覆盖情况：
- 主矩阵 4,410/4,410；登记扩展 E10–E12 共 1,800/1,800；线性参照 E9 共 160/160。
- 没有失败单元。汇总按代码哈希核对，没有被拒的单元。

所有区间都是以参与者为单位的 bootstrap，以已拟合的模型为条件。训练波动另列：单元层 SD，以及均值为正的单元数。

下文的"增益"指：同一组真实候选、同一标定下，错配 EEG 的对数损失减去真实 EEG 的对数损失，单位为 bits/5 s 查询。

本文件只做观察与可选框架，不下论文结论。

## 0. 运行中发现并修正的问题（影响解读的部分）

均在正式汇总之前修正，记录见 `IMPLEMENTATION_NOTES.md` §3–§6。

1. **统一读出最初为负平方误差评分。** 收缩后，候选自身的范数主导排序，所有方法都停在机会水平。
   - 改为重建相关评分后，所有方法都高于机会，错配 EEG 仍在机会水平。
2. **原始 CS 值不能选 checkpoint（规格 §4.6）。**
   - 冒烟测试中，错误配对模型在真实与错配下的 CS 都约为 0.011 nats。
   - 改为"自身目标 − 合法错配"后再选择。
3. **Federici 段落块划分存在内容泄漏：** 639 个测试刺激片段里有 612 个也出现在拟合中。
   - 已改为包络内容组划分，各角色之间的重叠为 0。
4. **私有分类头原先在受过梯度的试次上拟合**，导致对新儿童过度自信。
   - 改为只在早停块上拟合。已有私有单元从 checkpoint 只评价重跑，不重训。

这些修正本身就是方法学结果：EEG–声音对齐的评价对候选打分、checkpoint 选择、内容划分、读出拟合数据都很敏感。

## 1. 先列出的意外（未事先预期，或与规格的隐含预期相反）

**S1. 不训练的线性参照（E9）与多数深度方法相当，或更好。**
- 线性参照：原始 EEG 窗口 → 训练侧岭桥接，评价协议完全相同。
- 统一读出、完整窗：
  - **FAU**：只有 NCE 高于线性参照，Ac +0.37、Lz +0.21、Local +0.18 bits。CS_SINGLE 为 −0.09 到 −0.15；FMCA 与 CS_MULTI 为 −0.38 到 −0.55。
  - **DTU**：NCE 只在 Ac 上高于线性（+0.32），Lz 与 Local 和线性相当。其余方法都低于线性。
  - **Federici**：四种深度方法都比线性低 0.25–0.30 bits（线性 +0.35，最好的深度方法 +0.09 到 +0.17）。
- 私有任务上的"深度 − 线性"为 +0.27，但这是线性头的问题：3,020 维原始特征只用约 7,400 个早停试次拟合，严重过拟合。这一行不作为比较证据。

**S2. 冻结声音投影反而更好（E5，FAU Local 完整窗，统一增益）。**
- CS_SINGLE +0.13、CS_MULTI +0.15、FMCA +0.31 bits；NCE 不变（−0.01）。
- 可训练的声音侧，似乎让核/logdet 目标找到了不迁移到 EEG 读出的依赖形状。
- 这只是假设，未验证；而且只在 FAU 上做了。

**S3. 受限窗口常常优于完整窗。** 完整窗不是上界，因此时间结构的解读受编码器结构混淆。
- NCE 原生读出、FAU Local：晚窗 1.90 bits，完整窗 0.89 bits；DTU 3.64 对 2.06。
- E12 中，Ac 与 Lz 的联合窗也大多高于完整窗。例如 CS_SINGLE Ac：FAU 0.95 对 0.55，DTU 1.58 对 1.04。
- 对照正常：错配 EEG 的 top-1 在机会水平（FAU 0.010 ≈ 1/92，DTU 0.004 ≈ 1/209），困难候选增益也高（0.70 / 1.19 bits）。所以这不像泄漏。
- 更可能的原因是完整窗编码器把 600 ms 池化成 4 个时间单元，丢失了时间分辨率。这是推测，未验证。
- 因此，"晚成分比完整响应携带更多信息"这类神经解释不能成立。

**S4. 把 CI 排除在训练之外（E7），TH/HA 反而更好，CI 不变。**
- TH/HA 增益 +0.02 到 +0.16 bits，NCE 最明显：TH +0.14、HA +0.16。
- CI 的变化在 −0.06 到 +0.04 之间，区间都含 0 或接近 0。
- CI 参与训练没有帮助 CI 自己的读出，反而略微损害了其他组。这与 C3-DL 中 CI 训练后 G_EEG ≈ 0 一致。

**S5. 私有标准/偏差任务上，所有方法、所有窗口都约为 0。**
- 头增益 −0.002 到 +0.0005 bits/试次，头 AUC 0.50–0.53。
- 历史条件增益减去孪生对照最大约 +0.002 bits（CS_SINGLE 完整窗、共同支持：+0.0021 [+0.0006, +0.0036]）。
- 类别均衡训练（E11）、E5 的所有轴、年龄与佩戴时长，都没有改变这一点。
- 修正前读出协议给出的是 −0.02 到 −0.44，那是校准伪迹。

**S6. CS_MULTI 的行为异常。**
- 最佳 epoch 很早（中位数 15–50），原生读出增益接近 0（0.003–0.23）。
- FAU 原生排名百分位的分半相关为 −0.64。Federici 原生读出的增益约为 0，分半相关却约 0.85。
- 这说明按"原始排名百分位"算的分半信度会被刺激内容驱动，不是干净的个体重复性度量。
- 事后分析 R1 改用 EEG 特异增益：FAU CS_MULTI 原生 Local 变为 +0.55；Federici 原生读出约为 0。见 §2.9。

**S7. 组合目标（E10）由其中一项主导。**
- CS_SINGLE+NCE 与 NCE 相当：DTU −0.003，FAU +0.023 bits。
- FMCA+NCE 与 FMCA 相当，原生读出甚至比 FMCA 单独更差（DTU −0.25）。
- 按原始尺度相加时，NCE（约 5.5 nats）或 FMCA 的 logdet 梯度占主导。组合结果不能代表"CS 增益"。

## 2. 按问题整理的观察

### 2.1 解码有没有用（规格 §10.1）
- FAU 与 DTU 上，所有方法、目标与窗口都高于错配 EEG。
  - 统一读出增益：FAU 0.09–1.17 bits，DTU 0.13–2.39 bits。
  - 最好的 top-1：FAU NCE 原生联合窗约 0.13（机会 0.011）；DTU 约 0.17（机会 0.005）。
  - 困难候选（同故事/说话人、声学最近的 8 个真实片段）上也有正增益。
- Federici（儿童、只有包络、100 Hz、2–8 Hz）：深度方法的增益小（0.02–0.17 bits）；线性参照 0.23–0.35。
- 私有类别任务：约 0（见 S5）。

### 2.2 方法比较
- FAU、DTU 上，任一目标与窗口都是 NCE > CS_SINGLE > FMCA ≈ CS_MULTI。
  - 统一读出、Local 完整窗：CS_SINGLE − NCE 为 FAU −0.30、DTU −0.56 bits；CS_SINGLE − FMCA 为 +0.30 / +0.49。
- Federici：差异很小，CS_SINGLE 略高于 NCE（+0.04 [+0.02, +0.06]）。
- 原生读出与统一读出的排序基本一致，NCE 的原生优势更大。
- E5 调参没有改变排序。
  - CS_SINGLE 的带宽倍数 1 最好：0.5 时 −0.28，2 时 −0.06。
  - FMCA 在 512 行时 +0.34。
  - NCE 在 512 行时 +0.16，温度 0.05 时 +0.03。
  - 维数 8/16 差别不大；32 维时 CS_SINGLE −0.10。

### 2.3 核依赖值（规格 §10.3，解释材料）
- 测试数据上 CS(真实) − CS(合法错配) 都为正，CS_SINGLE 最大：FAU +0.005、DTU +0.013、Federici +0.003 nats。
- 它在多大程度上跟随检索增益，没有单独检验。
- 不跨数据集比较，也不称为信息量（bits）。

### 2.4 时间结构
- **FAU、DTU 的 Local：** 在早窗之上加入晚窗的收益（Δ_{L|E}）明显为正，例如 NCE 统一读出 +0.23 / +0.49 bits。在晚窗之上加入早窗的收益（Δ_{E|L}）小得多，在 −0.02 到 +0.14 之间。
- **E12：** Ac 与 Lz 方向相同。
- **Federici：** Δ_{L|E} 约 0 或为负，早窗反而更好。
- **私有任务：** 约 0。
- 受 S3 的结构混淆，这些只说明"受限编码器下哪个窗口更容易读出"，不能直接称为神经潜伏期结构。

### 2.5 组别（规格 §11.1）
- **FAU：** CI 低于 TH 与 HA，所有方法一致。CI − TH 为 −0.08 到 −0.53 bits；HA ≈ TH。
- **DTU：** HI 高于 NH，NCE +0.45、CS_SINGLE +0.21 bits。方向与 C3 的"HA > TH、HI > NH 声学独特信息"一致。
- **Federici：** CI ≈ HC，HC-v ≈ HC。幻影头（Artifact）约 0，作为负对照符合预期。
- 设备组没有进入网络输入。CI 的低值不能直接归因于神经功能：伪迹与电极图问题见 C3。

### 2.6 注意（E6）
- 二选一正确率不高：FAU 0.51–0.57，DTU 0.51–0.66。
- 用注意任务训练只比零样本（单说话人训练的模型）略好，NCE 与 CS_SINGLE 约 +0.01 到 +0.02。DTU 上 FMCA/CS_MULTI 的原生读出反而更差。
- 只有跨参与者模型；个体校准模型未做。

### 2.7 训练侧错误配对（E8）
- FAU、DTU 上，正确配对的模型都高于错误配对的模型。差值：NCE +0.57 / +1.30，CS_SINGLE +0.27 / +0.56，FMCA +0.05 / +0.12，CS_MULTI +0.02 / +0.06 bits。
- 错误配对的模型本身也有 +0.06 到 +0.28 bits 的增益。读出（训练侧岭桥接 + 相关评分）对一个与刺激无关训练的编码器，也能抽出部分声学跟踪信息。
- 所以"方法是否利用了对应关系"看差值：NCE 与 CS_SINGLE 明显，FMCA 与 CS_MULTI 很小。

### 2.8 发育与功能（规格 §11.2–11.3）
- **私有：** 年龄与佩戴时长的斜率都约为 0；年龄 × 窗口交互也约为 0。
- **Federici：** 组内年龄斜率约为 0。
- **功能层**，比较 C → C + 整体对齐 → C + 时间结构，LOO 风险差为正表示变差：
  - DTU 的 SRT、FAU CI 的 HSM、Federici 的行为正确率，都没有出现改善；有些模型因为加入对齐项，留一预测反而变差。
  - 与 C3 中功能层的零结果一致。

### 2.9 个体重复性（规格 §10.5）
- 单元记录中的分半度量是每半的原始排名百分位，受内容影响（见 S6）。
- 事后分析 R1 改用每半的 EEG 特异增益（错配 − 真实对数损失），已在计算前登记（IMPLEMENTATION_NOTES §5b）。
  - 方法：重新载入 780 个核心完整窗单元，原样运行评价。复算的全样本增益与已存记录的差：中位数 4×10⁻⁵，最大 8×10⁻⁴ bits。
- **FAU 与 DTU：**
  - NCE、CS_SINGLE、FMCA 的分半 r 为 0.5–0.9，Spearman–Brown 校正后 0.7–0.95。例如 FAU Lz：0.85–0.89；FAU Local 统一读出 0.57–0.71。
  - CS_MULTI 较低（0.25–0.82），DTU Local 只有 0.25–0.33。
  - 原先按排名百分位得到的异常值消失：FAU CS_MULTI 原生 Local 从 −0.64 变为 +0.55，Ac 从 −0.25 变为 +0.79。S6 的内容混淆解释得到支持。
- **Federici：**
  - 统一读出 0.16–0.45，原生读出 −0.13 到 +0.17。
  - 原先按排名得到的高原生信度（0.82–0.86）在 EEG 特异度量下消失，说明它来自刺激内容，而不是儿童的 EEG。
  - 儿童队列的个体重复性低。另外，样本里包含增益约为 0 的 9 个幻影头。

## 3. 用语边界

- **不能说**：
  - "CS-QMI 优于 InfoNCE"：在 FAU/DTU 上方向相反，Federici 只有 +0.04 bits。
  - "CS 值是信息量 / Shannon MI"。
  - "晚成分携带更多信息"（S3）。
  - "对齐反映听觉发育或功能"（§2.8 为零）。
  - "CI 的低对齐反映神经损失"。
  - "组合目标证明 CS 有附加价值"（S7）。
- **可以说**（量级照实）：
  - 在未见内容上，EEG 能识别所听的 5 s 语音片段，三个成人/儿童队列都高于错配 EEG。
  - NCE 是最强的深度目标，但只在部分条件下超过不训练的线性参照。
  - 传统核 CS-QMI 能训练出有用的表示，高于 FMCA 与多尺度版本，但低于 NCE 与线性参照。
  - 组别模式与 C3 一致（CI 低，HI 高于 NH）。
  - 私有类别任务中，这类对齐编码器没有提取到超出历史的当前类别证据。

## 4. 可选的论文框架

**A. 方法基准，以"核 CS 不胜出"为主结果。** 主体是 4 种目标 × 4 个队列的完整矩阵，加线性参照、E5 配方敏感性和评价陷阱（§0）。
- 优点：结果完整，结论诚实。
- 缺点：听觉故事退到次要位置。主要卖点变成"评价方法学"和"强线性基线"。

**B. 以听觉故事为主，方法作工具。** 主线是"EEG–语音对齐在未见内容上可用、组别结构稳定（CI 低，HI > NH）、但与功能和发育没有关联"。四种目标作为稳健性检验；CS 的结果放在方法比较一节。
- 与 C3 主线连贯。
- 风险：组别差异的来源（伪迹、听力、刺激呈现方式）需要和 C3 的对照一起讨论，不能单独作为神经结论。

**C. 评价方法学为主。** 主线是"EEG–声音对齐的评价对四个环节敏感"：读出候选打分、checkpoint 选择、内容划分、读出拟合数据（§0 四个修正，每个都有量化的前后对比）。再加上线性基线与训练侧错误配对对照（§2.7）的必要性。
- 结果独立，可以成为短文或方法附录。

**我的建议：** 以 B 为正文，C 作为方法学一节或补充材料，A 的完整矩阵放在附录表。理由：
- 听觉故事是规格 §16.2 明确要求的主线。
- §0 的四个问题对任何做同类分析的人都有用。
- CS 不胜出的结果按规格如实报告即可，不需要做成主卖点。

这只是建议，框架由你决定。

## 5. 可接着做的事（未开始，等框架决定后再选）

1. **编码器结构**：
   - 完整窗使用更细的池化或多尺度分支，检验 S3 是不是结构问题；
   - 若是，重跑时间结构分析。
2. **冻结声音投影**（S2）：扩展到 DTU、Federici 与全部目标，确认它是普遍现象还是只在 FAU 出现。
3. **线性 + 深度**：残差或叠加读出，看深度表示在线性参照之上是否有增量。若采用框架 B，这直接回答"深度对齐是否必要"。
4. **注意解码的个体校准模型**（规格 §10.4，本轮未做）。
5. **功能层与发育分析改用 EEG 特异增益**：成人队列可靠性足够（R1），可作为个体度量；儿童队列（Federici）不够可靠，个体层面的分析需谨慎。

# EEG_auditory 项目整体总结：做过什么、没做什么、用了多少数据（截至 2026-09-27）

本文把 2026-09-16 到 09-27 的全部轮次放在一起盘点：
- 每轮的数据用量，统一换算成占全部数据的百分比；
- 各轮试了什么、得出了什么；
- 哪些想法和哪些数据从未碰过。

逐轮细节以各轮 STATUS/RESULTS 文档为准，本文只做汇总。数字取自各轮文档与导出元数据；文档未写明的一律标"未载明"。

### 3.2 几个汇总数字

- **做过事件解码的记录**：286 / 296 = **96.6%**（GX 起才用全）。GX 之前，大多数轮次只用 HA 的 49–60 名儿童，约占事件记录的 17–20%、EEG 时长的 10–12%。
- **进过临床结局模型**（量表、PTA、阶段等）的记录：HA 最多 57 条 + MFF 71 个候选（repair），合计约 128 / 296 = **43%**。只算 HA 则约 19%。`DATASET_KNOWLEDGE.md` 的"18%"口径没有计入 repair 的 MFF 回归。
- **与临床量表有关的轮次**（Phase 2/3、auditory5 D、repair、retrain、F 档案、FN1-A、K1、R0、D2、PF）一共约 12 轮，**反复用的是同一批 52–57 名 HA 儿童**，约占事件记录的 18–19%、EEG 时长的 10%。
- **MFF 高密度数据**（98.23 h，占全部 EEG 时长的 83%）：
  - 主要用于刺激解码（弱）、年龄（强）和无标签自监督；
  - 只在 repair 一轮里进过临床模型；
  - CI 儿童的临床问题从未能建模。
- **规模从未碰过的原始材料**：MFF 平均/分段容器共 763 个，外加 SET/FDT、MAT、JSON、视频，以及 CI 表中的客观听力测量。

## 4. 各问题的结论状态（跨轮）

| 研究问题 | 做过的轮次 | 现状 |
|---|---|---|
| 能否跨儿童读出标准音 vs 偏差音 | Phase 3、auditory5、next v2、v2.1、v3、ST1、GX 1–5、PF | **能，但很小**：HA 0.556，MFF 0.51–0.53。受数据量限制（5→60 名儿童 0.520→0.568），60 名以后趋平（PF H20） |
| 读出的是什么 | GX 2–5 | 刺激锁定、δ/θ、0.12–0.32 s；早（0.16 s）/晚（0.28 s）两个成分；不是眼动 |
| EEG 能否预测功能量表（MUSS/IT-MAIS/CAP/SIR），且优于临床基线 | 约 12 轮 | **一直没有**。临床基线（月龄 + 佩戴时长）已接近天花板（SIR>3 的 AUC 0.98） |
| EEG 能否反映听力水平（PTA） | R0、D2 | **不能**（技能分 −0.01 / −0.05） |
| EEG 能否反映发育年龄 | D2、R0、GX2/3、PF H16 | **能，而且稳**：128 导 MAE 12.5 月（基线 19.1）；2 分钟饱和；约 96 电极前不饱和 |
| EEG 能否反映佩戴经验（阶段） | GX 4/5、PF、PF2 | **弱阳性**：w_late 区分阶段 AUC 约 0.64（p 0.04），但不超过月龄本身；月龄之上的增量未确立（+0.02，p 0.06） |
| 个体化模型 / 跨会话个体特征 | GX 1/6/14、repair F4 | 否；个体模型要 ≥4 次会话 + 群体模型才有用 |
| 跨范式 / 跨任务通用 | GX 4/12、auditory5 E0 | 否 |
| NH 与听障的读出差异 | GX 2/3、PF H5 | 方向一致（0.593 vs 0.551），样本不够（NH 9 名） |
| CI 专门问题 | Phase 3、GX | 可读性与非 CI 无差；临床问题因交集 1–2 名从未能做 |
| 采集预算（电极、时长、儿童 vs 试次） | D2、GX13、PF H18–H20 | 年龄：电极数是瓶颈、2 分钟够；刺激读出：儿童数与试次数的分配无差别 |

**方法学上的纠错（都已修正并记录）**：
- PTA 行键错位（旧 Phase 3 的 PTA 结果不可靠）；
- K0 目标函数尺度差 n 倍；
- D2 单折划分的假"饱和点"；
- PF 模型 (b) 的跨网络嵌入不可比；
- D1"378 条"实为 371 条成功导出。

### 5.2 数据上可行但从未碰过

- **MFF 平均波形容器 515 个、分段容器 248 个**：可能包含临床团队当年自己做的平均/分段结果，可用来对照复现，或补充事件信息。
- **CI 扩展工作簿的客观听力与发育测量**（ABR、DPOAE、ASSR、主观/助听阈值、发育商、P1/MMN 测量值）：这是 R0 建议的"客观听阈目标"的唯一来源，也是 CI 儿童仅有的非问卷变量。
- **SET/FDT 27 组**（含 10,965 个已分段的 NH epoch）、**JSON ERP 91 个**、**MAT 8 个**、**AVI 2 段**。
- **条件线索**（CI 儿童 quiet/noise × 方向，17 条记录）：偏差试次太少，只能做个案。
- **非规范连续 MFF 168 条**：只用于自监督，从未与任何标签对应。

### 5.3 按设计或规则明确排除

- ERP 主线（峰值命名、潜伏期、平均波形重建）；
- GX/ST 中的通道筛选；
- 把信号压缩或脑龄本身当主线；
- 用未校正的脑龄差当"听觉年龄"（已证实 r = −0.51 是伪迹）；
- 强制特定架构（Mamba、foundation model 等）；
- 因果康复或预后结论；
- 未经授权的对外发布与临床外联。

## 6. 总体判断与建议

1. **现有数据能支持的阳性结论只有三类**：
   - 跨儿童的刺激读出小而真实；
   - 连续 EEG 稳定编码发育年龄；
   - 晚成分权重 w_late 与佩戴阶段有弱关联，但未超过月龄。
2. **临床功能这条线在现有数据上已经反复穷尽**。约 12 轮都用同一批 52–57 名 HA 儿童，而临床基线已近天花板，继续换模型或换目标不会改变结论。
3. **数据利用的最大缺口在 MFF 一侧和 CI 一侧**。高密度 MFF 占 83% 的 EEG 时长，但只进过一次临床模型；763 个平均/分段容器和 CI 客观听力测量从未碰过。
   - 如果还要在现有数据上做事，性价比最高的是 R0 的 S1：在 MFF 203 条上把参考蒙太奇作为因子、先过信度门槛。
   - 其次是先审计 CI 客观听力测量能否与 EEG 对上，决定"客观听阈"目标是否可行。
4. **真正能推进阳性结论的，是新数据**：一批带佩戴时长和同期量表的新 HA 儿童，或更多 NH 儿童（0.04 的差异约需 20 名 NH）。

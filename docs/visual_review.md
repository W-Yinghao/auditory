# 图片与视频补充审阅

2026-09-16。Slurm 995113 完成 PNG 哈希与私有联系表生成，随后逐张查看 9 张联系表中的全部 80 个不同图像。81 个 PNG 中有一组字节完全相同。原始截图含身份和日期，联系表只存于 `private/visual_review_001/`，不作为可公开图件。

这些图像均为 Net Station Review 界面截图，主要展示已有平均/差值波形，部分同时显示多个通道或放大通道。可见 Standard、Deviant、MMN 分类文字、3 个存储 epochs、1,800 samples/1.8 s 的导出信息；这些是屏幕内对应文件的处理状态，不能外推至所有采集，更不能理解为三个独立试次。部分图显示较大尖峰、缓慢漂移或不同波形形态；截图的缩放、通道和光标位置不同，不能据此量化组间差异、峰值或伪迹比例。

可见 CI、CIHA、HA、quiet/noise、左右/前方及 `naked` 等源标签，它们扩充了条件线索，但不足以把全部记录的设备开启状态补成已确认。显示滤波 Off 只涉及当前显示设置，不能证明源文件未经滤波。未在此次联系表审阅中建立 HA 数字码 1/2 与 800/1200 Hz 的明确对应，也未获得量表与 EEG 同日评估的证据。没有逐字 OCR 或从截图反推数值数据。

两段 AVI 通过 Slurm 995118 读取 RIFF/AVI header 并扫描视频 chunk：均为 1280×720、25 fps、FMP4，时长约 569.04 s 与 587.16 s，视频 chunk 数分别 14,226 与 14,679，与各自 header 一致。环境未提供 ffmpeg/ffprobe，当前 PIL 不能解码 FMP4；抽帧未成功，**视频内容仍未审阅**。未安装新解码环境，也未把视频当作新增 EEG 采集。

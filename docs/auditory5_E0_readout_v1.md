# E0 native-layout technical protocol

The nine archived same-day task pairs are fixed. The native physical 128-sensor data use independently reset 60s raw blocks; complete epochs must satisfy the 20s startup guard and 10.823s ending embargo. The source reader preserves true acquisition gaps. Average reference includes the frozen physical sensor set; MFF QC fractions are fixed in mff_export_contract.md.

A record needs at least 40 accepted trials per local class and at least four filter blocks containing both classes. A fixed four-fold GroupKFold partitions these entire blocks. Every fit and calibration uses only its training blocks; three inner block folds select regularization. This is a within-record technical protocol, not child-held-out inference. For training readout weights, blocks have equal mass and classes equal mass within a block; evaluation first computes class-balanced CE for each record and then gives paired candidates equal mass.

Features are native-channel 20ms poststimulus bins. Candidate/block-weighted training scaling and PCA≤32 precede a linear readout or one 32-unit ReLU layer. The small head uses L-BFGS, max_iter1000, max_fun50000, tol1e-6, alpha [.01,.1,1,10], with training-inner-OOF temperature in [.25,4]. Both heads share every test trial. Solver convergence failures fail the affected run; no model-specific trial deletion or outcome-driven model replacement is allowed.

Only pairs with both tasks decoded enter paired-task summaries. The two task labels remain separate literal maps. Intervals resample fixed-OOF paired candidates 2000 times. These results do not estimate a population cross-task transfer gap and do not identify all sources as CI. E1 is independently SUPPORT_INSUFFICIENT because bapa has at most16 safe same-layout indices before new QC, below20.

# D1：研究方向 v1（第 1 轮锁定，后续轮次可修订）

依据：R0 方法审查（`docs/auditory_r0/R0_METHOD_REVIEW_AND_REDESIGN.md`）、文献边界核查、D1 数据预算。
约束：不做 ERP 分析（无试次平均、无 P1/N1/P2/MMN 成分）；走连续 EEG decoding；信息论实质参与；
真实数据全量训练；GPU。

## 1. 为什么换题

R0 证明了两件事，方向由它们决定，不由偏好决定：

- 可靠的连续 EEG 特征**携带大量成熟度信息**（年龄技能分 +0.574，负对照 −0.001，技术协变量单独 +0.006）。
- 同一批特征对**听力水平几乎没有信息**（裸耳 PTA −0.008，助听 PTA −0.051）。

文献核查进一步划定边界：

- 儿童 EEG 脑龄回归本身**已被占据**（Iyer 2024，N=1056，睡眠 EEG，MAE/SD≈0.17–0.20；Ju 2025，N=659+98，静息，3–14 岁，MAE/SD≈0.44）。
  我们的 21 月 / SD 40.5 = **0.52**，是可信基线，**但不能作为卖点**。
- EEG 基础模型评测**已饱和**（18 个月内 5 个基准），不作为新颖性来源。
- 但**没有任何一项** EEG 脑龄/成熟度研究做在聋、听障、CI 或 HA 儿童身上；
  听觉剥夺的脑龄工作全部是成人且全部基于 MRI。
- 非诱发的剥夺敏感指标是已知的（delta/theta 相对功率、主导/alpha 峰频、非周期指数、theta/alpha PLI、
  全局效率），但**从未被组装成听障儿童的成熟度指标**；非周期指数与听力损失的关系只有成人证据。

## 2. 主张（第 1 轮版本）

> **一个临床级 EEG 导联能保留多少关于儿童发育状态的比特？**
> 在同一批高密度记录内部按通道预算子采样来测这条信息曲线，并在同一人群的 22 导临床记录上验证可迁移性；
> 临床载荷是听障儿童的成熟度指标及其与**装置使用时长**的剂量关系。

三个层次，全部是 decoding，全部有信息论读数：

| 层 | 问题 | 单位 | 依赖标签 |
|---|---|---|---|
| L1 信息容量 | 记录身份信息随通道预算如何变化 | 全部 237 个采集（~100 h） | **不需要** |
| L2 发育信息 | I(Z; 年龄) 随通道预算如何变化，何时饱和 | MFF 66 身份 + BDF ~61 身份 | 年龄 |
| L3 临床载荷 | 成熟度残差与装置使用时长、助听 PTA 的关系 | 同 L2 | 年龄 + 装置变量 |

L1 使这项研究**不受标签稀缺限制**：它用满 100 小时和全部 237 个采集，而这批数据此前几乎未被使用。

## 3. 信息论怎么参与（不是装饰）

- **InfoNCE 作为 I(Z;Y) 的变分下界**，同时是训练目标——这是目前临床 EEG 文献里最站得住的一种用法，
  已出现在听障听觉注意解码的工作中。报告单位一律为**比特**。
- **解码可达比特 vs 界给出的比特**：两者之差就是"信息存在"与"信息可取"的距离，
  这正是 EEG 信息容量文献（arXiv:2510.17841，纯仿真）预言而**从未在真实临床儿童数据上验证**的东西。
- 该文献预言信息在 **64–128 电极处饱和**。我们的语料（129 导 HD-EGI + 22 导临床）是对它的直接经验检验。
- **点估计不作为主张**。按 Poole 2019 / Song & Ermon 2020 的批评，只用可优化的界 + 操作性解码读数，
  并强制附：打乱替代、样本量下采样曲线（估计量偏差）、以及**记录站点/设备身份负对照**
  （EFM 嵌入会编码站点身份——对双导联语料是致命混淆）。
- PID 不作为主线（当前正受子系统一致性质疑）；若使用必须显式声明格并附替代对照。

## 4. 必须预先挡掉的反驳

| 反驳 | 处理 |
|---|---|
| "临床改变不等于变老"，脑龄差在临床组可能失效 | 显式检验剥夺轴是否与年龄轴共线，而不是只报一个 BAG 数字 |
| 双导联比较其实在比设备/站点 | 通道预算曲线**在同一批 HD 记录内部子采样**测，完全避开设备混淆；跨导联迁移单列为另一实验并明确标注 |
| MI 估计量在小样本上有偏 | 样本量下采样曲线 + 打乱替代，二者都进主表 |
| 身份泄漏 | 按身份分折；自监督预训练池必须按折排除测试身份，或改用跨语料预训练 |
| n 太小 | L1 不依赖标签，用满 237 个采集；L2/L3 的 ~127 身份在临床 EEG 文献中属常规规模 |

## 5. 本轮不做

不做 ERP、不做试次平均、不做峰值提取、不重开 FN1-A/K1 的档案问卷回归、
不把 EEG 基础模型评测当作新颖性、不用 `V_given_A`。

## 6. 数据地基（已完成）

`auditory_d1_continuous_v1` 导出契约：零相位 0.5–45 Hz、整数抽取到 250 Hz、
全物理通道平均参考、逐存储区间独立滤波、逐 4 秒块 QC 只记录不丢弃。
分块滤波与整段 `filtfilt` 的一致性已核验（相对差 2e-12，Slurm 1000299）。

# D1/D2：研究方向 v2（第 4 轮后修订）

取代 `D1_RESEARCH_DIRECTION_v1.md` 的第 2–3 节。v1 的数据地基与约束不变。

## 1. 四轮之后，证据支持和不支持什么

**支持：**

- 连续儿童 EEG 的发育信息随电极数增加，在高密度硬件上可稳定测量；
  128 电极的 OOF MAE 为 12.50 月（猜均值 19.07），bits +0.595。
- 打乱身份后曲线完全平坦（MAE ≈ 猜均值，bits ≈ 0），两支线都是。
- 跨放大器、跨电极阵列的迁移成立，且不使用任何目标队列标签；
  在年龄分布重叠区间上代价很小（MFF→BDF 为 25.71 月，BDF 自身队列内为 26.04 月）。
- 信息冗余分布在低频功率与波形形状描述子上，没有必需的单一频带。

**不支持（已被自己的重复实验推翻或从未成立）：**

- ~~非线性读出把饱和点从 64 移到 16~~ —— 单折种子产物，重复后不成立（第 4 轮更正）。
- ~~BDF 独立复制了预算效应~~ —— 重复后效应与噪声同量级；BDF 的量程整个落在噪声段。
- EEG 对装置使用时长、PTA、四个量表在年龄之上有增量 —— 全部为零或负。
- 脑龄差与临床变量相关 —— 年龄偏差校正后全部区间跨零；未校正值是回归伪迹。
- 自监督相对位置表征迁移到年龄 —— 结构上不可能（头部为 `|z1−z2|`，抵消被试级分量）。

## 2. 主张收窄为

> **在儿童临床 EEG 上，发育信息的可提取量如何随电极预算变化；这条曲线本身需要多少硬件才能测准；
> 以及在这个人群中持续 EEG 编码的是发育轴而不是听觉剥夺轴。**

三条都是可陈述、有数据、有负对照的。第三条是负结果，但它是**被三种独立方法确认**的负结果
（R0 的技能分、第 2 轮的年龄之上增量、第 3 轮的偏差校正脑龄差），因此是结论而非失败。

## 3. 对 JBHI 的定位

- 信息学贡献：通道预算的信息曲线 + 其可测性的稳定性分析。
- 部署含义：儿童（尤其是戴助听装置的幼儿）对布极耐受度有限，电极数是真实约束。
- 方法学警示：一个未校正的脑龄差会给出 r = −0.51 的"装置使用时长效应"，而它完全是伪迹；
  我们有具体的差点中招案例。
- 诚实的边界：n≈60 的队列上单折划分不可作为结论，所有曲线主张附跨种子离散度。

## 4. 仍然缺的（按价值排序）

1. **嵌套电极选择的重复验证**（进行中）。单种子给出 16 电极 MAE 11.38，优于全部 128 导；
   在第 4 轮的教训之后，未经重复不得引用。
2. **样本量**。62（MFF）+ 56（BDF）。MFF 侧受限于"同名同日唯一参与者"这一有证据的身份判据，
   不放宽。
3. **学习表征臂**。相对位置已证伪；若继续，前置任务必须不抵消被试级分量。
   但在 n≈60 上，文献与本轮证据都指向"从零学习的表征不会超过谱特征"，
   因此该臂的价值是**作为对照说明这一点**，不是作为主结果。
4. 图与最终稿。

## 5. 明确不做

不做 ERP、不做试次平均、不做峰值提取、不重开档案问卷回归、
不把 EEG 基础模型评测当作新颖性、不在未校正脑龄差上作任何剥夺相关陈述、
不因单次运行好看就写进结论。

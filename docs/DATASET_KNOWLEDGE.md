# 数据集知识汇总（EEG_auditory，截至 2026-09-21）

本文把项目各轮（Phase 0–3、auditory5、D1/D2、FN1、R0、K0/K1、ST1、GX 三轮）整理出的**关于数据集本身**的事实收拢成一份。只收聚合数字与规则，不含姓名、日期、原始路径与逐人临床值（这些只在 `private/` 下）。数字后的括号给出来源文档；同一量在不同轮次因门槛不同而不同时，两个数都列出并说明原因。

**三条最重要的使用规则。** (1) 文件数、导出数、storage epoch 数、GUID 数都不是儿童数；"数据集有多少个独立儿童"被裁定为不能用单一数字回答的问题。(2) 来源标签（CI/CIHA/HA/NH/normal/unknown）是路径或 Patient ID 里的**字面证据类别**，不是诊断，也不是采集时设备开启的证据。(3) t=0 是触发标记而非声学起点；HA 的码 1/2 与 800/1200 Hz 的对应关系从未被材料确证。

D1 导出的现状：MFF 侧文档记 378 条记录 / 99.94 h，数组目录现有 371 个文件（348 个 128 通道、22 个 64 通道、1 个 129 通道；差 7 未核实）；BDF 侧 93 条 / 20.53 h，全部 20 通道；203 个 canonical MFF 来源全部在 D1 导出集合内。约 43 GiB 信号只在 `private/` 下。

## 8. 规则与已踩过的坑

| 类别 | 内容 |
|---|---|
| 隐私与来源 | 原始目录只读；姓名、精确日期、原始路径、源表临床行、逐人预测、身份密钥只在 `private/`（0700）；不外发 |
| 推断禁令 | 不从文件名推临床标签；不从类别频率推事件角色；不从 epoch/导出/GUID 计数推独立儿童；身份合并须附证据与状态 |
| 文献移植 | 任何参考论文的刺激、计时、设备、参与者参数不得移植到本数据集（无一篇文献能证明文件级对应） |
| 单位混淆 | MFF storage epoch、平均类别、厂商平均、采集计数是不同单位；RAW 与 MFF 样本不能相加 |
| 行键错误（已修） | PTA 旧读取器按非空行顺序编号，57/57 条错位（offset 3）；已禁用，改用 pta_007 |
| 目标函数尺度（已修） | K0：ridge 用 SSE+α‖γ‖²、网络用 MSE+α‖γ‖²，临床块正则强度差 n 倍；K1 修正后 EEG 增量仍跨零 |
| 单折结论 | D2 第 2 轮的"饱和点"在重复划分下不复现；n≈60 时不能以单一划分定论 |
| 目标漂移 | 临床目标改过五次（MUSS → 年龄/时长 → A/V → +CAP/SIR → A_archive），每次都在前一目标失败之后 |
| 天花板与似然 | 有上限、2.5 分粒度的目标一直用连续损失 + 事后截断，从未用删失或有序似然 |
| 差值波特征 | 信度 ≈0（0.06–0.07）却多轮送入临床模型；任何模型都不可能从它得到稳定关系 |
| 蒙太奇 | A1/A2 不可用 → 20 通道平均参考，是最不利于乳突极性反转（MMN 标志）的选择 |
| 已过时 | FN1-A 报告第 4 节（errata）；D1 v1 第 2–3 节被 v2 取代；NEXT 的 N1 增益（−0.025）被 v2.1 新估计器（+0.0003，跨零）取代 |
| 计算 | 全部数值任务经 Slurm；禁用 P100；优先 A100/L40S/H100 |

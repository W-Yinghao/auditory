# v3科研判断

本轮三个独立包均完成且通过各自能力门控，但没有一个主终点达到预设推进条件。执行成功与科学阳性必须分开。现有结果尚不足以支撑以“更好的信息目标”“方差分布增量”或“PCA隐藏有效信号”为核心的JBHI方法优势主张。

| 预设问题 | 实验支持到哪里 | 本轮不能支持什么 |
|---|---|---|
| P0：旧PCA8是否掩盖完整表示的收益 | 完整/截断/余空间/复制控制均已完整执行；主gain−0.001750，CI跨零 | 未建立截断惩罚，也未证明PCA8与FULL等价 |
| N2R：控制历史和二次均值后，袋内方差是否增加信息 | 同一嵌套算法能恢复强合成方差机制；真实主gain−0.000844，CI跨零，400维敏感性更差 | 未建立真实方差增量；不能称所有分布信息为零 |
| R3：MATCH相对SUP是否有跨身份增量 | 固定30个encoder及240个读出头完成；主gain0.034125，CI跨零；SUP/MATCH测试CE明显高于基线 | 未建立目标函数优势、临床生物标志物或皮层来源 |

P0/N2R的置信区间仍容许预设阈值附近的正效应，R3的区间更宽，因此“尚未检出”不等于排除小效应。合成检查分别验证有限机制或训练图，不是现实效应功效保证。强合成方差恢复20/20、null各0/20也不证明普遍假阳性率。

R3的主要现象是：SUP/MATCH接近机会水平的区分能力伴随过度自信，SIM则接近未训练与历史基线。下一份研究设计若继续，应先解释这种跨身份泛化问题，并明确可识别的事件/设备/人群范围；本轮没有自动增加架构、seed、epoch或重新打开临床路线。所有建议都是后续方向，不是已经验证的机制。

这轮范围是文档冻结的P_MATCH：49个安全身份组、698个已知条件匹配袋、5,584个唯一trial。它不是数据集所有CI资料的重新分析，也不是新增独立临床队列。CI覆盖与临床关联仍应按此前分阶段审计的来源、连接与未知状态理解，不能把本轮结果泛化到整个数据集。

主效应表、完整对照、训练曝光、数值修复、失败记录、资源与隐私审计均已保留。本轮应以完整的阴性/未决结果收束，后续问题由新版本协议明确，不从现有敏感性结果中挑选一个“新的主结果”。

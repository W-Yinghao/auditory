# R3结果与解释

R3已完整执行：15个selection encoder、180个内层读出头、15个final encoder及60个外层读出头。三个目标均使用A100、同seed11初始化、共同曝光计划、固定60epochs；外层测试身份不进入训练和正则选择。所有12个最终视图均覆盖完整5折、49个身份组，没有剔除不利fold或失败个体。

主比较为给定Htrial的SUP与MATCH完整64维表示：`CE(SUP)−CE(MATCH)=0.034125 bits/trial`，95%身份bootstrap CI **[−0.031363, 0.098477]**。CI跨零，未建立MATCH相对监督训练的可靠增量，研究状态为`NO_ADDED_VALUE_OVER_SUPERVISION`。点估计超过0.005本身不满足推进条件，不能单看该数值宣布成功。

SUP/MATCH的区分能力接近机会水平，却给出了代价较高的预测置信度，导致CE约2.7，而非机会基线的1 bit。这里CE差不代表计算失败：所有模型/极端logit均保留，损失采用稳定的原生logit交叉熵。结果与过拟合或跨身份泛化失败相容；本轮没有用新实验确定具体原因。SIM较SUP/MATCH的CE好很多，但接近Htrial与随机encoder的基线，这不构成学习优势证据。

post-only的SUP−MATCH为0.034020，CI[−0.031531,0.098276]，同样不确定。pre控制的对应差异为0.002127，CI[0.000371,0.003894]；该差异更小，且pre仅200ms、post400ms、encoder在post训练，不能据此证明皮层来源，也不能用pre的局部结果替换失败的post主比较。

实施中保留了两类技术记录：原生CUDA池化的首次确定性反向错误，随后用相同bin定义的无参数实现从同初始化恢复；以及有限logit经sigmoid舍入为1造成的评分溢出。后者通过6项独立测试后，从既有180个头重算全部内层评分，新增拟合为0。最终60个头使用同一稳定损失计算。原失败/原概率结果、修复来源和hash均保留；没有改encoder目标、训练轮数、正则网格、身份分折或外层主终点。

本轮可支持的结论是：在这个已探索人群、冻结网络与预算下，尚无证据支持匹配对比目标带来可推进的跨身份刺激解码增量。不能外推为所有EEG方法均无效、全部CI数据无信息，或临床量表不可预测；这些都不是本轮检验的问题。

# Phase 1：HA epochs 重建与第一轮测量实验

2026-09-16。已执行来源筛选、完整 BDF 数值检查、epoch 重建、时间块重采样、半份波形比较和预处理敏感性分析。**现有数据可继续研究，但“试次足够”与“临床指标可信”仍有距离：代码 1 的平均波形形状较稳定，代码 2−代码 1 差值明显较弱，耳参考存在重要异常。**

本轮未将数字码解释为标准/偏差音，未命名 P1/MMN 峰，未使用量表分数筛选 EEG、调参或拟合临床模型。记录的设备状态、声学延迟和量表同期性仍按未知处理。方法见 [固定处理方案](PHASE1_MEASUREMENT_PROTOCOL.md)，运行入口与明细见 [产物导航](PHASE1_ARTIFACTS.md)。

## 1. 实际完成的样本与试次

| 项目 | HA | NH | 合计 |
|---|---:|---:|---:|
| BDF 来源记录 | 84 | 9 | 93 |
| 通过事件/信号起始时钟等技术门槛 | 75 | 9 | 84 |
| 重建存储 epochs，尚未应用幅度 QC | 71,752 | 8,689 | 80,441 |
| 主方案保留 epochs | 52,090 | 5,789 | 57,879 |

所有数字中的“记录”均不等于独立儿童或确证临床访视。达到测量门槛的 70 个候选簇中，10 个有多条记录；其中 4 条 HA 记录仍有 DOB 冲突，不能直接计入无歧义儿童级验证集。NH 的 9 组是本轮 BDF 分支支持度，不能与上一轮 11 个 NH epoched SET 文件混为同一计数。

完整读取检查了 93 个信号文件的 **1,625,734,000 个通道采样值**；9 组时钟不一致的记录只做原始信号 QC，未自动移位分段。其余 84 组的目标事件为 82,926 条，2,485 条因记录边缘保护被排除，形成 80,441 个存储 epochs；其中 22,562 个因头皮通道峰峰值超出主阈值被剔除。保留账本逐项对账通过。

每条记录的保留比例以原始目标事件数为分母。记录层中位数为 **76.6%**（四分位 56.8%–89.7%），HA 为 79.3%、NH 为 67.6%；没有将这些描述差异作为组间推断。

## 2. 处理与验证

主方案：1000 Hz 连续数据先做 0.1–30 Hz 零相位 FIR；20 个头皮通道平均参考；−200 至 +500 ms epoch；基线 −200 至 0 ms（不含 0）；随后按事件零点对齐抽取至 250 Hz。任一头皮通道峰峰值超过 150 μV 的 epoch 拒绝。固定敏感性方案为 0.5 Hz 高通、100/200 μV 阈值及 A1/A2 平均参考；没有依据量表或优劣排名修改主方案。

独立读取、合成时间脉冲、零点与边界、基线、参考变换、联合时间块重采样和耳通道饱和保护共 **11 项测试通过**。每条派生包都校验了哈希、保存的 Fz/Cz ROI 与通道数据对应关系、阈值掩码的包含关系，以及事件数与保留数。

三个具有完全一致代码序列的连续 SET 候选与原始事件轴还做了逐事件交叉检查，均表现为固定约 **−1 ms** 偏移，偏移之外残差接近数值精度。它支持时间轴转换一致性，但不确证物理声音起点；本轮继续采用原始 BDF annotation 秒数，不沿用旧 SET 的偏移。

## 3. 波形稳定性：代码 1 与差值差别明显

ROI 固定为 Fz/Cz 平均，波形比较窗为 0–400 ms。下表是 HA 记录中波形相关的中位数；不同半份使用相同记录内互不重叠的试次。

| 波形 | 交替 30 s 时间块 | 前半/后半 |
|---|---:|---:|
| code 1 | 0.911，n=71 | 0.902，n=71 |
| code 2 | 0.719，n=70 | 0.687，n=69 |
| code 2−code 1 | 0.342，n=70 | 0.316，n=69 |

合并 HA/NH 后，差值波形相关中位数为交替时间块 **0.318**（79/80 条可计算），前后半份 **0.309**（78/80 条可计算）。缺失来自半份试次不足，明确保留在统计表中。

这些值描述**波形形状的一致性**，不是跨儿童幅值或潜伏期的心理测量信度。相关系数对幅度缩放不敏感；固定的刺激相关伪迹也能重复。连续滤波和慢变状态意味着相邻时间块不保证统计独立。因此代码 1 的较高相关还不能证明它适合作为临床标志物。

对 80 条满足门槛的记录，50–250 ms 差值均值的时间块 bootstrap 标准误中位数为 **0.794 μV**（四分位 0.613–1.100）；假设试次独立的解析 SME 为 **0.817 μV**（0.603–1.114）。两者均是本次评分和处理条件下的精度估计，不是神经响应存在与否的证明，也不是实际重测误差。

## 4. 参考和阈值敏感性

对相同试次，0.1→0.5 Hz 高通变化时，50–250 ms 差值评分的记录间 Pearson 相关为 0.928，Spearman 为 0.924，中位绝对变化 0.180 μV；仍有个别较大变化，不能据此视作所有预处理等价。

耳参考的问题更突出。84 条记录中有 **5 条**的主方案接受试次出现耳通道饱和，这些记录的耳参考敏感性结果被标为无效；**80 条**至少一个主接受试次的滤波耳通道峰峰值超过 150 μV。即使排除饱和记录，在 76 条有足够支持的匹配记录中，耳参考差值评分相对主方案的中位绝对变化仍为 **1.317 μV**，Pearson 相关约 0.004、Spearman 为 0.531；耳参考评分出现约 −73 至 +358 μV 的极端值。这里既有参考定义的影响，也可能有残余耳通道异常，不能把两个版本当作同等有效的生理测量来比较。

阈值从 150 改为 100/200 μV 时，达到试次数及时间块要求的记录数分别从 80 变为 **68/83**。与主方案共同支持的差值评分中位绝对变化为 0.327/0.249 μV。主方案和门槛均未事后调整。

## 5. 试次数和来源完整性

每码每半取 20/40/80 个试次的曲线分别有 79/70/33 条记录支持，160 个没有记录支持。差值曲线整体弱于单条件波形；各点支持人群不同，所以总体曲线不能单独证明增加试次造成多少改善。逐记录的重复抽样结果保存在表中，不能外推达到某种“临床可靠性”所需试次数。

试次数曲线及支持记录数（服务器产物：`../figures/phase1_measurements_001/trial_count_curves.png`）

93 个完整信号的数值哈希未发现精确重复。由于例图有相似平均形态，另计算了 80 条有支持记录之间的 3,160 对均值相似度，并针对最相似的 10 对及图中所见的一对做试次残差核查。共 11 对，匹配事件序号和代码、去除各记录的条件均值后，最大残差相关约 **0.024**；图中那一对约 0.014，位于试次打乱参照范围内。未发现这 11 对存在高度重合的逐试次残差；这不是对所有近重复、时间重排或缩放副本的穷尽证明。

完整 84 条记录的波形与参数敏感性存于 `record_waveforms.pdf`；报告例图按每组保留比例的最低、中间、最高位置确定性选取，包括未达到测量门槛的记录，没有按波形美观挑图。

## 6. 对下一阶段的决定

**优先完善单条件事件相关响应的测量验证，差值暂保留为次要技术终点。** 这一优先级来自不使用量表的稳定性结果，不是通过筛选 EEG—量表关系得到。下一阶段需要解决固定窗幅值是否能稳定区分个体、哪些信号成分由眨眼/参考/设备等因素主导，以及更明确的伪迹规则能否改善精度且不引入选择偏差。

保留本轮 v1 结果；任何新的伪迹或测量算法使用新配置、新结果目录，并与 v1 在明确共同支持的记录/试次上比较。不能因提高波形相关就宣称方法更好，也不能通过剔除不利儿童提高临床模型成绩。

临床增量分析仍需一个定义明确的终点和可辩护的身份/时间对应关系。当前可以继续技术测量研究与内部证据核查，尚不宜把这 70 个姓名候选簇直接作为“70 名儿童的同期临床预测队列”。本阶段没有启动 GPU 或临床模型。

## 7. 计算与复现

所有信号计算、统计、绘图、测试均经 Slurm。全量重建采用 8 个分片、最多同时 4 个任务，每任务申请 2 CPU/6 GB；主要测量任务运行约 52 s，最终逐 epoch 对账约 3 s。Slurm accounting 仍不可用，未声称获得 MaxRSS 或完整计费资源。原始数据和旧重启包未修改。

# 独立能力评估锁（评估输出之前）

独立评估沿用baseline_preserving_pca8_offset_v0单一学习器，不改lambda、步数、候选、校准或PCA规则；输入适配为25列H与64/64或400/200的P/B。25列合成H包含原7维强非线性历史信号及18维独立AR噪声干扰；这匹配宽度/训练难度，不声称复现全部真实历史变量的联合分布。样本数按零拟合预检的真实每组、每角色计数生成独立假身份，预先轮转5个外折支持profile。各role索引与fit/transform/calibration/selection路径和真实接口相同。

每个rate×world×mode单元20个独立seed，rate为0.15/0.20，seed为220000+rate_index*1000+replicate_index（0..19）。预检缺5折来源或支持的路线记录未评价并阻断真实分支，不更换人群/内折获取通过。21101/21102仅为开发，不计入正式分母。

N1门控世界：试次钥匙、身份稳定钥匙、真实加性去干扰、独立背景、history-only。N3门控世界：强随机历史且P无用、强历史加已知剩余P信息、H副本、近确定H上限。另固定弱试次钥匙系数0.5（强1.5）和弱N3增量0.3（强0.9）为描述性功效探针，不以弱世界失败去调参或将强世界通过解释成微弱真实效应可检出。

每个强正世界：主增益至少0.01 bits/trial、固定预测bootstrap区间下限>0；N1两个方向必须共用同一联合预测且同时满足。相对噪声与复制输入控制的风险优势也须至少0.005且区间下限>0。每20个世界至少16个恢复，所有20个必须可评价。基础风险还须比对应固定类别先验熵低至少0.02 bits，避免仅在无预测力的H基线上检验增量。

每个零信息世界：报告任何CI下限>0的未阈值误报率；另以增益>0.005且CI下限>0定义有最小量级的误报，20个中不得超过2个。0.005是有限样本算法筛查的风险差容差，不是临床门槛，更不把更小增益视作已证明为零。至少18/20的最大风险退化不超过0.005 bits，平均不超过0.002。N1 history-only同时检查两基础方向，independent-background只对HP→HPB作零信息约束；HB→HPB有真实P信息，不误标为零。N3近确定H另外要求基础风险≤0.05。

每个单元的恢复率/误报率保留实际分母、失败数、Clopper–Pearson 95%区间；不能将“做完20次”叫作通过。每条packet×mode只有全部必要单元通过才签发PASS，不以跨机制平均掩盖失败。复制H的小正风险增益属于逼近误差诊断，不能据此命名为条件互信息。

固定矩阵：N1每世界9头、3温度、7变换；N3每世界4头、1温度、7变换。四lane最大880世界、5920头、1840温度、6160变换。每次尝试在执行前记账，失败计入预算/分母，无自动重试或延长候选。输入、配置、估计器和生成器源码hash写入回执。能力PASS仅适用于本锁的训练算法、P_nat、输入宽度/支持范围及控制，不能背书旧MLP矩阵或任意新表征。

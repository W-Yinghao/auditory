# v2.1 增量估计器开发契约（合成开发阶段）

本稿在合成开发输出之前定义首个低复杂度候选；还不是独立能力评估锁。正式能力评估需冻结单独配置、门槛、未查看seeds及源码哈希。真实任务目前关闭。

## 训练角色与基础预测保留

每个外折采用五个互斥身份集合：A基础模型训练、B基础温度校准、C残差训练、D候选选择、E外部测试。表示采用固定旧D_inner0编码器。将其已声明验证身份池按hash排序分为B/C/D：B占floor(25%)且至少3组，剩余池均分C/D（余数给D）；A为其余合格outer-train，E为旧outer-test。要求A至少12组、B/E至少3组、C/D至少4组。编码器的实际训练身份必须与B/C/D/E均无交集。仅用D_inner0是预先缩小的算法训练设计，不择优内折，不称完整嵌套OOF。

基础模型及其全部输入缩放/PCA只拟合A，温度仅拟合B；B/C/D连同E均被旧编码器排除，C的offset来自没有使用C身份训练或校准的基础过程，D不参与上述拟合。测试E不参与任何转换、校准或选型。校准/残差/选型只有较少身份组，是新算法的明确代价；不称为原48组基线的等价修复。合成与真实使用同一角色分配和学习路径。编码器训练、验证、归一化来源和原搜索范围需由旧回执逐项核对，缺少证据则阻断真实分支。

H映射为训练标准化后的H、H各维平方、前8维两两乘积。P/B采用A上拟合的候选等权缩放及最多8个PCA坐标；在同一表示坐标内完成，不跨编码器拼接。权重为P_nat：每身份总权重相等、身份内试次等权。P_bal不在首个主实验内，不能宣称已验证。

N3基础预测q_H经B校准，增量使用ell_H + alpha*r(P,H)，固定r输入包含P坐标及前4个H坐标×P坐标。同一基础预测用于独立噪声及复制H对照；每个对照的维数、残差容量和选择预算一致。精确基线alpha=0保留原logit，不重新缩放整个增强logit。alpha仅从[0,0.5,1]在D选择，平局优先0。

N1先建立q_HP、q_HB。联合候选包括二者原样预测及分别为offset的同容量r(P,B)修正，r输入为P、B及所有坐标乘积。D选择唯一q_HPB，两个方向的增益共用它。噪声/复制P控制用对应Bnoise/P替代B，分别保持相同两个基础候选、残差容量及选择预算；精确重复拟合可复用但必须注明，而不计为新拟合。

固定残差输入的缩放只能用C的无标签特征；base输入变换只用A，维数不能通过测试结果更改。基础和残差均为加权平均BCE加明确lambda/2权重平方和（不罚截距）。首个开发值lambda=0.01，SciPy L-BFGS-B最多200步，float64。输出有限且目标不劣于初始化方可记录FINITE_BUDGET_ESTIMATOR；保存优化状态、梯度、目标变化、迭代数，不将有限预算终点称为已证明全局最优。非有限、身份范围错误、错误权重仍硬失败。

D的选择目标固定为不含惩罚项的P_nat加权交叉熵（bits/trial），身份等权且身份内试次等权。N3每个增强/控制3个候选；N1每个联合/控制6个候选，两基础模型各有独立B温度，重复P基础精确复用q_HP。分数在1e−8 bits内平局时先选未修改基础，然后固定候选顺序。主对比任一必要候选非有限时整对比失败，不跳过候选。N1选中的唯一anchor及其E预测同时用于两个方向；不保证测试上同时优于两个基础模型。

A/B/C/D各集合整体须有两类；缺失时记录对应角色支持不足，不更换身份分割。温度优化未正常结束或非有限为硬失败，不静默标校准完成。角色索引必须覆盖全部预定合格行且身份互斥。真实入口额外核验旧encoder的全部B/C/D/E排除证据、控制生成来源与冻结能力hash；仅有函数参数或口头声明不算通过。

## 能力评估前的必要检查

必须逐试次检验零残差与校准后基础logit完全一致；验证测试值/标签扰动不能改变任何已拟合对象或候选选择；验证A/B/C/D身份与编码器范围隔离。N1两个方向必须共享最终预测，噪声/复制控制不可偷换基础模型或额外搜索容量。

合成开发需覆盖强非线性H的零/正剩余信息、近确定H上限、试次级与身份级可跨身份泛化的背景钥匙、加性去干扰与独立背景，维数64/400，接近真实107–976试次/身份、约60身份与类别比例0.15/0.20。理论oracle与有限测试风险分别记录。正信息生成器不能只在H无预测力时验证增量。

正式评估前再锁定有限小矩阵、开发/评估独立seed、逐cell最低恢复要求、零信息假阳性与风险退化门槛；开发结果不进入通过率。所有能力世界必须走与真实相同的fit/transform/calibration/fallback/aggregate程序。

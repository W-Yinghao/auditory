# K0：目标函数尺度勘误

**依据：** `AUDITORY_NEXT_ROUTE_REVIEW_5b5b662.md` §4，核查版本 `5b5b662c4d7a2f7dc9dc5499ad0ad6f0add012c0`
**运行：** `K0_parity_002`（Slurm 999958）。零 EEG、零模型搜索、零新数据、零神经拟合。
**结论：** `OBJECTIVE_SCALE_DEFECT_CONFIRMED`

## 1. 缺陷

`auditory_fn1/models.py::ridge_solution` 求解的是**误差平方和**形式：

$$\sum_{i=1}^{n}(y_i-b-C_i\gamma)^2+\alpha\lVert\gamma\rVert^2$$

而 `auditory_fn1/models.py::train_set_network` 的目标是**记录平均**形式：

$$\frac1n\sum_{i=1}^{n}\bigl(y_i'-b-C_i\gamma-f_\theta(U_i)\bigr)^2+\alpha\lVert\gamma\rVert^2+\frac{\lambda}{2}\sum_{W\in\theta}\lVert W\rVert_F^2$$

`auditory_fn1a/fitting.py::_train_network` 把 M1 内层选出的 `clinical_spec["penalty"]` 直接传给后者。两者只共享数值，不共享有效正则化强度。

把岭回归目标整体除以 $n$，等价形式是 $\mathrm{MSE}+\frac{\alpha}{n}\lVert\gamma\rVert^2$。因此 **M3/M4 临床块的有效惩罚是 M0/M1/M2 的 $n$ 倍**，$n$ 是该次实际拟合的身份数——不是 52×32 个窗口，也不是全队列人数。

目标从 0–100 缩放到 0–1 **不**抵消这个因子：系数与截距同步缩放后，从 SSE 到 MSE 仍需除以 $n$。

## 2. 数值核验（144 个合成算例，FP64，容差 1e-10）

合成设计矩阵不含任何个人数据；覆盖原惩罚列表 {0.01, 0.1, 1.0}、实际拟合规模 {27, 28, 41, 42}、有/无常数列、有/无缺失指示列，以及三种目标单位（中心化单位、原表 0–100、缩放 0–1）。

| 命题 | 结果 | 最大偏差 |
|---|---|---|
| `ridge_solution` 即 SSE+α 形式 | 成立（144/144） | — |
| SSE+α ≡ MSE+α/n | **成立**（144/144） | 1.07e-14 |
| MSE+α ≡ SSE+(n·α) | **成立**（144/144） | 7.11e-15 |
| SSE+α ≡ MSE+α | **不成立**（144/144 全部不等） | 最小偏差 5.51e-04 |

过度惩罚下临床系数范数的收缩比范围为 **0.166 – 0.990**：最差情形下系数被压到正确量级的 17%。

## 3. 各拟合范围的实际 α 与 α/n

`fit_scope_penalties.csv` 逐行给出（身份键不公开）。规模分布：内层训练 n=27（8 次）与 n=28（22 次），外层训练 n=41（4 次）与 n=42（6 次）。两个目标的 M1 内层选择均落在 `additive_quadratic` 基上。

例：`A_archive` 外折 0，M1 选出 α=1.0，n=41 → 正确的 α/n = 0.0244，而网络实际施加的相当于 α=41。

## 4. 这一缺陷单独能造成多大变化

只用临床＋技术输入（**完全不含 EEG**），在**已冻结的外折与已选定的 M1 规格**下，把 α 换成 n·α 的固定 OOF 误差变化：

| 目标 | MAE（α，正确） | MAE（n·α，等效于网络所受） | 变化 |
|---|---:|---:|---:|
| `A_archive` | 6.6550 | **9.0824** | **+2.4274** |
| `V_archive_given_A` | 5.6379 | **6.3406** | **+0.7028** |

与已发布的 M1→M4 退化对照：A 为 +3.588，V 为 +2.933。**即临床块过度收缩这一项本身，在量级上就占到 A 退化的约三分之二、V 退化的约四分之一。**

**必须限定的话：** 这是纯岭回归下临床块单独的表现，网络还叠加了 400 步 Adam 优化预算与 EEG 分支。上表说明该缺陷**能造成多大量级**的变化，**不是**对 M3/M4 全部退化的因果分解。不能据此宣称修正后就会出现 EEG 增量。

## 5. 对已发布结果的影响

`docs/auditory_fn1a/ARCHIVAL_RECORD_LEARNING_REPORT.md` 中：

- **失效的解释**：该报告把 M3/M4 与 M0/M1 的差距归因于"400 步 Adam 联合拟合 vs 闭式解"的优化预算差别。这个说法**不完整**：两者的临床块连**目标函数**都不是同一个，差别不止于优化预算。原文"这个比较混淆了优化预算与信息含量"应修正为"这个比较同时混淆了**正则化尺度**与优化预算，而前者是可直接验证的规格缺陷"。
- **仍然成立**：M3 与 M4 的比较不受影响——两者受同一约束、同一架构、同一初始化、同一预算，所以"固定配方下未建立学习顺序优势"的结论保持。
- **仍然成立**：M2 在全部外折选择 EEG-off。M2 走的是 `ridge_solution`，不经过网络目标，因此不受本缺陷影响。
- **仍然成立**：全部绝对误差数值本身、导出与 QC 计数、身份隔离与折结构。

## 6. 原目标与修正目标的关系

设 $C$ 为该训练范围内拟合的临床＋技术基，$n$ 为该次拟合的身份数：

| | 临床块目标 | 与岭回归的关系 |
|---|---|---|
| 原实现 | $\mathrm{MSE}+\alpha\lVert\gamma\rVert^2$ | 等价于 $\mathrm{SSE}+n\alpha\lVert\gamma\rVert^2$ |
| 修正 | $\mathrm{MSE}+\frac{\alpha}{n}\lVert\gamma\rVert^2$ | 等价于 $\mathrm{SSE}+\alpha\lVert\gamma\rVert^2$，与 M0/M1/M2 一致 |

## 7. K0 不声称什么

K0 只确定一个尺度恒等式。它**不**说明修正后的 EEG 模型会有效，**不**量化真实性能损失的来源构成，**不**构成方法论贡献。原全部结果、失败记录与阴性结论保持原样，不回写、不覆盖。

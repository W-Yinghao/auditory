# 儿童听觉 EEG 项目：第一轮数据审计

日期：2026-09-16。目标期刊：IEEE JBHI 同级。结论：现有数据具备继续研究的基础，但当前应先建立可信的采集、事件和临床对应关系，再开展测量可靠性与临床增量价值分析。文件量和 epoch 数远大于独立儿童数，直接把所有预处理文件合并训练会有明显风险。

本轮使用数据目录中已有资料；未要求补充外部材料。无法由现有证据确定的字段保留为未知。未进行 EEG—量表相关性筛选、分类器比较或 GPU 训练。所有数据读取、统计、测试和绘图通过 Slurm CPU 任务执行，原始数据未修改。

## 1. 工作目录与数据组成

开始时的工作目录是项目重启包及其 ZIP，包含研究计划、历史复核、空表模板、文件清单脚本和测试，并非一套已完成的 EEG 分析工程。重启包校验通过；旧临床结论仅作为核对基准。本轮新增了审计脚本、Slurm 入口、结构化明细、图和分析方案。

指定数据目录共 **23,166 个常规文件，273,810,545,436 bytes（约 255 GiB）**，首次遍历无跳过、无目录读取错误。按实际格式识别如下。

| 数据类型 | 发现与解释 |
|---|---|
| BDF | 93 个信号文件 + 93 个事件伴随文件，组成 93 组候选采集导出 |
| SET/FDT | 27 组；16 个连续预处理 SET，11 个已有 epoch 的 SET |
| MFF | 1,161 个目录名；1,160 个有直接归属文件的容器，另一个是包含两个子目录的包装目录，并非空采集 |
| EGI `.raw` | 161 个实际文件：159 个连续、2 个分段；扩展名清单中的额外 4 个是 AppleDouble 旁文件 |
| MAT | 8 个 TF 数值数组；缺少可验证的轴、受试者、条件和来源字典，暂不能当作 trial 数据 |
| 临床/说明 | 4 个工作簿，2 个 DOCX，184 个 JSON；另有大量 MFF XML、处理日志和文本 |
| 参考/其他 | 10 个 PDF、1 个 7z、81 个 PNG、2 个 AVI；7z 已列目录，未把归档成员另计为独立采集 |

原始数据位于接近容量上限的数据盘；审计产物放在工作目录，没有复制整套 EEG。实际使用 Python 3.13.7、MNE 1.11.0、NumPy 2.4.4、SciPy 1.17.0、pandas 2.3.3、openpyxl 3.1.5、pyedflib 0.1.42。初始旧 EEG 环境不适用，已改用现有 `eeg2025` 环境，未改动共享环境。

依据：`results/inventory_001/`、`discovery_001/`、`supporting_001/`、`assets_001/`、`overview_001/`。

## 2. MFF 中到底是什么

| 实际存储层次 | 导出容器数 | storage epoch 条目数 |
|---|---:|---:|
| 连续或不连续记录 | 397 | 881 |
| 分段数据 | 248 | 192,816 |
| 平均波形/其后续处理版本 | 515 | 1,163 |
| 合计 | 1,160 | 194,860 |

这些数字包含多个处理版本。连续记录的 storage epoch 可能只是中断后的存储区段；平均波形文件中的 epoch 可能是条件平均或差值，不能解释为独立试次。逐条 ledger 保留容器、存储序号、时间单位、起止时间、binary block 索引、类别、事件偏移和历史状态。

193,979 条 category-segment 元数据中，历史标记为 bad 99,865、good 91,951、unedited 2,029、unknown 134。**这不是重新估计的坏试次率**，也不能跨处理版本相加作为有效试次数。已经抽取处理来源图：3,843 条候选历史来源边，形成 317 个候选处理连通分量；分量仍不是确证的采集或儿童数量。

495 个版本的历史记录含 **40 ms segmentation offset**。历史分段规则可以支持特定文件中类别与事件码的对应，例如 Standard/`stad`；它不能自动证明所有范式的物理刺激语义或声学零时刻一致。

独立拓扑核验尝试了全部 1,160 个容器：1,155 个完成结构读取，5 个因时间格式、缺少 EEG binary 或空 binary 未通过；在可读容器中，7 个存在 epoch 时序、block 范围或样本长度不一致。此处“可读”不等于“拓扑有效”，这些问题版本须隔离。验证使用 `infoN.xml` 声明的 EEG 流，而非仅依赖文件排序。

初次事件读取在 70 个容器遇到异常，随后针对性恢复：发现 67 个空事件 XML，非空事件轨道均可继续解析；二进制缺失/拓扑问题另行核验。恢复后的规范事件计数为 **1,858,215**，包括启动、刺激、响应/状态等事件以及不同处理版本的重复表示，不能全当作声音呈现次数。

依据：`mff_001/epoch_ledger.csv`、`category_segment_ledger.csv`、`mff_recovery_001/`。规范事件明细见 `finalization_001/mff_event_ledger.csv`，问题容器见 `finalization_001/mff_quarantine.csv`。恢复明细不得直接与旧失败容器的部分事件行拼接，否则会重复计数。

## 3. 已有 SET epoch 与信号质量

11 个 epoched SET 共 **10,965 个 epoch**。每一个 epoch 都已检查元数据与信号：

这 11 个 epoched SET **全部位于 NH 分支**。其他 16 个连续预处理 SET 为 NH 9 个、HA 7 个（目录标签线索）。现成 epoch 不能直接当作 HA 临床训练样本。27 个 SET 中 23 个找到唯一原始采集候选，12 个刺激码序列完全一致，22 个与原始序列的子序列关系相容；这支持候选来源关系，不解决声学语义或时钟偏移。

- 全部有唯一的零时刻事件码，代码保持原始 1/2，声学含义未擅自赋值。
- `EEG.event` 的 1-based、跨 epoch sample latency 与 `EEG.epoch.eventlatency` 的毫秒值逐条换算一致。
- 全部 epoch 未见 NaN/Inf、完全平直通道或字节相同的重复信号。
- 原始 `urevent` 追踪信息缺失，不能因此恢复所有原始采集上下文。
- 对一个连续 SET 和一个分段 SET，用独立 MNE 读取交叉核对，信号单位转换后的最大差值为 0，采样率一致。

27 个 SET 中 26 个完成全部存储采样点的基础数值检查；另一个 SET 内部引用的 FDT 名称不存在，同目录有一个大小匹配的候选 FDT，未静默改绑。采集 BDF 为 22 信号通道，而 SET 为 26 个 20 通道、1 个 18 通道，说明不能直接复用旧“32→22”表述代表全部版本。

另外按信号长度选择了 3 个 BDF 的前 30 s，以及 13 个 MFF 布局/目录条件分层样本的首个存储块，生成波形和 PSD。已有 epoch 的按码均值只作为对齐预览，没有据此识别 P1/MMN 或选择最有利窗口。MFF 预览使用原生浮点单位，物理校准尚未全面确认。

**数值检查通过 ≠ 儿童响应可靠或可用于某项临床问题。** 未完成所有原始信号的伪迹检查、CI 伪迹排除、通道级判定、个体测量误差和可靠性估计。示例图中的“无额外滤波”不表示源数据从未滤波。

依据：`other_eeg_001/`、`signal_001/`、`extra_002/`、`figures/signal_001/`、`figures/mff_002/`、`figures/overview_001/`。

## 4. BDF 事件、采集元数据与处理差异

93 组 BDF 共读到 92,202 条 annotation。93 组事件均落在对应信号时长范围内，但 **9 组事件文件与信号文件的 header 起始时间不同**：6 组 −1 s、2 组 +1 s、1 组 +2 s；其余 84 组相同。不能仅因同目录或事件数相近就忽略这些差异，也不能通过“哪种移位 ERP 最漂亮”决定校正量。音频到 trigger 的实际延迟仍未知。

161 个 EGI `.raw` 的事件通道也已全部扫描，保留 204,255 个非零事件采样点，不能未经脉冲去重便称为 204,255 次刺激；无读取错误。两个分段文件共 6 个 segment，各 600 samples、1000 Hz，保存三个类别的导出；是否为条件平均需结合来源进一步确认，未当作新增 trial。header 实现对照了 EEGLAB 官方 `readegihdr/readegi`，并通过连续/分段合成样例测试。

93 个 `recordInformation.json` 包含患者/检查标识、DOB、检查和录制时间、设备与采集设置；其录制日期均与对应 BDF 日期相符。它们比文件修改时间更有价值。不过，**91 个 PatientGUID 只对应 78 个姓名候选簇**，11 个姓名候选簇有多个 GUID，2 个存在不同 DOB 字符串。直接按 GUID 划分训练测试可能把同一儿童分到两侧。

184 个 JSON 已解析，其中 91 个 ERP 导出包含 182 个 condition average。部分导出字段将 SampleRate、StartPoint、EndPoint 置零，不能据此认定真实采样率或时间原点。OverlapSettings 显示高通 0.5/2/3 Hz、低通 35/45 Hz以及耳参考、无参考/全平均等不同设置；设置为空的文件单列。它们是软件导出设置证据，尚非完整预处理溯源。

现有说明文档声称 HA 范式采用 800/1200 Hz、200 ms、80/20、500–700 ms 间隔，但未找到足以确证数字事件码 1/2 与频率对应的材料。“间隔”也不能未经核验便当成 SOA。

## 5. 临床表及候选匹配

目前应使用 **clinical_003**，前两版仅保留为审计过程记录。读取原始 Excel 合并单元格范围后，主表复核为 **95 条临床记录，HA 84、NH 11**；按连续 HA 时长取 0–60 月为 67 条。不能把多个重复/扩展 sheet 直接拼接增加样本。

以姓名开头连续汉字建立 80 个候选簇，复现历史 80 的数量，但这是候选身份规则而非独立儿童的最终确证。原始名字串含日期样后缀 87 条、设备样后缀 81 条；这些保留为标签线索，不自动等于同期量表日期或采集时设备开关状态。4 条记录的历史分组与连续使用时长不一致。

主表年龄 6–192 月，HA 使用时长 0–123 月；MUSS=87 的特殊值确实存在一条，每日佩戴字段仅 16 条非空且单位不明。SIR 为 1–5，CAP 观测范围为 2–9，IT-MAIS/MAIS 与 MUSS 的百分比有大量最大值；CAP 的版本与理论上限、IT-MAIS 与 MAIS 的逐记录版本仍未确认。

NH 的设备使用时长字段为非适用/非数值，不应填成 0 月并与 HA 初始使用组混合。年龄—使用时长图只绘制 HA 记录。8 个 MAT 数组也做了数值检查，其中 1 个有非有限值；第一维与 20/129/130 通道的两两组合数相符只是数学线索，不能据此确证 connectivity 方法或各轴含义。

93 组 BDF 对应 78 个姓名候选簇。候选临床链接共有 95 行，其中 81 行有姓名及标签日期证据、14 行仅姓名证据；91 组采集各有一个候选临床行，2 组存在歧义。**当前确证的同期 EEG—量表匹配为 0**：这是证据等级的限定，不是说临床资料不存在。

扩展版工作簿有 CI 相关量表、听力学、发育和评估日期字段，推翻了“该分支没有量表”的旧工作假设。现有 schema 审计中 CAP/SIR 覆盖 43 个名字串候选簇，IT-MAIS/MAIS/MUSS 覆盖 44 个；这些尚未经过统一别名和采集身份复核，不能当作新增独立儿童数。

依据：`clinical_003/`、`linkage_001/`、`manifests/`；身份、原始日期和完整路径留在 `private/`。

## 7. 对项目方向的建议

最可靠的起点是 **header/伴随关系可核验的 BDF 采集与事件来源，以及已通过逐 epoch 技术核对的 SET 子集**。仍没有一个可直接宣称“身份、条件、时间和同期量表全部确认”的临床分析队列，因此本轮不启动临床预测。

优先问题：**在可追踪且采集条件可比较的记录中，听觉 EEG 能否形成可重复的个体测量，并为同期听言功能提供临床变量之外的信息？** 第一项实际实验应是测量可靠性。若同期或条件始终无法由现有数据确证，就将问题限定为测量研究或明确条件下的描述性关联，不把未知条件填成默认值。

建议按以下顺序推进：

1. 依据内部元数据与处理历史选择来源和版本，隔离时间、身份冲突，完成可重复的纳入规则。
2. outcome-blinded 地冻结滤波、参考、伪迹处理、epoch/baseline 和少量 EEG 指标，估计单记录可靠性、试次数效应和缺失。
3. 在证据支持的子集中，明确一个主终点及临床基线；先评估简单模型的增量价值，再判断是否需要深度表征。
4. 所有泛化实验按儿童隔离，所有重复记录、范式、版本和 epoch 同组；训练内完成标准化、特征选择和调参。报告儿童级不确定性。

现阶段不能支持因果康复效应、未经时间确认的纵向轨迹、由差值波形直接推出 MMN 机制、基于小 NH 样本建立正常标准、或按 epoch 随机划分得到的跨儿童泛化结论。

完整方案见 [ANALYSIS_PROTOCOL_DRAFT.md](ANALYSIS_PROTOCOL_DRAFT.md)，问题明细见 questions_to_resolve.csv（服务器产物：`../manifests/questions_to_resolve.csv`）。本项目对临床问题和可靠测量的侧重是研究设计判断；[IEEE JBHI 的官方范围说明](https://www.embs.org/jbhi/articles/jbhi/)强调信息技术与健康、生物医学的交叉，并不保证本数据能达到发表要求。

# 新队列／新划分完整重训后的判断

本轮已补齐此前缺失的 HA D 完整编码器重训：52个临床候选身份、5外折各3内折、
40个新编码器和5个固定表征任务，以及三种表征的全部主要模型与预定对照。
最终Slurm999581核验通过。数值和图表见
`reports/auditory_retrain_v1/verification_001/REPORT.md`；这里仅解释已核验的结果，
未重新拟合或选择新的模型。

主要自监督设定中，null特征在临床变量与刺激可见方向之外的增益为+0.020分，
95%条件bootstrap区间为[−0.274,+0.295]。全试次、试次数／QC、全试次加QC
三个敏感性的相应点估计为+0.109、+0.060、+0.087分，方向一致，但区间都跨零。
这些低幅度线索应保留。主要分析相对纯临床模型仍差0.094分，
去掉单个候选身份时主要null增益也可能改变符号，现有结果尚不支持稳定的额外临床获益。
这不是用0.5分或显著性门槛判定“没有价值”。

监督表征的刺激可见方向仍有小的正向线索：C→CV改善+0.227分，区间[−0.105,+0.595]，
去一人点估计范围约[+0.125,+0.284]。L0的可见方向也有+0.135分点估计。
但是监督表征再加入预定PCA null特征使误差增加约0.338分；不能把可见方向的改善归因于null方向。
不同表征及完整、刺激前特征的结果均已保留。

质量控制后的正向增益需要连同基线绝对误差阅读。例如监督表征在budget40+QC下，
CVN相对C+QC改善约0.466分，但C+QC的MAE为7.209，CVN+QC为6.743，
仍高于未加这两个QC变量的纯临床模型6.607。该结果不能直接写作最佳临床预测能力提高0.466分。
这些控制反映对调整方案的敏感性，也没有涵盖所有可能混杂因素。

随机方向图中的每个点对应C+V+随机null子空间，相对C计算改善；黑线对应C+V+预定PCA null。
因此随机方向模型相对C的改善也包含V的贡献，不能全部归因于随机null。
监督模式下随机方向模型均优于预定PCA null模型，未给出该null提取方式的特异性优势。
新的null刺激探针接近机会水平，只是当前线性探针与样本下的阴性解码结果，不能证明刺激信息完全独立。

监督训练在训练身份内部的刺激损失监测最终选择了1–2个epoch；SIM固定训练100个epoch。
本轮保留原优化规则以便对照数据／划分修正，临床结果没有参与提前停止。
不能据此将结论推广到所有监督优化方案、所有编码器或所有种子。
所有区间均以保存的外层预测为条件，没有覆盖重新划分及编码器重训的不确定性。

49个共同身份上的新旧比较进一步表明，缓存回放与完整重训不能互相替代；
其差异同时包含训练队列、划分、临床缺失值策略和重新拟合的影响。
本轮按有限计划全部完成。独立临床队列验证和真实功能随访仍是不同任务，
不能由这次内部重训宣布完成。

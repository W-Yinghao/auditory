## 结论摘要

发育信息随电极数上升，96 导前未饱和（年龄 MAE 17.68→12.50 月，猜均值 19.07）；
记录时长在**两分钟**饱和（128 导 12.22±0.05 对全长 12.50±0.27）；
**16 个嵌套选出的电极（12.49±0.81）与全部 128 导（12.50±0.27）不可区分**，
而 16 个空间展开的电极为 15.69±1.00。跨放大器迁移在年龄重叠区间内代价很小。

三条阴性：持续 EEG 在年龄之上对装置使用时长、PTA 与四个量表**无增量**；
未校正的脑龄差会给出 r=−0.509 的假阳性，年龄偏差校正后全部区间跨零；
记录内相对位置自监督在结构上抵消被试级子空间，因此不可能迁移到年龄。

**一次自我更正**：`docs/auditory_d2/D2_ROUND4_CORRECTION.md` 记录了第 2 轮"非线性读出
在 16 电极饱和"这一结论被重复交叉验证推翻的过程。所有曲线主张现在一律附跨折种子离散度。

## 提交前对抗性复核的发现（内部范围内接受）

提交前对暂存树做了四个视角的对抗性复核（再识别、代码泄露、主张与数字是否相符、完整性），
并对每条发现另派独立 agent 尝试证伪。其中一条经我本人独立复算确认：

**聚合量之间存在精确的年龄重建通道。** 时长臂的四个结果文件（1/2/4/8 分钟）同时给出
`age_months` 的均值、样本标准差（ddof=1）与 n，而这四个臂的记录集**严格嵌套**——缩短时长
只会移除记录（`spectral.record_feature_matrix` 的 `minutes` 过滤对时长单调，配合
`min_windows` 闸门）。年龄是个体的固定属性、在各臂之间不变，因此对相邻两臂的和与平方和作差，
可唯一解出那一名差异儿童的年龄。三次实测的解均落在**整数天**上（残差约 1e-11 天），和/平方和一致性相对误差约 2e-15；
解出的具体数值不在此记录。同理，临床支线 n=57 的队列摘要与 n=56 的曲线文件之间可再解出一名。
另外各文件的 `min`/`max` 按定义就是两名个体的精确年龄。48 个已发布文件带年龄分布块。

**研究者决定：本仓库为内部仓库，上传内容仅供内部分析，只要不上传数据集即可，
因此本轮不做脱敏，按现状发布。** 原始与导出的 EEG 信号（约 43 GiB）、逐人预测、身份键
与含姓名的路径注册表均未上传。

**若将来对外发布，此通道必须先关闭。** 最小改动是：任何结果文件都不再携带 `age_months`
分布块，队列年龄只在**唯一一个**文件中描述（单一集合无法作差），且该处的 min/max 向外取整。
正则门禁抓不到这类问题——每个单独的数字都是合法聚合量，泄漏住在文件之间的关系里。

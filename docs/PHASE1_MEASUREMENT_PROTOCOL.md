# Phase 1：固定规则的 epoch 重建与测量精度实验

版本 `phase1_v1`，2026-09-16。在查看本轮 EEG 特征与量表关系前固定；属于项目内技术方案，不声称事前注册。参数完整保存在 `configs/phase1_v1.json`，运行时保存配置与代码哈希。临床分数不进入管线。

## 范围与来源

使用 93 组 BDF 原始导出的既有对应关系。全部做完整信号数值检查；只有 header 起始时钟相同、单位/采样率一致、事件有序且无采样点冲突和越界的记录进入 epoch 分析。当前通过 84 组：HA 75、NH 9，均为记录数。9 组秒级时钟差记录隔离，不按波形效果自动平移。姓名候选身份及 DOB 冲突保留；本阶段没有训练/测试划分，也不宣称独立儿童数。

以事件文件 annotation 的相对秒数乘信号采样率，最近整数取样，保持零基 sample 索引。仅将 1/2 作为分析条件；0/4 等保留为未知事件，不自动解释为边界或伪迹。声学延迟未知；结果称为相对记录事件的波形，不能据此标定声学潜伏期或命名 MMN。独立 MNE 与 pyedflib 在三个确定性样本上交叉验证单位和采样点。

## 固定处理

- 原始 1000 Hz 连续数据先滤波，主方案 0.1–30 Hz、零相位 Hamming FIR，`firwin`，低频过渡宽度等于高通频率、高频过渡 7.5 Hz；0.5–30 Hz 为固定敏感性方案。滤波前检查非有限值，记录数字饱和和逐通道统计。不做 ICA、插值或根据量表选择参数。
- 采用 20 个头皮通道等权平均参考；这是本轮的明确参考变换，不声称知道采集时参考。耳通道 A1/A2 保留供固定参考敏感性分析。头皮通道集合不因个体波形而改变。
- epoch 为 −200 至 +500 ms，两端包含；基线 −200 至 0 ms，右端不包含。连续滤波后从事件对齐的样本每隔 4 点取值，得到 250 Hz，保持 time zero；不先重采样连续数据再重新定位事件。
- 排除距离记录两端不足 20 s 的 epoch，并检查实际 FIR 半长度不超过此保护区。若相邻已知目标事件落入 epoch 窗口，则标记重叠并排除；不将非目标码推定为声音。
- 主方案剔除任一头皮通道峰峰值大于 150 μV、滤波但未重参考的头皮通道峰峰值小于 0.5 μV，或原始 epoch 有饱和/非有限值的试次。峰峰值与平直检查使用完整 1000 Hz epoch；降采样仅用于保存和评分。100/200 μV 为阈值敏感性分析。规则是保守技术筛选，不是经过验证的完整儿童伪迹算法；不通过的数据也必须列明。
- 0.5 Hz 高通及有效的耳参考比较使用主方案相同试次，以隔离处理选择的影响。工程烟测发现主方案接受的 epoch 中可能有耳通道饱和；在全量运行前补充固定保护：任一主方案接受试次存在耳通道原始饱和，或任一耳通道在至少 20% 原始 2 s 区段平直，则整条记录的耳参考敏感性结果缺失，标记 `invalid_reference_channels`，不为保留结果而改变匹配试次。头皮平均参考主方案保持原规则。全局漂移/眨眼/设备伪迹可能仍残留，重复的伪迹也能产生高重复性。

## 指标、精度与时间稳定性

ROI 固定为 Fz/Cz 等权平均。两个宽窗：50–250 ms（主要描述窗）、250–400 ms（次要窗）；不搜索个体峰，不命名为特定成分。分别记录 code 1、code 2、code 2−code 1 的均值与不确定性。

至少每码 40 个保留试次，且每码覆盖至少 8 个 30 s 时间块，才报告主要不确定性结果。保留每 epoch 的原始事件序号、样本、代码、时间块、拒绝原因及阈值状态。按 30 s 连续时间块有放回抽样 500 次，联合重采样两个条件，计算均值/差值的块 bootstrap 标准误及百分位区间。另输出假设独立试次的解析 SME（单试次评分 SD/√N）；它仅作参照，不能忽略时间依赖。

比较交替 30 s 时间块形成的两半，以及真实时间前半/后半，给出波形相关、RMSE、窗口均值差。波形相关使用固定 0–400 ms 窗；它是波形形状重复性的描述量，**不是跨儿童临床特征的心理测量信度**，不套用 Spearman–Brown 宣称信度达标。半份比较要求每半每码至少 20 次。

试次数曲线固定取每码每半 20/40/80/160 个试次，在相互分离的交替时间块半份中各自抽样，重复 50 次；条件差值使用等量的两种代码。没有足够试次的点缺失；不外推需要多少试次才能获得临床可靠测量。

30 s 时间块不能保证完全独立：连续滤波会跨越相邻区块边界，慢变状态也可能持续更长。块 bootstrap 和交替半份因此只是本次假设下的精度/稳定性估计；前后半份比较用于补充检查，不能当作独立重测。

## 输出与解释

每条记录保存一个 epoch/元数据派生包、拒绝账本、通道 QC、条件均值、测量精度、时间稳定性和处理敏感性。文件采用既有不透明记录 ID。原始数据不修改，CPU Slurm array 最多同时 4 个任务，每任务 2 CPU/6 GB；无 GPU。先运行有意义的合成测试，检查时间零点、取整、基线、参考不变性和块抽样；再运行确定性小样本作工程检查，参数不因结果调优。

报告先描述记录层结果及候选身份重复情况，不把试次数当儿童数，不使用量表进行筛选。如果出现低保留率或处理不稳定，明确报告并决定是否需要第二版伪迹方案；不悄悄修改 v1。

## 方法依据

连续滤波后再按 epoch 降采样，避免先重采样造成事件抖动，参考 [MNE 1.11 官方教程](https://mne.tools/1.11/auto_tutorials/preprocessing/30_filtering_resampling.html)。个体评分精度与群体信度的区分及解析 SME 参考 [Luck 等，Standardized Measurement Error](https://pmc.ncbi.nlm.nih.gov/articles/PMC8169536/)。本项目的窗、阈值、时间块和可用性标准是本轮明确设定的技术选择，不是这些来源验证过的本队列最优值。

# F1/F2 最小实验设计：资格通过后才激活

这是新方案阶段一的设计交付，不是已经训练的实验，也不是冻结完成的临床协议。量表版本/评分与 EEG—评估时间关系必须先由支持表解决。不能为了继续运行，将档案数值可读、候选日期后缀或原有 53 人模型替代这个门槛。原文指定的临床问题与旧 MUSS 阴性保持不变。

## 分析对象与终点

F1 主终点优先是有版本与适用范围证据的 IT-MAIS 或 MAIS 单一量表；不能把混合标题当作合并授权。原 HA 说明文档确实给出 IT-MAIS、CAP-II、MUSS 和 SIR 的评分说明，但需另列其对具体临床行的归属证据。CAP-II 仅在归属成立时作为预先定义的独立有序补充，不在主结果失败后替换终点。

F2 的言语使用目标优先 MUSS；SIR 属言语可懂度，独立解释，不与 MUSS 平均。共标签子集和各目标可用集合分别列出。画像任务不把真实待预测量表作为测试输入；条件言语任务明确使用真实听觉分数，并与临床＋听觉分数基线比较。

主单位是访问，身份组为外层隔离及不确定性重采样单位。重复访问随身份入同折。是否取单一访问、时间容差、版本归属、上下限及最低支持须随最终合格集合一并冻结。不得用目标大小、EEG质量表现或预测结果选择访问、补日期、换量表或删天花板分数。

## 输入与有限模型比较

先选一个可追溯的记录级固定表征入口。优先评估已登记连续记录是否支持足够长的有效片段及一致通道；已有 0.7 s 的 baseline-corrected epochs 不能直接冒充长时连续/静息记录，也不能靠它们估计未经支持的低频结构。片段长度、频段、参考、坏段规则和一个稳健聚合方式，应在查看新的临床关联前按来源冻结。暂不抽取所有人的新特征，以免先花算力再决定目标。

在相同合格人群及外层划分比较以下有限模型。临床协变量至少包括可解释年龄、设备经验和有单位/时间依据的听力阈值；助听阈值可用时纳入，缺失及其人群变化明示。

| 模型 | 用途 |
|---|---|
| 训练均值/适当的有序基线 | 描述目标难度 |
| 临床变量线性正则模型 | 简单基线 |
| 临床变量有限非线性模型 | 检验简单基线欠拟合的替代解释 |
| 固定 EEG 单独模型 | 记录级可预测性 |
| 临床＋固定 EEG | F1 主要临床增量比较 |
| 临床＋来源/有效片段量/质量摘要 | 排除仅由可用性与来源解释的改善 |
| 临床＋上述摘要＋固定 EEG | 在可用性与来源控制下的增量 |

临床模型与 EEG 模型共享外层划分、训练内选择机会和主要损失。标准化、缺失处理、任何低维投影和正则选择只拟合外层训练中的相应内折。质量摘要来自记录，不能用量表挑片段；标签缺失掩码只控制损失，默认不作为输入。所有候选和失败保留，不能只汇总成功的折。

F2 初筛复用同一固定 EEG 入口，分别测量听觉/言语的临床增量以及 `临床＋听觉` 对 `临床＋听觉＋EEG`。固定表征的多输出比较不能证明已经完成“目标训练表征的交叉充分性”实验。共享/独立/少量特有表示的比较属于后续受限学习阶段，需另行固定一个方法、对照及预算；不以一个平均多任务指标替代逐目标结果。

## 验证与结果解释

身份级嵌套验证的折数、最低训练支持和一个随机种子在合格集合确定后一次冻结。重复划分不能产生新儿童。阈值/时间证据不足不能由交叉验证弥补；若合格集合为空，不生成空折，也不套用 V3 外折。

连续量表主要报告原量表单位的 MAE 增量，补充 RMSE/校准；有序量表采用明确的有序观测模型，避免默认等距。固定 OOF 的配对身份 bootstrap 必须明确不包含全流程重新训练的不确定性。MAE 差不是 bit，训练瓶颈 KL 不是真实 CMI。

只有来源/质量控制后仍有可解释的样本外增量，才考虑一个有具体动机的小型学习模型，并分别判断“EEG 有增量”与“学习方法优于固定表征”。已探索队列只能支持探索性结论；临床效用、机制与外部泛化需要另有证据。

## 当前未激活字段

主分析行集合、逐行终点版本、临床评估日期/时间对应、最终协变量与单位、可用连续信号范围、片段和特征配置、外内折及正式拟合预算均需通过资格阶段后写入新配置。它们不能由一个看似完整的默认 CLI 自动补齐。本轮若支持不足，只完成这些条件化设计与证据清单，不启动模型或 GPU。

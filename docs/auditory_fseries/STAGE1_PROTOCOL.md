# F-series 阶段一：定向临床目标与访问资格核对

依据 `AUDITORY_FUNCTIONAL_DECODING_F1_F4_RESEARCH_PLAN_v1.md` 第 7、9 节执行。本方案是新研究方向的资格阶段，不能把旧 P_MATCH 或旧 MUSS 档案模型自动认定为新临床研究合格队列。既有结果和源文件均保持不变。

先分别核对 HA/BDF 与全部 canonical MFF 的临床来源，不把混合 MFF 来源称为全体 CI。沿用临床 003、HA covariates 004、CI clinical 004、CI linkage 005、metadata addendum 001 的来源与证据；回读其登记的原表头、备注与必要单元格。仅使用既有登记资料，不重扫完整 EEG 目录，不查看 EEG—量表关联。

审核单位与计数分开：临床原始行、去重候选身份、EEG 采集、任务对、临床访问和纵向儿童分别统计。候选身份可以保留为有明确证据限制的分组，不能据此确证独立儿童，也不能因为身份尚非临床确证就将所有档案数抹零。各门槛同时报告独立覆盖和逐步交集；不同分母不相加。

## 临床证据规则

- 原表数值存在只建立“可读档案数值”；量表名称、版本、评分方式与适用范围可解释后才建立可比较终点。IT-MAIS/MAIS 混合标题不据分数或年龄自动拆分版本，CAP 不据观察最大值猜版本，MUSS 不将百分比标题下的 0–40 数值自动乘 2.5。
- EEG 日期使用采集内部记录。临床日期使用明示的量表评估日期或明确同次访问说明；姓名后缀、单个 EEG 结果表的评估日期及文件修改日期不能自动作为功能量表评估日期。不同类型日期并列记录，允许有证据的可解释时间间隔，不要求所有研究只能同日。
- 听力阈值分别记录裸耳/助听、耳侧、频率、单位、日期；不得跨工作表或人群借用单位。设备使用月数与实际佩戴/开机状态分开。
- F3 核对同一候选身份两任务及临床目标交集，保留任务定义、设备与时间证据，不从两批不同人拼配对。
- F4 核对实际基线与后续功能评估、先后顺序和间隔；多 EEG 文件或标签日期不构成真实临床随访。

## 分阶段授权与决策

阶段一不拟合模型、不读取 EEG 数值建立新特征。主终点尚未冻结，不按相关强弱选择。阶段一若建立可解释的目标与访问集合，再独立冻结终点、输入、身份划分、模型比较和资源上限，进入 F1/F2 初筛。若量表版本或时间关系仍不能解释，按原方案报告 `SUPPORT_INSUFFICIENT`，不把它解释为 EEG 科学阴性，也不通过改做档案混合量表模型绕过门槛。

F3/F4 按自身证据独立决定，既不要求 F1 阳性，也不因文件存在而自动启动。不存在受支持的分支时，完成支持表、终点定义表、条件化最小实验设计和路线可行性报告即为本轮应完成的工作；不能制造“全部实验都训练完了”的表述。

## 执行与资源

HA 与 CI 各由一个轻量审计任务负责，主任务核对研究文档并汇总、复核。所有统计、哈希、环境读取、测试与图表均经 Slurm；文件编辑/查看和调度为编排。阶段一最多同时 4 个 CPU 作业，申请资源上限 8 CPU core·h，不申请 GPU，不拟合任何临床模型。每个运行使用新目录，保留源码、配置、输入哈希、完成/失败记录。逐行证据及原始定位仅存 private；仅经检查的汇总进入 results/reports。此轮不自动发布。

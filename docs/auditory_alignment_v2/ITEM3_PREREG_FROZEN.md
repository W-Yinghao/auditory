# ALN2 补充实验（第 3 项）预登记——冻结于任何新计算之前（2026-10-10）

用户指示（2026-10-10）："先 push 到 github 上，然后把 1，2，3 都做"。第 3 项是三个新问题：（a）为什么 DTU 上训练出的读出远低于保留通道的线性探针；（b）基础模型更细的时间对齐；（c）为什么全量微调常常不如冻结或 LoRA。

## 0. 设计依据（已看过的现有结果，全部来自已完成的 seed 3401 单元，如实披露）

- 修复后的结果摘要（`REPAIRED_FM_RESULTS.md`）中，DTU 上探针常常高于训练读出（如 CBraMod 全量 CS 0.341 对 0.044）。
- 训练曲线（B_FM，NCE，seed 3401）：微调单元的训练损失下降约 3–5.5（NCE，对数），而早停损失在第一次验证时已最低、之后上升 1–3；最佳 checkpoint 多在训练的前 8–40%。冻结 REVE 的读出头也有同样现象（训练下降 1.4，早停上升 1.3）。小编码器（16–33k 参数）训练下降只有 0.01–0.17，早停损失持续改善，最佳 checkpoint 在 56–76%。验证间隔为训练轮数的 1/20（CBraMod 每 5 轮、REVE 每 2 轮），所以最早的若干轮内的最佳点可能看不到。
- 全量微调选出的主干学习率多为候选上限 1e-4。

这些观察用于提出问题，不作为结论。本登记的所有臂在看到任何新结果之前固定。

## 1. 共同规则

- 数据、外折、内容折、声音目标、候选集、主要计分规则、修复后的读出层、检查点选择规则（早停上的"自身目标 − 合法错配"）全部沿用 B_FM。seed 3401。目标函数 NCE（参考基线）。三个语音队列 FAU、DTU、Federici 的全部外折与内容折（每个配置 25 个单元：FAU 10、DTU 10、Federici 5）。
- 主要终点：测试参与者的统一读出 gain（比特/查询，错配 EEG − 真实 EEG 的 log loss），参与者 bootstrap 95% 区间，与同配置 B_FM（seed 3401）单元做参与者配对差。次要：原生读出 gain、top-1、注意 2AFC（FAU/DTU）、探针 gain。
- 不设任何以表现为条件的门槛；全部登记的单元都跑完并报告。不按 HA/CI 差异或临床显著性选择任何配置。
- 区间以已训练模型为条件；单 seed，不含训练波动（多 seed 面板给出的跨 seed 标准差 0.001–0.023 比特可作参照）。
- 新代码放在新文件中，不改动第 2 项正在使用的任何代码文件（保持其代码哈希不变）。

## 2. 3a：读出瓶颈诊断（只评价，不训练）——X_READOUT_DIAG

对全部已完成的 seed 3401 B_FM 单元（500 个：2 架构 × 5 适配 × 2 目标函数 × 25），从已保存的 best checkpoint 重新加载，增加一个读出：

- **D1（空间分量读出）**：读出层在最终 16 维投影之前的空间分量 z（K×e = 256 维/patch），经与探针相同的统一 ridge 读出（训练参与者的 fit+es 片段拟合，同样的 300 个片段与 alpha 选择规则）。

与已有读出组成三级比较：R0 训练出的 16 维读出（已有），D1 空间分量，R2 保留全部通道的探针（已有）。另报告 R2(微调单元) − R2(同外折冻结单元)：微调是否改善了主干表示中线性可读的部分（无需新计算）。

解读表（写于看结果之前）：
| 结果（DTU 为主，FAU/Federici 并列报告） | 含义 |
|---|---|
| D1 ≈ R2 > R0 | 信息在 8 个空间滤波后仍在，损失发生在最终 16 维投影/目标函数这一步 |
| R2 > D1 ≈ R0 | 8 个空间滤波（K=8）是瓶颈 |
| R2 > D1 > R0 | 两步都有损失 |
| D1 ≈ R0 ≈ R2 | 训练读出不是瓶颈（与已观察到的 R2 > R0 矛盾，需检查） |
| R2(微调) ≤ R2(冻结) | 微调没有改善线性可读的表示，反而可能损害（与过拟合一致） |

## 3. 3c：微调为何不如冻结——两个逐步叠加的臂

适配方式：pretrained_full、pretrained_partial、pretrained_peft；两种架构；NCE；每臂 3 × 2 × 25 = 150 个单元。

- **X_FT_VAL**：与 B_FM 完全相同的配方，唯一改变是每一轮都验证（val_every = 1，并在第 0 轮之后的第 1 轮开始），从而在更细的粒度上选择 checkpoint。对比 B_FM：只检验 checkpoint 粒度。
- **X_FT_REG**：在 X_FT_VAL 之上加入（i）逐层学习率衰减 0.75（最顶层 transformer 块 = 主干学习率，向下每层 × 0.75；嵌入与位置层用最底层的值）；（ii）主干学习率在开发单元上重新选择，候选向下扩展：全量/部分 {1e-6, 3e-6, 1e-5, 3e-5}，LoRA {3e-5, 1e-4, 3e-4}；读出头学习率 {1e-4, 1e-3}；选择规则与 B_FM 相同（开发单元、20 轮、训练侧早停分数）。对比 X_FT_VAL：检验学习率与逐层衰减。
- 训练轮数沿用已登记的 CBraMod 100、REVE 50（曲线显示最佳点在早期，因此不增加轮数；训练长度不作为单独的臂）。

解读表：
| 结果 | 含义 |
|---|---|
| X_FT_VAL > B_FM | checkpoint 选择粒度是微调结果偏低的原因之一 |
| X_FT_REG > X_FT_VAL | 更低的主干学习率/逐层衰减减少了过拟合造成的损失 |
| 两者都 ≈ B_FM | 过拟合不能用这两种手段缓解；更可能需要更多数据或不同的训练目标 |
| X_FT_REG(全量) ≥ 同配置冻结 | 在这一配方下，全量微调不再弱于冻结 |

## 4. 3b：更细的时间对齐——X_PHASE

基础模型每个 1 s patch 产生一行对齐。X_PHASE 在训练时对每个 batch 随机选一个相位偏移 o ∈ {0, 0.25, 0.5, 0.75} s：EEG 片段从 e0 + o 开始裁剪（CBraMod 取完整的 1 s patch，最多 4 个；REVE 按原规则分 patch），各 patch 的声音窗口相应平移 o。其余（batch 大小、步数、训练轮数、学习率配方）与 B_FM 相同；评价不变（只用相位 0），因此评价协议与 B_FM 完全一致。适配方式：pretrained_frozen、pretrained_peft；两种架构；NCE；2 × 2 × 25 = 100 个单元。

这一臂同时改变了对齐行的时间相位与训练数据的多样性（相当于时间增强），二者无法在本设计中分开，报告时如实说明。

解读表：
| 结果 | 含义 |
|---|---|
| X_PHASE > B_FM（同配置） | 更多时间相位/时间增强有助于基础模型的对齐 |
| X_PHASE ≈ B_FM | 在 1 s patch 的分辨率下，增加相位不改变结果；时间分辨率可能需要从主干内部（更短的 patch）解决，本轮不做 |
| X_PHASE < B_FM | 相位偏移引入的错位或训练噪声有害，需要检查实现 |

# ALN2 基础模型修复后结果（2026-10-10）

完整表格：`docs/auditory_alignment_v2/FULL_RESULTS.md`（汇总脚本 `auditory_alignment_v2/aggregate.py` 自动生成，含全部配置与配对对比）；数值汇总 `results/auditory_alignment_v2/aggregate.json`。数值均为参与者均值及参与者 bootstrap 95% 区间，以已训练模型为条件；gain 为错配 EEG 与真实 EEG 的 log loss 之差（比特/查询，统一读出），私有任务为 head AUC。

## 1. 修复的来源与完成情况

- 起因：原对齐头先对通道取无权重平均（实现回执 §11）。按修正 A1 改为保留通道身份的带符号空间滤波读出（`spatial_signed_k8_e32_v1`），并为每个单元附上保留通道的线性探针参照（回执 §12）。旧结果作为通道平均变体保留在 `legacy_chmean_v1/`，见完整表格附录 L，不作为基础模型或数据听觉内容的证据。
- 重跑：学习率在开发单元重新选择（80 个配方键），按登记规则定训练轮数（CBraMod 100、REVE 50）；所有基础模型族从原始预训练或随机初始化重跑，donor、教师、蒸馏、迁移基础全部重新生成。
- 完成（10-10 11:46）：范围内 4,560 个单元全部完成，其中依赖基础模型的 1,650 个（单 seed 矩阵 1,170 + 多 seed 面板 480）。最终审计（`private/auditory_alignment_v2/repair/final_audit.py`）：无缺失、无未完成；全部依赖基础模型的单元使用修复后代码（FM `234202b1`、STAGE `6ddfa147`、ADAPT `8889ea03`）且带探针结果；蒸馏教师与 C_ADAPT 基础单元均为修复后单元；10 个 donor 均为修复后读出；主结果目录中无通道平均记录。
- 运行中的事件（均已记录于回执 §12）：迁移脚本漏移 6 个旧文件，导致两个 C_ATTENTION 单元在加载时报错（形状不符，没有混用新旧结果），已从头重跑；被抢占的 worker 曾占住单元的领取，已改为自动释放。

## 2. 主要结果

**2.1 修复后的基础模型稳定高于同架构随机初始化，但在 FAU/DTU 上仍远低于小编码器。**

| 数据集 · NCE | 小编码器 density_tokens 完整窗 | 最好的基础模型配置（seed 3401） | 预训练 − 随机初始化（同配置，三个 seed） |
|---|---|---|---|
| FAU | 0.665 [0.578, 0.749] | REVE LoRA 0.055 [0.043, 0.066] | +0.045 / +0.050 / +0.027 |
| DTU | 1.580 [1.421, 1.744] | CBraMod LoRA 0.164 [0.131, 0.198] | +0.143 / +0.149 / +0.156 |
| Federici（包络目标） | 0.086 [0.059, 0.113]；lag_local_tokens 0.258 [0.213, 0.303] | REVE 冻结 0.287 [0.230, 0.344] | +0.284 / +0.248 / +0.242 |

- 通道平均变体在同样配置下几乎全部接近 0（附录 L）；修复后在三个数据集上都出现了一致的预训练收益。
- FAU 上全部 10 个 NCE 预训练配置都高于随机初始化（+0.016 至 +0.045），三个 seed 方向一致；CS_SINGLE 下 CBraMod 的部分/冻结/LoRA 与随机初始化无差别，REVE 各配置为正。
- Federici 是例外：REVE 冻结（NCE）比小编码器 density_tokens 高 +0.201 [0.149, 0.258]，与 lag_local_tokens（0.258）处于同一水平。Federici 使用 2–8 Hz 的预处理缓存与包络目标，与 FAU/DTU 不同，不能外推到其他数据集。
- 在 FAU/DTU 上，所有基础模型配置仍比小编码器低 0.6–1.6 比特。

**2.2 适配方式没有单一最优，全量微调常常不如冻结或 LoRA。** 例如 REVE 在 DTU（NCE）：冻结 0.117、LoRA 0.086、部分 0.084、全量 0.037；在 Federici：冻结 0.287、全量 0.041。CBraMod 在 DTU 则是 LoRA（0.164）最好、冻结（0.012）最差。这一模式在多 seed 面板中复现（见 2.6）。原因（学习率只在一个开发单元上选、训练轮数、过拟合）尚未区分。

**2.3 保留通道的线性探针常常高于训练出的读出，DTU 上尤其明显。** 例如 DTU CS_SINGLE：CBraMod 全量 训练读出 0.044 / 探针 0.341，REVE 部分 0.093 / 0.324，REVE 冻结 0.072 / 0.170。FAU 上两者接近（如 CBraMod 冻结 NCE 0.040 / 0.036）。也就是说，至少在 DTU 上，主干表示中线性可读的声音信息多于训练出的对齐头所利用的部分；瓶颈可能已转移到读出/目标函数这一侧。探针本身是固定的工程选择（PCA 256、300 个片段拟合），不是上限。

**2.4 公开听觉数据上继续训练（B_AUDITORY_CONTINUE）的效果小且不一致。** 与同深度的普通预训练相比：CBraMod 有若干为正（DTU NCE 部分 +0.032 [0.011, 0.053]，FAU NCE 全量 +0.027 [0.019, 0.034]），其余接近 0；REVE 多为 0 或为负（DTU NCE 部分 −0.035 [−0.052, −0.017]）。

**2.5 私有儿童当前类别任务：所有基础模型配置 AUC 0.50–0.55，与小编码器一致。** 公开听觉 donor 相对通用预训练：−0.017 至 +0.004；蒸馏学生相对同窗口的无蒸馏学生：−0.013 至 +0.013。私有任务上探针的 gain 一律为负（约 −0.02 比特），而 AUC 在 0.50–0.53，应视为探针逻辑回归在 256 维上的校准问题，不解释为负信息。NCE 原型头的原生读出仍有校准偏差（−0.03 至 −0.12 比特），与上一轮小编码器的现象相同。

**2.6 多 seed 面板（登记于结果产生前，3 个 seed）。** 配置均值的跨 seed 标准差为 0.001–0.023 比特，小于配置之间的差异。预训练 − 随机初始化的方向在三个 seed 上一致的有：FAU 全部 6 个、DTU 的 CBraMod 全量/LoRA 与 REVE 冻结/LoRA、Federici 的 REVE 三种与 CBraMod 全量；不一致的有 REVE 全量在 DTU（−0.014 至 +0.011）与 CBraMod 冻结在 DTU/Federici。私有任务的差值都在 ±0.03 AUC 内，CBraMod LoRA 三个 seed 为 +0.016 至 +0.027。

**2.7 其余族（CBraMod 臂）。**
- 注意 2AFC：基础模型 0.50–0.55，小编码器 FAU 约 0.56、DTU 约 0.67。
- 训练人群覆盖（FAU）：CBraMod 臂的增益都很小（≤0.05 比特），不足以比较组别。
- 个体适配（C_ADAPT，以修复后 CBraMod 单元为基础）：空间适配器 30% 支持相对无适配 −0.014 至 +0.003，低秩适配 ≈ 0。

## 3. 仍然不确定的部分

- 读出层的 K=8、e=32、探针的 PCA 256 是事先固定的，没有调节；不同读出设计可能改变结论。
- 时间分辨率：基础模型每个 1 s patch 对应一行对齐（每段 5 行），声音目标窗口 1.2 s；小编码器在更细的时滞上对齐。这可能是 FAU/DTU 差距的重要来源，尚未检验。
- 学习率只在一个开发单元（外折 0、内容折 0）上选择；全量微调弱于冻结的原因未区分。
- 单 seed 矩阵的区间以已训练模型为条件；跨 seed 的不确定性只由面板（B_FM、D_FM_GENERIC 的 NCE、四种适配）提供。
- 探针高于训练读出（2.3）说明当前比较低估了主干表示中线性可读的信息，但不说明主干优于小编码器。
- 这些结果是对"当前接口与训练配方"的结果，不是对基础模型或数据中听觉信息的结论。

## 5. 模块 A（时间表示）及小编码器部分

- **架构**：
  - legacy_pool4：上一轮的 EEGEncoder，沿用旧窗口规则（右端多取一个采样点）。
  - density_tokens：同样的卷积主体，按约 20 ms 步长平均池化成 token（128 Hz 为 3 点，100 Hz 为 2 点，250 Hz 为 5 点），加学习的位置嵌入，展平后投影。
  - lag_local_tokens：40 ms 局部编码器按约 20 ms 的滞后步长滑动，参数共享，加滞后位置嵌入，展平后投影。
  - 新架构一律使用半开窗口 `[start, stop)`。
  - 技术测试确认：三种架构在四种窗口下的窗外梯度都为零，窗外数值改变也不影响输出。
- **声音头**：
  - fixed_features：训练侧标准化 + 按队列固定种子的半正交投影，同一队列的所有单元完全相同。
  - frozen_random：上一轮的 MLP 头，随机初始化后冻结。
  - trainable_head：上一轮的 MLP 头。
  - anchored_head：可训练 MLP + 线性解码器，重建标准化后的目标；权重 λ ∈ {0.1, 1.0} 都训练，按早停选择分数选定。
- **目标函数与选择**：
  - 上一轮的参考实现：NCE（温度 0.1，按刺激去重）、传统核 CS（训练校准中位数带宽 × 1）、FMCA（相对 ridge 1e-3）。
  - 每批行数：NCE 与 CS 为 256，FMCA 为 512。
  - checkpoint 选择沿用上一轮规则：自身目标 − 合法错配，在 40 个早停批上计算。
- **注意任务**：
  - selection 损失：同一时刻注意流与忽略流的 2AFC，训练时随机交换候选顺序并同步交换标签。
  - NCE 路径用余弦打分；CS 路径用显式训练的双线性桥。
  - 联合训练的选择权重 ∈ {0.1, 1.0}，按早停 2AFC 选定。
  - 纯选择训练按早停 2AFC 损失选择 checkpoint。
- **复用**：规范签名（缺省值归一化后的完整配置）相同、代码哈希相同的单元，只训练一次，其余记为 `reuse_of`。小编码器部分共 4,620 行，对应 4,350 个独立模型。

## 7. 依赖型实验族（只有技术依赖，没有结果门槛）

- **donor**：多队列公开配对继续训练，用参考 NCE；共享 backbone 和 patch 头，各队列的声音头固定；轮流从各队列取批，训练 20 遍，以最终状态作为 donor。
  - B_AUDITORY_CONTINUE：只用目标队列以外的公开队列（FAU 用 DTU + Federici，DTU 用 FAU + Federici），对目标队列的所有外折都安全。
  - D_FM_PUBLIC：用全部公开队列，没有私有儿童。
- **D_LOCAL_DISTILL**：教师 = 同架构、同目标、同外折、同 seed 的 D_FM_PUBLIC auditory_pretrained_full 单元。学生 = lag_local_tokens，只看受限窗口；蒸馏项为 λ·(1 − cos(W·u_学生, u_教师))，λ ∈ {0.1, 1.0}，按训练侧早停分数选定。推理时不使用教师。
- **C_ADAPT**：基础模型取同外折、同 seed、同目标的已完成单元。
  - 支持集：每名测试参与者按记录顺序取最早的 10% 或 30%；查询集：最后 70%，各变体共用同一组查询。
  - 适配方式：输入 C×C 映射（恒等初始化），或输出端秩 4 残差。
  - 更新步数：只在训练参与者上，从 {20, 50, 100} 中选定。
  - 记为个体适配，不称零样本。

## 11. 基础模型对齐头的设计问题（2026-10-07 中期汇总时发现）

- **现象**：B_FM 中 CBraMod 各适配方式在 FAU 上的统一读出 gain 为 0–0.008 比特（小编码器 0.67），连同架构随机初始化也接近 0。
- **原因（探针确认）**：我实现的对齐头 `PatchHead` 先把每个 patch 的 token 在所有通道上取平均，再做 LayerNorm 与线性投影。包内没有规定这一步，是实现时的选择。探针 `private/auditory_alignment_v2/fm_head_probe.py`（开发单元，相同切段、重采样与声音目标，只换"特征 → 线性读出"）的检索增益（rank 百分位，错配 − 真实，测试参与者均值与 95% 区间）：

  | 特征 | FAU（31 通道） | DTU（64 通道） |
  |---|---|---|
  | 原始 EEG，保留各通道 | +0.070 [0.038, 0.104] | +0.147 [0.113, 0.182] |
  | 原始 EEG，通道平均 | −0.004 [−0.026, 0.023] | +0.111 [0.083, 0.144] |
  | CBraMod 冻结 token，通道平均（正式单元的头） | +0.002 [−0.022, 0.025] | +0.057 [0.030, 0.084] |
  | CBraMod 冻结 token，保留各通道（PCA 512） | +0.048 [0.021, 0.074] | +0.078 [0.059, 0.097] |

- **含义（按用户审阅收窄表述）**：
  - 通道平均的接口丢掉了保留通道的读出能用到的信息，在 FAU 上尤其明显（CBraMod：保留通道减通道平均，FAU +0.046，DTU +0.021；原始 EEG：FAU +0.074，DTU +0.036；单位是 rank 百分位增益，不是比特，不能与小编码器的 0.67 比特直接比较）。因此现有结果不能作为基础模型适配的主要比较。
  - 不是"完全抹掉"：DTU 上通道平均的 CBraMod 特征仍有 +0.057（保留通道为 +0.078）。对隐藏 token 取平均也不等同于对原始 EEG 取平均，可训练的主干原则上能在汇总前重新分配信息；完整训练失败也可能涉及优化或时间汇总。
  - 探针只说明在所测路径上存在可用的对应关系，降低了粗大配对错误的可能；它不能证明精确的潜伏期解释、每个数据集适配器或每条下游评价路径都正确。
  - 保留通道的原始 EEG 在两个数据集上都强于冻结的 CBraMod：现有证据说明 CBraMod 特征含有可用的对应关系，而不是说明预训练已经优于原始 EEG 或小编码器。这正是修复后实验要回答的问题。
- **说明**：包内规定了模型输入、适配方式和时间访问，但没有规定通道 token 的汇总方式（用户确认这是规格上的缺口，不只是实现问题）。官方 CBraMod 示例去掉重建投影后把通道、片段和特征维展平送入学习的分类器，并不先做无权重的通道平均。

# D2 第 5 轮：选择哪些电极比用多少电极更重要（经重复验证）

第 4 轮的教训是单折种子不可作结论，因此本轮全部结果基于多个独立折划分种子。

## 1. 主结果

嵌套贪心前向选择：电极集合只在每个外折的**训练折内**用内折误差选出，
外折测试数据从不参与选择。报告的是整个**流程**的留出误差。

| 配置（5 个独立折种子） | OOF MAE（月） |
|---|---|
| 猜训练均值 | 19.07 |
| 16 电极，空间展开（最远点采样） | 15.69 ± 1.00 |
| **16 电极，数据选出（嵌套）** | **12.49 ± 0.81**（范围 11.38–13.36） |
| 全部 128 电极（RBF，4 种子） | 12.50 ± 0.27 |

**16 个选出的电极与全部 128 导不可区分**（12.49 对 12.50），而同数量的空间展开配置要差
**3.20 月**。在本队列与本特征族下，**布放位置的选择比电极数量更决定可提取的发育信息**。

这条结论与第 4 轮更正不矛盾：第 2 轮被推翻的是"空间展开的 16 电极就能追平 128"，
而这里是"**选出的** 16 电极能追平 128"。二者差 3.2 个月，正是选择带来的。

## 2. 诚实的限定

- 折间选择重叠仅 **0.245**：具体是哪 16 个电极**不稳定**。稳定的是流程，不是导联。
  跨种子反复入选的有 E55（5 次中 4 次）、E9（4 次）、E126（3 次）、E16（3 次）。
  本文给出的是"选 16 个"这一做法的性能，**不是**一个可照抄的固定导联表。
- 选择同时起正则化作用：n=62 时 1152 维（128 导）比 144 维（16 导）更易过拟合，
  因此"16 导追平 128 导"部分来自维度而非纯信息量。两种解释都应写明。
- 该结果在 MFF 高密度支线上成立；BDF 支线只有 20 导，无法执行同一实验。

## 3. 与整条曲线的关系

- **空间展开**子集：要到约 96–128 电极才达到 MAE ≈ 12.5。
- **数据选出**子集：16 电极即达到同一水平。
- 两者的差在低预算处最大，到高预算处必然收敛（128 选 128 无可选）。

部署含义是直接的：在儿童临床场景中，与其增加电极数，不如把有限的电极放对位置——
但"放对位置"目前只能靠在本队列上做嵌套选择得到，尚不能给出一张通用导联表。

## 4. 运行

Slurm：`D2_select_rbf16_001` 与 `D2_sel_rbf16_s{11,22,33,44}`（5 个折种子），
`D2_select_lin16_001`（线性读出对照，MAE 16.77，明显更差且标定失效，bits 为负）。

# 成稿骨架（带全部已验证数字）

工作题名（暂）：**儿童临床 EEG 的采集预算——电极数与记录时长的信息曲线，
以及为什么持续 EEG 编码的是发育而不是听觉状态**

目标期刊：IEEE JBHI。定位：信息学贡献（采集预算的信息曲线）+ 部署含义 + 方法学警示。
不做 ERP，全部为连续 EEG 解码。

## 1. 贡献声明

1. 在真实儿童临床语料上给出**发育信息随电极预算变化的曲线**，并给出该曲线本身的**可测性**分析。
2. 加上**记录时长**这第二条轴，得到二维采集预算图；结论是时长在 2 分钟饱和而电极数不饱和。
3. 证明**电极位置的选择比电极数量更决定可提取信息**：16 个嵌套选出的电极追平全部 128 导。
4. 跨放大器、跨电极阵列的迁移，不使用任何目标队列标签。
5. 三条互相独立确认的阴性：持续 EEG 在年龄之上对听觉临床变量无信息；
   未校正的脑龄差会制造一个看上去可发表的假阳性；相对位置自监督在结构上不可能迁移到被试级目标。

## 3. 读数

`bits_recovered = CE(训练折边际) − CE(模型)`，标定来自内折残差。
配对比较用身份级自助（2000 次，共享抽样）。**所有曲线主张附跨折种子离散度**。

## 5. 必须写进讨论的限制

- n=62 / 56，单中心；MFF 侧身份判据为"同名同日唯一参与者"，未放宽。
- BDF 的电极量程（1–20）整个落在曲线噪声段，**不构成对预算效应的独立复制**。
- 16 导追平 128 导部分来自正则化（n=62 上 1152 维对 144 维），不纯是信息量。
- 年龄是先验可解码的锚点，不是临床终点；本文不作脑成熟的因果陈述。
- 2 分钟略优于全长不作过度解读，只声称"不劣于"。

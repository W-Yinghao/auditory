# PF 协议附录 001（2026-09-27，写于看到第一遍真实结果之后）

冻结协议 `PF_PROTOCOL_FROZEN.md` 保持不变（只读）。本附录记录第一遍真实分析（`analyze_001`，Slurm 1010422）之后发现并处理的问题。**本附录中的一切都发生在看到结果之后**，读者应据此加权。

## A1　模型 (b) 的嵌入来源：协议写法在构造上无效，改为单编码器（看结果后修正）

**问题**。协议 §4.1/§4.2 规定：训练儿童的记录特征用内层网络 M_i 的交叉拟合嵌入，测试儿童用外层网络 M_o 的嵌入。可是独立训练的网络，各自 192 维嵌入的坐标系互不对应。于是：
- (b) 的 logistic 在 5 个不同网络的混合特征上训练，再用到第 6 个网络的特征上，特征彼此不可比；
- 第一遍中 (b) 的阶段 AUC 0.477、b-ord 的 SIR AUC 0.525、H16 事件表示的年龄 MAE 35.5（比猜均值还差），都与这一缺陷相符。

这是协议写法本身的错误，写入者与实现者都是我。

**修正**。每个外层折的所有儿童（训练与测试）都用该折的 M_o 提取嵌入，即标准的"冻结编码器 + 线性探针"。M_o 从未见过测试儿童，符合 R10；训练儿童参与过 M_o 的刺激训练，但 M_o 不使用阶段或 SIR 标签。只做推理，不重训任何模型（`reembed`，Slurm 1010430）。

**受影响的量**：(b)、(b-dev)、(b-std)、H2 条款 A、H3、H5 的 (b) 次要行、H11、H12、H13 的分母（全 EEG 解码器技能）与 (b) 阶段分数次要行、H14 的 Z、H16/H17 的事件表示与联合表示、MUSS 次要分析、(b) + 背景。

**不受影响的量**：
- H1 的主模型 (a1)：用遮挡 AUC 曲线，与网络坐标无关；
- (a2)；
- (c) 端到端：每折只有一个网络；
- H4、H6–H10、H15、H18–H20：只用刺激 logit 或 (a1)/(c) 分数。

**报告方式**：协议原版 (`embed_source=xfit`，`analyze_001`) 与修正版 (`embed_source=mo`，`analyze_002`) 并列报告；修正版标为"看结果后修正"。修正版的 (b) 置换（1000 次）与 H12 打乱（2×200 次）全部重跑（`perm_b_002`、`shuffle_h12_002`），判定规则不变。

## A2　执行细节（不改变任何计算，发生在看结果之前）

端到端置换阵列在任何任务启动前被撤销，改为每块 GPU 4 个工作进程的等价提交（1010250 → 1010378）；单元分配方式改变，单元内容与种子不变。

## A3　探索性检查（看结果后加入，不是主张）

第一遍中，仅用月龄这一固定分数区分阶段的 AUC 为 0.696，与 H1 主模型 (a1) 的 0.707 相当。为回答"w_late 在月龄之外有没有增量"，加入两个嵌套 logistic：仅月龄；月龄 + w_late（训练儿童用交叉拟合 w_late）。折与惩罚选择同其他模型。只报告估计与区间，不给状态。

## A4　结果表述上的说明（不改变判定）

- **H20** 的推翻条件是"增益 <0"。第一遍点估计 −0.0000014，按字面为推翻。报告时同时写明：增益实质为零，区间 ±0.003 排除了预测的 +0.005。
- **H2 与 H12** 的"部分成立"来自 §7 的定义（部分条款满足、未触推翻）。第一遍中它们依赖的 (b) 与 b-ord 本身没有信号，因此报告时同时写明这一前提。

## A5　探索性置换：按条件聚合的 (b)（看修正版结果后加入，不是主张，不改变 H2 的判定）

修正版中 H2 两个条款都满足（偏差聚合 0.604、标准聚合 0.456，差 +0.148，bootstrap 区间 [0.018, 0.283]；H2 背景 0.537）。但协议没有给偏差聚合本身安排置换检验。为了知道这个信号能否与机会水平区分，加做 1000 次儿童级全流程置换（每次重新选惩罚），分别得到偏差聚合 AUC、标准聚合 AUC 及二者之差的零分布（`perm_bdev_001`，Slurm 1010454）。只报告 p 值，H2 的状态仍按冻结规则。

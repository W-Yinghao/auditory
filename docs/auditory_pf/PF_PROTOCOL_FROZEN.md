## 1. 数据与队列

- **车道**：`bdf_puretone`（HA/BDF 纯音 oddball），`private/auditory_gx/GX_stage_001` 的事件锁定 epoch。20 个头皮导，250 Hz，−0.2…0.6 s，只用暂存时的 QC 接受试次（标准 = 类 0，偏差 = 类 1）。共 84 条记录、73 名儿童（身份组）。

## 2. 共用规则（R1–R12）的操作化

| 规则 | 本轮实现 |
|---|---|
| R1 | 标签与输入都来自同一次合格访视；外层折按儿童划分，一名儿童的所有访视在同侧 |
| R2 | 学习型模型：儿童级置换阶段（或 SIR）标签，重跑所有依赖标签的步骤（模板、惩罚选择、训练），得到零分布。外层/内层折的划分**不依赖**阶段标签（只按 有标签 / NH / 无标签 分层），因此置换时无需重训与标签无关的上游刺激解码器。p = (1 + #{null ≥ obs}) / (1 + P) |
| R3 | 每次抽样：每条记录每类取 K=80 个可用试次（不放回）；共 D=10 次独立抽样（固定种子）。记录级聚合（嵌入均值、logit 均值、遮挡曲线）先在每次抽样内按类分别计算，再对 10 次抽样取平均。每次抽样内的类别组成对所有记录完全相同。**严格敏感性**：只用第 0 次抽样（每条记录精度也完全相等） |
| R4 | 阶段任务的背景基线：月龄、较好耳裸耳 PTA（缺失用训练折中位数插补，另加缺失指示）、技术变量（记录尺度、可用试次数、接受比例、记录时长、平均超阈通道比例）。**不含**佩戴时长 |
| R5 | SI 的临床基线 q(Y\|C)：月龄与 log(1+佩戴月数) 各一组三次 B 样条基（3 个内节点，按训练折分位数放置），比例优势序数 logistic + L2，惩罚在训练折内选择。SIR 为主目标，MUSS 为次 |
| R6 | 以记录第一个试次为起点切 60 s 物理块；试次的 epoch 窗与块边界的距离 <5 s 时剔除（保护带）。偶数块为支持块，奇数块为查询块。方向只由支持块决定 |
| R7 | 逐儿童报告只做两个固定终点：全长一次（H9/H10）、前 5 分钟一次（H19）。本轮不做序贯检验 |
| R8 | 资源比较按相同总试次（H18） |
| R9 | 端到端阶段模型的广播损失与记录级损失并行：同编码器、同批次、同步数；每步按儿童均匀抽记录，每条记录每类抽同样数量的 epoch |
| R10 | 第二层（阶段分数 → SIR、临床 + EEG 联合）用嵌套交叉拟合：外层测试儿童不进入任何上游拟合、模板或惩罚选择 |
| R11 | 结果状态见 §7；不用 p 值区间给方向下结论 |
| R12 | 不删 AUC<0.5 的儿童；不按查询成绩翻转方向；遮挡窗与通道组预先固定 |

## 3. 折、抽样、重复

- **外层**：3 个划分种子 {101, 202, 303} × 5 折，按儿童划分，在 {有标签 HA、NH、无标签 HA} 三组内各自轮流分配。
- **内层**：在每个外层训练集内再划 5 折（同样的分层），供交叉拟合与嵌套使用。
- **早停验证**：训练儿童中随机 15%（与标签无关）。
- **统计量**：每个划分种子在全部合格有标签儿童上得到池化的 OOF AUC，报告 3 个种子的均值，并附最小–最大值。逐儿童量取 3 个种子分数的平均。
- **区间**：儿童级 bootstrap（2000 次，每次重算各种子的 AUC 再取平均）的 95% 百分位区间。
- **置换次数**：(a) 2000；(b) 1000；(c) 200（同一组置换标签向量在 (a)(b)(c) 间共用）。H12 分层打乱 200 次。

## 4. 模型

### 4.1 上游刺激解码器（与阶段标签无关）

对每个外层 (s,k)：
- **M_o**：GX 共享 EEGNet（F1 16, D 2, F2 32，GX 训练配置），用该折全部训练儿童（有标签 + NH + 无标签，所有访视）的全部可用试次训练。
- **M_i**（i=1..5）：内层 5 折，各用 4/5 的训练儿童训练。它们给训练儿童提供**留出**的试次 logit、嵌入与遮挡曲线（交叉拟合）；外层测试儿童的这些量由 M_o 提供。
- **M_pre**：只保留预刺激 0.2 s（刺激后样本置零）的同构 EEGNet，训练集同 M_o（H19 假阳性对照）。
- **M_13**：只用训练折中 ≥13 月的有标签儿童训练（H8）。
- **L_o**：全窗线性基线（20 导 × 200 点展平后接一层线性，同训练循环与早停），与 M_o 在同一批测试儿童上比较逐儿童刺激 AUC（采纳评审的"全窗线性基线"，只报告，不设主张）。

嵌入 = EEGNet 分类头之前的 192 维特征。

### 4.2 阶段模型（B1 三种并列）

- **(a1) 折内模板汇总量（H1 主模型）**：逐儿童的时间遮挡曲线（80 ms 窗、40 ms 步，窗中心 0.04–0.56 s，即 R5 的定义）= 该儿童留出模型的刺激 AUC 下降量；每次抽样在 80+80 个试次上算，再对 10 次抽样取平均。模板**只用该折训练儿童的交叉拟合曲线**：曲线峰 <0.2 s 的儿童平均成早模板，≥0.2 s 的成晚模板（与标签无关），截负为零。测试儿童：NNLS 求早、晚权重，w_late = 晚/(早+晚)，作为阶段分数。
- **(a2) 标签化模板（次要）**：模板 = 训练儿童 stage1 平均曲线 − stage0 平均曲线；分数 = 测试曲线与该模板的内积。
- **(b) 冻结刺激表示 + logistic**：记录特征 = [偏差聚合嵌入 192 维, 标准聚合嵌入 192 维]，训练折内标准化，L2 logistic（class_weight 平衡），C ∈ {1e-4, 1e-3, 1e-2, 1e-1, 1} 由训练折内 5 折分层 CV 的 AUC 选择。训练儿童用交叉拟合嵌入，测试儿童用 M_o 嵌入。
- **(c) 端到端**：同一 EEGNet 结构，二分类阶段头，只用有标签训练儿童。每步 8 条记录 × (16 偏差 + 16 标准)。
  - **(c-bc) 广播损失**：每个 epoch 带记录标签的 BCE。
  - **(c-rec) 记录级损失**：同一批次内每条记录 32 个 epoch 的 logit 取均值后算 BCE。
  - 两者同批次序列、同最大步数（40 × 150 步），按验证记录的 BCE 早停（耐心 6）。
  - 测试时记录分数 = 每次抽样 80+80 个试次的 logit 均值，再对 10 次抽样取平均。
  - 概率换算：为得到平衡先验下的概率，减去训练折的对数先验比（先验偏移校正）。
  - **(c-rec-dev) / (c-rec-std)**：只用偏差 / 只用标准 epoch 训练和打分（H2 次要）。

### 4.3 基线

- **阶段背景基线**：R4 中的变量 → L2 logistic（平衡，C 由内层 CV 选择）。
- **H2 背景基线**：技术变量 + 预刺激谱。预刺激谱 = 每个试次 −0.2…0 s 加 Hann 窗做 FFT（5 Hz 分辨率），取 5、10、15、20、25–45 Hz 各频带的对数功率，按预算抽样平均，得 20 导 × 5 = 100 维。

### 4.4 SI 模型

- **全 EEG SIR 解码器（H11 主模型，b-ord）**：(b) 的记录特征 → 比例优势序数 logistic（累积 logit，对斜率加 L2），λ 由内层 CV 的 MAE 选择。输出 E[SIR] 与 P(SIR>3)。
- **(c-ord)（次要）**：端到端 EEGNet + 累积 logit 头，记录级损失。
- **评价**：SIR>3 vs ≤3 的儿童级 AUC（评价标签不进训练；两者按比例优势模型给出相同排序），序数风险 = E[SIR] 的 MAE。
- **MUSS（次要）**：岭回归，报告 MAE 与 Spearman，不设阈值主张。

### 6.1 H14 被推翻时的三世界模拟（本协议自定义，替代不可得的评审 X5）

保持观测到的 C 与 Y，生成三种 Z：
- W0：Z 与 Y 在给定 C 时独立（打乱观测 Z）。
- W1：Z = 阶段的函数 + 噪声（与观测 Z 同方差）。
- W2：Z = 观测 SIR 的函数 + 噪声，信噪比按观测 Z 与 Y 的相关标定。

每个世界跑 200 次同一 H14 管线，报告"下界 >0"的比例。只有在 W0、W1 的比例 ≤10% 且 W2 明显更高时，才把观测结果报告为"候选条件增量"。

## 7. 结果状态（六类，本协议定义）

1. **成立**：所有预测条款满足。
2. **部分成立**：部分条款满足，且未触推翻条件。
3. **精度不足（方向一致）**：既未成立也未推翻，点估计方向与预测一致。
4. **精度不足（方向不一致）**：既未成立也未推翻，点估计为零或与预测相反。
5. **推翻**：满足推翻条件（推翻优先于成立，如 H14）。
6. **不可评估**：前提不满足。附原因码：`support`（人数不足）、`upstream_null`（依赖的模型没有信号）、`numerical_failure`（技术失败）。技术失败不得写成科学阴性。

## 8. 与方案的偏离（写定于看结果之前）

1. **H15**：按方案的 12–24 月时长层，数据中是 SIR>3 5 名 vs ≤3 5 名，不是 7 对 7。按 12–24 月执行，另报 12–36 月（11 vs 7）作敏感性。
2. **H18**：只有 11 名儿童（全部访视合计）有 ≥1000 个可用试次，"30 × 1000"不可行。改为同总量、同 2:1 比例的 30×900 vs 60×450。每名儿童取主访视在前、其余访视在后的前 B 个可用试次（模拟"录得更短"）。
3. **H20**："73 人规模点"按留一儿童实现，训练集最多 72 名（车道共 73 名），不外推。
4. **B2**：方案写"H1 成立才值得做"。用户已指示执行全部路线，因此 B2 无论 H1 结果如何都执行；其解读以 H1 的状态为条件。
5. **评审文件缺失**：六类状态与三世界模拟由本协议定义（§6.1、§7）。
6. **H6 的配对**：沿用 R4 冻结配对表（新 ≤2 月、有经验 ≥12 月、|年龄差| ≤12 月的贪心配对）。13 对中有经验一方的时长都 ≥14 月，与 ≥13 的阶段定义一致。

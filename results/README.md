# Published aggregate results

These directories contain selected aggregate outputs only. Participant/record tables, private predictions, epoch signals and ledgers remain on the server. A directory's presence does not mean its full server contents were released.

| Directory | Included evidence |
|---|---|
| [phase1_final_001](phase1_final_001/) | Cohort flow, counts and processing sensitivity |
| [phase2_measurements_001](phase2_measurements_001/) | Half-amplitude ICC, matched processing comparisons and block uncertainty aggregates |
| [phase2_archival_001](phase2_archival_001/) | Fixed-model clinical feasibility and repeat-level aggregate errors |
| [phase2_diagnostics_001](phase2_diagnostics_001/) | Aggregate leave-one-out influence ranges |
| [phase3_ha_science_001](phase3_ha_science_001/) | Nested HA model comparisons |
| [phase3_ha_sensitivity_001](phase3_ha_sensitivity_001/) | Subsequent separate-penalty sensitivity check |
| [phase3_trial_budget_001](phase3_trial_budget_001/) | Retrospective trial resampling summaries, draw-level ICC and plots |
| [phase3_ci_measurements_001](phase3_ci_measurements_001/) | MFF trial retention, waveform reliability and decoding aggregates |
| [phase3_synthesis_001](phase3_synthesis_001/) | Source/task stratification and same-day task-pair aggregate comparisons |
| [phase3_ci_clinical_feasibility_001](phase3_ci_clinical_feasibility_001/) | Original strict-source and mixed-source clinical intersections |
| [phase3_metadata_addendum_001](phase3_metadata_addendum_001/) | Final metadata counts and expanded CI clinical intersection; use alongside the preceding results |
| [phase3_delivery_002](phase3_delivery_002/) | Original server delivery verification summary, not a claim that restricted inputs are distributed |

Read [the Phase 3 report](../docs/phase3_report.md) for limitations and the order in which analyses were conducted. JSON nulls and CSV missing values represent unsupported or unavailable estimates, not zeros. Small stratum summaries are descriptive and must not be interpreted as confirmed diagnostic-group effects.

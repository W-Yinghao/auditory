# DEP12 轮次报告（依赖包 v1.2；2026-10-23）

研究中心（包 00）：声音–EEG 依赖能否被可靠测量、在明确条件下比较，并跨人群与任务使用？依赖剖面能否帮助作出有效的使用决策？

## 执行概况

- **训练**：E0 四个 2,500 步试训按冻结规则选定 LoRA。之后完成 9 个主模型（CS-pair / InfoNCE / Sigmoid × seed 3401/3407/3413）和 2 个机制对照（raw-CS、WRONG @3401），共 115,000 次更新。
- **扩展**（超出包预算，见 DECISIONS 07:30）：raw-CS 与 WRONG 补齐 seed 3407/3413，+40,000 次更新。决定是在看到它们的任何测量之前做的。
- **公共队列**（DTU 44 人、FAU 67 人）：
  - 共同测量：每人 128 个锚点，199 个块内循环移位零分布，描述子为包络、谱、Whisper L27（Lz）；
  - 20 s 注意判定：152 个密集锚点。规则 (a) 为候选依赖差；规则 (b) 为训练侧线性包络读出；
  - 外源 EEG 对照，以及事后去偏（自身 margin 减 8 个外源 margin 的均值，DECISIONS 07:55）；
  - 400 ms 输入扰动面板；公共选择器。
- **私有儿童**（64 人）：
  - U0 的 history-only（B1）与 history+EEG 风险差 G；strict twin；δ 剖面；
  - U10 四策略选择；MFF 作为第二私有队列（57 人）；跨刺激回收。
- 外部对照见 F_EXTERNAL.md 与 EXTERNAL_COMPARISON.md。
- 统计口径：人为单位；seed 先在人内平均；bootstrap-t，B = 10,000；族内同时 95% 区间。逐 seed 结果与合并结果并列报告。

## 1. 学习：CS-pair 相对 B0 与目标对照改变了什么？

| 终点 | CS-pair − B0 | CS-pair − InfoNCE / Sigmoid | CS-pair − raw-CS | CS-pair − WRONG |
|---|---|---|---|---|
| 私有 U0 G（bits/试次） | **+0.0034** [+0.0011, +0.0056]，3 个 seed 的同时区间各自都 > 0 | +0.0002 / −0.0003 | **+0.0011** [+0.0002, +0.0021] | −0.0001 |
| DTU 20 s 读出 (b) | **+0.055** [+0.027, +0.083]；去偏后 +0.046 [+0.021, +0.070]，3 个 seed 各自都 > 0 | +0.012 / +0.012 | **+0.029** [+0.012, +0.047] | +0.002 |
| DTU 20 s 依赖 (a) | −0.018 [−0.041, +0.005] | ≈ 0 | **+0.018** [+0.003, +0.033] | −0.0005 |
| FAU 20 s 读出 (b) | +0.018 [−0.001, +0.036]；**去偏后 −0.011** | −0.015 / −0.011 | **+0.015** [+0.002, +0.028] | +0.009（逐点） |
| 共同测量超额（包络 / 谱 / Lz） | ≈ 1e-5 nats，全部含 0 | 全部含 0（Lz 逐点为正） | DTU 包络 **+5.9e-5** [+1.3e-5, +1.05e-4] | 全部含 0 |

方括号为合并 3 个 seed 后的族内同时 95% 区间。

判断：
- 本轮源训练改变了表示，并带来可迁移的用途：DTU 注意读出提高，儿童历史之外的当前事件信息增加。
- 配对参照（中心化）明显优于 raw-CS。
- 但提升**不依赖正确的正配对**：WRONG 与 CS-pair 相当。提升也**不是 CS 目标特有**：InfoNCE、Sigmoid 与 CS-pair 相当。
- 按包 02 §8，这对应"用途改善，但不支持学到了更多可用声音关系"。机制上更符合中心化起正则作用，抑制了 raw-CS 靠特征分离（核趋近单位阵）抬高分数的退化路径（README_math §2）。
- E0 的 dev 探针在强收缩状态下没有显示改善（四个试训都 ≤ B0）。最终的用途差异来自下游读出和儿童任务。

## 2. 测量：同属性方法差是否稳定？哪些可以报告？

- **能分辨的**：共同测量能看出大的表示差异。用目标队列配对音频训练的 ALN3.4 折模型，DTU 包络超额约 18–20e-5 nats，B0 只有 3.3e-5（访问级别不同，单列）。
- **分辨不了的**：源训练各臂之间的小差异全部低于测量分辨率，F_MEASURE 所有成员都含 0。
- **对带宽敏感**：DTU-env、seed 3401 上，σ×0.5 时 B0 的超额是 40.9e-5，方法排名翻转；σ×2 时接近 0。n ≤ 64 时区间太宽。所以方法差**不能**脱离带宽和 n 报告。
- **私有 δ 剖面**：B0 在 n128 时 +1.5e-5 nats，64 人中 32 人为正。结果随 n 从负变正，不能作为稳定的个体测量。
- **零参照与对照**：
  - 噪声 EEG 约 0。
  - 外源 EEG 对照揭示**候选边际偏置**：拿别人的 EEG 打分，DTU 规则 (a) 为 0.45–0.49，FAU 为 0.49–0.61，而不是 0.5。即使用各候选自己的循环移位零分布，FAU 的偏置也没有去掉；这与 W7 的 R_z 结论一致。
  - 因此跨候选的依赖比较必须带外源或去偏对照才可解释。
- **可以稳定报告的**：大差异，或与零分布的比较；而且要固定属性、n128、σ×1，并同时报告零均值、零标准差和核诊断。

## 3. 用途：哪些支持迁移，哪些没有？

- **注意判定**：
  - DTU 的读出提升在去偏后仍成立，属于 EEG 特异的改善。
  - FAU 的读出提升去偏后消失，原本来自候选偏置。
  - 依赖规则 (a) 在两个队列都没有改善。
- **儿童当前事件**：
  - CS-pair 的 G 比 B0 高 0.0034 bits/试次。但绝对值仍为负（约 −0.0025），只比 64 维读出在无信号时的样本外代价（约 −0.006）高。
  - EEG 部分 AUC 的变化未分辨。
  - MFF 队列的所有对比都约为 0。跨刺激（纯音 → bapa）对所有表示都约 0.5，R2 回收结果也一样。
- **外部对照**（同一组 20 s query，读出 (b)）：
  - CS-pair：DTU 0.609、FAU 0.524。
  - 低于 mTRF / VLAAI / Transformer-CLIP，差 0.19–0.22（DTU）和 0.11–0.16（FAU），区间都不含 0。
  - 高于 MindMix 完整系统：DTU +0.078、FAU +0.033，区间不含 0。
  - 与 MindMix EEG 分支的差未分辨。
  - 访问级别不同（是否用了目标注意标签、是否在目标上更新参数），见 EXTERNAL_COMPARISON.md。

## 4. 使用：依赖选择能否改善独立 query？

- **私有 U10**（合并 3 个 seed）：
  - δ-CS 选择 − 固定选择 +0.0002，− 支持集 CV 选择 −0.0004，都未分辨；
  - − 均匀组合 **−0.0025** [−0.0030, −0.0019]；
  - 扩展策略：训练儿童 δ 剖面选择 − 固定选择 +0.0005（未分辨）；PCA64 核版本也没有更好。
- **公共选择器**：依赖选择 ≈ 读出 CV 选择。在 DTU 规则 (b) 上，两者都不如均匀组合。
- **判断**：依赖测量在本轮的表示选择上**没有额外的决策效益**，简单集成最好。按包 02 §8，这属于"剖面存在但 selector 不胜普通读出"：测量的描述价值和决策效益要分开看，不能说成"解释性没用"或"信息不存在"。

## 5. 汇总：四个判断

- **学习**：源训练带来 DTU 注意读出和儿童当前事件上的可迁移改善，中心化优于 raw-CS；但改善不依赖正确配对，也不是 CS 目标特有。
- **测量**：共同 CS 测量能分辨大的表示差异，分辨不了源训练臂之间的小差异；对 σ 和 n 敏感；跨候选比较受候选边际偏置影响，需要外源 / 去偏对照。
- **用途**：DTU 注意读出（去偏后仍成立）和儿童当前事件（相对 B0）有支持；FAU 注意、MFF、跨刺激没有支持。
- **使用**：依赖选择没有胜过普通读出选择或固定选择；均匀组合最好。这一项不能归为 CS 测量或 CS 训练的收益。

## 6. 下一轮最值得确认的一个问题

**问题**：本轮的可迁移改善，是来自"中心化目标对表示的正则作用"，还是来自"与声音的统计依赖"？WRONG 与 CS-pair 相当，提示前者。

**能改变判断的最少证据**：
- 在同一配方、同样 3 个 seed 下，训练一个**不使用任何声音**的中心化对照，例如只用 EEG 核的配对参照项或方差 / 秩保持正则。
- 只看两个终点：DTU 去偏读出注意、私有 G。
- 若它复现了 CS-pair 相对 B0 的提升，则"CS 依赖学习"的主张应收回为"中心化正则"；若做不到，则声音依赖（即使与配对无关）有贡献。

不建议扩展到新骨干、新数据集或更多描述子。

## 测量与数值

- **E0 的 dev 探针**处于强收缩状态：PCA16 方差远小于 ridge 0.1。四个试训都 ≤ B0；LoRA 是在全部低分下按规则选中的。
- **LoRA 有效参数**：CBraMod 每 1 s 只有一个时间 patch，时间注意力的 Q 适配器拿不到梯度。有效 LoRA 参数为 57,600 / 76,800（S17）。
- **同 seed 重放**在 ALN4.1 衍生的训练路径上不是逐位一致：cuDNN 卷积反向的差约 1e-9，dev 探针的差在 1e-6–1e-5 级。
- **设备混用**：特征在 CPU、V100 和带 TF32 的 A100 类 GPU 上导出，差最大 3.1e-5（P23a）。
- **共同测量对 σ 和 n 敏感**：σ×0.5 时方法排名翻转；n ≤ 64 的区间过宽。
- **候选边际偏置**：块内循环移位零分布在 FAU 上没能去除它（外源 EEG 对照 0.49–0.61）。规则 (a) 在 FAU 上没有 EEG 特异的证据。
- **儿童 G 的参照点**：64 维读出在无信号时的样本外代价约 −0.006 bits/试次，G 应对照这个值来读，而不是 0。

## 推断范围

- 训练 seed 只有 3 个。区间以这 3 个 seed 为条件，不代表任意未来 seed 的分布。
- DTU 和 FAU 已在此前多轮中反复使用，不是从未见过的确认集。本轮结果是固定协议下的复评。
- 外部系统的数据访问级别不同：mTRF / VLAAI / Transformer-CLIP / MindMix 完整系统都使用了目标训练人的注意标签。这些差异不能当作纯粹的损失函数效应。
